# Stillness (적막)

〈하프 소드〉에서 영감을 받은 **물리 기반 중세 결투 게임**을 만들어 보는 첫 게임 프로젝트예요.
스마트폰 브라우저에서 바로 플레이할 수 있게 만들고 있어요.

최근: [한손 팔 고정 수정 비교판](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#onehand-comparison) · [검증과 남은 관문](docs/strike/onehand_manual_round1.md). 선택형이며 일반판 승격 전입니다.

- 몸은 관절로 이어진 **액티브 래그돌**이에요. 애니메이션 없이 "근육 힘"으로 서고, 걷고, 버텨요.
- 카메라는 원작처럼 **내 캐릭터 어깨 너머(3인칭)**에서 상대를 바라봐요. 원형 경기장을 자유롭게 돌며 싸워요.
- 칼은 **손가락으로 끌어서** 직접 휘둘러요. 손가락 위치가 곧 **실제 롱소드 자세**예요 (위 = 지붕, 오른쪽 위 = 어깨 지붕, 그 안쪽 = 황소,
  가운데 = 긴 자세, 오른쪽 아래 = 쟁기, 맨 아래 = 바보 …). 자세에서 자세로 빠르게 옮기면 그게 베기예요.
  예: 오른쪽 위 → 왼쪽 아래 = 사선 베기, 위 → 아래 = 내려베기, 오른쪽 → 왼쪽 = 가로베기, 쟁기 → 가운데 = 찌르기.
  빠르게 휘둘러야 세게 들어가요. 칼은 **두 손**으로 잡아요.
- 폰에서는 **왼쪽 아래 조이스틱**으로 걸어요. (설정에서 "기울기" 이동으로 바꿀 수도 있어요.) 몸은 항상 상대를 향해 돌아요.
- **체력 게이지가 없어요.** 칼이 닿은 순간의 에너지로 베기·찌르기·타박을 가려 상처를 내요.
  목이나 머리에 제대로 들어가면 한 방에 끝나고, 얕은 상처는 피를 흘리며 서서히 약해져요.
- 무게중심이 발 밖으로 밀려나면 비틀거리며 발을 딛고, 못 버티면 넘어져요.
- 크게 다치면 **부상**이 몸에 남아요: 절뚝거림, 늘어진 팔, 웅크린 몸, 멍한 비틀거림, 창백한 얼굴.
  넘어지면 무릎을 꿇었다가 일어나고, 다리를 크게 다치면 무릎 꿇은 채로 싸워요.
- 칼이 지나간 자리엔 **옷이 찢어지고**, 피가 옷에 번지고, 투구는 긁히고 찌그러지다 벗겨져 날아가요. 칼날에도 피가 묻어요.

## 조작법

| | 스마트폰 (가로) | PC |
|---|---|---|
| 칼 휘두르기 | 화면을 손가락으로 끌기 | 화면 클릭(마우스 잠금) 후 마우스 이동 |
| 걷기 (전후좌우) | 왼쪽 아래 조이스틱 | W A S D 또는 방향키 |
| 기울기 영점 | ◎ 버튼 | - |
| 일시정지 | Ⅱ 버튼 | P |

설정의 **이동 방식**을 "기울기"로 바꾸면 폰 윗부분을 앞/뒤로 기울여 전진·후퇴, 운전대처럼 돌려 옆걸음해요.
이때 ◎ 버튼을 누르면 **지금 폰을 든 각도**가 "가만히 서 있기"의 기준이 돼요.

## 실행하기

Node.js 20 이상이 필요해요.

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소를 브라우저로 열기
npm run build    # 배포용 파일을 dist/ 에 만들기
```

`npm run dev` 를 하면 `Network:` 주소도 나와요. 같은 와이파이에 있는 폰에서 그 주소를 열면 폰으로도 볼 수 있어요.
다만 **기울기 센서는 https 주소에서만** 동작해서, 이 방법으로는 조이스틱으로 움직이게 돼요.
기울기까지 폰으로 제대로 테스트하려면 아래 GitHub Pages 배포를 쓰세요.

### 폰에서 플레이하기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿔요 (처음 한 번만).
2. `main` 브랜치에 코드가 올라가면 자동으로 배포돼요 (`.github/workflows/deploy.yml`).
3. `https://<아이디>.github.io/halfsword/` 를 폰에서 열어요.

### 핵심 원리 (fighter.js)

1. **몸 (해부학)**: 골반·배·가슴·머리, 위팔·아래팔, 허벅지·정강이·발 15조각. 길이와 무게는 생체역학 표준표(Winter)의
   체중 75kg 성인 비율을 따랐어요 (가슴 16kg, 허벅지 7.5kg, 머리 6kg …).
   무릎·팔꿈치·발목은 한 방향으로만 굽는 **경첩 관절**, 허리·목·어깨·엉덩이는 구형 관절이고,
   모든 관절에 사람이 실제로 굽힐 수 있는 **가동 범위**를 걸었어요 (무릎은 뒤로 안 꺾임).
2. **근육**: 각 관절에 물리 엔진의 **관절 모터**를 달아 목표 자세로 돌아가게 해요.
   관절마다 **낼 수 있는 최대 힘(N·m)** 이 있어서 (무릎 250, 엉덩이 280, 어깨 110, 목 40 …)
   무거운 칼이나 충격은 근육이 다 버티지 못하고 밀려요. 다친 부위는 그만큼 힘이 빠져요.
   (표의 숫자는 엔진 모터가 실제로 내는 값이에요. 예전엔 엔진이 각도를 절반으로 잰다고 잘못 알고 2배를 곱했는데,
   진동 실험으로 확인해 보니 온각도로 재서 표를 실제 값으로 고쳤어요.)
   **출렁임 잡기**: 팔·칼의 무게를 어깨·팔꿈치·손목 근육이 미리 버티는 **중력 보상**을 넣었고, 감쇠는 "멈춤"이 아니라
   "목표가 움직이는 속도"를 향하게 해서 휘두르는 속도를 잃지 않고 흔들림만 줄였어요. 손 목표는 딱 멈추는 2차 필터로
   걸러서(휘두를 땐 더 빠르게) 목표가 순간이동해도 몸통이 출렁이지 않아요. 가벼운 배(허리)에는 회전 관성을 더해
   엔진의 반복 계산이 허리 근육 힘을 제대로 전달하게 했어요.
   처음엔 회전력을 직접 계산했는데, 가느다란 팔다리를 길이 방향으로 비트는 축은 관성이 아주 작아서
   1/120초 계산이 매번 목표를 지나쳐 다리가 프로펠러처럼 돌았어요. 관절 모터는 엔진이 충돌·관절과
   함께 한꺼번에 풀기 때문에 아무리 세게 해도 떨리지 않아요.
3. **균형**: 다리 근육이 "골반은 위로" 밀어 몸을 받쳐요. **딛고 있는 발이 있을 때만** 받칠 수 있어서, 두 발이 뜨면 주저앉아요.
   몸을 세우는 힘은 출렁이지 않도록 감쇠비 ≈ 1(딱 멈추는 값)로 맞췄고, 가속할 때는 그만큼 앞으로 숙여요.
   앞으로 미는 힘은 골반과 상체에 무게 비율대로 나눠 줘요(골반만 밀면 상체가 뒤로 젖혀져 마리오네트처럼 보여요).
4. **걷기**: 다리 흔드는 속도를 **실제로 이동한 거리**에 묶었어요. 한 주기의 60%는 발을 딛고(몸이 가는 만큼 발이 뒤로),
   40%는 무릎을 들어 앞으로 가져와요. 다리는 실제 이동 방향(앞/뒤/옆/대각선)으로 흔들고, 딛는 다리가 기울어진 만큼
   골반을 낮춰 발이 땅에 닿게 해요.
   너무 기울거나 균형 게이지가 바닥나면 근육 힘을 빼서 래그돌로 쓰러뜨려요.
5. **칼과 팔 (IK)**: 칼은 아래팔 끝 손목에 관절로 붙어 있어요. 손 목표는 가슴 앞 평면의 (좌우, 위아래) 점이고,
   가운데로 모을수록 팔을 앞으로 뻗어요. 예전처럼 손을 줄로 끌어당기지 않고, **역운동학(IK)** 으로
   "손이 거기 가려면 어깨와 팔꿈치가 몇 도여야 하나"를 풀어서 **어깨·팔꿈치 근육**이 그 각도로 당겨요.
   그래서 칼 무게는 팔 근육이 버티고, 반작용은 어깨를 통해 몸통으로 자연스럽게 전해져요.
   손목 힘은 칼끝 방향과 칼날 각도만 맞춰요.
   **손 위치 = 검술 자세**: 가슴 높이 가운데면 칼끝이 상대를 겨누고, 머리 위로 올리면 칼이 서서 살짝 뒤로 눕고(지붕 자세),
   옆으로 빼면 그쪽으로 눕고, 허리 아래면 칼끝이 내려가요. 자세에서 자세로 옮기면 칼이 100° 넘게 돌며 베기가 돼요.
6. **검술 층 (skill.js, guards.js)**: 캐릭터가 이미 검술을 익혔다고 보고, 몸놀림을 덧붙여요.
   바꾸는 건 **목표**뿐이고 실제 움직임은 근육·물리가 만들어요 (맞으면 흐트러지고, 칼은 여전히 무거워요).
   - **검술 자세 지도**: 손가락 위치를 리히테나워 전통 롱소드 자세(지붕 Vom Tag, 황소 Ochs, 쟁기 Pflug, 바보 Alber,
     긴 자세 Langort, 옆 지킴 Nebenhut, 바꿈 Wechsel, 좌우 거울 자세)로 바꿔요. 자세마다 손 위치(앞뒤 깊이 포함),
     칼끝 방향, 골반·가슴을 트는 각도, 숙이기가 정해져 있고, 사이에서는 가까운 자세끼리 부드럽게 섞여요.
     그래서 지붕 → 긴 자세 → 바보로 옮기면 교본(마이어)대로의 내려베기가, 오른쪽 위 → 왼쪽 아래는 분노의 베기가 돼요.
   - **힘의 순서**: 몸(골반·가슴)은 손가락 입력을 곧바로, 손은 부드럽게 걸러서 따라가요. 그래서 베기를 시작하면
     골반 → 가슴 → 팔 → 칼 순서로 움직여요 (실제 베기의 순서. 예전엔 손이 먼저 가고 몸통이 끌려가서 흐물거렸어요).
   - **두 손 잡기**: 빈손이 칼자루 끝을 잡아요(빈팔 역운동학 + 부드러운 스프링). 빈팔을 다치거나 쓰러지면 놓아요.
   - 이어 베기: 폰 화면에서 짧게 그어도 칼이 그 방향으로 끝까지 지나가요.
   - 내딛기: 한 걸음 거리(1.3~2.4m)에서 새로 휘두르면 앞발을 내딛어요.
   - 메뉴의 **검술 보정**(끔/약/보통/강)으로 세기를 고를 수 있어요. "끔"이면 자세 지도 없이 날것의 매핑을 써요.
     AI는 난이도마다 숙련도가 달라요. AI 공격도 실제 기술(분노의 베기, 내려베기, 가로베기, 올려베기, 찌르기)이에요.
   - 화면 위쪽에 지금 자세 이름이 잠깐 떠요.
   - **자세로 돌아가기**: 베고 나서 손가락을 떼면 칼이 교본의 기본 자세(쟁기)로 돌아가요. 손가락을 누른 채 있으면 그 자세를 유지해요.
     (돌아갈 자세 `SKILL.homeGuard`, 기다리는 시간 `SKILL.recoverDelay`)
7. **엉겨 붙지 않기**: 옷·살끼리는 잘 미끄러지고(마찰 0.25), 발은 상대 발·다리와 부딪히지 않아요(서로 발을 밟고 끌려가던 문제).
   바짝 붙은 채 뒤로 물러나면 빈손으로 상대 가슴을 **밀쳐내요** (같은 힘이 나에게도 반대로 걸리는 작용·반작용).
   붙어 있을 땐 손을 상대 몸 속으로 뻗지 않고 팔을 접어요. AI는 경계에 몰리면 가운데 쪽으로 옆걸음 쳐요.
8. **칼의 무게감 (묵직한 칼)**: 칼이 스티로폼처럼 느껴지던 원인은 칼이 가벼워서가 아니라, 손목이 사람의 3~5배 힘(60N·m)으로
   칼을 곧바로 돌렸기 때문이었어요. 그래서
   - **실제 롱소드의 질량 분포**: 1.6kg, 무게중심은 코등이에서 약 11cm, 손 기준 회전 관성 0.27kg·m²
     (Albion Liechtenauer 1.58kg·무게중심 9.8cm, Le Chevalier가 측정한 Albion Crécy의 회전 관성을 참고).
   - **사람 수준의 근력**: 두 손목 22N·m (손목 굽힘 힘 한 손 약 12N·m, Delp 1996), 어깨·팔꿈치 80N·m.
   - **힘-속도 관계(Hill)**: 빨리 움직일수록 근육이 낼 수 있는 힘이 줄어요. 휘두를수록 칼이 "도망가는" 느낌이 여기서 나와요.
   - **놓아주기**: 칼이 목표를 향해 날아가는 동안엔 손목이 붙잡지 않아서 관성으로 가속하고, 멈출 수 있는 거리 안에서 제동해요.
     그래서 베기의 가장 빠른 순간이 호의 끝쪽(치는 순간)에 오고, 목표를 조금 지나쳐 이어 베어요.
   - **두 손 지렛대**: 빈손이 칼자루를 "있어야 할 곳"으로 밀고 당겨 칼을 돌려요 (자세를 잡으면 칼끝이 흔들리지 않는 이유).
   - **베고 지나가기**: 칼이 몸에 닿으면 한 순간에 멈추지 않고, 몸 속을 지나는 동안 매 순간 저항(끌림)을 받아 흡수된 만큼 느려져요.
     충돌 예측은 부드러운 방식(soft CCD)이라 이 판정을 거쳐요 (예전 딱딱한 방식은 칼을 한 순간에 멈춰 세웠어요).
   - **맞은 점의 실제 유효 질량**: 강체 역학으로 계산해요 (칼끝 쪽은 0.3kg 안팎). 판정용 에너지는 실제 에너지 × 2 (`STRIKE.energyScale`)로
     예전 치명성에 맞췄어요.
   - **연출**: 칼마다 계속 도는 바람 소리가 칼끝 속도를 따라 커지고 높아져요. 멈칫은 재질에 따라(깨끗이 가르면 짧게, 박히거나 뼈·투구면 길게,
     최대 0.1초). 칼의 타격 중심(코등이에서 약 58cm)에 맞으면 손이 울리지 않고, 칼끝·밑동에 맞으면 진동·화면 흔들림이 커져요.
9. **타격 (combat.js)**: 칼이 몸에 닿는 순간을 분석해요.
   - 닿은 점에서 칼과 몸의 **속도 차이**를 구하고, 운동 에너지 = ½ × 유효질량 × 속도² (J)를 계산해요.
   - **날이 앞장서면 베기**, 칼끝으로 곧게 들어가면 **찌르기**, 칼 면이나 손잡이면 **타박**이에요.
   - 부위마다 "살을 가르기 시작하는 에너지"와 "완전히 통과하는 에너지"가 달라요 (`ANATOMY`). 투구는 머리 윗부분을 막아줘요.
   - 에너지가 충분하면 물리 엔진의 **충돌 훅**으로 튕겨내는 힘을 끄고, 칼이 **살을 가르며 지나가게** 해요.
     몸이 흡수한 에너지만큼 칼이 느려지고, 그 운동량이 몸에 전달돼요. 모자라면 칼이 박히거나 튕겨요.
   - **반작용**: 칼끼리 부딪히면 강철 재질(반발 계수 약 0.25, 마찰 0.4)로 물리 엔진이 튕겨 내요. 두 칼이 주고받은 충격량은
     같은 크기·반대 방향이고, 손목 관절을 타고 팔 → 가슴으로 전해져요. 맞댄 채 누르는 동안(바인드)엔 튕기지 않아서 떨리지 않고,
     상대 칼이 내 칼을 미는 힘은 `fighter.feel`(검술의 "느끼기")에 담겨요. 투구·머리·뼈를 쳤는데 날이 들지 못하면
     칼이 되튀어요 (반발 계수 식으로 모자란 충격량을 계산해 칼과 맞은 곳에 반대 방향으로 줘요).
     코등이 끝에 걸려 튕길 때 칼이 손 안에서 팽이처럼 돌며 날이 휙 뒤집히지 않도록, 그 축 회전은 손아귀가 잡아 줘요 (`STEEL.gripTwistMax`).
10. **몸 상태**: 피(양·출혈), 의식, 통증, 팔다리 기능을 따로 계산해요 (`VITALS`).
   목 베임·머리 치명상은 즉사, 피가 45% 아래면 쓰러지고, 머리를 세게 맞으면 기절, 칼 든 팔을 크게 다치면 칼을 놓쳐요.
11. **균형 (fighter.js `updateFooting`)**: 무게중심과 그 속도로 "캡처 포인트"(멈추려면 발을 디뎌야 할 곳)를 구해요.
   그 점이 발 밖으로 나가면 자동으로 그쪽으로 발을 딛고, 너무 멀면 몸을 세우는 힘이 빠지면서 실제로 넘어져요.
12. **타격감**: 에너지에 비례한 멈칫, 재질별 소리(베기/찌르기/타박/뼈/쇳소리), 휘두르는 바람 소리, 결정타 슬로모션.
   카메라는 "스프링에 매단 카메라"라서 충격 방향으로 밀렸다가 부드럽게 돌아오고, 발을 디딜 때 살짝 내려앉아요.
   - **소리 (sound.js)**: 예전 쇳소리는 사인파 3개라 실로폰처럼 가볍게 "딩" 했어요. 지금은 **모드 합성**이에요.
      - 롱소드 칼날(1m 쇠막대)은 굽힘 진동이 200Hz~9kHz에 수십 개 촘촘히 있어요 (막대 공식 f₁≈22Hz × (βₙ/β₁)², 칼날이 가늘어지며 3~4% 어긋남).
        날 방향 굽힘(7.5배 높음)·비틀림·코등이 진동까지 두 자루 몫을 한꺼번에 울리고, 비슷한 모드끼리 맥놀이("우웅~")가 생겨요.
      - 두 손이 쥐고 있어서 낮은 진동은 금방 죽고(무거운 "텅"), 1~5kHz 울림만 길게 남아요. 부딪히는 "딱", 두 팔이 받는 "쿵",
        살짝 찌그러뜨린 거친 맛을 더해요.
      - **세기에 따라**: 세게 칠수록(맞닿는 속도) 크고 밝아지고, 센 층("쨍그렁")이 나와요. 약하면 둔탁한 "텅". 칠 때마다 조각·높낮이가 달라요.
      - **스침과 바인드**: 칼날을 따라 미끄러지면 "스르릉", 칼을 맞댄 채 밀며 미끄러지면 계속 "지이익" 긁는 소리가 나요
        (combat.js가 부딪히는 속도와 미끄러지는 속도를 나눠 줘요). 예전엔 맞댄 동안 0.09초마다 "딩"이 반복됐어요.
      - 살: 누비옷이 찢기는 "지직" + 젖은 소리(작은 방울 수십 개) + 몸통 "퍽". 투구는 둔탁한 "깡", 뼈는 여러 번 겹치는 "우득".
      - 돌기둥에 되울리는 가벼운 **경기장 울림**, 소리가 겹쳐도 깨지지 않게 누르는 리미터, 동시에 12개까지만 울려요.
      - 소리 조각은 시작 버튼을 누른 뒤 일꾼 스레드에서 만들어요. 들어보기: 메뉴의 **소리 들어보기** (예전 소리와 비교할 수 있어요).
13. **흔적(데칼)**: 상처·찢김·번지는 핏자국·멍·투구 긁힘을 몸 표면에 투사해서 붙여요 (`effects.js`의 `stickDecal`).
    옷이 찢어진 곳, 찌그러진 투구는 다음 타격을 덜 막아줘요.
14. **진동**: 안드로이드는 표준 진동. 아이폰 사파리는 손가락을 누르거나 뗀 순간에만 진동을 허락해서,
    맞히면 예약해 두었다가 **손가락을 뗄 때** 울려요 (실험). 제대로 된 진동은 앱으로 감싸야 가능해요.

### 튜닝 팁

`src/config.js` 의 숫자를 바꾸고 저장하면 개발 서버가 바로 새로고침해 줘요.

- 너무 쉽게 죽는다 / 안 죽는다 → `ANATOMY`의 `cut`, `stab` 값 (클수록 질김)
- 칼이 너무 가볍다/무겁다 → `WEAPON.mass`, 손목 힘 `WEAPON.maxAimTorque` (작을수록 칼의 관성이 더 느껴짐)
- 휘두르는 게 너무 느리다 → `WEAPON.maxAimTorque`, `WEAPON.wristVmax` ↑, 팔 근육 힘은 `fighter.js`의 `jointDefs`(k, max)
- 너무 쉽게 죽는다/안 죽는다 → `STRIKE.energyScale` (판정용 에너지 배율)
- 칼끼리 튕기는 정도 → `STEEL.restitution` (칼끼리 = 이 값², 실제로는 그 절반쯤), 투구·판금·머리·뼈에서 되튀는 정도 → `STEEL.steel`(투구·판금), `bone`(두개골·팔다리 뼈)
- (실험) 휘두르는 반작용·충격을 골반·몸통까지 → `RECOIL.anchorRelax = true`
- 너무 잘 넘어진다 → `BALANCE.fallRange` ↑, `VITALS.staggerPerJoule` ↓
- 상대가 너무 세다/약하다 → `AI_LEVELS`
- 폰 조작 감도 → `INPUT.touchSensitivity`, `INPUT.tiltFullDeg`
- 걸음 보폭 / 걷는 속도 / 몸 돌리는 속도 → `BODY.stepLength`, `BODY.moveSpeed`, `BODY.turnSpeed`
- 손이 목표를 따라가는 빠르기 → `SKILL.aimFilter`, `SKILL.aimFilterStrike` (크면 날렵하지만 몸이 출렁인다)
- 칼끝이 흔들리는 정도 → `WEAPON.aimStiffness`, `WEAPON.aimDamping`
- 몸이 휘청이는 정도 → `BODY.uprightStiffness`, `BODY.uprightDamping` (감쇠를 줄이면 출렁인다)
- 검술 보정 세기(이어 베기·손 따라가기·내딛기) → `SKILL`, 몸이 자세를 따라가는 빠르기 → `SKILL_BODY`
- 자세의 손 위치·칼끝 방향·몸 틀기 → `src/guards.js`, 두 손 잡기 → `GRIP`
- 붙었을 때 밀쳐내는 힘 → `BODY.shoveForce`
- 시작 간격 → `ARENA.startGap`, 경기장 크기 → `ARENA.radius`
- 카메라 거리/높이/어깨 위치 → `CAMERA`
- 옷 색, 투구 바꾸기 → `src/looks.js`
- 전체 음량, 경기장 울림, 녹음 소리 섞기 → `SOUND` (소리마다 세기·밝기는 `src/sound.js`의 `clash`, `cut` … 함수)

브라우저 개발자 도구 콘솔에서 `game.config.WEAPON.mass = 3` 처럼 실행 중에 바꿔볼 수도 있어요.

### 무기 바꿔보기 (src/weapons.js)

기본은 롱소드지만, 실제 자료(가능한 곳은 박물관·제작사 실측, 부족한 곳은 물리적 추정)로 채운 무기고가
`src/weapons.js`에 있어요: 츠바이핸더·에스톡·세이버·레이피어·팔쉬온 같은 실제 무기부터, 청강검(랴오)·모노호시자오(코지로의
노다치)·엑스칼리버·라이트세이버·나뭇가지·고무 닭·냉동 참치 같은 이름 있는 무기까지. 등급(쓰레기/커먼/레어/에픽/레전드)이 있고
등급이 낮을수록 잘 부러져요.

URL 파라미터로 골라서 테스트할 수 있어요: `?weapon=monohoshizao&foeWeapon=chicken` (내 무기/상대 무기, 무기
id는 `WEAPONS` 객체의 키. `branch`·`chicken`·`tuna`·`katana`·`jian`·`replica` 같은 짧은 별칭·옛 이름도 된다).
`foeWeapon`을 생략하면 `weapon`과 같은 것, 둘 다 없으면 고른 캐릭터의 무기를 든다. `weapon`을 적으면 무기 카드 뽑기를
건너뛴다. 뽑기에서는 왼쪽 두 장이 내 카드, 맨 오른쪽 회색 칸이 상대 무기(내가 고른 뒤 뒤집힌다)이고, `?cards=rapier,lightsaber`로
내 카드 두 장을 정해 볼 수 있다(카드 뒷면은 main.js `CARD_BACK_DEFAULT`, 그림 파일 뒷면이 생기면 `?back=<id>`로 미리 본다). 헤드리스 시뮬 쪽은
`tools/sim/weapon_smoke.mjs`(안정성 훑기), `tools/sim/weapon_balance.mjs`(승률 재기),
`tools/sim/weapon_measure.mjs`(유파용 간격 실측) 참고.

### 상대 AI (ai.js)
좀비처럼 달려들지 않고 검객처럼 싸워요.
- **간격 재기**: 상대의 칼이 닿지 않는 거리(가슴과 가슴 사이 약 2.1~2.6m)에서 조금씩 들락날락하고 옆으로 돌며
  1~3초마다 자세를 바꿔요(지붕, 황소, 쟁기, 긴 자세, 바보, 바꿈). 공격할 때가 아니면 앞으로 걸어오지 않아요.
- **빈틈 노리기**: 상대가 헛치고 아직 자세를 못 잡았을 때, 간격 안으로 들어왔을 때, 비틀거리거나 다쳤을 때 들어와요.
  기다리다 지치면(7~12초) 먼저 칼을 뽑아요. 상대 자세가 가리지 못하는 곳(위 자세면 아래, 아래 자세면 머리)을 노려요.
- **막고 받아치기**: 반응 시간(난이도에 따라 0.17~0.38초)만큼 늦게 보고, 물러서거나 막거나(보통·어려움은) 상대 공격 속으로
  마주 베어 들어가요(Indes). 막은 뒤엔 상대가 자세를 되찾기 전에 되받아쳐요.
- **속임수와 성격**: 보통·어려움은 가끔 속임수 베기를 써요. 판마다 좋아하는 거리·자세·기술·리듬이 조금씩 달라요.
- 약점: 쉬지 않고 돌진하며 휘두르는 상대에게는 아직 약해요 (로드맵 참고).
