# 최신 규칙: 공통 액자·고정 격자 low (2026-10-18)

사용자 선택에 따라 **코드 편집·합성**을 사용한다. 1254 정사각 캔버스에 인물 22×22셀(각50px, 시작77,77), 공통 액자1을 같은 위치에 합성한다. 플레이어1·아르토리아도 예외 없이 검사한다. 얼굴 크기·상반신 크롭·노출된 눈의 존재를 필수 검수하며, 설정상 가려진 눈은 유지한다. 기본 병마용은 토우의 눈 홈으로 표현한다. 원본과 low를 함께 보존하고 기존4배low는 되살리지 않는다.

구체 기준과 재현 소스: [엄격 검수 기록](pixel_profiles_strict_20261018/README.md). 아래 ‘격자 보장 없음’·imagegen 전용 제작 문구는 이전 시안의 이력이다. 최신 사용자 승인 코드 편집과 이 절을 우선한다.

# Stillness 프로필 제작 기준

2026-10-17 사용자 확정. 이전4배low 규칙과 얼터원본only 규칙을 대체한다.

- 캐릭터마다 정사각 고화질 `original.png`와128표현의 `low.png`를 함께 보존한다. 신규/수정 캐릭터에도 두 파일을 함께 갱신한다.
- low의 화풍 기준은 승인된 플레이어1과 기본 아르토리아128시안. 매우 큰 픽셀 덩어리로 실루엣·색·식별 특징을 재구성한다. 단순 모자이크/축소필터를 쓰지 않는다. 배율128은 표현 목표이며 정확한 정수 격자를 보장하지 않는다.
- 인물 방향/얼굴 비중/복식은 해당 고화질 원본 기준. 얼터는 최신v2를 사용한다. 기본 병마용은 토우, 얼터 병마용은 창백한 사람이다.
- 액자1의 금선과 네 모서리 장식은 선명하게 남긴다. low의 인물 뒤 빈 공간과 액자 바깥 바탕은 실제 PNG alpha로 투명하게 한다. 그림 속 체크무늬/검은색을 투명으로 오인하지 않는다. 흰머리·흰옷·하이라이트는 남긴다.
- 고화질 원본은 배경을 포함한 제작 원본으로 보존하고, 게임 표시용low가 투명 PNG다. 생성 모델이 미세한 알파/가장자리 변형을 남길 수 있으므로 실제 어두운 배경·다른 색 배경에서 확인한다.
- 플레이어1은 정면/낮은 케틀햇/눈가림. 플레이어2는 최초 시트 맨 왼쪽의 오른쪽3/4 각도. 각자 원본과low를 저장하며 서로 덮어쓰지 않는다.
- 현재 대상은 기본NPC16명+플레이어2종+얼터16명, 총34개. 앞으로 인원이 달라지면 현행 목록으로 계산한다.
- 이전4배low PNG는 현재자산과 공개본에서 삭제한다. 옛커밋/실험보고의 과거기록을 현재규칙으로 복원하지 않는다. 폐기된4배생성 도구는 다시low를 만들지 않도록 중단한다.
- 이미지 편집/재구성은 imagegen을 사용한다. 프롬프트·참고 원본·모든 시도·선택본·SHA256을 보존한다. 파일명만으로128완성이나투명도검증을 주장하지 않는다.

현재 갤러리/자산: `public/encounters/pixel-profiles-low128-20261017/`. 기존 기본/v2 고화질원본은 출처로 유지한다. 게임 UI에 연결할 때 투명PNG 자체를 사용하고 이미지 뒤에 불투명 카드 배경을 깔지 않는다. 실제 게임 연결과 독립 검토 페이지는 보고에서 구별한다.
