# 베르나르도 프로필 — 복식 부분 수정

사용자 “해” 승인으로 MSG-S-014의 흰 겉옷/금관 검은 사자·금빛 망토 요청을 구현했다. 받는 쪽 메시지 기준a2a5f135, 기존 승인 초상은 올리비에/black_king과 동일하다. 새 그림은 `public/encounters/bernardo-profile-20261024/`의 별도 검토안이다. 기존 승인37초상 갤러리와 게임 UI는 덮어쓰지 않았다. 새 결과의 사용자 미감 검토/우화 전달 전이다.

## 제작

고화질 원본을 imagegen으로 부분 수정한 생성 원본 `master/generated-costume.png`를 보존. 결과에서 옷 두 영역만 마스크로 합성하고 나머지는 기존 승인 원본 바이트를 유지했다. 공통 액자·배경 alpha·머리/얼굴/눈·목/수염·어깨 철갑/브로치 보존. 망토와 머리 경계에서 이전 옷 색이 남는 부분을 확인해 기존 황토색 천 픽셀만 좁혀 보완했다. 검토 중 첫 마스크는 원본 alpha253을 불투명으로 인식하지 못해 적용되지 않았고, 실제 변경 픽셀 수 검사를 추가해 고쳤다.

최종 원본을 기준으로 low의 복식 색면을 고정22×22 격자에 다시 배치했다. 단순 모자이크 대신 옷 주름·금빛 면·검은 사자의 머리/앞발/꼬리를 셀 단위로 정리. 원래 얼굴/머리/눈/어깨/크롭은 그대로, 옷82셀만 수정. 사자의 세부 해부/왕관 장식은 이 격자에서는 추상적인 실루엣으로 단순화된다. 더 작은 보조 픽셀을 섞어 넣지 않았다.

## 최종 자산 / 검증

- 원본/low/grid 1254² RGBA. 공통 액자1 같은 파일·좌표.
- low22×22·셀50px·원점77,77·배경투명. alpha/인물 실루엣 동일.
- 얼굴핵심 폭8셀/턱14행/상반신크롭 동일. 눈끝(13,7)/(16,8)은 #4F3829 그대로.
- 고화질 머리 보호영역·마스크 밖 픽셀 동일. low 보호영역/양눈 동일. frame/각 셀 단색/PNG 복원 검증.
- 셀 정본 `sprite.json`, 변경 기록 `cell-edits.json`, 마스크/생성 원본 보존. 기존 갤러리/다른36인물 자산은 변경하지 않음.
- 실제 게임 모델이나 전투를 바꾸지 않아 물리 대련 검사는 반복하지 않는다. 브라우저 검수와 공개 전달 결과는 `browser.json`/`publication.json`.

재현: `python3 tools/content/build_bernardo_costume_20261024.py` (이미 생성한 원본+마스크+셀 편집, 추가 이미지 생성 호출 없음). 기존 승인본을 수정하지 않는 별도 출력. 공개 ZIP은 original/low/grid/frame1/sprite/편집기록/manifest 포함.
