# 올리비에 별도 눈매 시안

사용자가 아래 점을 제거하는 작업 도중 “아예 눈 다른 방식으로도” 요청했다. 점 제거본(v4)은 그대로 보관하고, 별도 경로에 눈썹과 눈을 분리한 시안을 만들었다.

- 위쪽은 갈색 눈썹, 아래쪽은 작고 어두운 눈동자와 갈색 눈꺼풀. 눈썹과 눈 사이에 피부색 행을 남겨 연결된 T자 덩어리를 피했다. 밝은 흰자위는 없다.
- 얼굴의 방향·크기·턱·크롭, 공통 액자1·1254정사각·22×22/50px 격자·투명 배경 유지. 고화질 원본은 같은 기준 파일을 복사 보존. 기존 갤러리37개와 v4를 변경하지 않는다.
- `sprite.json`과 `changes.json`에 픽셀 원본과 개별 변경을 보관. `validation.json`은 고정격자·액자·alpha·출력 해시 확인. `tools/content/build_olivier_eye_alternative_20261023.py`로 재현.

새 시안의 사용자 선택은 미정이다. 새 우화 메시지/게임 연결 없음. 배포 완료는 `publication.json`.
