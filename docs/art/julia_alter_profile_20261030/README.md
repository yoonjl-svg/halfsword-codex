# 광기의 쥘리아 크리스테바 · 프로필

사용자 요청에 따라 현재 native 모델 f51d7820의 외형을 고화질 초상으로 옮기고, 승인된 공통 격자 방식의 128 low를 제작했다. 기본 쥘리아와 반대인 화면 왼쪽 3/4 방향. 갈색 머리·땋기·얼굴 정체성을 유지하고, 회백 머릿수건/먹남 조끼·작은 붉은 눈·화면 왼쪽 얼굴 금속과 오른쪽 기계 상체를 표현했다. 서사·별칭 추가0. 이탈리아 숙련4는 기존 설정이며 이번에 전투 코드를 바꾸지 않았다.

## 보존 파일과 검수

- original.png / low.png / grid.png: 액자1의 1254×1254 RGBA 정사각형. 배경 실제 alpha 투명.
- masters/selected.png: 고화질 생성 원본. attempt-01.png는 얼굴 금속이 반대편에 생긴 첫 결과로 보존하며 채택하지 않았다. 생성 도구로 해당 위치를 수정한 뒤 공통 액자를 코드 합성했다.
- low는 22×22셀, 셀50px, 원점77·77. 128은 화풍 이름이며 실제 128px 격자라는 뜻이 아니다. 액자는 원래 해상도 그대로다.
- draft-sprites.json에서 눈·금속 안면·입·머릿결/땋기·목/가슴/관절을 119회 셀 편집해 sprites.json에 보존했다. 단순 축소 결과를 최종으로 채택하지 않았다.
- 두 눈 (6,9)/(10,8), 얼굴 핵심 폭6셀, 턱13행, 눈~턱4/5셀. 머리 장식/귀를 얼굴 핵심에 넣지 않았다. 어깨·윗가슴 크롭이며 손/허리는 넣지 않았다. 좌표는 수동 시각 기준이다.
- 공통 액자 SHA8d6ec8d1, 모든 low 셀 단색·정확50px·alpha0/255, 원본/low/grid 동일 불투명 액자픽셀, 기본 b-05 세 파일 해시 불변 검증(qa.json).

기술 검사와 사용자 미감 승인은 다르다. 공개 검토 페이지에서 원본/low·격자·기본과의 비교를 제공한다. 일반 게임 프로필 UI 연결과 우화 전달은 이번에 수행하지 않았다. 게임 화면 캡처가 아닌 프로필 그림이다.

## 재현과 공개

Python Pillow/NumPy: refine.py는 최초 격자 초안에 셀 편집을 재적용, build.py는 고화질 원본과 확정 셀/공통 액자를 합성, verify.py는 최종 PNG를 다시 읽어 검증한다. browser.mjs는 모바일/PC 이미지·격자 전환·비교 펼침·다운로드·투명도·오류를 검사한다. 생성 지시는 generation-prompts.json. 최종 공개 결과는 publication.json에 기록한다.

브라우저 alpha 검사 첫 지점(90,90)은 공통 액자 모서리 장식 위여서255로 실패했다. 인물·액자가 없는 상단 안쪽 여백(627,127)으로 검사 위치를 바로잡았다. 자산을 투명하게 지워 통과시킨 것이 아니다.

공개 브라우저 검증에서 별도 Node HTTP 클라이언트의 ZIP 조회가 직접 IPv6 경로 ENETUNREACH로 실패했다. 다운로드 검사를 실제 브라우저의 동일 출처 fetch로 옮겼다. 원격 ZIP 자체는 별도 환경 프록시 경유 해시 검증에서 이미 일치했다.
