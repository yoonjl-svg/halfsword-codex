# 얼터 인물 프로필 — 액자 1 고화질 원본

2026-10-17 사용자 요청에 따라 현재 등록된 얼터 NPC 16명의 프로필 원본을 제작했다. 플레이어 얼터는 현재 캐릭터 레지스트리에 정의되어 있지 않아 포함하지 않았다. 기본 인물 17명의 원본과 로우, 다른 액자 선택지는 변경하지 않았다.

완성 자산은 `public/encounters/pixel-profiles-alter-frame1-20261017/{id}/original.png`에 있다. 모든 파일은 **1254×1254 정사각형 PNG**이며, 전체 크기는 34,297,311바이트다. `profiles.json`의 `quality`는 `original-only`, `complete`는 `true`다. 로우 파일은 생성하지 않았다. 이 문서 작성 시점에서 원격 발행·게임 UI 연결은 수행하지 않았으며, 검토 갤러리는 부모 담당이다.

## 제작 방법과 원본 보존

1. 승인된 기본 인물 원본을 얼굴·나이·화풍·액자 1의 기준으로 사용했다. 최신 게임 소스의 실제 얼터 렌더를 복식·머리·소품의 기준으로 함께 입력했다.
2. `image_gen.imagegen`으로 **인물 한 명과 완전한 액자 1이 포함된 정사각형 이미지 전체**를 직접 생성했다. 시트에서 잘라낸 파일이 아니다. 액자를 CSS로 덧씌우거나 외부 래스터 편집으로 합성하지 않았다.
3. 생성 결과를 직접 확인한 뒤 PNG를 바이트 그대로 작업 원본 및 public 경로에 복사했다. 크롭·리사이즈·색보정·픽셀 확대·다운샘플링은 하지 않았다. 생성 화풍 자체의 세밀한 도트 질감은 그대로 보존했다.
4. 마야의 첫 생성은 문서 주머니가 가슴에 위치해 채택하지 않았다. `image_gen`으로 구도를 넓히고 주머니를 승인된 허리 옆으로 옮겼다. 첫 생성 원본도 삭제하지 않았으며 `generation-attempts.json`에 기록했다.

생성 도구의 최초 파일은 `/workspace/generated_images/`에 모두 보존했다. 채택된 작업 원본은 `/workspace/portrait-alter-originals-frame1-20261017/{id}.png`다. `completed-records.json`은 각 파일의 생성 경로, 실제 입력 파일, 실제 최종 프롬프트, SHA-256, 바이트 수, 크기를 기록한다. `generation-jobs.json`은 채택된 결과에 대응하는 요청이며, `samira-correction-job.json`은 마야 교정의 이유와 입력을 따로 보존한다.

액자 1은 얇은 금빛 이중 직선과 작은 네모 모서리 장식, 좁은 암갈색 바깥 여백, 아이보리 안쪽 배경이다. 기본 초상에 포함된 승인 액자를 참조했다. 액자의 네 모서리와 캔버스는 모두 남겼다. 일부 머리나 왕관은 기존 초상처럼 액자의 안쪽 선과 겹칠 수 있으나 캔버스 밖으로 잘린 부분은 없다.

실제 렌더 소스는 `/workspace/halfsword-icon-handoff`, 촬영 당시 HEAD는 `c8ca9c340527de0d60e88d4117f555f248d45d7e`다. 최신 수신 기반은 `e92b5a6f`다. 이전 `15e18adf` 기준의 night checkout과 `looks*`, `outfit*`, `characters*`, `mad_eyes*` 외형 파일 30개를 대조해 모두 바이트가 같음을 확인했다. 파일별 해시는 `provenance.json`에 있다.

`references/*-bust.png`는 게임의 production `Fighter`와 외형 레지스트리를 중립 조명에서 촬영한 **외형 검토 렌더**다. 공통 카메라를 상반신 위치로 옮긴 뒤 캔버스를 직접 캡처했으며, 완성 이미지를 잘라 확대하지 않았다. 게임의 실제 전투 조명·전투 자세를 주장하는 스크린샷은 아니다. 물리를 진행하지 않고 휴식 팔 자세만 공통으로 맞췄으며 모델·재질·색·복식 소스는 변경하지 않았다. 일반 캡처에서는 무기를 숨겼으므로 김씨 무기는 별도의 승인 게임 캡처를 추가 참조했다.
