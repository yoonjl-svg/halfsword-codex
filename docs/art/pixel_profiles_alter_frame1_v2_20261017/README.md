# 얼터 프로필 v2 — 얼굴 비중·반대 구도 개정

현재 등록된 얼터 NPC **16명**의 정사각형 고화질 원본입니다. 각 파일은 **1254×1254 PNG**, 액자 1, 원본만 보존합니다. 플레이어 얼터는 등록되어 있지 않아 대상에 포함하지 않았습니다. 기본 17명 및 얼터 v1 원본 16개는 변경하지 않았습니다.

## 바뀐 점

- 각 기본 초상을 먼저 보고, 그 반대 방향으로 머리·목·어깨가 자연스럽게 돌아간 3/4 흉상을 다시 그렸습니다.
- 모자·머리 장식 크기가 아니라 실제 얼굴의 화면 비중을 기준으로 구도를 조정했습니다. 마야의 허리 주머니, 토메의 열쇠, 아르토리아의 높은 허리끈, 김씨의 칼은 흉상 밖에 놓일 수 있으며 얼굴을 작게 만드는 이유로 쓰지 않았습니다.
- 아르토리아는 턱을 조금 든 절제된 우월감, 랴오는 미소를 거둔 집중된 입매, 토메는 얕은 비대칭 미소와 계산하는 눈썹, 오마리는 지친 완고함으로 변주했습니다.
- 투야나는 차분한 표정을 목표로 두 차례 제한 교정을 했으나 확대하면 아주 약한 입꼬리 상승이 남습니다. 완전한 무표정을 달성했다고 주장하지 않고 현판을 보존했습니다.
- 아르토리아의 얼굴은 첫 시안보다 가까이 배치하고 금관은 별도로 작게 했습니다. 토메는 머리/흉상 위치를 조금 내렸습니다.
- 광원은 부드러운 화면 왼쪽 위 방향을 공통 기준으로 지시했습니다. 얼굴 방향에 따라 광원까지 좌우 반전하지 않았습니다.

초기 이마–턱/눈선 수치는 계획용 지침이었습니다. 선행 4명의 검토 뒤 **랴오·마야의 근접 흉상과 실제 눈–턱 비중**을 시각적 기준으로 삼았습니다. 모든 얼굴에 동일한 숫자를 강제로 맞추거나 정확한 수치 일치를 검증했다고 주장하지 않습니다. 모자·앞머리·투구의 가림과 나이·골격 차이를 유지합니다. `canonical-roster.json`의 `targetFaceLandmarks`는 초기 목표 기록이며 실측값이 아닙니다.

## 외형·좌우 기준

최신 승인된 기본 원본, 얼터 v1, 실제 엔진의 얼터 렌더를 함께 참조했습니다. 엔진 출처와 사진 촬영 방법은 [v1 provenance](../pixel_profiles_alter_frame1_20261017/provenance.json)에 있습니다. 기반은 `e92b5a6f`, 촬영 당시 checkout HEAD는 `c8ca9c340527de0d60e88d4117f555f248d45d7e`입니다.

- 토메 외눈안경은 해부학적 왼눈입니다. 새 오른쪽 방향 얼굴에서는 화면 오른쪽의 먼 눈에 놓입니다.
- 미나미 나뭇가지, 라트나 이구아나, 이졸데 길드 문양, 찬다 청록 천은 실제 엔진의 해부학적 왼쪽을 기준으로 확인했습니다.
- 오마리 귀걸이는 엔진의 해부학적 오른쪽을 따릅니다. v1 그림의 화면 배치를 고정하지 않았습니다.
- 하인리히는 새 시안에서 잘못 반전된 가까운 뺨의 흉터를 제거했습니다. 실제 오른뺨의 흉터는 새 각도에서 대부분 가려집니다.
- 브론은 낮은 케틀 햇 아래 눈을 계속 가립니다. 얼굴 눈선 측정을 위해 챙을 들지 않았습니다.
- 병마용 얼터는 기본 토우와 달리 창백한 인간의 얼굴과 얇은 흰 망토입니다.

## 생성·보존 방법

모든 초상 생성 및 교정에는 `image_gen.imagegen`만 사용했습니다. 참조 파일은 편집 전에 직접 확인했습니다. 생성 결과는 한 명씩 완전한 정사각형으로 받았고, 파일은 바이트 그대로 복사했습니다. **좌우 뒤집기·크롭·리사이즈·색 보정·모자이크·low 변환을 하지 않았습니다.** 초상 원본 위에 셸/PIL/Canvas로 액자나 그림을 합성하지도 않았습니다.

- 생성 원본: `/workspace/generated_images/` 아래 개별 생성 파일 유지
- 작업 원본: `/workspace/portrait-alter-originals-frame1-v2-20261017/{id}.png`
- 배포 자산: `public/encounters/pixel-profiles-alter-frame1-v2-20261017/{id}/original.png`
- 선택된 최종 원본 16개, 선택되지 않은 교정 전 원본 5개와 실제 프롬프트/입력을 보존했습니다.
- `review-sheet.png`는 HTML에 원본을 나란히 표시한 브라우저 검토 캡처입니다. 캐릭터 자산을 변형한 파일이나 게임 화면이 아닙니다.
