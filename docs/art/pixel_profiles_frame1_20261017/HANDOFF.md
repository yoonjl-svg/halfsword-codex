# 프로필 전달 자료 — 준비본

상태: 17명 제작·보존·우리 포크 검토 페이지 배포 완료. 사용자가 “우화에게 네가 프로필 다 만들었다고 전했어”라고 알렸다. 이는 사용자가 완료 사실을 전했다는 기록이며, 샛별의 정식 교환 메시지 발행이나 우화의 파일 수신·열람 확인은 아니다.

## 받을 자료

공개 자산 커밋: `786e102fc8a86d18b0c585d57428c2a3234988c8` (`yoonjl-svg/halfsword-codex`).

2. `public/encounters/pixel-profiles-20261017/frame-samples.png`: 빈 액자 1·2·3, 왼쪽부터 이름을 부여. 세 안 모두 사용자가 좋아했고 최종 프로필에는 액자1을 선택했다. 원본 전체 시트를 전달해 세 디자인을 모두 보존한다. 함께 있는 `frame-samples.html`은 모바일 검토 페이지다.
3. 제작 규칙: [프로필 기록](../../codex_team/PIXEL_PROFILES_FRAME1_20261017.md), 변환 도구 `tools/content/build_profile_low_20261017.mjs`, 이 디렉터리의 프롬프트·수정·검증·배포 영수증.

## 반드시 유지할 규칙

- 원본을 먼저 완성하고 액자1을 적용해 저장. low는 같은 원본에서 픽셀4배로 변환한 별도 파일이다. low를 재생성 도구로 새로 그리지 않는다.
- 모든 인물 정사각형. 현재17명 원본/low 모두1254×1254. 마지막 가장자리 블록만2픽셀인314×314 유효 격자.
- 두 종류 모두 삭제하지 않고 보존한다. 사용자의 명시적 원본 수정은 허용하며 수정 후 해당 low를 다시 만든다.
- 플레이어는 정면, 낮게 쓴 케틀햇으로 눈 가림 유지.
- 병마용은 토우 조형: 동공 없는 눈 홈과 단순한 눈썹·코·수염. 표면만 흙으로 칠한 정밀한 사람 얼굴을 다시 사용하지 않는다. 사용자의 명시 지시로 병마용 원본만 수정본으로 덮어썼다.
- 이전 생성형2배/4배 비교 샘플은 분위기 실험 이력이며 정확한 low 파일로 사용하지 않는다.
- 기본 캐릭터만 제작했다. 얼터 초상은 이번34개에 포함되지 않는다.

## 연결과 동기화

현재 자산은 검토 페이지이며 게임의 실제 프로필 UI 연결 코드는 없다. 인물 ID는 `profiles.json`을 따른다. 실제 게임 외형 참조 기준은 `15e18adf`이며, 받는 쪽 최신 인물 ID·모습이 바뀌었으면 차이를 검토한다.

정식 보냄 시에는 규약대로 **받는 쪽 최신 main 기준 전달 가지를 먼저 준비**하고, 위 자산과 필요한 연결만 이식한다. 전체 저장소 파일 일치를 요구하지 않는다. 우리 정적 배포 커밋을 받는 쪽 최신 동기화 완료로 대신하지 않는다. 그때 사용자 지정 방식으로 발행하고 결과/원격 해시를 기록한다.
