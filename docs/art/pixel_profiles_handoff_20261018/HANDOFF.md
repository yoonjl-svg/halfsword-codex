## 연결과 의존성

검토 페이지: `public/encounters/pixel-profiles-low128-20261017/index.html`. `?grid=1`로 선 표시를 바로 켤 수 있다. 각 초상을 누르면 원본/low/그리드 저장 링크가 나온다. 폰트는 기준판에 이미 있는 `public/fonts/Pretendard-Regular.subset.woff2`를 사용한다.

`integration.json`에 실제 수신 인물 ID 32개를 모두 대조했다. `player`는 `player1`, `player2`는 별도 선택용 각도. 얼터는 `_mad` 파일이 별도 있으므로 **얼터 초상 채택 시** 현재 `variantOf`로 기본 초상을 찾는 분기보다 명시적 얼터 ID를 먼저 조회해야 한다. 기본 표시 모드 변경은 이번 전달에서 하지 않았다.

수신판의 low 경로는 아직 옛 4px판이다. 이번 `profiles.json`을 128 low의 최신 기준으로 쓰며 옛 4px low를 다시 생성/혼합하지 않는다. 기존 기본 원본 WebP·오프라인 캐시는 보존했다. 새 이미지를 실제 게임 기본으로 연결할 때 선택한 low/원본 파생본만 새 파일명으로 `ui/portraits/`에 옮기고 PWA를 다시 만든다. 큰 원본과 `grid.png`는 검토/편집용이며 설치 캐시에 넣지 않는다. `encounters` 전체는 현재 PWA 제외 대상이다.

그리드 PNG에는 검수용 선이 실제로 그려져 있다. **게임에는 선 없는 low PNG**를 사용한다. 프레임까지 거칠어지지 않도록 CSS 전체 `image-rendering:pixelated` 강제보다 `auto`를 권장한다. 비정사각 늘리기/추가 프레임 중복을 피한다.
