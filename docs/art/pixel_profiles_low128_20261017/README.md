# 전체 프로필의 새 low 기준

2026-10-17 사용자가 승인한 플레이어·아르토리아 128 시안의 큰 도트 표현을 전체 캐릭터에 적용했다. 현재 자산은 `public/encounters/pixel-profiles-low128-20261017/`이며, 인물별로 `original.png`와 `low.png`를 함께 저장한다. 앞으로의 제작 규칙은 [PROFILE_STANDARD.md](../PROFILE_STANDARD.md)를 따른다.

- 기본 NPC 16명, 플레이어1·2, 얼터 16명: 총 34개 초상, 68개 PNG.
- 플레이어1은 정면. 플레이어2는 최초 시트의 오른쪽 3/4 구도를 액자1과 정사각형으로 정리한 별도 원본이다.
- 기존 기본·얼터 v2 고화질 원본 33개는 바이트 그대로 보존한다. 플레이어2 원본만 추가 제작했다.
- 새 low의 인물 뒤 빈 공간과 액자 밖 바탕은 실제 PNG alpha다. 흰 머리와 흰 옷은 남겼고, 금색 액자의 선과 모서리는 선명하게 유지했다.
- 기존 4배 low 17개는 작업 트리와 공개 자산에서 삭제한다. 옛 기본 갤러리는 새 갤러리로 연결하고, 옛 manifest도 새 low를 참조하도록 변경한다. 과거 Git 기록은 이력으로 남는다. 4배 자동 변환 도구는 중단했다.

128은 승인된 재해석 화풍의 이름이며 정확한 128px 정수 격자가 아니다. 자동 모자이크를 적용하지 않았다. 초도 생성에서 얼굴·갑옷·수염이 지나치게 촘촘했던 인물은 low만 다시 단순화했다. 원본 배경은 제작 마스터로 보존하며 투명 처리는 게임 표시용 low에 적용했다. 액자도 이미지 생성 과정에서 가장자리의 미세한 차이가 생길 수 있어 원본 액자와 바이트가 같다고 주장하지 않는다.

검토 페이지에서는 기본·얼터 범위, 원본·low, 어두운색·청회색·투명도 확인 배경을 바꿀 수 있다. 인물을 누르면 두 파일을 비교하고 각각 저장한다. 휴대전화에서는 두 열로 표시한다.

검증 기록은 `asset-validation.json`, `browser-verification.json`, `generation-records.json`에 저장한다. 공개 상태와 원격 파일 확인은 `publication.json`이 기준이다. 스크린샷은 이 독립 검토 페이지의 화면이며, 실제 게임 UI에 프로필을 연결한 작업으로 보고하지 않는다. 우화에게 새 메시지를 보내지 않았다.
