# 미나미 눈매 추가 시안 — 2026-10-18

사용자 요청: 현재 미나미에서 다른 눈매 하나를 더 비교. 후속으로 **B안의 화면 왼쪽 눈을 모양/색/높이 그대로 오른쪽 한 셀 이동**했다. 정식 low는 여전히 A를 보존한다. 아래 2셀 변경은 최초 B 제작 이력이다.

- A는 현재 `minami/low.png`와 바이트까지 같은 복사본이다.
- B는 화면 왼쪽 눈의 두 셀 `(10,8)`과 `(12,8)`만 수정했다. 바깥 눈꼬리를 진하게 하고 안쪽 윗눈꺼풀 끝을 피부색으로 비워 사선으로 가늘어지는 눈매를 만든다.
- 22×22 / 50px 셀, 고해상도 공통 액자, 얼굴 크기와 크롭, 투명 배경은 동일하다. 두 셀 밖 모든 출력 픽셀이 동일함을 확인했다(변경 출력 픽셀 5,000개).
- 기존 34쌍 원본/low 및 편집 소스는 변경하지 않았다. 이 시안은 아직 채택되지 않았다. 새 우화 전달은 없다.

`variant.json`에 재현 가능한 셀과 검증 결과가 있다. `comparison.png`는 브라우저에서 촬영한 비교 갤러리다. 공개 상태는 `publication.json` 참고.

## 눈 위치 후속

왼쪽 눈을 구성하는 세 셀 `(10,8)`, `(11,8)`, `(11,9)`를 각각 오른쪽 한 셀로 옮겼다. 비워진 자리는 주변 피부색으로 복원했다. 이동 전후의 눈 모양과 색은 일치하며, 이 영역 밖의 모든 출력 픽셀은 동일하다. 기존 A/원본/정식 low는 그대로다. `variant-before-shift.json`/`low-eye-option2-before-shift.png`에 직전 B를 보존하고, `variant.json`에 이동 후 셀을 저장했다. `shift-comparison.png`는 이동 전후 브라우저 스크린샷이다.
