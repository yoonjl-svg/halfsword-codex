- A는 현재 `minami/low.png`와 바이트까지 같은 복사본이다.
- B는 화면 왼쪽 눈의 두 셀 `(10,8)`과 `(12,8)`만 수정했다. 바깥 눈꼬리를 진하게 하고 안쪽 윗눈꺼풀 끝을 피부색으로 비워 사선으로 가늘어지는 눈매를 만든다.

- 기존 34쌍 원본/low 및 편집 소스는 변경하지 않았다. 이 시안은 아직 채택되지 않았다. 새 우화 전달은 없다.
