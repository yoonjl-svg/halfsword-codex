# 굵은 픽셀 재해석과 선명한 액자

사용자가 16·32배 시험을 호평하고 64·128배까지 확대하되 액자는 원본 해상도로 유지하도록 요청했다. 랴오·마야 얼터 8장 제작·그림 검토를 마쳤다. 이어 기본 플레이어·하인리히·아르토리아의 64·128배 6장을 추가 요청했다.

## 제작 방식

- 원본을 단순 축소하거나 모자이크 필터로 처리하지 않고 imagegen으로 윤곽·명암·특징의 우선순위를 새로 그렸다.
- 인물만 굵은 픽셀로 단순화하고 액자1의 가는 금선·네 모서리 장식은 고해상도 참고 이미지에 맞춰 유지한다. 앞선16·32배도 액자 세부를 복원했다.
- 64배는 얼굴 방향과 최소 표정을 남기고 128배는 머리·얼굴·복식의 큰 색 덩어리로 읽는 아이콘에 가깝다. 새 기본3명은 원본 각도/복식 유지, 플레이어는 정면과 낮은 케틀햇 눈가림 유지.
- **배율은 목표값**이다. 생성기는 정확한78·39·20·10칸 고정 격자를 따르지 않았으며 색 면적/단계도 불균일하다. 액자는 선명한 원본 스타일 재묘사이고 원본 액자 픽셀의 완전한 바이트 복제는 아니다.
- 고화질 원본, 기존low, 이전 시험 시도, 미선택 생성 결과를 삭제하거나 덮어쓰지 않는다. 이번 결과는 기존low 제작 규칙의 자동 변경이 아니다.

## 경로와 출처

- 검토 페이지: `public/encounters/pixel-profile-redraw-16-128-20261017/`.
- `?group=base`: 기본 플레이어·하인리히·아르토리아. `?group=alter`: 얼터 랴오·마야. `?group=all`: 전체.
- 원본은 기존 기본/v2 갤러리의 PNG를 직접 참조한다. 변형14장만 새 경로에 저장한다.
- `provenance.json`: 선택 결과와 imagegen 원본 경로·해시·치수. 원본 파일을 바이트 그대로 복사, 이미지 후처리 없음.
- `frame-restoration-jobs.json`, `frame-restoration-results.json`, `provenance-16-32.json`:16·32배 액자 보완.
- `coarse-generation-*`: 랴오·마야64·128배 프롬프트/참조/선택4장/첫4장 미선택 기록.
- `base-generation-*`: 후속 기본3명6장 생성 기록(완료 후 보존).
- `verification.json`: 원본/기존파일 보존·결과 바이트 일치 검사.
- `gallery-verification.json`: 휴대폰·데스크톱 비교/범위/다운로드 검사. `base-comparison-desktop.png` 등은 **생성 시안 검토 페이지**를 브라우저로 촬영한 사진이며 실제 게임 화면이 아니다.

## 검토·공개 범위

부모가 최종14장 모두 실제로 확인했다. 기본3명은 원본과 같은 방향/복식을 유지한다. 플레이어는 정면과 낮은 케틀햇/눈 가림, 하인리히는 은발/턱수염과 금테 은갑옷, 아르토리아는 은발/청록 눈·보석과 기본 갑옷이다. 각128배가64배보다 큰 색 면과 단순한 얼굴로 구별되며 액자의 가는 선은 선명하다.

플레이어는128배에서도 투구와 교차 가슴 끈이 인물을 알아보게 한다. 하인리히·아르토리아는64배에서 나이·눈매·얼굴 방향이 더 잘 남는다. 극단적인128배에서는 흉터, 수염 가닥, 입매 같은 세부가 빠지고 일부 색 면에 미세한 그라데이션이 남는다. 정수 격자 픽셀아트의 기술적 완성본이나 원본과 동일한 표정 복원으로 주장하지 않는다.

검토 페이지와 이미지에 한정하여 우리 포크에 공개한다. 게임 UI 연결·우화 전달은 하지 않는다. 공개 완료 근거는 인접 `../pixel_profiles_alter_frame1_v2_20261017/publication.json`에 기록한다.

## 최종 검증

- 최종14장 모두1254×1254, imagegen 원본과 공개 복사본 바이트 일치.
- 기존 기본17명 원본/low, 수정 얼터16명 원본 및 이전 보호파일153개 해시 유지.
- 320/390/844/1600px 전체 보기,390/1200px 기본3명 보기,1600px 얼터2명 보기에서 로딩·정사각 표시·배율 전환·다운로드·가로 넘침/JS·HTTP 오류 검사 통과.
- 기본3명에는16/32배 시안이 없으므로 해당 그룹의 버튼을 숨긴다. 전체 보기에서16/32배를 누르면 랴오·마야만 표시한다.
- 로컬 Chromium으로 촬영/동작 검증했다. 환경 네트워크 정책 때문에 실제 Pages 도메인 직접 접속은 불가하며 원격 커밋의34개 공개파일 바이트와 GitHub Actions 배포 상태를 별도로 확인한다. 공개판 Safari 실기 검증이라고 주장하지 않는다.
