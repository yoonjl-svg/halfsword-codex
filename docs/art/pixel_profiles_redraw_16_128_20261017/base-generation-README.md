# 기본 3명 — 64·128배 목표 픽셀 재해석

기본형 플레이어·하인리히·아르토리아를 각각 64·128배 목표의 굵은 픽셀로 재해석한 6개 시안이다. 얼터 복식은 사용하지 않았다. 각 출력은 1254×1254 PNG이며 생성 원본과 작업 복사본의 SHA-256/바이트가 일치한다.

입력은 `public/encounters/pixel-profiles-frame1-v1-20261017/{player,heinrich,artoria}/original.png`의 승인된 기본 고화질 원본이다. 각 입력을 직접 확인했고, 이미 승인된 랴오 64/마야 128 시안도 굵기·고해상도 액자 스타일 참고로 확인했다. 참고 이미지의 캐릭터 외형은 복제하지 않도록 지시했다.

- 플레이어: 정면, 낮은 케틀 햇으로 양쪽 눈 가림, 크림색 누비옷과 갈색 X끈.
- 하인리히: 원본의 오른쪽 방향, 은발·흰 턱수염, 금색 테두리의 은갑옷.
- 아르토리아: 원본의 왼쪽 방향, 특유의 앞머리·긴 밝은 머리, 기본 은갑옷·청록 계열 옷/보석. 얼터의 금관·검은 드레스는 넣지 않았다.

6장 모두 직접 검토했다. 각 128 시안은 64보다 머리·얼굴·복식의 세부를 더 생략한다. 제작에는 `image_gen.imagegen`만 사용했고 자동 모자이크·래스터 축소/확대·크롭·색 보정은 하지 않았다. 출력 파일 복사 외 후처리는 없다. 이번에는 첫 6장 모두 선택했으며 생성 원본·실제 프롬프트·입력·해시를 보존했다.

**64·128은 재해석 목표다.** 정확한 고정 배율이나 20×20/10×10 격자 일치를 의미하지 않는다. 큰 색 덩어리의 배치와 미세한 그라데이션은 생성 결과마다 달라진다. 128에서는 세부 표정·나이선·흉터 등도 의도적으로 사라질 수 있다.

액자의 섬세한 금색 이중선·사각 장식·고해상도 외형을 유지하도록 지시했다. 다만 생성 모델이 원본 액자 픽셀의 완전한 동일성을 보장하지는 않는다. 원본 액자의 정확한 복원과 공개 갤러리는 부모 담당이다.

- `coarse-generation-manifest.json` / `manifest.json`: 통합용 `characters` 배열, `baseId`, `targetScale`, 생성 경로·해시·크기, 실제 프롬프트/입력
- `generation-jobs.json`: 사용한 6개 실제 생성 작업
- `generation-attempts.json`: 선택된 6개 시도 전부
- `provenance.json`: 제작·참고·보존 방법과 한계
- `verification.json`: 6개 바이트 일치 및 원본3+스타일2 입력 해시 보존

작업 범위는 이 새 폴더뿐이다. 기존 기본/얼터 원본·기존 픽셀 시안·public·docs·게임 소스·git은 변경하지 않았다.
