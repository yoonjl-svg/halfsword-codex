# 64·128배 목표 픽셀 재해석 시험

랴오·마야의 v2 고화질 원본을 기준으로 각 64·128배 목표 시안 1장씩 제작했다. 선택된 4장은 모두 1254×1254 PNG이며 생성 파일과 작업 복사본의 바이트가 일치한다.

`64`는 원본 대비 약 20×20 논리 격자, `128`은 약 10×10 격자를 지시한 **재해석 목표**다. 생성기가 격자를 엄밀히 지키지 않으므로 실제 고정 배율·정확한 픽셀 크기라고 부르지 않는다. 최종 128 시안은 64보다 얼굴·머리·의상의 작은 특징을 더 버리고 큰 색 덩어리로 구성했다.

원본과 기존 32배 시안을 모두 직접 확인했다. 첫 생성 4장은 액자 세밀함은 유지했으나 인물의 픽셀이 충분히 커지지 않았다. 두 번째 생성에서는 32배 참조를 제외하고 원본만 참조하여 얼굴의 눈·코·입, 머리카락, 작은 소품을 생략해도 되도록 지시했다. 그 두 번째 4장을 선택했다. 첫 4장과 실제 프롬프트도 삭제하지 않았다.

생성·교정은 `image_gen.imagegen`만 사용했다. 자동 모자이크, 래스터 축소/확대, 크롭, 색 보정, 액자 합성은 하지 않았다. 작업 PNG는 생성 파일의 바이트 복사다. 생성 원본은 `/workspace/generated_images/` 아래에 보존했다.

액자는 원본의 세밀한 금색 이중선·사각 모서리와 고해상도 외형을 유지하도록 지시했다. 실제 그림에서도 세밀한 액자와 거친 인물이 분리되어 보인다. 다만 **원본 액자의 픽셀 단위 완전 동일성은 생성 모델이 보장하지 않는다.** 정확한 원본 액자 복원과 갤러리 작업은 부모 담당이다.

- `generation-jobs.json`: 첫 4개 실제 프롬프트/입력
- `generation-jobs-attempt2.json`: 선택된 두 번째 4개 실제 프롬프트/입력
- `attempts.json`: 첫 4개 결과 경로/해시/미선택 이유
- `manifest.json`: 선택된 4개 생성 원본·작업 원본 경로, 해시, 크기, 시각 검토, 한계
- `verification.json`: 원본 참조 2개 보존, 입력 4개 해시, 복사본 바이트 검증

기존 v2 원본·기존 16/32 시안·저해상도 자산·public·docs·게임 소스는 변경하지 않았다. 원격 커밋/푸시/우화 전달도 수행하지 않았다.
