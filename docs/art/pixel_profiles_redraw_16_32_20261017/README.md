# 랴오·마야 16배/32배 목표 픽셀 재해석 시안

사용자가 단순 모자이크 효과를 피하고, 원본의16배·32배 크기 픽셀로 원본을 가장 잘 묘사하는 픽셀아트를 시험 요청했다. 고화질 얼터v2 중 랴오·마야를 골라 각2개, 총4개 시안을 별도로 생성했다. 기존 원본/low 작업 규칙을 대체하는 결정은 아니다.

## 실제 제작과 한계

- 수정 고화질 원본을 참조하여 imagegen으로 윤곽/눈/입/머리 덩어리/명암의 재구성을 요청했다. 모자이크 필터나 크기 축소 알고리즘을 적용하지 않았다.
- 원본1254×1254에서 목표 논리 해상도는 대략78×78(16배),39×39(32배). **생성기는 정확한 고정 격자와 단색 픽셀 제약을 지키지 못했다.** 따라서 `16배 목표`, `32배 목표` 재해석 시안으로 표시하고, 정확한 배율의 제작용 스프라이트 완성본으로 부르지 않는다. 실제32배 파일의 칸 수가39개라고 주장하지 않는다.
- 첫32배2장은16배와 차이가 부족하여 미선택 이력으로 보존. 다시 생성한32배는 얼굴과 머리의 정보를 더 생략해 차이가 커졌으나 일부 그라데이션/격자 불규칙성이 남는다. 자동 모자이크를 추가해 제약을 충족한 것처럼 만들지 않았다.
- 부모 육안 평가:16배 목표안이 얼굴 표정·머리카락/눈가리개의 인물 특성을 더 잘 보존한다.32배 목표안은 큰 실루엣과 상징적 색 덩어리를 읽기 쉽지만, 특히 마야의 입매/눈 비례가 단순화돼 원본과의 유사성이 줄어든다. 사용자 비교용이며 전체 캐릭터 제작 방식으로 채택하지 않았다.

## 보존

- 공개 비교 경로 `public/encounters/pixel-profile-redraw-16-32-20261017/`.
- `generation-jobs.json`, `coarse-correction-jobs.json`: 실제 생성 프롬프트/참조.
- `generation-results.json`, `provenance.json`: 생성 경로,6개 시도 전부의SHA-256/바이트, 선택4개. 최초 생성본은 `/workspace/generated_images/`, 복사 보존본은 `/workspace/portrait-pixel-redraw-16-32-20261017/attempts/`.
- 기존 얼터v2 랴오/마야 원본은 `profiles.json`의 원본 해시로 고정했으며 덮어쓰기0. 결과PNG도1254×1254이며 후처리0.
- `comparison-desktop.png`와 `comparison-mobile.png`는 비교 갤러리를 실제 Chromium으로 찍은 화면이다. 시안 원본 이미지의 후처리본이 아니다.
