# 128 low 엄격 재검수 — 2026-10-18

사용자는 이전 34개 low의 픽셀·액자 크기와 디테일 비율 불일치를 지적했고, 공통 액자와 고정 격자를 코드로 합성하는 방식을 명시적으로 선택했다. 플레이어1과 아르토리아도 검사 예외가 아니다. 원래 가려진 눈은 유지하되, 노출된 눈이 없는 결과는 탈락한다.

## 이번 기준

- 출력 1254×1254. 인물 영역 `(77,77)`부터 1100×1100, **22×22 셀, 셀당 정확히 50×50px**. 인물 안의 반 셀·작은 보조 픽셀·그라데이션 금지. 동일 색의 여러 셀이 이어진 큰 면은 허용.
- 기존 두 기준의 체감 밀도 사이에서 22셀을 선택했다. ‘128’은 이전 실험에서 붙인 스타일 이름이며 128px 셀이라는 뜻이 아니다.
- 공통 `frame1.png`를 같은 좌표에 합성한다. 금선·네 모서리·장식·굵기는 전원 동일한 RGBA 데이터. 인물의 격자를 액자에 적용하지 않는다.
- 얼굴 핵심 영역은 머리카락/투구/관을 제외해 수동 확인한다. 폭은 6–10셀, 눈~턱 간격은 대략 4–6셀, 턱은 13–15행을 기준으로 삼는다. 김씨처럼 삿갓 아래 보이는 얼굴은 가림 범위를 별도로 확인한다. 나이·성별·방향 차이를 같은 얼굴로 만들지 않는다.
- 상반신은 어깨와 윗가슴까지만 보인다. 턱 아래 7–9행을 남기고 아래 변의 21–22셀을 몸이 채우는 흉상. 머리장식 때문에 얼굴을 줄이거나 손·허리를 넣으려고 넓게 크롭하지 않는다. 갑옷 어깨판과 드레스의 높이 차이는 보존한다.
- 눈이 노출된 29명은 눈 셀이 반드시 있어야 한다. 기본 병마용 1명은 인간 동공 대신 토우의 눈 홈. 플레이어1·2, 얼터 브론, 얼터 랴오 4명은 설정상 가림을 유지한다. 기본 랴오는 안대 반대쪽 눈을 보인다.
- 인물 alpha는 0/255. 배경은 투명, 흰 옷·머리·가림천을 지우지 않는다. 원본 34개 해시 보존.

## 제작과 검수

기존 개별 생성 low를 시작 재료로 격자에 옮긴 뒤, `sprites.json`에서 눈·눈꺼풀·입·안경·동물·관 등 특징을 개별 셀로 수정했다. 단순 축소 결과를 완성본으로 채택하지 않았다. 이전 파일은 원 커밋 `341fd3b5` 및 작업 백업에 보존된다. 원본 제작 이미지는 변경하지 않았다.

재현 소스는 `sprites.json`의 팔레트/셀과 공통 액자다. `tools/content/build_profile_grid_20261018.py`는 이 셀을 정수 배율로 합성하며 원본을 재축소하지 않는다. `edits`에 셀별 변경 이유와 이전/이후 색을 남겼다.

독립 검수의 얼굴 좌표는 수동 근사치(±35px, 가림 ±60px)이지 자동 얼굴 검출 결과가 아니다. 최종 셀 단위 얼굴 박스도 시각 검수용 기준점이며 피부 영역의 정밀 분할을 주장하지 않는다. 파일 검사와 시각 검수를 구별한다.

- `asset-validation.json`: 저장 PNG를 다시 읽어 모든 셀의 단색/50px 경계, 공통 액자 픽셀, 원본 해시를 검증.
- `independent-before-review.*`: 이전 34개 전체 검수 및 초기 수정본 독립 검수.
- `sprites.json`: 인물별 셀, 특징 보정, 얼굴/눈 기준.
- `browser-verification.json`: 갤러리와 모바일 비교 화면 검사.
- `publication.json`: 공개 여부/커밋/검증 영수증.

게임 UI에 연결하거나 우화에게 새로 발송하는 작업은 이번 변경에 포함되지 않는다. 사용자 검토용 갤러리의 이미지 갱신이다.
