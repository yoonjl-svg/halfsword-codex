# 비기 공통음·고노센 발도음 v1 — 2026-10-25

사용자 지시: 우화 MSG-S-015 소리 제작 요청 수행. 추가 확정: **고노센은 칼집에서 검을 빠르게 뽑는 ‘철컹’**. 긴 칼 휘두름/바람만으로 대신하지 않는다. 이번 결과는 청취 검토용 음원과 재현 자료이며 게임 연결/음량 조정은 요청대로 우화 담당이다. 사용자 청감 승인·우화 새전달 전이다. 용 전투/기존 게임 소리·캐릭터 음성은 변경하지 않았다.

`-repeat.mp3`는 같은 소리3회, `gonosen-a-b.mp3`는 G1→G2, `common-then-hit.mp3`/`gonosen-then-hit.mp3`는 **타격 단독→발동음과160ms 뒤 타격→한번더**의 고정 청취 시퀀스다. 실제 게임 녹화/자동 발동을 녹음한 자료가 아니다. `-phone-band.mp3`는350~4500Hz 모노 대역 제한 비교이며 특정 휴대폰 재현이나 실기기 청취 통과가 아니다. 대역 비교 파일은 다시 크게 정규화하지 않았다.

## 원료와 허가

고노센 원료는 모두 **CC0 1.0**. 원료에 저작자 표시 의무는 없지만 출처를 보존한다.

- [SamsterBirdies — Sword draw unsheathe,581594](https://freesound.org/people/SamsterBirdies/sounds/581594/): 제작자 설명은 검 인출처럼 들리는 **마체테 소리**. 실제 일본도 발도 녹음이라고 쓰지 않는다. HQ MP3 미리듣기에서 .400~.680초 발췌, 재생률.93, 금속층.
- [hushless — Sword Unsheath,772113](https://freesound.org/people/hushless/sounds/772113/): 제작자 설명은 스튜디오에서 작은 검을 가죽 칼집에서 뽑은 녹음. HQ MP3 .150~.405초/1.65배 템포와 .155~.555초/1.4배 템포. 템포 변환은 음높이 보존, G1/G2의 인출 마찰층.
- [Vehicle — Fantasy Weapons and Apparel SFX Library](https://opengameart.org/content/fantasy-weapons-and-apparel-sfx-library): CC0 원본 ZIP의 `seax-unsheathe-02.wav`, .247~.330초 이탈 클릭. 원 제작자는 정규화 외 유기적/비가공 소리라고 설명. 읽은 라이선스·ZIP 해시·선택 WAV 해시와 readme를 보존했다.
- S1: 외부 샘플 없는 프로젝트 자체 절차적 합성. 고정 난수의 대역 제한 공기층과 감쇠한 비정수 공명5개. 생성 코드는 `prepare.py`. 외부 녹음/생성형 음원 서비스로 만들었다고 하지 않는다.
- 청취 맥락의 타격음만 기존 게임 `flesh/edge1.mp3`를 복사했다. [SoundsForHim399616](https://freesound.org/people/SoundsForHim/sounds/399616/) 상세 페이지에서 이번에 CC0를 직접 확인했다. 발도음 원료/새 게임 타격음으로 들어가지 않는다.

Freesound 파일은 **사이트의 HQ MP3 미리듣기**이며 업로드 원본 WAV/OGG가 아니다. 직접 열람한 라이선스 링크/페이지 내용/원문 해시/다운로드 URL/파일 해시는 `sources/evidence.json`. 실제 녹음 환경은 제작자의 설명이며 독립 실사로 확인한 사실이 아니다. 한국 사용자의 ‘철컹’ 요구를 위한 가공/레이어링이며 사료상 일본도 소리를 복원했다고 주장하지 않는다.

검토했으나 사용하지 않은 소리: ihitokage395364(CC0,긴 인출·배경잡음 후보), visualasylum329787/Halleck19334(CC BY4.0이므로 이번 CC0 중심 묶음에서 제외). OGA 다른 스크랩/충돌 후보도 본 결과 원료에는 쓰지 않았다.

## 편집과 수치 검사

Python NumPy/SciPy + FFmpeg. 원채널을 평균해 모노화하고 float PCM 상태로 필터/가공해 중간 클리핑을 피했다. 시작/끝 페이드, 저역/DC와 과도한 고역 제거, G1 금속층 음높이7% 내림, 인출 마찰 템포 단축. S1 PCM 피크−10dBFS, G1/G2−8dBFS. 합본은 S1만 낮게 더하고 통합 피크를 다시 크게 만들지 않는다.

첫 G1은 금속 꼬리에 에너지가 많이 남아99% 에너지 시각이262ms였다. 후속 타격 공간을 남기려고120ms 뒤 꼬리를 감쇠해 **179ms**로 줄였다. S1은170ms, G1+S1은177ms. G2는 비교용으로 조금 더 인출 과정을 남겨226ms. 초기 측정은 `measurements-before-tail.json`에 보존한다. 이 수치는 청감상 가림을 완전히 해결했다는 증명이 아니다.

모든 형식의 실제 디코딩·유한 샘플·4배 오버샘플 피크<−2dBFS·PCM 시작/끝0을 확인했다. 신호 에너지의350~4500Hz 대역 비율은 S1 약73%, G1 약46%다. 실제 휴대폰 스피커/청각적 적합성은 사용자의 청취 검토 대상이다. 실제 게임 전투 믹스/발동 이벤트는 이번에 연결하지 않았다.

재현: `python docs/audio/secret_20261025/prepare.py`. 고정 난수/PCM 제작법을 보존한다. 인코더 버전에 따라 압축 파일 바이트는 달라질 수 있으며 WAV와 디코딩 신호를 비교한다. Python3·NumPy/SciPy·FFmpeg 필요. 모든 외부 원료는 같은 폴더에 보존되어 재다운로드 없이 재현 가능.

## 연결 제안 — 우화 담당

1. 준비창/느낌표가 아닌 **비기 발동 확정**에1회. 성공한 공격 ID당 한 번, 타격 이벤트마다 중복 재생하지 않는다.
2. 독일 모르트슐라크·이탈리아 안다레 리솔루토·이베리아 싱지르·동방 격살은 S1. 일본 고노센은 **G1+S1 합본1개**를 추천한다. 공통음을 또 얹지 않는다. 일본도 같은 시작 신호를 가지면서 ‘철컹’을 전면에 둔다.
3. 0.4배 화면 시간 연출과 분리해 `playbackRate=1`로 한 번 재생하는 안을 권한다. 발도음까지 늘어지면 빠르게 뽑는 인상이 약해질 수 있다.
4. 파일의 여유 피크를 유지한 채 기존 효과음 버스로 시작하고 실제 전투에서 음량을 맞춘다. 확인된 최종 믹스 수치/모든 플랫폼 공통 최적값으로 제시하지 않는다.

검토/배포 결과는 `publication.json`에 기록한다. 사용자가 들을 파일과 전달 후보 파일의 해시가 같도록 묶는다. 별도 전달 지시 전 우화에게 새 메시지를 발송하지 않는다.

검토 페이지 검증:320/390/844/1280px 가로넘침0,21개 MP3/OGG/WAV 전부브라우저디코딩,4개단발끝까지재생·다른음재생시앞음정지,HTTP/JS오류0. 처음 검사는 재생 시작을 기다리지 않은 즉시 단언에서 실패했으며, 재생상태 대기를 적용하고 버튼 클릭 때 앞음을 즉시 멈추도록 보완했다. 초기 실패 로그 보존. 검토 탈락 원료는 저장소 조사 폴더에만 보존하며 ZIP에는 재현에 필요한 원료를 넣었다.
