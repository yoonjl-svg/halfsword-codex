# 드루이드의 채찍: 녹음 후보와 말린 섬네일

사용자 요청: 우화가 넣은 채찍 타격음이 이상하므로 실제 채찍처럼 “찰싹 찰싹” 하는 소리를 찾아 달라. 섬네일은 긴 채찍이 둥글게 말린 모습으로 변경.

## 기준과 범위

- 수신 최신 `488fa7ca66961025a6f966343d50566cff61239f`에서 우리 가지 `codex/whip-audio-thumb-20261024`로 작업.
- 현재 `src/sound.js`의 `whipHit`는 AntumDeluge **Thwack Sounds**(물건 타격 녹음, CC0), `whipCrack`은 Basel의 **Peitschen.ogg**(여러 사람이 야외에서 채찍 치는 녹음, Public Domain) 일부. 타격음 자체가 채찍 녹음은 아니며 두 사건은 별도 호출된다. 이것이 불만의 유일한 원인이라고 확정하지 않는다.
- 기존 음원과 소리 라우팅·발동 조건·음량 곡선·채찍 물리는 변경하지 않았다. 이번 소리는 비교 후보이며 실제 적용 전이다.
- `public/ui/weapons/druid_whip.webp`만 새 말린 구도로 교체. 카드와 인벤토리가 이 경로를 공유한다. 별도 생성한 일러스트를 사용한 섬네일이며 3D 무기를 말아 바꾸지는 않았다.

## 확보한 두 후보

| 후보 | 원본 | 제작자 | 길이(원본/타격용) | 추천 용도 |
|---|---|---|---|---|
| A | [Whip](https://soundbible.com/1150-Whip.html) | Mike Koenig | 약0.886초 / 0.285초 | 짧고 잔향이 적은 타격음 우선 후보 |
| B | [Whip Crack](https://soundbible.com/1375-Whip-Crack.html) | snottyboi | 약1.082초 / 0.310초 | 더 긴 꼬리가 남는 비교 후보 |

사이트는 A를 cattle bullwhip의 휘두름과 파열음, B를 clean whip crack으로 설명한다. 녹음 현장을 독립 검증한 것은 아니다. 둘 다 **CC BY 3.0**, 제작자·작품·원본 URL·라이선스·가공 사실을 비교 페이지와 sources.json에 표시했다. 원본 WAV와 당시 페이지는 `sources/`에 보존.

A를 우선 추천하는 이유는 원본의 타격 후 꼬리가 짧고, 반복 재생에서 이전 울림이 다음 타격에 겹칠 여지를 줄이기 쉽기 때문이다. 사용자의 실제 기기 청취·게임 손맛 평가는 아직 받지 않았다. 음원만으로 타격 감각의 완성을 확정하지 않는다.

가공: 타격 앞부분부터 짧게 자름(A .235~.520초, B .410~.720초), 1ms 시작/35ms 끝 페이드, PCM 피크−6dBFS, MP3 q2. 음높이·속도 변경/합성음 추가 없음. 디코딩 피크 A−6.004/B−5.988dBFS. 세 번 재생은 같은 후보를 420ms 간격의 무음과 연결한 시청용 파일이며 서로 다른 녹음3개로 세지 않는다. 휘두름 포함 원본도 음량을 낮춰 들을 수 있다.

기존 소리 비교본도 최대음량을 약−6dBFS로 맞췄다. 게임 원본 파일은 그대로다. 기존 crack1 MP3를 부동소수 PCM으로 디코딩했을 때 순간 피크 약+1.99dBFS가 관찰되지만 실제 게임에는 후속 게인/버스가 있으므로 이것만으로 재생 클리핑을 확정하지 않는다.

## 섬네일

원본은 `art/weapons/druid_whip_coiled_20261024/original.png`(1254² RGBA), 게임용은 같은 폴더 `game.webp`(256², 약23KB). 식물 줄기 꼬임/탁한 올리브·갈색, 수피 손잡이와 잎을 유지하고 둥근 두 겹 코일로 바꿨다. 기존 펼친 섬네일은 비교 페이지 before.webp에 보존.

`tools/browser/weapon_thumbs.mjs`에서 채찍만 이 마스터를 복사하도록 했다. 전체 무기 섬네일 재생성 때 펼친 모양으로 되돌아가는 것을 막는다. 다른 무기는 기존 촬영 그대로. 재생성 실제 실행 후 마스터와 바이트 동일 확인.

## 확인과 공개

- 비교 페이지: `public/encounters/whip-sound-20261024/`. 기존/신규 섬네일, 현재 소리·A/B의 한 번/세 번/원본 재생, 출처.
- 게임 카드 화면과 모바일/데스크톱 비교 페이지 검사, 오디오 디코딩/재생 결과를 별도 JSON과 사진에 보존한다.
- 전체 공개 게임을 수신 최신 게임으로 교체하지 않는다. 공개 검토 자료와 우리 가지의 섬네일 변경이며, 새 우화 전달은 사용자 검토 후 별도 지시에 따른다.
- 상대 저장소 직접 쓰기0. 새 음원 게임 적용0. 제작자 크레딧은 음원 사용 시 함께 유지해야 한다.

되돌림: 채찍 WebP와 생성 도구의 예외만 이전으로 돌리면 섬네일은 복구된다. 비교 페이지/원본은 기록으로 보존할 수 있다. 전투/저장 형식은 불변.

검증 완료: 실제 게임 카드844×390/568×320/1280×800 모두 글 넘침 없음·등급/이름 정상·콘솔오류0. 정적 비교페이지320/390/844/1280 모두 넘침0, 8오디오 디코딩/끝까지재생·다른오디오 자동정지 확인. 첫 정적 검사에서 Vite의 디렉터리 fallback이 게임 첫화면을 반환하여 이미지 대기 실패; public을 정적 서버로 제공해 올바른 페이지에서 다시 검사했다. 게임 오류로 집계하지 않는다. 빌드/PWA 성공, 기존 큰번들 경고 유지.
