## 적용 범위

수신 기준 `f29ed8178cfb652542d30f9e85ce7b3de44f8fc7` 위 우리 작업 가지 `codex/whip-a-variants-20261024`. 앞선 후보/코일 자료 `9f757e4d`를 `cd7d49ef`로 가져왔다. 상대 저장소에는 쓰지 않았다. 새 전달 메시지는 아직 보내지 않았다.

- 선택된 **A / Mike Koenig, Whip**를 우리 작업본의 살·옷 타격 `whipHit`에 반영했다. 샘플은 승인 후보와 바이트 동일, SHA256 `13787e0d56d26231e093ee79e3cf5b846ed53e03e389f3cbefce17c2941d51ab`.
- 새 파일 `public/sfx/whip/hit-mike-koenig-a.mp3`. 기존 세 타격 파일은 이력으로 보존한다. 서로 다른 새 녹음 세 개를 만든 것이 아니다. 기존 실행 시 음높이 변화 .94–1.06은 유지한다.
- 휘두름/공중 파열음/갑옷/무기 충돌 소리, 타격 조건·물리·음량 곡선은 그대로다.
- 출처 https://soundbible.com/1150-Whip.html · **CC BY 3.0** https://creativecommons.org/licenses/by/3.0/. 제목·저작자·원본 링크·라이선스·편집 사실을 `public/sfx/LICENSE.txt`에 기재하고 게임 메뉴에 ‘음원 출처’ 링크를 추가했다. 원본에서 .235–.520초 발췌, 진입1ms/끝35ms 페이드, 피크−6dBFS, MP3 변환. 이전 후보 문서의 ‘선택 대기/게임 음원 미적용’은 이 결정 이전의 이력이다.
- 공개 비교 페이지는 정적 자료다. 우리 일반 공개 게임 소스를 수신 게임 트리로 바꾸지 않는다. 작업본 적용과 우화 본판 적용을 구별한다.

## 실제 음성 연결

| 인물 | 현재 지정 | 결과 |
| --- | --- | --- |
| 롤랑 | `tome` | 토메 음성 묶음 정상 사용 |
| 베르나르도 | 롤랑 정의 상속, `tome` | 토메 음성 묶음 정상 사용 |
| 백린의 전사(몽골 무사) | `renji` | 해당 VOICES 묶음이 없어 정상 공유되지 않음 |

김씨·라트나도 `tome`을 쓴다. `renji`는 김씨의 **캐릭터 ID**이고 김씨가 실제 사용하는 음성 ID는 `tome`이다. `main.js`는 이 값을 캐릭터 ID로 재해석하지 않고 Sound에 직접 전달한다.

실제 Sound 로딩/분기 함수를 계측한 결과, 백린의 녹음 목록은 비어 있었다. 피격 `hurt`는 `generic` 녹음도 준비되지 않아 소리가 나지 않으며, 출혈 사망은 기본 합성음으로 넘어간다. 캐릭터별 음성 지정은 이번 질문만으로 임의 변경하지 않았다. 이는 피격·사망 등 목소리 묶음이며 장비/재질에 따르는 발소리·금속음과는 별개다.

근거: `src/character_roland.js`, `src/character_bernardo.js`, `src/character_white_scale.js`, `src/characters.js`, `src/main.js`의 `voiceOf`, `src/sound.js`의 `VOICES`/`prepareVoices`/`hurt`/`death`. 계측 원문 `voice-audit.mjs`, 결과 `voice-audit.json`. 파일 디코딩/출력 노드는 모의 구현이며 실제 캐릭터 정의·Sound 조회/분기/합성 생성 경로를 사용했다. 사람의 실제 청취 검사라고 하지 않는다.

## 추가 섬네일

- **1안 기존:** 넓은 원형. 그대로 보존/작업본 연결 유지.
- **2안:** 촘촘한 원형 코일, 오른쪽 위 손잡이. 작은 카드에서 줄기의 양감과 질감이 또렷하다.
- **3안:** 느슨한 8자, 왼쪽 아래 손잡이. 긴 줄의 흐름이 보인다.

새 두 시안은 이미지 생성 도구로 제작한 일러스트다. 실제 3D 무기를 말아서 찍은 게임 사진은 아니다. 투명 원본 PNG와 256² WebP는 `art/weapons/druid_whip_variants_20261024/`에 보존했다. 코드 변환은 크기/포맷 변환뿐이다. 새 시안 중 어느 것도 사용자 선택 전 게임 섬네일을 덮어쓰지 않는다.

비교 페이지 `public/encounters/whip-variants-20261024/`, 64/96px 축소 예와 원본 다운로드 제공. `variants.png`는 이 비교 페이지 촬영, `credits-menu.png`는 실제 로컬 게임의 출처 링크 촬영이다.

## 확인과 한계

- `node docs/audio/whip_20261024/followup/voice-audit.mjs`: 3인물 실제 음성 ID와 로딩/피격/사망 분기 확인.
- `node docs/audio/whip_20261024/followup/audio-game.mjs`: 실제 브라우저 샘플 로딩4/3/1/3/3, 타격/갑옷/파열음 라우팅, 약한 타격 무음 유지, 0.285초 디코딩, 크레딧 링크 표시/클릭 가능 및 라이선스 확인. 실제 전투를 흉내 낸 성능 시험이 아니라 각 소리 함수를 명시 호출한 연결 검사다.
- `node docs/audio/whip_20261024/followup/gallery.mjs`: 폭320/390/844/1280, 그림9개 표시/넘침·페이지 오류 없음, 원본2개 다운로드 확인.
- `npm run build` 통과(기존 번들 크기 경고). 새 MP3/라이선스가 서비스워커 캐시에 포함됨 확인. 전투 변경이 없으므로 물리 대련 반복은 하지 않았다.
- `applied.json`: 승인 MP3 해시와 전투/인물/기존 섬네일 보존 확인. 새 썸네일 미감은 사용자 검토 대기다. 몽골 무사의 음성 연결 오류는 발견만 했으며 수정 전이다.

되돌림: `whipHit`를 이전 `nums('whip/hit',3)`로 복구하면 타격음만 돌아간다. 새 자료와 출처는 보존할 수 있다. 공개 확인 영수증은 `publication.json`을 따른다.
