# 8자 채찍 섬네일 연결 수정

사용자 지적: 꼬임이 이상하고 줄이 이어지지 않는다.

이전3안은 손잡이 아래/위 두 곳으로 줄이 붙고, 위 고리 끝에도 잘못된 연결이 있어 한 가닥의 채찍으로 읽히지 않았다. 이미지 생성 도구로 수정했다. 첫 생성은 아래 고리의 잘못된 연결과 떨어진 끝 조각이 남아 거절하고, 두 번째 수정에서 아래 고리를 열어 한 가닥으로 만들었다.

최종 경로: 손잡이의 위쪽 출구 하나 → 가운데 아래로 통과 → 위 고리 → 가운데 위로 통과 → 아래 곡선 → 고리 안쪽의 붙어 있는 가느다란 끝. 중앙 교차 한 번, 손잡이 아래와 줄 끝 사이에 명확한 빈 공간. 마지막 검수는 원본 및 64/96px 실제 페이지 촬영을 눈으로 확인한 것이며 수학적 끈 복원 검사라고 주장하지 않는다.

원본 `art/weapons/druid_whip_variants_20261024/variant3-original.png`, 축소본 `variant3.webp`. 이전은 `variant3-v1-original.png`/`variant3-v1.webp`로 보존했다. 코드 작업은 크기/포맷 변환뿐이며 창작 편집은 이미지 생성 도구를 사용했다. 공개 페이지는 캐시 혼동을 줄이기 위해 `variant3-v2-original.png`/`variant3-v2.webp`를 참조한다. 기존 공개 그림 경로는 이력으로 남긴다.

- `gallery.mjs`: 320/390/844/1280px 그림 로딩/가로 넘침/오류, 새 원본 다운로드 확인.
- `variant3-card.png`: 수정3안 실제 비교 페이지 촬영. 별도 섬네일 일러스트이며 게임 3D 모델 촬영이 아니다.
- `inspection.json`: 원본/WebP 해시와 육안 확인 항목.
- 1/2안, 게임에 연결된 기존1안, 음원/캐릭터/전투 변경 없음. 음성 재배분은 아직 제안이다. 새3안 사용자 미감 확정/우화 전달은 아직 없다.

공개 완료 여부는 `publication.json` 확인. 새 이미지/정적 페이지 작업이므로 물리 전투 검사를 반복하지 않았다.
