링크·CC0 확인·편집 범위·SHA256은 `sources.json`, 상세 페이지의 설명/라이선스 발췌와 다운로드한 HQ MP3는 `sources/`. 이는 사이트가 제공한 **HQ MP3 미리듣기**이며 로그인 뒤 받는 업로드 원본 WAV/M4A라고 표시하지 않는다. 제작자가 주장한 녹음 현장을 독립 확인한 것은 아니다.

선별 근거는 소스 설명, 지속시간, 파형의 고립된 타격·주변 레벨이다. 사람이 실제로 들어 평가한 것으로 쓰지 않는다. C1/C2는 같은 소리를3번, C3는 다른타격3개. 청취자는 공개 비교 페이지에서 직접 선택할 수 있다. 발췌·모노44.1kHz·피크−6dBFS·1ms/35ms페이드·MP3변환만 시행했으며 EQ/피치/속도/합성레이어는 없다. 피크 일치는 지각 음량 일치가 아니다. 전체 HQ 미리듣기도 제공한다.
