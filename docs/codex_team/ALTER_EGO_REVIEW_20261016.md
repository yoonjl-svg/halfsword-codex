# 광기의 / 밤의 얼터 에고 — 현재 구현 확인과 설계 검토

2026-10-16 사용자 요청. **현재 구현 확인·탐색 측정・설계 규칙**이며 새 캐릭터/무대/능력치의 게임 적용은 하지 않았다. 최신 사용자 확정은 **얼터 캐릭터 = 옷 색 변경 + 추가 변주1개**, **모든 밤 무대 = 새벽3시 + 고유한 밤 요소 최소2개**다. 이전 캐릭터 외형 한 포인트 제안을 대체한다. 유파 동작·보법 변경 없음.

확인 소스 `40fa2805422208113b69104a670466c3cb0c3917`(게임 코드는 공개 `e1f09c3e`와 같고 이후 문서만 추가). 우화 최신 원격을 새로 읽은 결과로 표현하지 않는다.

## 1. 기존 구현

- `src/characters.js`의 `CHARACTER_VARIANTS`에는 **heinrich_mad 1명**. 붉은 눈/흔들리는 안광/짧은 잔상은 `src/mad_eyes.js`이며 본체 외형과 옷 색은 원본 하인리히와 같다. 같은 `look` 객체를 공유한다.
- 일반 변형 규칙은 **숙련도 +1, 상한 5**, 그 숙련도의 원본 실효 실력 수치를 `MAD_SCALE=1.2`로 강화한다. 힘 +30%가 아니다. 반응·준비 대기시간은 1.2로 나누고, 확률/정규화 수치는 1에서 제한한다. 공격성(aggression)은 그대로다.
- 하인리히: 숙련도 **2→3**, 힘 **1.15→1.38(+20%)**, 반응시간 **.21→.175초**, 공격 손 목표 속도 **13→15.6**. 숙련도 단계 기본값도 달라져 준비 속도 **3→4.56**, 막기 속도 **4.5→6.6**처럼 원본 대비20%를 넘는 항목도 있다. 따라서 '전체 성능 정확히20% 증가'라고 표시하면 틀리다.
- 하인리히 변형에는 온몸 타격 취향, 시작 자세, 근접 밀기 취향의 기존 별도 설정도 있다. 수치만 다른 복제본이 아니다. 새 변형에 자동 복제해야 할 일반 규칙으로 해석하지 않는다.
- `밤의` 접두를 가진 정식 변형 무대는 **밤의 포세이돈 신전 1개**, 여정 마지막. `src/stage_poseidon_night.js`는 낮 신전을 재사용하고 하늘·바다·달빛·안개 및 장식을 바꾼다. 다른 어두운 무대가 있다는 것과 밤 변형 체계는 구별한다.

## 2. 힘의 실제 의미

`ai.js:setLevel`이 `fighter.strength`에 값을 전달한다. `fighter.js`에서는 칼팔 관절 토크, 손목 구동, 밀기와 근접 다리 추진에 곱한다. 손목 속도 한계는 **√힘**에 비례한다. 힘1.15→1.38이면 이 한계는 약9.54% 높다. 힘을 올려도 보행 속도나 기력 최대치가 직접 오르는 것은 아니다.

`combat.js:analyze`의 기본 판정 에너지는 실제 접촉 상대속도의 제곱과 유효 질량에서 나온다. 힘을 피해량에 일괄 곱하는 식이 아니다. 가속·칼 궤적·맞은 부위·시점·날 정렬·무기·방어구 등에 따라 결과가 달라진다. 따라서 근력은 실효성 있는 물리 스탯이지만 모든 공격의 피해/명중/승률을 일정 비율 높이는 강화가 아니다.

현재 소스 탐색: 무기3종 × 힘1.15/1.38 × 같은 시드4개 = **24조건, 각 최대20초**. normal AI의 힘만 바꾸고, 가만히 칼을 든 더미를 상대시켰다. 기력 켬, 감정 능력 끔. 수치24/24 유한, 끝까지 지정 힘 유지. 전체 광기의 캐릭터 비교나 사람 상대 승률 실험이 아니다.

| 무기 | 상위25% 타격 이벤트 평균 판정 에너지, 힘1.15→1.38 | 더미 사망 조건 수 / 각4조건 |
|---|---:|---:|
| 롱소드 | 139.7→187.5 J | 2→4 |
| 에스토크 | 34.3→38.9 J | 1→0 |
| 츠바이핸더 | 114.9→87.1 J | 1→0 |

롱소드에는 강화가 보였지만 다른 두 무기에서 처치가 개선되지 않았다. **힘 상승이 무기 전반의 일관된 강화라고 보증할 수 없다.** 힘이 바뀌면 이후 접촉·AI 상태도 달라지며, 일찍 사망한 조건은 측정 시간과 타격 수가 다르다. 같은 타격의 인과적 피해 배율도 아니며 표본4개로 최적값·전체 밸런스를 결론짓지 않는다. 과거 `docs/characters.md`의 다른 소스 실험은 이번 결과와 구별한다.

재현: `node tools/sim/strength_variant_probe.mjs /tmp/strength-variant-probe` (현재 기본 설정, 시드901~904). [원자료](alter_ego_20261016/strength-probe.json), [집계](alter_ego_20261016/strength-summary.jsonl). 이번 조사에서 기준 관문 재실행은 하지 않았다(게임 코드 변경 없음).

## 4. 얼터 에고 외형: 색 변경 + 추가 변주1개

**2026-10-16 최신 사용자 지시:** 얼터는 **원본과 확연히 다른 옷/갑옷 색 + 그 인물만의 추가 변주1개**, 총2가지 외형 차이로 설계한다. 색만 바꾸거나 색 변경과 장신구 변경 중 하나를 고르는 이전 제안을 대체한다. 추가 변주는 인물의 다른 면을 보여주는 장신구·가림천·동행 동물 등으로 한다. 모델·유파 동작·보법·장비 판정은 가능한 범위에서 재사용한다.

| 캐릭터 | 첫 변화 | 추가 변주1개 — 사용자 지정 예시 |
|---|---|---|
| 랴오 | 원본과 다른 옷 색(구체 배색 미정) | 한쪽 안대를 대신해 **양눈 전체를 천으로 동여맨 장님 검객** 외형 |
| 라트나 | 원본과 다른 옷 색(구체 배색 미정) | 기존 동행 동물 대신 **어깨 위 이구아나** |

랴오의 가림천은 눈 전체를 가리는 외형이 우선이다. 기존 하인리히의 붉은 안광을 모든 새 변형에 노출해야 한다는 규칙으로 확대하지 않는다. 라트나는 현재 원숭이의 등짐 위 배치와 구별하여 이구아나를 사용자 지정대로 어깨에 둔다. 동물 추가를 장식2개 추가로 해석하지 않고 동행 동물 교체 하나로 센다. 눈 가림·동물 교체가 감지 범위·전투 능력 변경을 자동 승인한 것은 아니다.

후보(기획, 미적용): 하인리히 은빛 판금→먹철, 마르그레테 먹색 판금→밝은 상아색 판금, 랴오 청색 도복→녹슨 주황/황토. 전원을 검정으로 만드는 대신 원본의 색조와 명도에 대비를 준다. 피부·머리·무기까지 함께 뒤집는 자동 RGB 반전은 쓰지 않는다.

기술 주의: `look` 팔레트가 있지만 `outfits.js`의 하인리히 판금 등은 색상 상수를 직접 사용한다. 팔레트 한 칸만 바꾸어서는 전신이 바뀌지 않는 인물이 있다. 공통 팔레트 연결을 보완하고 원본과 변형의 데이터/재질을 분리해야 정상판까지 같이 바뀌지 않는다. 색 변경을 방어구 종류·파손·피격 판정 변경과 섞지 않는다.

밤 무대에는 어두운 옷이 배경에 묻히지 않도록 명도·외곽 반사광을 함께 확인한다. 첫 구현 보고는 같은 카메라/거리의 원본-변형 게임 스크린샷을 낮·밤 조건에서 촬영한다. 이번 문서는 화면 변경 보고가 아니며 새로운 외형을 만든 것처럼 기존 사진을 사용하지 않는다.

## 5. 밤 무대 확장 방향

**사용자 추가 지시:** 모든 밤 무대의 시간은 **현지 새벽3시(03:00), 깊은 밤**으로 통일한다. 낮 무대의 서로 다른 시간대·다양성은 유지한다. 밤의 공통 시각 안에서도 계절·지형·날씨·밤 생태·인물의 흔적으로 무대별 차이를 만든다. 이는 실시간 시계에 따라 바뀌는 기능이 아니라 무대의 연출 기준이다.

밤 스테이지는 '색만 바꾼 무대'가 되면 안 된다. **그 무대만의 밤 요소를 최소2개** 넣으며 캐릭터 또는 스테이지와의 연관성을 암시한다. 시간·색·밝기 변경만으로 두 요소를 충족했다고 세지 않는다. 초안의 '무대 기믹 한 가지 제한' 제안은 폐기했다. 캐릭터는 색+추가 변주1개, 무대는 깊은 밤+고유 요소 최소2개의 서로 다른 규칙이다.

- **얼어붙은 만:** 사용자 예시 **오로라 + 기존 곰에 더한 새끼곰**을 첫 기획안으로 기록. 현재 `stage_frozen_bay.js`에는 돔 앞에서 결투장을 바라보는 북극곰이 실제로 있다. 오로라/새끼곰의 밤 변형은 아직 구현되지 않았다. 제안: 오로라는 북방의 밤 풍경, 곰 곁에 붙어 쉬는 새끼는 관계를 드러내는 가까운 단서로 역할을 나눈다. 새끼를 기존 곰의 정확한 자식/가족이라고 서사 확정하거나 공격 대상으로 만들지는 않는다.
- **기준 사례, 현재 밤의 포세이돈:** `stage_poseidon_night.js`의 하인리히가 건 찢어진 검은 천(350줄), 석상 앞 은화·꺼진 초 둘/켜진 초 하나·마른 꽃 제물(372줄). 후자는 누군가 조금 전에 다녀간 흔적을 암시한다. 달·화로·불티 외에 이런 장소/인물의 단서가 이미 있다. 제물의 주인을 코드 이상으로 단정하지 않는다.

설계 권고: '밤의 자연/공간 변화'와 '인물 또는 장소의 사연을 보여주는 변화'를 한 가지씩 배치하면 두 요소의 역할이 겹치지 않는다. 이것은 권고이며 사용자가 요소 종류를 반드시1+1로 제한한 것은 아니다. 단순 어두운 색·전 무대에 똑같이 넣는 달/횃불만으로 고유 요소2개를 채웠다고 간주하지 않는다. 전투 규칙을 새로 추가해야만 밤 요소가 되는 것은 아니다.

원본 지형·충돌을 공유하고 전투 면적2배를 유지한다. 밤 하늘·조명·안개·환경음과 고유 요소를 별도로 구성한다. 눈·칼·기력 바를 읽을 수 있을 정도의 밝기는 확보한다. 기획 단계에서 두 요소·관계의 암시·전투 카메라에서 보일 위치를 기록하고, 구현 보고에는 실제 게임 스크린샷을 넣는다. 새 밤 스테이지 전체 목록·순서·해금 조건·인물 짝은 이번 확인으로 확정하지 않았다.
