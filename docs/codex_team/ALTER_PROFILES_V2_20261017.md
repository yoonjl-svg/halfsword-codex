# 얼터 초상 v2 — 얼굴 비중·반대 각도·표정 수정

사용자가 v1의 완성도, 인물별 얼굴 크기 차이, 기본 캐릭터와 같은 각도/입매/표정을 지적했다. 16명 전체 재제작과 실제 그림 검토를 완료했다. 원본only·low0·액자1·정사각형은 유지한다.

## 수정 기준

1. 얼굴 크기는 머리카락·모자·왕관 전체 외곽이 아니라 실제 얼굴의 이마~턱, 눈선~턱을 보고 맞춘다. 머리와 윗가슴의 흉상. 나이·골격 차이를 똑같은 얼굴로 만드는 것은 아니다.
2. 각 기본 초상과 반대쪽을 향하는3/4 시점. 기본을 직접 확인한 좌우 방향표를 사용한다. 눈동자만 돌리거나 전체PNG를 기계적으로 뒤집지 않는다. 비대칭 장비의 캐릭터 기준 좌우와 공통 좌상단광을 보존한다.
3. 기존 얼굴의 인상·골격·나이를 지키되, 옛 프롬프트의 입매/각도/표정 고정 요구는 철회한다. 아르토리아=절제된 우월감, 랴오=미소를 거둔 집중, 토메=계산적인 얕은 미소, 오마리=피곤하고 완고함, 투야나=고요하고 감정이 옅음. 과장된 광기나 전원 같은 찡그림으로 바꾸지 않는다.
4. 허리 소품을 보여주려고 카메라를 빼지 않는다. 마야 문서 주머니/토메 열쇠의 실제 부착 위치는 유지하되 흉상에서 잘리는 것은 허용한다. 장비를 가슴으로 옮기지 않는다.
5. 선·명암·재질 묘사는 승인 기본 원본의 정밀도를 기준으로 한다. 최종 이미지를 작게 한 전체 갤러리와 개별 원본에서 함께 평가한다. 얼굴 비중의 숫자만 맞추고 납득되지 않는 그림을 통과시키지 않는다.

## 선행4장 실제 검토

- 기본 방향표 확인 완료: 화면 왼쪽을 보는 기본5명(아르토리아·랴오·토메·오마리·마야)은 수정 얼터에서 오른쪽, 나머지11명은 왼쪽을 본다.
- 첫 생성4장 실제 확인: 반대3/4 방향과 새로운 눈매/입매 확인. 랴오의 미소를 거둔 집중과 마야 근접 흉상의 얼굴 비중은 수용.
- 아르토리아는 얼굴이 다른3명보다 작고 금관이 다시 커 보여, 얼굴 비중 약10~12% 증가/세로 위치 아래로/금관 자체 약20~25% 감소를 재요청. 왕관이 땋은 옆머리 전체를 둘러 거대해지는 이전 거절안을 되살리지 않는다.
- 토메는 얼굴 크기는 충분하나 눈선이 높아 흉상 배치를 약3~4% 아래로 보완 요청. 최종숫자 강제보다 랴오·마야와 나란히 보는 시각적 통일성을 기준으로 한다.
- 얼굴 비중 수치는 수동 시각 추정이며 자동 정밀 계측이나 실제 화가의 머리모델 치수로 주장하지 않는다. 원본 얼굴의 골격/나이를 지키면서 카메라 배치로 조절한다.

## 6명 중간 검토

아르토리아의 얼굴 확대·작은 금관과 토메의 세로 배치 보완을 실제 그림으로 확인했다. 랴오·마야·오마리와 함께 수용. 투야나는 기존 따뜻한 미소가 남아 표정만 중립화 요청했다. 앞머리 때문에 드러난 이마 면적이 작은 것을 얼굴 자체가 작다고 오인하지 않고 눈~턱 비중도 함께 확인했다. 해당6명 얼굴 크기는 자연스러운 골격 차이를 유지하는 범위로 맞아졌다.

`first-two-comparison.png`는 부모가 기본/수정 랴오·마야 이미지를 HTML에 표시해 촬영한 비교 화면이다. 이미지 픽셀을 편집하거나 새로 합성한 원본이 아니며, 최종16명 갤러리 검토와 별개인 중간 증빙이다.

## 10명 중간 검토

슈바르츠·이졸데·다라이시의 수정본도 실제 확인했다. 반대 방향, 눈~턱 비중, 부러지지 않은 뿔/회색 머리, 이졸데의 원래 앞머리와 어깨선 단발/길드 조끼, 다라이시의 애쉬 실버/검정 복식/붉은 끈을 유지했다. 하인리히는 방향 전환에서 흉터가 보이는 쪽 뺨으로 옮겨져 실제 오른뺨 위치로 제한 교정 요청했다.

토메 외눈안경은 게임 `src/outfits.js`의 `librarianHead` 좌표 `−RZ`와 왼쪽=`−z` 정의를 확인했다. v2의 해부학적 왼쪽 눈 배치가 맞으며, 이전 초상의 화면 위치를 단순 고정하지 않는다.
