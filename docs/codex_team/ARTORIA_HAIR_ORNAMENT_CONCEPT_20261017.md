# 아르토리아 머리 장식 · 대체된 초기 제안

사용자 요청: 머리 장식도 고안. 은발·검은 궁정 예복·작은 붉은 목걸이에 맞춘 세 가지 창작 디자인이다. 실존 유물의 정밀 복원은 아니다.

1. **금세공 머리빗(추천)**: 한쪽 관자놀이 위에 가는 잎3장과 작은 진주를 비스듬히 배치. 은발 위에서 읽히는 탁한 금색, 기존 아이보리 뒤 리본 유지. 목걸이와 같은 큰 붉은 보석은 중복하지 않는다.
2. **낮은 진주 반관**: 정수리 앞부분을 따라 얇은 금테/작은 진주. 중앙 뾰족한 왕관은 피하고 낮게 밀착한 귀족풍 실루엣. 기존 뒤 리본 유지.
3. **검은 벨벳 머리띠**: 가는 검은 띠, 한쪽 금장과 작은 진주1개. 뒤 리본도 검정으로 통일하는 절제된 방향.

질문으로 선택지를 전달했다. 선택/구현 전. 목걸이 v7 조정과는 별도이며 현재 소스에는 머리 장식이 없다. 우화 미발송.

사용자 후속: 세 작은 장식 대신 **더 크고 화려한 모자나 관**. [백합 금관 시안](ARTORIA_CROWN_20261017.md)으로 진행. 위 세 안은 최신안이 아니다.
