## 최신 사용자 문구 확정 — 황약사의 검

초기 구현의 무기명 ‘취생몽사’는 **황약사의 검**(Huang Yaoshi's Sword)으로, 능력 줄은 **취생몽사: 몽롱한 일격**으로 변경한다. 아래 초기 구현/검증 기록은 당시 이름을 보존한 이력이다.

> 흰 천으로 감싼 검. 오랫동안 풀지 않은 듯 단단히 매여 있다.
> “사람의 가장 큰 번뇌는 기억력 때문이라더군.”
> (취생몽사: 몽롱한 일격)

사용자 확정 문구를 그대로 사용하고 따옴표만 한 쌍으로 정리했다. ‘매이다’의 활용인 ‘매여 있다’가 맞으며, 사용자가 대안으로 물은 ‘묶여 있다’로 임의 교체하지 않았다. 기존 리볼버 설명은 조회만 했다. 이름/설명/능력 문자열만 바꾸며 내부 ID와 물리·카드 추첨·저장은 유지한다. 실제 카드 사진은 `public/encounters/huang-sword-20261016/`에 갱신한다. 우화 전달은 기존 사용자 컨펌 절차를 따른다.

검증: 빌드 성공, 기존 실제 카드 선택/장착/이어하기 검사 통과.1200×675·844×390·568×320에서 이름/설명/능력 줄 넘침 없음, 앱/콘솔 오류0. 휴대폰 카드의 본문은 이전보다 조밀하지만 기존 글자 크기로 모두 표시된다. 문자열 변경이므로 기존 물리 관문을 다시 돌리지 않았다.

## 구현

- 찬다 `epithet`를 수문지기→**식물학자**로 변경했다. 원본/얼터 공통이며 전투 수치·유파·외형은 바꾸지 않았다.
- `brothers_sword`의 정식 이름은 **취생몽사**, 등급은 **에픽**. 기존 `characterOnly:true` 제한을 제거해 일반 플레이어 무기 카드 추첨에 들어간다. 기존 시험용 선택 목록에도 새 이름/등급이 표시된다. 시작 지급품을 늘리거나 대기실에 자동 지급하는 변경은 아니다.
- 능력 줄은 정확히 **황약사: 몽롱한 일격**. `ability`는 카드 설명 문자열이며 별도의 혼란·몽롱·수면·기절 확률 또는 발동 효과를 추가하지 않는다. 일반 둔타의 기존 물리/손상 반응만 사용한다.
- 질량1.6kg, 손~끝.93m, 둔타1.6, 파손0/내구1, 한손, 날/가시/베기/찌르기/갑옷 무시 없음 유지. 레어→에픽에 따라 **등급 공통 power만1.05→1.1**이다(동일한 입력 에너지에서는 이전 대비 약4.76% 증가). 원본 김씨는 철퇴, 얼터는 취생몽사. 내부ID를 유지하여 기존 저장/URL/학교 및 실측 매핑은 유지한다.
- 김씨의 천 감싼 칼 그림과 섬네일은 이전 최신 모델을 그대로 사용했다.
