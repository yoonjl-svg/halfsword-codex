# 다라이시 얼터 · 컨셉 제안 단계

> 후속 사용자 “그렇게 해”로 아래 컨셉 구현 승인. [구현·검증](DARAISHI_BLACK_20261016.md)이 최신이다. 아래 미승인·미구현 표기는 제안 시점의 기록이다.

## 사용자 확정

- 기본 머리색은 앞서 촬영한3번 **따뜻한 애쉬 실버**(`v7-silver-c`). 이전 추천1번/미선택 상태를 대체한다. 이번 대화는 컨셉 우선이며 공개 기본 버전 전환은 다음 구현에 포함한다.
- 얼터도 같은 머리색을 유지하고 **어두운 흑의 검사** 톤으로 간다.
- **다라이시의 정체는 기억을 잃고 흘러든 사사키 코지로**다. 사용자 확정 세계관이며 화면에 바로 공개할지는 미정이다. 임의로 UI 설명/스포일러를 추가하지 않는다.
- 우선 컨셉 제안. 아래 새 외형/세부 서사는 미승인·미구현이며 우화 전달 전이다.

## 제안: 몸이 기억하는 검객

기억을 되찾았다고 확정하지 않는다. 잃어버린 이름과 별개로 검을 쥔 몸에 과거의 흔적이 드러나는 방향. 페르시아에서 얻은 우아한 옷의 재단과 승인된 S곡선 앞섶, 앞머리/슬림한 옆머리를 활용한다.

1. 옷 배색: 푸른 먹색 겉옷, 검보라 안옷, 목탄색 하의. 금빛 선/여밈은 탁한 은색으로. 순흑으로 뭉개지지 않게 재질/밝기를 구별한다.
2. 고유 변주1개: 기존 뒤쪽 머리 묶음에 짧고 해진 붉은 끈 하나. 원래 애쉬 실버색/머리 형태 유지. 자신도 의미를 기억하지 못하는 과거의 물건이라는 제안이다. 실존 코지로의 복식 고증 주장 아님.
3. 기존 임시 얼터의 손목 족쇄는 이 끈으로 대체할 것을 제안한다. 포로/호위 서사는 사용자 확정이 아니므로 새 정체의 기정사실로 연결하지 않는다.
4. 공통 얼터의 절제된 붉은 안광 유지. 얼굴이 보일 때만 약하게 드러나도록 한다. 의상 배색+고유 변주1개 규칙을 지킨다.

실제 전투 동작·보법/수치 변경은 이 컨셉에 포함하지 않는다. 밤 역참의 열린 철창/맨발 자국은 기존 검토안이며 이번 제안만으로 무대를 고치지 않는다. 컨셉 방향을 정한 다음 기본색 확정 반영과 새 얼터를 실제 게임 사진으로 보고한다.
