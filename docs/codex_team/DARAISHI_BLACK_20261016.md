# 다라이시 · 확정 애쉬 실버와 흑의 얼터

사용자가3번 따뜻한 애쉬 실버를 선택하고, ‘몸이 기억하는 검객’ 컨셉에 “그렇게 해”로 구현 승인했다. 기본도 `v7-silver-c`로 전환하고 얼터 `v7-alter2`에 같은 머리색·승인된 슬림한 옆머리/앞머리 한 가닥·곡선 앞섶·목 연결·칼집8mm 보정을 적용했다.

## 외형

- 먹청 겉옷 #28313c, 검보라 셔츠 #403947, 목탄 자락 #303139. 허리띠도 어둡게 맞추고 은색 선/여밈으로 층을 구별한다. 흑의 톤에서도 순검정 한 덩어리로 보이지 않게 면별 명도 차이를 둔다.
- 머리색은 기본/얼터 모두 #93877e, 밝은 결 #aa9e93, 땋음 #c9c0b3, 앞머리 결 #bcb2a6.
- 기존 뒤쪽 묶음의 상아색 장식/얇은 금속 고리를 **짧고 해진 붉은 끈 하나**로 교체. 같은 묶음 자리, 천 띠·매듭·약12.7/8.8cm의 두 끝. 머리 형태를 바꾸지 않는다. 기존 손목 족쇄 제거. 옷 배색+고유 변주1개 규칙.
- 공통 안광의 일렁임/잔상을 유지하되 새 다라이시의 빛만65%로 낮췄다. `head.userData.madEyeIntensity`를 안광 생성 때 읽고, 다른 인물은 기본1배를 유지한다. 새 조명/전투 상태 추가 없음.
- 사용자 확정 세계관 ‘기억을 잃고 흘러든 사사키 코지로’는 개발 기록에 보존. 게임/소개 문구에는 이름을 바로 드러내지 않고 기억하지 못하는 붉은 매듭을 묘사한다. 과거 족쇄/호위 설명은 현재 캐릭터 설명에서 교체. 밤 무대의 철창·발자국은 기존 상태 유지.

## 연결과 경계

`looks.js` 기본 선택 → `characters.js` 얼터는 확정된 기본 외형을 명시적으로 참조하고 `daraishiBlack` 지정 → `outfit_alter.js` 전용 색 대응 → `outfit_alter_daraishi.js` 머리끈/족쇄 분기. `outfit_daraishi_front.js`의 기본 전용 제한을 해제해 이미 지정한 앞섶/목 보완을 얼터에 공유. `court_hair`는 새 얼터일 때 묶음 장식만 교체한다. `mad_eyes.js`는 선택적 강도 배율만 추가한다.

기존 v7 외형으로 만든 아카이브 얼터는 옛 배색/족쇄 경로를 유지한다. 새 얼터는 appearanceOnly, 원래 무기 모노호시자오·힘·몸·음성·생리·AI 동일. 다른 유파/보법·공격속도·기력·충돌/갑옷 판정/무대는 변경하지 않는다. 우화 저장소 열람/수정/메시지 전달 없음.

## 확인

- Vite/PWA 빌드 성공. 기본/얼터 실제 전투 각7초: 유한 위치/행렬, JS·렌더 오류0. 이전 공개본 snapshot과 질량·충돌69개·힘·무기 동일.
- 기본 하의·팔/칼집 geometry/material 해시 보존. 승인 앞머리·얼굴/정수리 geometry 해시 동일하며 새 얼터도 기본과 동일. 둘 모두 목 연결부 존재, 족쇄0, 얼터만 매듭1개/끝2개.
- 기본23,278삼각형, 새 얼터23,386(기본 대비108개 추가). 이전 얼터18,022에서 늘어난 주된 이유는 기본에서 승인받은 앞판/머리 보완을 공유했기 때문이다.
- 원본/얼터 숙련도1~5의 AI·무기·몸·힘·음성·생리 동일. 밤14쌍 연결/기존 일반 여정 유지 확인. 이번에는 무대/전투 핵심을 바꾸지 않아 기존 전수 무대/물리 관문을 반복하지 않았다. 과거 물리 관문2개의 낡은 기대값 불일치를 해결한 것으로 표시하지 않는다.
- 같은 밤 조명·시각·카메라로 기본/얼터 실제 전신·앞섶·뒷모습·머리끈/게임 시점 촬영. 사진 색/밝기 보정 없음. 첫 촬영에서 검은 옷 대비 강한 안광을 발견해 다라이시만65%로 낮춘 최종본으로 다시 촬영했다.
