# 다라이시 기본 외형 · 앞섶과 한 가닥의 앞머리

**후속 최신:** [수직 곡선 앞섶·옆머리 슬림화](DARAISHI_CURVE_20261016.md)가 대각선 앞섶을 대체한다. 아래는 첫 시안의 이력이다.

사용자 승인: v7 하의는 유지하면서 상의 앞판을 보강하고 긴 앞머리 한 가닥을 추가한다. **기본에 먼저 적용한 뒤 얼터로 진행**한다. 작업 기준 `f5220f29`, 우리 포크 `codex/refork-20261015`. 상대 저장소 수정/메시지 발송 없음.

## 적용

- 기본 외형만 `v7-front1`. 원본 v7 아카이브와 v8 자리의 빈 검집은 보존한다.
- 따뜻한 아이보리 앞판에 약간 비스듬한 자주색 앞섶, 옅은 금실 가장자리와 작은 잎무늬, 끈 여밈 세 개, 얕은 주름 세 줄.
- 기존 은발과 긴 땋은 머리를 유지하고 한쪽 눈 바깥으로 뺨 아래까지 내려오는 가는 머리 한 가닥. 끝은 가늘게 모은다.
- 페르시아풍의 우아함을 위한 창작 복식이다. 특정 시대 복식의 정확한 복원이라고 주장하지 않는다.
- 새 `outfit_daraishi_front.js`는 머리/가슴/복부의 시각 장식만 추가한다. 형상은 각 신체 부위에 붙이며 충돌·갑옷·질량을 추가하지 않는다.
- 얼터는 명시적으로 기존 `v7-alter1`을 사용한다. 기본 외형의 새 앞판/머리 변경을 자동 복사하지 않는다. 얼터 후속은 기본 화면 검토 뒤다.
