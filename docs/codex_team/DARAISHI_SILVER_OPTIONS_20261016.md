# 다라이시 · 목 연결 수정과 은발 시안 3개

사용자가 목이 떠서 뒷머리가 비치는 문제를 지적하고 에메랄드색을 거절했다. 직전에 승인한 머리 형태는 유지하며 원래 은회색에 가까운 색 변주 정확히3개를 실제 화면으로 제시한다. 이번 후보를 선택한 것으로 처리하지 않는다.

## 적용

기본 `v7-front4`는 `v7-front2`의 원래 은회색/승인 형태에 칼집 안쪽8mm 보정을 유지하고 목 연결부만 추가했다. 기존 열린 옷깃 안에는 목 메쉬가 없었으므로, 가늘어진 셔츠 윗부분과 피부색 목을 겹쳐 가슴–머리를 연결했다. 장식 메쉬만 추가하며 충돌·방어 면적·질량을 바꾸지 않는다. 얼터는 기존 `v7-alter1` 고정.

| 비교 시안 | 바탕 | 밝은 결 | 땋음 | 앞머리 결 |
|---|---|---|---|---|
| 1 진주빛 은회색 (`v7-silver-a`) | #94919b | #aaa7b1 | #cbc8d1 | #bdbac4 |
| 2 푸른 은회색 (`v7-silver-b`) | #7f899b | #959fb0 | #b8c2d0 | #acb7ca |
| 3 따뜻한 애쉬 실버 (`v7-silver-c`) | #93877e | #aa9e93 | #c9c0b3 | #bcb2a6 |

세 시안은 기존 `?look=silver_wanderer:v7-silver-a` 방식으로만 연다. 기본 색은 원래 #77737f이며 후보1을 추천하되 사용자 선택 전 기본에 지정하지 않았다. 원래 앞머리 한 가닥·좁힌 옆머리·곡선 앞섶·칼집 보정은 유지한다.

## 검증

- Vite/PWA 빌드 성공. 실제 전투7초의 유한 변환/JS·렌더 오류0. 이전 에메랄드 실제 실행 snapshot과 비교해 얼터 모든 부위 geometry/material 해시 동일, 기본 앞머리·얼굴/정수리 형상과 하의/팔/칼집 해시 동일. 질량·충돌69개·힘·무기 동일.
- 기본 삼각형23,094→23,278(+184), 얼터18,022 유지.
- 실제 전투24자세/216개의 중앙 옷깃 탐침 모두 가슴 앞 표면에서 차단됨. 그중77개는 새 목/셔츠에 직접 닿고, 나머지는 움직이는 얼굴/팔 등 기존 앞 표면에 가려짐. 같은 자세에서 새 연결부만 제외하면27개가 뒤쪽으로 노출된다. 최초 ‘모든 탐침은 새 목에 닿아야 한다’ 가정은 움직이는 팔/얼굴의 정상 가림을 실패로 분류해 수정했다. 모든 가능한 극단 자세를 증명하는 검사는 아니다.
- 기본 및 후보3개를 고정 시각·같은 밤 조명·카메라에서 실제 게임 촬영, 오류0. WebP 형식 변환만 하며 색/밝기 보정 없음.
- 전투 핵심 변경이 없으므로 직전 앞섶 작업의 공통 관문을 반복하지 않았다. 이전 관문2개의 오래된 기대값 불일치 상태를 이번 작업으로 해결했다고 표시하지 않는다.
