# 일본 흘림 기회 확대 개편안

상태: **사용자 요청에 따른 개편 제안. 아직 게임에 구현·배포하거나 우화에게 발송하지 않았다.**

사용자는 추가 기력 40을 전제로 흘림 기회를 확대하는 개편안을 요청했다. 기력 차감의 이득 자체를 입증하는 정량 전투 실험은 하지 않는다. 이 문서는 그 전제에서 판정·몸꼴·입력 연결을 제안하며, 새 자세나 개별 수치를 승인·검증 완료로 취급하지 않는다.

## 근거와 목적

기존 연구의 독립 36조건에서 막기 제어 중 새 칼 접촉 408회, 흘림 14회, 흘림 없는 조건 26개였다. 408접촉 중 하강 속도 미달 359, 낮은 접점 157, 칼끝이 위 139로 제외 조건이 겹친다. 이는 실제 인간 성공률이 아니라 입력 대본의 기존 기록이다. 수직 속도 3.5→1m/s만 낮춘 선별 후보는 발동 기회가 늘지 않았으며, 지붕 자세를 더 기울이거나 고정한 과거 안은 일부 방어 손해를 보였다.

현 코드에서 흘림 전용 몸꼴은 highC 하나지만, `st.nagashi`는 일본 흘림 기능 보유 표식이어서 판정 자체가 highC 선택 중에만 가능한 것은 아니다. 기존 14회 중 몸꼴 가중치 0.5 이상은 4회였다. 따라서 highL/highR에 단순 플래그를 붙이는 것만으로 해결된다고 말하지 않는다.

목표는 일반 방어의 무조건 성공률을 동방처럼 높이는 것이 아니라, **일본의 위·옆 베기를 받아 바깥으로 흘리는 선택을 사람이 반복해서 노릴 수 있게 하는 것**이다. 성공 시 큰 기력 손실로 전세가 바뀔 가능성을 준다. 자동 공격·비기 연결이나 새 보법은 제안하지 않는다.

## 1. 내려오는 빠르기보다 들어오는 방향과 빠져나갈 방향

- 중앙 위 베기뿐 아니라 좌우 사선·상체 가로 베기까지 대응 범위를 넓힌다. 낮은 다리 공격·곧은 찌르기는 이번 개편에서 기존 막기 대응을 유지한다.
- 전역 아래 방향 속도 3.5m/s와 칼끝 높이의 부호를 공통 필수 조건으로 삼는 대신, **접촉 직전 상대 칼이 방어자의 머리·상체로 들어왔는지**, **실제 두 칼의 접점과 방향이 상대 칼을 몸 바깥으로 흘릴 수 있는지**를 본다.
- 수직/사선/가로 공격에 맞는 실제 접촉 위치로 판단한다. 한 가지 가슴 높이 조건을 전체 동작에 일괄 적용하지 않는다. 느리게 닿아 있는 칼이나 이미 지나간 공격을 새 공격 기회로 세지 않는다.
- 기존 물리 충돌과 미끄러뜨리는 효과는 유지하며 충격 계수 증가는 첫 개편에 포함하지 않는다. 상대 칼을 순간이동시키거나 타격 피해를 소급 취소하지 않는다.

## 2. 첫 접촉 한 순간 대신 짧은 접촉 구간

- 현재는 떨어졌다 새로 닿은 한 스텝에서만 판정한다. 처음에는 약간 맞지 않더라도 바로 이어서 칼을 비껴 세우고 실제로 흘려낼 기회를 준다.
- 초기 제안은 **접촉 시작 후 약 0.12초 이내, 같은 공격의 이어지는 칼 접촉**을 다시 확인하는 방식이다. 수치는 검토용이며 실측 최적값이 아니다. 이는 버튼을 누른 뒤 0.12초만 유효하다는 뜻이 아니다.
- 접촉 직전의 접근 방향은 보존하여 충돌로 속도가 꺾인 뒤의 값만으로 공격을 놓치지 않는다. 반면 발동 자세·실제 접촉·몸 바깥으로 향하는 경로는 현재 상태로 확인한다. 이전 조건들을 서로 다른 순간에서 임의로 합쳐 성공시키지 않는다.
- 같은 공격의 추가 기력 40은 한 번만 청구한다. 접촉이 이어진다고 매 프레임 반복 청구하거나 접촉 구간을 무한 연장하지 않는다. 별도 재사용 대기시간·판당 횟수 제한은 제안하지 않는다.

## 3. 중앙 지붕 + 좌우 비껴받기

- **중앙**: 팔 꼬임을 해결했던 기존 우케나가시 지붕을 출발점으로 유지한다. 흘림을 늘리려고 칼끝만 크게 내리는 이전 방식은 반복하지 않는다.
- **좌우**: 기존 일본의 좌우 막기 자리를 기반으로, 검 든 팔을 먼저 가리면서 상대 칼이 몸 바깥으로 빠질 기울기를 갖는 변형을 제안한다. 정수리 지붕을 좌우 공격에 모두 강제하지 않는다.
- 양손 칼은 단순 좌우 반전 시 팔이 꼬인 이력이 있다. 좌우를 별도로 구성하고 실제 관절·팔/목 노출을 확인해야 한다. 실존 고류의 특정 기술을 고증 복원했다고 주장하지 않는다.
- 성공 뒤에는 해당 방향의 자세를 유지하며, 현재처럼 무조건 중앙 우케나가시로 옮기지 않는다. 사용자가 공격하면 기존 연구의 입력 우선 해제를 적용한다.

## 4. 조작과 보상

- 기존 막기 버튼을 사용한다. 공격 방향에 맞는 세 변형 선택은 기존 방어 제어를 보완해 연결한다. 새 버튼·엄격한 순간 누르기 조건·강제 옆걸음을 넣지 않는다.
- 위협 방향이 잠깐 흔들린다는 이유만으로 접촉 중 자세를 바꾸지 않는다. 실제 접촉이 이어지는 동안의 방향 안정성을 확보하되, 다른 공격·명확한 위협 변화와 사용자 공격 입력에는 반응한다. 기존 실패한 장시간 지붕 고정으로 되돌리지 않는다.
- 성공 시 공격자에게 **기존 공격 비용과 별도로 고정 40**. 추가 팔/손목 제어력 저하는 기본 조합에 넣지 않는다. 기존 일반 막기 비용은 유지한다.
- 플레이어와 AI의 성공 판정·추가 비용은 같은 원칙을 사용한다. 사람이 보지 못하는 공격 예약·AI 모드에 의존해 성공시키지 않는다. 이 변경으로 일본 AI도 더 위협적이 될 수 있으므로 인간이 공격자일 때도 조작을 확인해야 한다.
- 사용자가 결정한 −70 진입 / 자연회복 / −35 해제 탈진안은 별도 확정 사항이며, 흘림 보상과 함께 적용할 때 재충전 보상이 되지 않도록 연결한다.

## 제안하는 진행 순서와 확인 범위

1. 기존 몸꼴을 보존한 채 접근/이탈 방향 판정과 짧은 접촉 구간을 구현한다.
2. 새로 대응할 좌우 공격에서 기존 자세가 실제 접점을 만들지 못하는 부분에 좌우 비껴받기 변형을 보완한다. 판정 확대만으로 필요한 빈도와 조작감을 확보하면 불필요한 자세 변경은 줄인다.
3. 실제 게임 화면에서 정수리·좌우 사선·상체 가로 베기를 받고, 공격자/방어자 양쪽으로 확인한다. 사람의 작은 입력 시점 차이에 기회를 놓치지 않는지, 팔/목을 과하게 내놓는지, 무효 접촉으로 40이 빠지는지, 같은 공격의 중복 차감이 있는지를 확인한다.

기력 패널티의 존재 가치를 증명하는 대량 대련은 하지 않는다. 위 확인은 구현과 조작 검토이며, 아직 수행한 결과가 아니다. 판정 범위 확대가 실제 흘림 빈도 증가나 순이득을 보장한다고 미리 말하지 않는다. 반복해서 노릴 수 있는지와 약30초 공방의 실제 득실에 대한 사용자의 판단을 우선한다.
