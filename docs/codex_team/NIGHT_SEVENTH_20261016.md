## 구현

- 다라이시: 원본 은발·얼굴·장검을 유지하고 먹청색/탁한 동색 옷, 왼손목에 끊어진 족쇄 하나. v10 치마의 정점 색상도 함께 변경한다. 족쇄는 빈 철띠와 짧은 고리3개, 방어구/질량/구속 조건 없음. 공통 붉은 안광 사용.
- 새벽3시의 역참: 기존 아치방 한 곳의 철창이 열리고 안에는 빈 깔개와 끊어진 잠금 사슬. 맨발 자국48개가 우물 옆을 돌아 문루 밖으로 이어지고 소금 먼지 속에서 끊긴다. ‘누가 누구를 지키고 있었는가’를 암시한다. 특정 역사적 사건·복식의 고증 복원은 아니다.
- 기존 벽과 문기둥에 작은 기름등3개, 달빛으로 인물/건물 가독성 확보. 밤 생성에서만 석양 원반과 바닥의 구운 주황빛을 제거한다. 바람·돌바닥 발소리·기존 호송 고리 소리를 재사용한다.
- 새 장식은 결투장 밖, 추가 물리 충돌0. 맨발 자국의 최소 반경15.20m, 전투장 반경9.192388m 유지. 낮 무대 파일·낮 표시 이름 ‘소금 사막’·일반 여정 편성 유지. 직접 대련에서는 `dayr_night/silver_wanderer_mad`, 원래 무기 `monohoshizao` 사용. 총14쌍.

## 연결과 이식

신규 `stage_dayr_night.js`는 기존 dayr, night wrapper, workshop/animate에 의존한다. `stages.js`에 빌더/표시명/상대를 등록한다. 신규 `outfit_alter_daraishi.js`는 `outfit_alter.js`에서 호출하고 `characters.js`에 외양 전용 변형을 추가한다. `sound.js`와 `stage_detail_sound.js`의 night 별칭은 바다 배경음으로 잘못 폴백하지 않도록 필요한 의존 변경이다. 전투·유파 핵심은 변경하지 않는다.

되돌림: 구현 커밋과 검토 페이지 커밋을 함께 revert. 우화 이식 시 최신 받는 쪽 main 위 전달 가지에서 위 연결의 현재 호환성을 먼저 확인한다. 전체 파일 동일성은 요구하지 않는다.
