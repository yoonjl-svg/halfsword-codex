## 재사용할 판단·검증

- 총상처 감소를 그대로 막기 실력으로 해석하지 않는다. 실제 관측 시간, 사망, 목/머리의 치명상, 한 충돌의 여러 부위 상처를 구별한다.
- 피해 무효는 방어자만이다. 공격자도 죽을 수 있다. E 훈련10씨앗 노출1200→1178.4초, E2 독립5씨앗은 두 버전 모두489.842초였다. ‘모두120초 완주’라고 하지 않는다.
- 낮은 막기는 좌우/유파마다 물리 효과가 다르다. E2를 고른 뒤에는 씨앗1–15를 독립 검증이라고 부르지 않았다.
- 버튼 놓기/재누르기·준비만·범위 밖85판에서 놓은 동안 유지0/준비 발동0/범위 밖 발동0. 브라우저4장 실제 사진은 Node와 같은 결과, 예외/HTTP 실패0.

## 남은 방향과 전달 상태

전체 막기 개선은 아직 못 풀었다. 다음 연구는 ‘원래 접촉13을 얼마나 보존했는가’만 좇기보다 **실제 위험 차단 / 해당 유파 자세의 물리 도착 / 흘림 / 인간 조작**을 각각 검토해야 한다. 공통 유지 타이머를 다시 넓히거나 실패한 중립 처리·재취득을 좋은 버그 수정처럼 채택하지 않는다. E2도 실제 피해에서 충분히 작동한 비교가 없으므로 배포하지 않는다.

이번에는 우리 포크의 연구 결과만 보존했다. 사용자에게 실제 화면/결론을 보고한 뒤 컨펌과 전달 지시가 있으면 최신 우화 main을 다시 기준으로 맞춰 ‘보냄’ 규약을 적용한다. 공개 게임 교체/우화 저장소 쓰기/새 메시지 발송 없음. 기력·콘텐츠·이전 전달 메모를 이번 연구 성과로 섞지 않는다.
