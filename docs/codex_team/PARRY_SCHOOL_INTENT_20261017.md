# 유파의 역할을 기준으로 한 막기 연구 · 사용자 정정 2026-10-17

## 사용자 지시와 현재 상태

확장 연구 결과 뒤 사용자가 유파별로 다른 유지시간을 적용할 가능성을 물으며 목적을 명시했다.

> ‘100% 막는 것이 좋은 막기는 아니다’
> ‘높은 막기 확률이 아니라 유파별 컨셉을 적절한 막기가 보조해야 한다’

| 유파 | 사용자가 정한 역할 |
|---|---|
| 동방 | 막기 특화. 더 높은 성공률, 이를 위한 고유 몸꼴3종 |
| 일본 | 평균적인 성공률. 일부 막기가 상대 공격을 빗겨 흘리며 실제 이득이 있어야 한다. 현재 판당 발동 횟수가 기대 이하 |
| 이베리아 | 평균적인 성공률. 일부 막기가 쳐내듯 작동 |
| 독일 | 가장 못 막지만 카운터를 노리는 공격적 성격 |
| 이탈리아 | 연구중 |

이는 새 실험의 **설계 목표**다. 현재 게임에서 이 성능 순서가 이미 실현됐다는 뜻이 아니다. 유파별 유지시간 수치는 아직 정하지 않았고 이번 대화에서는 게임 코드를 변경하지 않았다. 원래 실험 결과/성공기준을 소급해 고치거나 실패 후보를 통과로 바꾸지 않는다.

## 샛별의 해석·권고 (구현 확정과 구별)

유파별 조정은 타당하다. 일본만 한정한 E2가 일부 대본을 개선한 사실도 범위를 분리할 이유가 된다. 다만 ‘동방은 길게, 독일은 짧게’라는 한 숫자만으로 역할이 구현되지는 않는다. 실제 칼의 도착/충돌/이탈과 읽은 방향의 유효성을 함께 본다.

여기서 유지시간은 **막기 버튼을 누른 동안 선택한 방향을 붙잡는 시간**이다. 버튼을 놓은 뒤 자동으로 막거나 플레이어의 공격 입력을 지연시키는 시간이 아니다. 다음 세 구간을 분리해서 평가한다.

1. 접촉 전: 손 입력은 끝났지만 칼은 아직 오는 경우 같은 방향을 얼마나 유지할지.
2. 방향 변경: 속임수/찌르기 전환을 알아차렸을 때 기존 방향을 풀고 새 방향으로 옮길지.
3. 접촉 후: 칼을 흘리거나 쳐내는 실제 동작이 끝나는 때와 플레이어가 다음 입력을 할 수 있는 때.

| 유파 | 유지·전환 연구 방향 | 주요 판정 지표 |
|---|---|---|
| 동방 | 거정세·어거세·요략세의 올바른 선택과 전환 우선. 맞는 방향에서는 실제 타격이 지날 때까지 충분히 유지. 틀린 줄을 오래 고정하지 않음 | 동일 공격/거리/무기 조건에서 높은 유효 방어율, 치명 부위 피해 억제, 3몸꼴의 실제 기여 |
| 일본 | 일반 막기는 평균 성능. 흘릴 수 있는 내려베기에만 우케나가시의 준비·접촉 유지 시점을 맞춤 | 정상 대전의 판당 흘림 수/0회인 판의 비율, 흘릴 수 있는 기회당 발동률, 흘린 뒤 공격선 이탈/상대 복귀 지연/플레이어 선택 가능한 반격·이동 여유 |
| 이베리아 | 해당 방향의 접촉 순간에 쳐내는 동작이 작동하고, 불필요하게 붙잡고 있지 않도록 검토 | 평균 방어 성능, 실제 상대 칼 이탈 방향·거리, 다시 위협이 되는 시점, 플레이어 다음 동작까지의 시간 |
| 독일 | 순수 방어의 안정성은 낮게 허용하되 필요한 접촉을 확보하고 맞받아칠 수 있는 공격 전환을 우선 | 막기 단독 성적과 별도로 인간의 반격 입력 성공/시간·교환 피해·카운터 실효성 |
| 이탈리아 | 현 상태를 비교 기준으로 보존 | 독립 연구 후 역할 결정 |

독일의 역할을 ‘아무 이유 없이 막기를 실패시키기’로 구현하지 않는다. 기존 성능을 낮추는 구체 변경이 필요하면 반격 이득과 함께 검토하며, 이번 목표를 임의 하향 적용 승인으로 해석하지 않는다. 순수 막기만 누른 채 서 있는 시험으로 공격형 유파 전체의 가치를 판단할 수 없다.

## 기존 실험에서 재사용할 근거

- E의 공통 낮은 줄 유지: 일본17→15/228, 동방17→17이지만 동방에서는 신규부상1/구제1. 유지시간을 늘리는 것과 성공률 향상은 단조 관계가 아니다.
- E2 일본 lowL 한정은17→15/228이지만 정수리 B 몸꼴0/13 그대로, 독립AI 상처92→91. 일본의 흘림이라는 핵심 역할을 개선한 안으로 보지 않는다.
- 우화 기존 연구 `docs/strike/ukenagashi_talho_2026-10-17.md` §12-3: 흘림38회 중 상대 칼이 막을 자리로 복귀하는 시간이 늦어진 경우8회, 해당8회의 지연 .18~.81초/중앙 .31초. 칼이 움직였어도 실제 빈틈이 안 생긴 경우가 많았다. **빈도 개선과 발동 가치 개선은 별도 과제**다.
- 흘림을 고노센과 자동 연결하지 않는 기존 결정은 유지한다. 실제 물리 이득을 평가한다고 자동 비기·기절·추가 피해를 승인받은 것은 아니다.
- 이베리아의 쳐내기는 자세 모양만 보고 효과를 확언하지 않는다. 실제 접촉 뒤 상대 칼의 경로를 계측한다.

## 다음 실험의 평가 방식

유파별로 별도 후보를 만들고 한 유파 안에서도 막는 방향과 접촉 단계를 구별한다. 아직 검증되지 않은 유지시간을 최적값처럼 제시하지 않는다. 기존 실패 후보를 공통 시간만 바꿔 대규모 반복하지 않는다.

비교 시 같은 공격 구성·거리·무기/숙련·기력 조건을 맞춘다. 헛침을 막기 성공으로 세지 않으며, 한 번의 공격에서 여러 부위 상처나 연속 칼 접촉이 생기는 것을 따로 센다. 순수 막기와 막은 뒤 인간이 가능한 입력을 이어가는 조건을 분리한다. 자동 AI 반격 성공을 사람의 성공으로 대신하지 않는다.

공통 하한은 조작 의도 준수·예측 가능한 약점·정상 입력에서의 이유 없는 치명 회귀 방지다. 그 위에서 동방의 방어 안정성, 일본의 유효 흘림, 이베리아의 쳐내기, 독일의 공격 전환을 각각 평가한다. 모든 유파가 동일하게 잘 막아야 한다는 점수 하나로 합치지 않는다. 기존 테스트의 원자료·실패 기록은 그대로 보존한다.

우화 자세/보법·물리·막기 손속도·NAGASHI는 현 단계에서 변경하지 않았다. 유지시간만으로 일본의 발동 가치를 확보하지 못한다면 그 한계를 분리 보고한다. 이번 기록은 설계 목표 정리이며 게임 적용이나 우화 메시지 발송이 아니다.
