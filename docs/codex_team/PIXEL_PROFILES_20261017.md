# 기본 캐릭터 17명 도트 프로필 · 첫 시안

사용자가 흘림 개편과 프로필 제작의 병행을 요청했고, 기본 캐릭터부터 시작한 뒤 플레이어도 포함하도록 명시했다. 기본 NPC 16명 + 플레이어 1명이며 얼터는 제외했다.

## 결과와 범위

- 검토 페이지: `public/encounters/pixel-profiles-20261017/index.html`.
- 5개 원본 PNG 시트, 17개 ID/이름/호칭/외형 버전/표시 영역/해시는 같은 경로의 `profiles.json`.
- 생성된 도트 프로필 시안이다. 실제 게임 렌더 또는 게임 내 프로필 UI 적용 완료라고 보고하지 않는다.
- 플레이어는 케틀 햇을 낮게 눌러써 눈을 가린다. 기존 크림색 옷·갈색 교차 끈 유지. 기본 브론은 금발에 모자 없는 모습이며 플레이어와 구별한다.
- 기본 다라이시의 애쉬 실버·흰 옷, 기본 아르토리아의 판금과 은발, 랴오의 외눈 안대, 기본 라트나의 원숭이 등 현행 식별 요소를 참조했다. 얼굴은 픽셀 일러스트로 해석한 첫 시안으로 사용자 검토 대상이다.
- 장식 프레임을 포함한 원본 시트는 유지하고 웹페이지에서 캐릭터별 영역을 표시한다. 생성 도구 이외의 방식으로 원본 이미지를 수정하지 않았다. 김씨의 삿갓이 옆 캐릭터 영역에 겹치던 배치는 생성 도구로 보정했다.
- 첫 시안의 카드 비율은 정사각형과 세로형이 섞여 있다. 실제 UI 채택 시 최종 규격을 통일할 수 있으며 현재는 외형·화풍 검토가 목적이다.
