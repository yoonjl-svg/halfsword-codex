# 액자 1 프로필 원본과 low — 2026-10-17

사용자 확정 제작 방식: 고화질 원본을 먼저 만들고 액자 1을 적용해 저장한 뒤, 그 완성 원본에서 픽셀을 4배 키운 `low`를 만든다. 두 파일을 함께 보존한다. 생성 도구로 low를 다시 그리지 않는다.

## 결과와 최신 수정

- 기본 캐릭터 16명+플레이어 총 17명. 각 원본과 low는 모두 **1254×1254 정사각형**이다.
- 플레이어는 정면. 낮은 케틀햇이 눈을 가리는 원래 외형을 유지했다.
- 병마용 첫 수정은 표면만 흙으로 바뀌고 이목구비가 사람처럼 정밀하다는 사용자 지적을 받았다. 후속 수정은 눈을 동공 없는 얕은 홈으로, 눈썹·코·수염을 단순한 흙 조형으로 바꿨다.
- 사용자가 “병마용은 고쳐서 원본 파일에 덮어써”라고 명시했으므로 작업 원본 `terracotta.png`를 새 이미지로 덮어썼다. 새 low는 이 수정본에서 변환했다. 다른 16명의 원본은 다시 생성하지 않았다.
- 액자 1·2·3 그림과 이전 17명 시안, 생성형 도트 비교 샘플은 기존 경로에 남아 있다. 액자 3안을 우화에게 보내는 시점은 사용자가 나중에 지시할 때이며 **현재 발송하지 않았다**.

이 이미지들은 게임용 초상 자산이며 실제 3D 게임 화면을 찍은 사진이 아니다. 게임 내 프로필 화면에 연결하는 작업과는 구별한다.

## low의 정확한 의미

[변환 도구](../../tools/content/build_profile_low_20261017.mjs)는 브라우저 canvas의 최근접 표본으로 원본을 4픽셀 블록마다 한 색으로 줄인 뒤 같은 크기로 되돌린다. 색 보정·재생성·그림 수정은 없다. 각 low의 모든 4×4 블록이 같은 RGBA인지 검사한다.

1254는 4로 나누어떨어지지 않으므로 임시 처리 공간의 마지막 행·열만 연장하고, 결과는 원래 1254 크기로 자른다. 유효 격자는 314×314이며 오른쪽·아래 마지막 블록만 2픽셀이다. **원본 이미지 자체의 크기나 바이트는 바꾸지 않는다.** 한 이미지당 98,596블록, 17명 모두 검증했다. 파일별 원본과 low SHA256을 기록했다.

재현: 저장소에서 `node tools/content/build_profile_low_20261017.mjs`. 도구는 기존 보존 파일의 내용이 다른 경우 자동 덮어쓰지 않는다. 사용자가 원본 수정을 명시할 경우 수정 이력을 남겨 현재 원본을 교체하고 해당 low를 다시 만든다.
