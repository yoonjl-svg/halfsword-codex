# 밤의 소금길 역참 — 잠들지 않은 대상단

## 사용자 확정과 표현

기존 탈옥 서사는 거절됐다. 사용자가 새 대상단 방향을 승인하면서 다음 세계관을 직접 정했다. 대상단은 상인을 가장한 암살자들이며 이 역참에서 술탄 암살을 모의한다. 다라이시는 무사시에게 기습당해 기억을 잃었을 때와 비슷한 강렬한 살의를 느끼고 본능적으로 깨어나 칼을 빼 들고, 깨어 있는 자들을 닥치는 대로 베어넘긴다. 이는 게임 세계관이다. 다라이시가 술탄을 지키려는 정의로운 호위라고 바꾸지 않는다.

화면은 **다라이시가 들이닥친 직후**를 표현한다. 사사키 코지로/무사시의 이름과 기억 상실의 전말은 개발 설정에 보존하며 공개 소개에서는 ‘기억보다 먼저 반응한 살의’를 암시한다. 실제 NPC 난전이나 자동 학살 시스템을 추가한 것이 아니라, 기존 1대1 대련이 시작될 때 이미 남아 있는 무대의 흔적이다.

## 구현

- 문루 바깥의 짐을 실은 낙타2마리, 우물 옆에 무릎을 꿇은 낙타1마리. 기존 게임과 같은 절차적 저다각형 형상, 외봉/긴 목·갈라진 발/고삐·말뚝/안장 천·매듭 짐. 고개와 천이 조금씩 움직인다. 바깥 소금벌 높이−.08m에 접지하고 부드러운 접촉 그림자를 추가했다.
- 원래 우물을 이용한 물통·젖은 바닥, 내려놓은 안장과 짐. 새로운 거대한 건물이나 전투장 장애물을 추가하지 않았다.
- 기존 아치방의 낮은 상과 도면, 창작 왕실 태양 문장, 잔. 상품 천과 직물 옆 열린 상자에 같은 단검3자루를 숨겼다. 문양/건물 도식은 창작이며 특정 실존 궁전 도면이 아니다.
- 뒤집힌 의자, 떨어진 잔과 단검, 방 앞/우물 곁의 쓰러진 인물2명. 형상은 배경 소품이며 질량·충돌·피격·사망 처리 없음. 침상에 누운 방문객이나 다라이시가 보호하는 대상단으로 설명하지 않는다.
- 열린 철창/끊어진 사슬/도주 발자국48개와 전용 소금 먼지는 제거. 새벽3시·기존 달빛·전투 인물 조명은 유지. 기존 벽 기름등3개에 이동식 등불3개를 더했다. 첫 촬영의 과한 빛을 낮춰 도면과 짐의 색을 보존했다.

구현 `2322af28`, 천의 혹 관통 후속 `e01958c6`. 다라이시 외형·AI·힘·체력·무기·유파/보법, 무대 크기·일반 여정 편성은 그대로다. 소품은 반경10.5m의 카메라/전투 여유 공간 밖, 추가 충돌0이다.

## 이식과 전달

`stage_dayr_night.js`가 신규 `stage_dayr_caravan.js`를 호출하며 기존 workshop/animate/canvasTex를 재사용한다. 외부 모델·런타임 다운로드·새 라이브러리 없음. 기존 밤 등록/음향 별칭 그대로. 되돌림은 위 구현과 소개 갱신 커밋을 함께 되돌린다. 상대 최신 main 기준 전달 가지는 사용자 실제 화면 컨펌과 ‘보냄’ 지시 이후 준비하며, 이번 구현을 우화에 아직 전달하지 않았다.
