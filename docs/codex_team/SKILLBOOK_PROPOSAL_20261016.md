# 스킬북 25권 기획 — 원전과 게임 전수서

2026-10-16 KST. **기획안이며 미구현.** 사용자 지시: 유파마다 5권, 1급 보법 → 2급 막기 → 3급 고유자세 1 → 4급 패시브 → 5급 비기. 먼저 실제로 참고한 책들을 정리해 보고한다. 우화 담당 동작·보법, 전투 수치, 기존 해금은 변경하지 않았다.

## 1. 구성 제안

**실제 원전을 바탕으로 유파별 전수서 5권을 만든다.** 현재 연구는 유파마다 여러 저자의 문헌을 함께 사용한다. 역사서가 각 유파에 정확히 5권씩 있는 것으로 꾸미지 않는다. 한 원전에서 기초·심화 내용을 나눠 여러 전수서를 만들 수 있다.

- 표시명 예: `보법: 리히테나워`. 표지에는 유파 문양과 급수, 상세에는 실제 원전명·저자·연도·근거 절을 적는다. 리히테나워는 저자/전승명이며 이 표시명 자체가 역사서 제목은 아니다.
- 높은 등급은 책의 연대나 현실 중고 가격보다 **해당 유파에 특유한 내용과 숙련 깊이**를 뜻한다. 5급은 유파 비기다.
- 희귀도 명칭 제안: **1급 커먼 / 2급 언커먼 / 3급 레어 / 4급 에픽 / 5급 레전드**. 현재 무기 등급에는 언커먼이 없으므로, 이는 스킬북에 추가하는 명칭 제안이다. 기존 무기의 쓰레기·커먼·레어·에픽·레전드·??? 체계를 변경한 것이 아니다. 급수와 기능 배치는 사용자 결정, 희귀도 명칭은 이번 제안이다.
- 3급은 사용자가 지정한 **고유자세 한 가지**다. 기존 고유 공격 4개를 자동으로 묶어 주거나, 현재 AI 자세를 새 플레이어 기능으로 간주하지 않는다.

## 4. 인벤토리 표현

- 승인된 **5×4 격자**, 한 칸에 책 한 권. 전체 25권은 두 페이지(20+5)로 보고, 유파 필터를 고르면 해당 유파 다섯 권만 볼 수 있게 제안한다. 격자를 5×5로 몰래 바꾸지 않는다.
- 첫 화면과 같은 나무·베이지·금색 계열. 표지 실루엣과 문양으로 유파를, 모서리 장식·책 잠금쇠·I–V 표기로 급수를 구별한다. 모든 텍스트를 등급색으로 바꾸지 않는다.
- 독일: 장검 문양과 가죽 잠금쇠 / 이탈리아: 가는 레이피어와 직선 문양 / 이베리아: 큰 양손검과 원호 / 일본: 칼 한 자루와 실 제본 / 동방: 곧은 검과 선장본. **새 게임 표지 디자인**이며 원본 표지를 복원했다는 뜻은 아니다.
- 선택 시 표시명 → 급수·유파 → 효과 한 문장 → 실제 원전의 짧은 출처 순서. 상세 효과와 서지 정보를 같은 크기의 긴 설명으로 나열하지 않는다.
- 소장품 화면에는 획득한 책을 둔다. 미획득 25권 전체를 항상 채울지, 별도 도감으로 보여 줄지는 미정이다. 현재 테스트용 지급이나 자동 해금은 하지 않았다.

## 5. 실제 적용 전에 맞출 항목

[현재 유파 지도](../strike/school_kit_map.md)와의 차이:

1. 현재는 유파별 **고유 공격 4단계+비기**, 보법·막기는 상시 사용이다. 이번 5권 구조는 새 해금 체계이므로 단순히 기존 인장 이름만 바꾸면 기능과 책 내용이 어긋난다. 우화가 정리 중인 최종 슬롯과 연결해야 한다. 기본 걷기·기본 막기는 처음부터 제공하고 책은 유파 특유의 기능을 여는 것을 권한다.
2. 현재 패시브는 대부분 **AI만 자동 실행**한다. 인데스·카바치오네·이어 돌기·잔심 등 이름을 책에 쓴다고 인간에게 기능이 생기지 않는다. 4급은 사람의 조작으로 성립하는 조건부 효과로 정해야 하며, 현재 AI 확률·자동 궤적을 복사하지 않는다. 이번 기획에서는 수치·효과를 확정하지 않는다.
3. 카바치오네와 동방 자→격 등은 이미 고유 공격과 겹친다. 같은 능력을 3급·4급에 이중 배치하지 않는다. 3급 고유자세 한 가지와 4급 효과의 최종 대응은 우화 정리본 기준으로 한다.
4. 독일 박차기 배정은 **사용자 결정**이고 현재 포크의 옛 유파 지도는 아직 기본 보법으로 남아 있다. 이번 작업에서 그것을 이미 구현한 것처럼 표시하지 않는다.
5. 기존 결정인 ‘시작 지급품 제외, 이후 습득 아이템·스킬북당 레벨+1’은 유지한다. 판매가·드롭률·중복 책·사용 시 소모·순서 제한은 이번 요청에서 확정하지 않는다.
