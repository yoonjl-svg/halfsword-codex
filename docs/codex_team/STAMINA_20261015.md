## 적용 규칙

`src/config.js`의 `STAMINA`에서 조정한다. 플레이어와 상대가 같은 계산을 쓴다. UI 프레임 수가 아니라 실제 물리 시간으로 계산하며 일시정지·메뉴·카드 선택 동안은 진행하지 않는다. 새 판은 기력 100으로 시작한다.

| 항목 | 기본값 |
| --- | --- |
| 최대 기력 | 100 |
| 이동 | 입력 크기 1에서 초당 4 × 이동 무게 배율 |
| 공격 | 공격 중 초당 22 × 무게 배율 |
| 막기 | 막는 중 초당 2 × 무게 배율 (공격의 약 9.1%) |
| 사격 | 발당 2 × 무게 배율 |
| 무게 배율 | `clamp(sqrt(현재 무기 질량 / 1.5kg), 0.65, 3)` |
| 이동 무게 배율 | `0.85 + 0.15 × 무게 배율` |
| 회복 | 행동을 멈춘 뒤 0.8초부터 초당 15 |
| 고갈 | 0에서 팔 관절·손목 힘을 60%로 낮춤 |
| 고갈 해제 | 기력을 20 이상 회복하면 원래 힘으로 |

무기 질량은 물리 엔진에서 계산하고 파손 시 갱신되는 `swordMass`를 쓴다. 실제 질량: 레이피어 약 1.1kg, 롱소드 1.6kg, 츠바이핸더 2.9kg. 공격/막기 배율은 각각 약 0.856/1.033/1.390이다.

이동·공격·막기 비용은 필요한 경우 합산한다. 막기 버튼이나 AI 방어가 만든 빠른 손 이동을 공격으로 이중 청구하지 않는다. AI 간 보기 중 자세 변경도 공격으로 청구하지 않는다. 버튼 없이 칼을 세워 상대 칼과 접촉하는 동안도 막기로 센다. 따라서 맞댄 칼을 버티는 중에는 회복하지 않으며, 간격을 벌리고 쉬면 회복한다. 시작 시 발이 묶였거나 쓰러져 이동할 수 없는 상태에서는 이동 입력 비용을 청구하지 않는다.

기력 고갈은 팔·손목이 낼 힘에만 적용한다. `gait.js`, `skill.js`, `schools.js`, `guards.js`, `frames.js`, 유파 동작 자료는 수정하지 않았다. `ai.js`에는 기존 행동 상태를 읽을 관찰자 연결 한 줄만 추가했다. 공격 궤적·보법 순서·AI 판단을 기력에 맞춰 재작성하지 않았다. 실제 물리 결과는 약해진 팔 힘 때문에 달라질 수 있다.

두 검객의 머리 위 바는 최초 56×3px, 본문 베이지색 `--c-text`로 구현했다. 사용자 후속 의견(테두리가 두껍고 너무 밝음)에 따라 **56×2px, 보조 베이지색 `--c-sub` (`#b8a88e`)·불투명도85%**로 낮췄다. 일반 상태의 바깥 테두리는 없애고, 고갈 시에는 내부에만 0.5px·불투명도45%의 은은한 테두리를 둔다. 화면 밖·뒤, 사망/부활·메뉴·일시정지·판 종료 시 숨긴다. 새 판마다 DOM을 쌓지 않는다. 세로 모바일 화면은 기존 회전 안내가 가린다.
