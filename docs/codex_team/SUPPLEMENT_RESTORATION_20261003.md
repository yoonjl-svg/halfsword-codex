## 채택·공개 범위

이번 수령은 연구 근거 보존이다. 과거 실패 자료와 옛 계획은 최신 Git 보고서·사용자 지시를 대체하지 않는다. 실패한 projected 지지·budgeted 절삭은 철회를 유지한다. 한손 회복 활성은 실제 전투1차의 제동·발 지지 후퇴 때문에 공개 CTA·직접 URL과 일반 승격을 계속 보류한다.

WAV는 원본/단축 A2/B2의 청취·렌더 참고 자료이며 런타임 자산의 자동 교체 근거가 아니다. 이미 승인·전달한 사운드와 게임 기본값은 그대로 유지했다. 공유 Git 기록에는 수령 메타데이터만 남기며 복호화 키·임시 전송 주소·원자료 본문·비공개 운영 기록을 복사하지 않는다.
