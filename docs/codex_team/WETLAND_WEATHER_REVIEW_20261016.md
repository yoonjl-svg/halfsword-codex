# 밤의 잠든 습지 · 날씨 기술 검토 · 2026-10-16 KST

## 1. 요청과 결론

사용자는 다른 밤보다 구름이 많고 더 어두운 습지, 약한 비, 가끔 천둥번개가 가능한지 기술 검토를 요청했다. **가능하다.** 현재 렌더·이벤트·오디오 구조에 연결할 수 있다. 이 문서는 검토안이며 **날씨 소스는 아직 변경하지 않았다**. 같은 작업의 브론·라트나 외형 수정과 구별한다. 밤은 기존 기준대로03:00이다.

## 2. 현재 코드에서 확인한 것

- `stage_sluice_night.js`는 `beginNight`의 그라데이션 하늘·별700개를 사용한다. 습지의 환경광1.03, 주광원.61, 인물 보조광.64/윤곽1.25다. 현재 구름·비·번개 연출은 없다.
- `stage_clearing.js`의 `springRain`은2400점의 `THREE.Points` 하나·질감 하나를 사용한다. 범위48×48m/높이14m, 크기.55/불투명도.42, 기존 seeded RNG를 쓴다. 점 위치를 매 프레임 갱신하며 물리 충돌은 없다. `n`과`seed` 옵션은 이미 있다.
- `sound.js`에6초짜리 합성 `rainLoop`와 비 배경음 경로가 있다. 습지를 화전 터로 분류하면 까마귀·잔불 등도 따라올 수 있으므로 빗소리만 재사용해야 한다. 기존 천둥 합성/번개 연출은 발견하지 못했다.
- 무대의 `onEvent`가 `sound.stageEvent`로 연결된다. `StageDetailSound`는 현재 `sluice_night`를`sluice`로 합쳐 처리한다. 밤만의 비·천둥을 넣으려면 원래 ID 또는 별도 날씨 프로필을 보존해야 한다.
- 기존 일시정지/무대 변경의 소리 감쇠·음원 정리 경로가 있다. 새 날씨도 이 경로에 연결해야 한다.

## 3. 권장 표현과 시작값 — 미적용

| 요소 | 권장 시안 |
|---|---|
| 구름 | 짙은 구름이 하늘 대부분을 덮고 별을 가림. 저해상도 질감1~2층이 느리게 이동. 푸른 새벽빛이나 달 추가 없음 |
| 어둠 | 환경광1.03→약.80, 주광원.61→.35~.40부터 조정. 이는 광원 입력값이며 화면 밝기가 정확히 몇% 떨어진다는 뜻은 아님. 인물 윤곽과 바닥 경계 가독성은 실제 사진으로 결정 |
| 잔비 | 기존2400점 대신600~900점, 크기.32~.40/불투명도.18~.25부터 비교. 옵션을 추가하되 기존 비의 기본값은 보존 |
| 번개 |25~45초 사이 불규칙한 간격. 구름 안쪽의 먼 섬광1회, 약.12~.20초. 기존 조명과 구름 밝기를 짧게 올렸다 복귀. 화면 전체를 하얗게 덮는 UI 효과는 쓰지 않음 |
| 천둥 | 섬광1.5~3초 뒤, 멀리서2~4초 낮게 구르는 소리. 새 저역 잡음 합성 버퍼를 캐시하고 칼 소리를 가리지 않도록 조절 |

번개 때 수문·옛 돌길·빈 문턱이 잠깐 드러나면, 단순한 날씨 장식이 아니라 라트나가 돌아다니는 옛 마을의 흔적을 읽게 하는 역할을 한다. 추가 횃불보다는 지금의 인물 윤곽광과 밝은 편지·돌의 대비를 먼저 활용한다.

## 4. 비용과 주의점

비는 추가 그리기1회, 구름은 대략1~2회로 구성할 수 있다. 번개는 기존 광원의 세기를 바꾸므로 새로운 그림자 맵이나 고비용 체적 구름이 필요하지 않다. 천둥도 매 프레임 합성하지 않고 캐시한다. 이는 구현 구조에 대한 예상이며 **휴대폰 FPS/발열을 측정한 결과는 아니다**. 투명 구름의 겹침 면적과 비의 픽셀 비용을 실제로 확인해야 한다.

날씨 전용 seeded RNG와 무대 시간 누적을 사용한다. 지연 천둥을 긴 `setTimeout`으로 방치하지 않고 일시정지·무대 전환·음소거에서 정리한다. 기존 습지 이동·물 깊이·AI·전투 난수·판정은 날씨와 분리한다. 밤 화전 터의 ‘비 갬’ 및 낮 습지에는 영향을 주지 않는다.

## 5. 구현 시 확인할 것

같은 카메라에서 현재/먹구름/섬광 전후 실제 화면, 움직이는 검·기력 바·바닥 경계 가독성, 섬광과 천둥 지연, 일시정지/재개/무대 전환의 잔류 소리·조명 복구, 자원 반복전환, 모바일 프레임 시간. 날씨를 위한 강제 관찰은 일반 대전 기록과 구분한다. 이번에는 기술 검토만 했으므로 새 날씨 스크린샷이나 성능 수치를 제시하지 않는다.

## 6. 이식 범위

예상 범위는 `stage_sluice_night.js`의 날씨 구성, `beginNight`의 하늘 옵션, `springRain`의 기본값 보존 옵션, 무대 상세음의 밤 구분/빗소리/천둥 처리다. 기능과 의존 경로의 호환성을 맞추면 되며 파일 전체 동일성이 필요하지 않다. 우화 코드·저장소 변경/메시지 없음.
