# 최종전 제복 캐릭터 · 2026-10-10 KST

기준 `c1e4f9b`. 사용자는 가죽 v2를 ‘내복 같다’고 거부하고 새 제복 이미지를 제시했다. v1/v2는 미채택 외형 이력으로 보존한다. 구리빛 피부·청색 계열 옷을 지정했고, 인도/아랍 출신 중 인도 출신 성인 여성으로 구성했다. 참고 이미지의 분홍 갈색 머리는 첫 시안 후 거부됐다. 추천3색 중 사용자가 **짙은 흑갈색**을 선택했다.

## 구현

현재 `crown_boss:v3`, 임시 이름은 ‘푸른 제복의 검사’다. 청색 하이칼라 상의·작은 단추·어깨 장식·밝은 대각 끈, 허리벨트/주머니, 남색 주름치마, 밝은 장갑/긴 부츠, 단발과 옆 땋은 머리를 구현했다. 눈은 기존 작은 검은 눈이다. 특정 인도 역사 제복의 고증을 주장하지 않는 창작 캐릭터다.

치마는 양쪽 허벅지를 따라 움직이는 두 부분이며, 제복 허리는 가슴/골반과 겹치는 표면으로 연결했다. 첫 초안의 가로 빈틈, 치마 윗부분이 상의를 뚫던 모양, 땋은 머리의 가시성을 교정했다. 옷 겹침 경계와 기존 관절형 무릎은 남으며, 실제 천 시뮬레이션은 아니다.

## 게임 규칙과 범위

기존 최종전 ID/순서·무기 롱소드·AI·체격/질량/관절/콜라이더를 유지한다. 이름/출신/짧은 소개는 새 외형에 맞췄다. 왕관/망토/판금을 없앤 제복형이므로 **무투구·판금0부위**로 처리한다. 이전 판금의 방어·기존 이동 감쇠도 적용되지 않는다. 따라서 전후 전투 결과나 이동이 완전히 같다고 주장하지 않는다. 새 힘/피해 보너스나 물리 공식 수정은 없다.

## 근거와 재현

- `node tools/sim/experiments/crown_boss_gate.mjs <새 절대경로.json>`: 제복 분기15항목. 실제 두 seed 전투1,440step, 별도 가슴/머리/허벅지/팔 합성 상처와 외형 유지/유한 상태240step PASS. 왕관 파손 검사를 했다고 세지 않는다.
- 저장소 밖 `construction.mjs`로 이전/현재 생성 당시의 world snapshot·부위 질량·무기·AI 일치를 확인했다. 방어구 제거 효과와 분리한다.
- 흑갈색 결정 전후 src 차이가 `looks.js`의 머리색1값뿐임을 검증해 그 전에 통과한 물리 검사를 재사용한다. 최종 사진·빌드·모바일 검사는 새 색으로 다시 확인한다.
- 최종4사진은 실제 게임 메시를 기존 `alber` 자세로1.25초 진행한 뒤 중립 조명에서 촬영한다. 별도844×390 사진은 원래 AI/조명/경기 카메라다. 사용자 참고 이미지는 공개하지 않는다.
- `node tools/browser/artoria_rare_delivery_20261010.mjs --encounter=crown_boss --base=<URL>/ --build=<동결 빌드> --out=<새 출력>`의 full 범위는2무기 터치와 별도 최종전 진행 fixture다. 색만 바꾼 최종 빌드는 mobile 범위로 진입/입력/재시작과 실제 제공 파일을 다시 확인한다. `--local-evidence`에는 반드시 같은 최종 빌드의 PASS를 넣는다.

최종 진행 fixture는 명시적 `Fighter.die`를 사용한다. 자연 승리·승률 또는 인간 동작의 자연스러움 검사가 아니다. 모바일은 Chromium 터치 에뮬레이션이며 실제 폰 FPS와 미적 수락은 별도다.

관측된 일반 경기 화면(844×390)은215 draw /87,868 triangles /텍스처10개다. 캐릭터 전용 투명 메시0개, 새 텍스처0개이며 최종4장 WebP 합계71,586바이트다. 렌더 계측은 해당 장면 관측값이고 기기 FPS 또는 성능 향상률은 아니다.

실제 배포 상태는 [전달 영수증](crown_uniform_release.json)을 따른다. 분홍 머리 시안과 최종 흑갈색의 사진/빌드/검사를 구분한다.
