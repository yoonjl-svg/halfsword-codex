# 다라이시 · 일몰의 소금길 역참

기준 `325a5c3`(공개 게임 `0840e81`). 사용자가 역참을 일몰로 바꾸고, 다라이시의 이란 고위 검객 인상을 보강하도록 요청했다. 매끈한 v5 앞머리는 ‘대머리 바가지’로 거부했다. 풍성한 장발과 땋은 장식을 원하며, 후속으로 원래 인상을 유지하는 범위의 하의 길이·디자인 변경도 허용했다.

## 변경과 범위

- `dayr`: 문루 너머 낮은 해, 살구·산호색 노을과 보랏빛 위쪽 하늘. 보이는 태양과 광원 방향을 맞추고, 안뜰은 차가운 채움광과 문루로 들어오는 따뜻한 빛을 조합했다. 기존 건축·충돌·이동·소리 사건은 유지한다. 사용자가 노을은 채택했고, 후속으로 해를 더 크게·지평선에 살짝 걸치도록 요청했다. 최종 후보는 태양 지름을 첫 노을안 대비30% 늘린다. 추가 흰 둔덕/얼룩안은 사용자가 거부했다. 최종 방향은 먼 지면의 넓고 아주 옅은 염분 흔적2–3곳이며, 문루 안에서 보이도록 강제하지 않는다. 내부는 낡은 문짝의 철물·벽돌 짜임·회랑의 직물 짐과 항아리로 보강한다.
- 이름은 사용자 표기 **다라이시**로 반영한다. 옛 이름과 출신을 잃고, 실력을 인정받아 이란 왕실 근위대에 들어가 지금 이름으로 불린다는 설정이다. 역사 인물이나 특정 시대의 제복 복원은 아니다.
- v6 `court_braided_layers`: 풍성한 머리층과 땋음, 작은 장식. 보라·흰색의 기존 긴 실루엣과 팔각 꽃무늬·덩굴을 중심으로 하의 자락/가장자리를 다듬는다. 얼굴·눈·신체 치수·무기 성능은 변경하지 않는다. v4/v5 비교는 보존한다.
- 공개 소개·게임 이름·음성 목록의 표기를 맞춘다. 음원 배정과 오디오 데이터는 변경하지 않는다. 기존 무대/의상의 전후 사진과 직접 플레이를 같은 소개 페이지에서 제공한다.

## 검증과 재현

무대 생성·해제 3회 통과: 56,302삼각형/17draw, geometry17/material15/texture5 정확히 해제, 바닥 y0·카메라 통행 반경·문루 시야·우물 고리의 120초 사건 시각 유지. 이는 무대 단독 카메라 비용이며 전체 게임 draw 수나 실기 FPS가 아니다.

```sh
node tools/browser/dayr_scene_20261014.mjs http://127.0.0.1:4320/ /tmp/halfsword-dayr-sunset-20261014/scene-refined
CAPTURE_IDS=silver_wanderer CAPTURE_VIEWS=front,threeq,back,detail CAPTURE_BASE=http://127.0.0.1:4320 CAPTURE_OUT=/tmp/halfsword-dayr-sunset-20261014/portraits-final node tools/browser/native_character_portrait.mjs
node tools/browser/dayr_capture_20261014.mjs /tmp/halfsword-dayr-sunset-20261014/scene-refined/game-preview
npm run build -- --outDir /tmp/halfsword-dayr-sunset-20261014/build-refined
```

캐릭터 native9검사 통과: v4/v5/v6/외형 제거의 물리 snapshot 동일, 얼굴 형상/배치 동일, 갑옷/투구 물리 미추가, 전 정점 유한, 수작업 부상4개 뒤120step의 유한 상태/유효 관절/외형 부착 확인. v6 캐릭터202mesh·48,167삼각형(관찰용 모든 하위 외형 포함)이며 실제 화면 draw나 인간 동작 판정을 뜻하지 않는다.

`new_pair_delivery_20261010.mjs --encounter=silver_wanderer`로 최종 빌드의 로컬·공개 모바일 진입/공격/이동/정지/재개/재시작과 전달 파일 해시를 검사한다. 음향 코드는 불변이므로 직전 master-render 검사를 재사용하며 무대 사건 시각만 재확인한다. 실제 휴대폰 FPS, 사용자 미적 수락, 모든 부상 자세에서의 옷·머리 관통은 미검증이다.

상태·소스 해시·결과·공개 커밋은 [전달 영수증](daraishi_sunset_release.json)에 기록한다. 전후 이미지는 게임 모델을 렌더링한 것으로, 새 원화나 생성 이미지가 아니다.

## 화면 검토에서의 수정

첫 v6의 앞머리 두 덩어리가 벌어져 매끈한 삼각형 면이 남았고, 옆 땋음은 기존 머리 덩어리에 묻혔다. 공개 전 확대 렌더에서 이를 확인해 양쪽을 덮는 넓은 머리층으로 연결하고, 땋음과 받치는 머리층을 함께 바깥으로 옮겼다. 첫 검사/이미지는 저장소 밖에 보존한다. 수치 통과를 미적 수락으로 취급하지 않는다.

소금 표현 첫 시안의 작은 흰 둔덕과 경계가 선명한 얼룩은 사용자가 어색하다고 거부했다. 해당 시안의 기술 검사 통과는 조형 채택이 아니다. 밝은 섬처럼 보이는 흰 부분을 제거하고, 넓은 범위에 베이지색과 섞이는 약한 명도 변화로 고쳤다. 초기 scene-salt 결과는 저장소 밖에 보존한다.

소금 둔덕안의 local02는 실제 입력 검사 뒤, 진행 중 전투 화면 캡처에서30초 시간 초과가 났다(200응답·페이지 오류0, 전체 통과로 처리하지 않음). 동시에 장면 렌더가 진행 중이었다. 최종 검사에서는 다른 브라우저 작업을 끝낸 뒤, 기존에 검증하던 일시정지 상태에서 사진을 저장한다. 전투 중 입력·이동 검사와 정지/재개/재시작 조건은 유지하며, 시간 제한을 늘리거나 검사를 삭제하지 않는다.
