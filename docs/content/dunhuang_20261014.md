기준 `dc358ace563d60ea38042ea691b01ee4bba0118f`. 사용자가 [둔황 제안](dunhuang_proposal_20261014.md)의 추천 무대 **천불의 절벽**과 **간장 고정**을 승인했다. 건조하고 서늘한 초가을 오전8시, 막고굴에서 착안한 절벽 앞뜰의 별도 시험판이다. 진대 병마용과 후대 둔황 석굴을 함께 둔 것은 창작이며 고증 복원이 아니다. 일반 여정 순서는 유지한다. 진입 페이지는 `dunhuang.html`로 준비하며, 이 기록 시점의 모바일·공개 전달 검증은 대기 중이다.

## 구현과 범위

무대 ID `dunhuang`: 퇴색한 벽화와 석굴 그늘, 목재 처마·간판, 모래흙 앞뜰을 배치한다. 첫 화면은 절벽이 지나치게 평평하고 벽화가 깨끗해 보였으므로 연속적인 암반 요철·불규칙한 윤곽으로 바꾸고 벽화 액자 띠를 제거했다. 29개 석굴, 63,719삼각형·15메시＋입자·5텍스처(최대1024), 평지 중앙 반경10.5m를 비운다. 실제 Three.js 무대 생성/갱신/해제3회에서 결정적 형상, 유한 좌표,36자원의 단일 해제를 확인했다(Canvas2D 그리기만 대역).

캐릭터 ID `terracotta`, 이름 병마용, 간장 고정, `voice: 'silent'`. 회갈색 구운 흙 장식40층을 기존 신체 부위의 메시 아래 붙인다. 기존 머리·코·눈(`stockEyes`), 몸 규격·관절·질량과 간장 AI를 유지하며 금속 갑옷 보호를 추가하지 않는다. 인간 신음·숨·사망 음성은 끄고 발·무기·타격·몸 착지 소리는 유지한다. 도자기 파쇄나 별도 생리 모델은 없고 기존 상처·출혈·사망 판정을 사용한다.

음향은 낮은 절벽 바람과 가는 모래 마찰, 실제 간판 흔들림 정점의 `stageDetail/dunhuangWood`를 사용한다. 첫 정점11초, 이후31초 간격이며 위치는 움직이는 간판의 세계 좌표를 전달한다. 목재음1.65초, 프로필 최소 간격24초·gain0.023, 무대의 amp0.5. 기존 모래 발걸음/바닥 알갱이 녹음을 재사용한다. 기존 합성곱 경로로 전투의 금속/몸 소리에만 약한0.28초 반사를 더한다. 반사는 무대 전체 설정이며 동굴 접근 거리에 따라 변하지 않는다. 지속 합창·음정 드론·바다·비·용암음이나 새 유료 음원을 추가하지 않았다.

- 캐릭터 native11검사 통과: 기본 외형 대비 초기 Rapier 스냅샷 동일, 실제 AI240스텝과 직접 주입 상처7개 뒤90스텝, 총330스텝에서 몸 상태·관절 유한/유효. 장식40층과 대표 메시 소유 관계를 보존했다. 실제 양손8메시와 잡기 모드도 포함한다. 이는 단일 시드의 외형·연결 검사이며 전투 밸런스나 자연 피격 성공률 검사가 아니다.
