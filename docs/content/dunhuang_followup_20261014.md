# 병마용 무혈·머리 분리 사망 / 둔황 누각 깊이

기준 `5918752`. 사용자: 병마용은 피를 흘리지 않고 머리가 날아가야만 죽는다. 절벽 누각이 평평하고 가짜처럼 보이므로 실제 구조와 비교한다. 별도 `dunhuang.html` 대련판 후속이며 일반 여정 순서는 유지한다.

## 변경

캐릭터가 `physiology: {bleeds:false, deathRequiresHeadDetachment:true}`를 제공하고 main의 실제 생성에서 전달한다. 이름/무기별 분기 없이 공통 Fighter가 처리한다. 피·출혈·상처 출혈을0으로 유지하고 실제 목 관절이 제거되기 전에는 `die`/`setState('dead')`를 거부한다. 몸통 찌르기/마무리/환경 피해로 죽지 않으며 팔다리 손상·절단·넘어짐은 유지한다.

기존 인간의 치명상 기준을 재사용한다: 목 심각도>.5, 머리 베기>.8/찌르기>.5, 머리·목 둔격의 누적 의식<=0. 병마용에게만 이 조건을 목 연결부 파손→실제 머리 관절 제거→사망 순으로 연결한다. 총·찌르기·둔기도 가능하며 모든 머리 타격이 성공하는 것은 아니다. 새 힘 배율/관성/갑옷/무기 예외를 추가하지 않는다. 이는 흙 목의 파손을 표현한 게임 규칙이며 도자기 응력/균열 전파를 계산하는 물리 모형은 아니다.

핏방울·분출·붉은 상처·옷의 피 번짐·공격자의 칼에 묻는 피를 막는다. 대신 무광의 잔균열·짧게 사라지는 흙 알갱이·마른 충격음을 쓴다. 목/사지 끝면은 회갈색이며 뼈가 보이지 않는다. 인간과 병마용이 동시에 잘려도 공유 재질이 서로의 단면색을 바꾸지 않게 분리한다. 병마용 자신의 칼에 인간 상대의 피가 묻는 것은 정상이다.

실제 참고: [xiquinhosilva의 막고굴 사진, CC-BY2.0](https://commons.wikimedia.org/wiki/File:Mogao_Caves_(54376969262).jpg), 기존 `public/references/dunhuang/cliff.jpg`. 실제 누각도 절벽에 기대 있지만 옆벽·회랑·층별 벽체·깊게 돌출한 처마가 있다. 이전 시안은 기둥/난간/지붕 위주로 깊이가 부족했다. 계단식 방과 측벽,0.83m 파인 문, 약1m 회랑,두께18cm 지붕·서까래·공포를 보완했다. 실제 특정 건물을 그대로 복원한 것은 아니며6층 창작 구성은 유지한다.

무대63,719→83,335삼각형,15→17메시,기존5텍스처 재사용. 최근접 경관13.56m, 중앙 반경10.5m 유지. 벽화·절벽 자연면·환경음은 유지한다.

## 검증과 재현

- 실제 Fighter/Rapier23검사: 몸통·목·머리·총·둔격·직접 사망 호출·사지 절단·용암·부활 예외·재진입. 기존 마무리58검사 통과.
- 기준 인간과 건강/몸통/머리/목베기/마무리/둔격6상황×180프레임×2명의2,160상태가 완전 일치. 수치 프레임 일치이며 사람의 장시간 체감 검증은 아니다.
- 실제 FX4조합: 인간/병마용 동시 처리 순서×피 설정. 병마용 분출0, 회갈색 끝면/뼈 제거, 인간 효과 유지, 흙 알갱이 소멸. 마른 타격음 경로1검사.
- 무대 생성/갱신/해제3회와 깊이 광선 검사: 결정적 형상·유한 좌표·40자원 단일 해제. 실제 게임 측면 사진도 확인했다.
- 실제 main 상처 진단과 고정 빌드 모바일 시작/선택/공격/이동/정지/재개/재시작을 통과했다. 187로컬 응답이 고정 빌드와 일치하고 오류0. 전체 회귀/공개 최종 판정은 후속 영수증에 기록한다.

```sh
node tools/sim/experiments/terracotta_vitals_gate.mjs /tmp/terracotta-vitals.json
node tools/sim/experiments/terracotta_fx_gate.mjs /tmp/terracotta-fx.json
# 현 체크아웃 Vite4320에서 직접 상처를 주입하는 별도 진단: 자연 타격 성공률 검사가 아님
node tools/browser/terracotta_wounds_20261014.mjs /tmp/terracotta-wounds
```

첫 용암 검사 실패는 테스트에서 고정 물체를 사용해 센서 접촉이 생기지 않은 것이었다. 동적 물체의 위치/회전을 잠그는 방식으로 바로잡고 실제 접촉에서 인간 사망/병마용 생존을 확인했다. 첫 브라우저 입자 계측은 Vite의 타임스탬프 없는 별도 모듈을 감시해 입자0으로 나왔다. 실제 로드한 모듈 URL에 계측을 붙여 재검사했고, 흙 입자/혈흔0·마른음·인간 피 효과·참수 뒤 목관절 제거/회갈색 단면을 실제 main 연결에서 통과했다. 실패 증거를 성공 결과와 함께 보존한다.

회귀 실행의 첫6그룹 자체는 전부 통과했으나, 실행 중 안내문의 ‘쓰러집니다’를 ‘죽습니다’로 바꿔 동일 소스 검사에서 실패했다(변경 파일은 `public/dunhuang.html` 하나). 검증 기준을 낮추지 않고 파일을 고정하여 전체 회귀6그룹과 소스 안정성 검사를 다시 통과했다. 두 실행의 최종 빌드 파일도 전부 일치한다. 첫 결과와 재검사 결과를 모두 보존한다.
