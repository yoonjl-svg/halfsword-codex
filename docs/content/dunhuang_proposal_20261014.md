# 둔황 / 병마용 구상 · 2026-10-14

요청은 간장 또는 막야를 든 병마용 캐릭터와 둔황 무대의 참고 이미지/설정 제안이다. [휴대폰 제안서](https://yoonjl-svg.github.io/halfsword-codex/dunhuang-proposal.html)를 제작했다. 게임 모델/무대 구현이나 최종 선택은 아직 아니다.

추천: 초가을 오전8시 ‘천불의 절벽’, 석굴 입구의 깊은 그늘·퇴색한 적갈/청록 비천 벽화·절벽 바람/모래/목재 소리. 대안은 초여름 해 뜨기 전 월아천, 늦가을 오전10시 명사산 고개. 기존 역참의 일몰/벽돌 안뜰과 청람잔도의 녹음/강을 반복하지 않는다. 실제 세 장소를 한 시야에 합쳐놓는 복원이 아니다.

캐릭터는 회갈색 구운 흙, 조각한 머리/수염, 갑옷과 끈까지 같은 재질. 기존 신체/눈 규격을 기준으로 하고 큰 골렘화는 제안하지 않았다. 임시 칭호 ‘돌아오지 않은 근위병’; 서역으로 옮겨져 깨어난 흙 병사는 창작 연결이다. 밝은 몸에 대비되는 간장 우선 추천, 막야는 그늘에서 선명한 대안이다.

근거: UNESCO [막고굴](https://whc.unesco.org/en/list/440/)(366년 시작/4–14세기 미술), [진시황릉](https://whc.unesco.org/en/list/441/)(진시황 사망기원전210년/다양한 병사 조각), Wikipedia 월아천/막고굴/병마용과 Commons imageinfo. 모두 실제 HTTP200 본문을 읽었다. 기원전3세기 시안 병마용과 후대 둔황 석굴은 다른 시대·지역이며 간장/막야가 출토검이라는 주장은 하지 않는다. 명사의 저음은 조건부 모래 운동 현상에서 착안한 음향 제안이며 바람의 상시 실제음이라고 주장하지 않는다.

실제 참고 이미지4장(석굴 외관,월아천,비천 벽화,장군 머리)을 원본의 제공 이미지 그대로 보존하고 사진별 저작자/라이선스/출처/해시를 `public/references/dunhuang/credits.json`에 남겼다. CC BY2.0, CC BY-SA4.0/3.0, Commons public domain 구분. 현대 건축 사진을 진/당대 복원이라고 부르지 않는다. AI 생성 이미지를 실경으로 사용하지 않았다.
