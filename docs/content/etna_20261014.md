# 에트나 · 검은 재의 능선

기준 `db72960`. 사용자가 승인한 범위: 에트나에서 착안한 화산 무대, 실제 경사, 낮은 쪽 용암 접촉 시 즉사. 바다는 제외하고 검은 용암 껍질/주황빛 틈, 푸른 새벽, 먼 분화구와 관측소 흔적을 만든다. 별도 테스트 무대이며 일반 여정 순서와 캐릭터 풀은 그대로다. 상대는 기존 세르파/세이버.

## 구현

공통 `etna_ground.js`의 높이·법선·용암면을 그림, Rapier, 발 지지, AI가 함께 읽는다. 중앙7도(+z내리막), z≤−4m는 평평한 위쪽 암반. 용암은 z≥5.25m/높이−tan(7°)×5.25m. 중력·근육·무기 위력 가중치는 추가하지 않는다. 기존 원형 외곽의 경계 벽은 남고, 그 안의 낮은 쪽에도 용암이 있어 접근·접촉할 수 있다.

발목·발끝·착지 목표와 몸 높이는 지면에 상대적으로 계산한다. 경사면의 발 고정 마찰은 실제 접촉 하중과 기존 마찰 한도로 제한한다. AI는 발 위치·현재 관성·요청 이동을 미리 보고 안전한 쪽으로 자발적 이동을 바꾸고, 충돌하는 내리막 공격 스텝은 취소한다. 외력·위치·속도는 덮어쓰지 않는다.

세계의 실제 용암 센서와 붙어 있는 신체 collider가 교차하면 `용암` 사망. 무기/파편/절단된 부위만 닿으면 소유자는 죽지 않는다. 양측 동일하며 부활 중에도 접촉사는 최종 사망이다. 렌더링 프레임이 아닌 각 물리 스텝 뒤 판정한다. 카메라·발소리·피 입자·부활 바닥광·낮은 상대의 마무리 판정도 지면 높이를 따른다.

## 판정과 재현

- 실제 Fighter/Rapier 걸음10조건: 위/아래 정지, 오르막·내리막·횡단·옆걸음, 위쪽 평지 전환, 두 위치의 충격 후 기립. 말미 발 지지98.5–100%, 기립 성공. 이전 평지 전신120표본 동일.
- 용암9조건: 수면 위1mm생존/아래1mm접촉사, 머리 접촉, 무기·절단 부위 무효, 일반판 센서 없음, 실제 양측 부활 우회, 수동 입력 내리막 보행으로4.792초 발 접촉사.
- AI: 단위24조건 및 native5검사. 한 시드6초 접근에서 내리막 명령102회 수정하며 생존. 추가 외력으로 밀었을 때 발 접촉사 발생해 보이지 않는 보호벽이 아님을 확인. 기존 평지480스텝/양측960표본 동일.
- 무대3회 생성·해제: 36,595삼각형/10메시, 형상·텍스처 해시 동일. 매회10형상/10재질/5텍스처 각1회 해제, 카메라 반경10.5m 내 지면 오차≤5.95e−8m, 실제 게임 캡처 오류0.
- 환경음 PCM45렌더: 기존42결과 원본과 동일, 새 지각 균열음3샘플레이트 유한/비무음/클리핑 없음. 이 수치만으로 소리의 사실감을 확정하지 않는다.

node tools/sim/experiments/etna_gait_gate.mjs /tmp/etna-gait-gate.json /tmp/etna-flat-before.json
node tools/sim/experiments/etna_hazard_gate.mjs /tmp/etna-hazards.json
node tools/sim/experiments/etna_ai_gate.mjs /tmp/etna-ai.json
node --test tools/sim/terrain_navigation.test.mjs

무대 생성·해제, 실제 게임 화면, 고정 빌드 로컬/공개 모바일 진입·공격·이동·정지·재개·재시작 결과는 [전달 영수증](etna_release.json)에 이어 기록한다. 테스트용 초기 위치/충격 설정은 재현 조건이며 사용자 플레이나 성공률로 부르지 않는다. 실제 휴대폰 FPS, 모든 무기·부상 조합과 장시간 AI의 추락률, 사용자의 미적·조작감 수락은 미검증이다.

## 수정과 한계

첫 용암은 밝고 균일한 다각형 선이 격자처럼 보여 폐기했다. 검은 껍질의 어두운 경계와 불규칙한 넓은 열점/흐름으로 수정했다. 최초 캡처의 debug getter가 존재하지 않아 캡처 도구가 실패했으며 게임 자체의 오류와 구분한다. 카메라의 바깥 회전 반경을 위해 큰 바위/울퉁불퉁한 지형은 결투장보다 더 바깥으로 이동했다(가장 가까운 고체 장식12.024m).
