기준 `d27f85c`, 앞선7도/접촉즉사 시안은 [원 기록](etna_20261014.md). 사용자는 무대를 채택하고 경사·용암 움직임 보강, 즉사 대신 기존 붉은 화면과 다리 손상/무릎 꿇기를 요청했다. 세르파는 완성도 때문에 사용 보류. 미배정 인물은 아르토리아와 찬다이며, 이번 테스트 상대만 아르토리아로 교체한다. 정식 무대 짝/일반 여정은 바꾸지 않는다.

## 변경과 이유

- 경사7→10도. 그림/실제 충돌/접지/AI는 같은 ETNA 계약을 사용한다. 중력·무기 위력에 별도 배율을 넣지 않는다.
- 용암: 느린 표면 이동과 불규칙한 흐름 변형, 국소적으로 일렁이는 주황 열점, 작은 용암 조각16개의 간헐적 낮은 궤적. 하나의 추가 메시/64삼각형이며 매 프레임 같은 버퍼를 쓴다. 경계·액면은 실제 센서와 일치하고 기존 소리는 유지한다.
- 실제로 닿은 부위만 화상. 다리는 약0.25초 접촉하면 지지 한도 아래로 손상되며 기존 물리 무릎/기립 동작으로 주저앉는다. 멀쩡한 반대 다리를 함께 손상시키지 않고, 파괴된 지지 다리가 평균 건강값에 가려 다시 서는 것만 막는다. 새 좌표/자세를 직접 덮어쓰지 않는다.
- 기존 붉은 비네트는 혈액 감소·출혈·통증으로 계산된다. 화상은 `burn` 상처/강한 통증, 실제 팔다리 기능 손상을 만들며 출혈량0이다. HUD 색/공식은 그대로다. 기존 피격 음성은 새 상처에 반응한다.
- 우선 지속 접촉6초의 열노출 한도로 지연 사망. 접촉을 벗어나면 새 피해가 멈추고 열노출은 초당0.5초씩 감소한다. 손상된 다리 기능은 자동 회복하지 않는다. 기존 부활 기능의 회복은 별도이며, 지속 용암 사망은 부활로 회피하지 않는다. 시간 수치는 게임 판정이며 의학적 생존 시간으로 주장하지 않는다.
- 무기·파편·절단된 부위의 접촉은 소유자를 다치게 하지 않는다. 한 다리의 콜라이더가 여러 개 닿아도 피해가 중복되지 않는다. 양측 동일 규칙이며 물리 시간으로 계산한다.
