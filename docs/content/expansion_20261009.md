## 구현과 제공 범위

- `characters_expansion.js`의 3인·native 복식을 `CHARACTERS_BY_ID`에 추가한다. 기존 일반 진행 6무대와 무작위 5인 풀은 유지하고 [별도 선택 화면](https://yoonjl-svg.github.io/halfsword-codex/new-encounters.html)에서 세 결투에 진입한다. 링크는 `stage`/`foe`만 사용해 정상 무기 카드 선택을 유지한다.
- 몸·손·관절·질량·무기 계수·상처·갑옷 공식을 바꾸지 않는다. 머리 장식/모자는 방어구가 아니다. 복식은 각 native 부위에 붙고 기존 상처 표면을 유지한다. 통짜 외부 모델 교체나 유료 생성은 없다.
- 세 무대는 기존 평평한 결투장을 공유한다. 큰 건축·나무·배는 카메라 회전 범위 밖에 두며 병합/인스턴싱한다. 바닥 소리·잔향·배경음을 연결했고 신음은 기존 음성을 재사용한다.
- 선택 화면의 이미지는 실제 게임을 멈춰 카메라만 옮긴 장면이다. 이미지 촬영의 AI 정지는 외형 점검용이며 실제 전투 검사와 별도다.

## 핵심 검증과 실패 보존

외부 근거 루트는 `content-expansion-20261009/`이며 재현 도구는 저장소에 둔다. 해시/명령/검사 범위를 각 JSON에 기록한다. 같은 검사를 문서마다 복제하지 않는다.

1. `node tools/sim/content_expansion_20261009.mjs --out=<새 외부 경로>`: 최신 일반판 생성 설정 위에서 **3인 생성자 + 2seed씩 6대결, 15,142step**. 모든 수치 유한, 원형 대비 외형의 질량·관성·기하 불변, 학교/무기/파지/재생성 일치, 각 인물의 실제 접촉과 새 상처를 확인했다. `native-final02/summary.json`의 `sourceStable`, `frozenUnchanged`, `engineUnchanged`는 모두 true다. AI가 플레이어 입력을 대신하므로 인간 플레이/자연스러움/승률 평가와 구분한다.
2. 토메의 초기 후보는 유효 접촉 없이 빨리 패배했다. 사용하는 자세 ID를 교정하고 가까운 준비 A, 더 적극적인 B, 시작 자세 C를 같은 2seed로 좁혀 비교했다. **A의 간격 .39→.25, 준비 .76→.64만 채택**했다. 힘·공통 AI는 그대로다. 최종에서 찌르기 명령13회, 유효 접촉12회(둔타11/베기1), 새 상처1이지만 실제 찌르기 접촉은0이다. 전문가의 찌르기 성능을 검증 완료로 쓰지 않는다. 실패와 후보는 `tome-persona-comparison.json`에 남긴다. 사용자 지시로 추가 성향/밸런스 조정은 중단한다.
3. 오마리 실제 베기·상처와 영만 실제 베기·양손 파지를 확인했다. 이번 짧은 대결에서 새 인물의 절단·무기 파손·기립 장면은 미노출이다. 모든 손상 장면을 전수 검증했다고 하지 않는다.
4. 근접 화면에서 오마리의 모자가 떠 보이는 결함을 발견해 모자 전체를3.5cm 내렸고, 실제 게임 재촬영과3인 생성자 검사를 다시 통과했다. 전투 공식은 바뀌지 않아6대결은 반복하지 않았다. 외형 자체의 14개 상처 표면·무갑옷/무투구·유한 geometry·자원 해제와 기존 visual_resources21검사를 확인했다. 강체 부위에 붙인 복식이므로 극단 굴곡에서 천처럼 접히지 않거나 겹칠 가능성은 남는다.
5. 무대 단독 렌더/3회 자원 해제와 실제 게임 조명 기준, 휴대폰 크기에서 정상 무기 카드 선택→터치 이동/공격→일시정지→새 판을 확인한다. 공개 파일 바이트와 로컬 빌드 일치는 영수증에 갱신한다. SwiftShader의 실행 시간은 실물 휴대폰 성능으로 해석하지 않는다.

개발 회귀6묶음(힘·파지·절삭·팔 연결·기존 대결·빌드)을 모두 통과했다. 결과의 소스 안정성을 확인했으며, 사진/모자 수정 이후 최종 소스로 실행했다.

공개 배포 `af98fff`와 Pages Actions `37900661426` 성공 후 로컬/공개 각각3개 모바일 흐름을 완료했다. 공개 요청470건/고유169파일이 검증한 빌드와 일치했고 오류0, 실제 터치 무기 선택·이동·공격·일시정지·재시작을 확인했다. 브라우저의 짧은 조작에서는 상대 상처가 미관측이므로 native 대결 근거와 구분한다. 세 사진·선택 화면·주 게임 파일도 별도 HTTP200/바이트 일치를 확인했다.
