# 플랑베르주 외형 · 2026-10-11 KST

사용자 요청: “플람베르쥬(이름 맞나?) 무기 디자인해줘 원전에 충실하게”. 일반 표기는 플랑베르주. 이전 사용자가 특수효과를 직접 정한다고 했으므로 이번은 에픽 후보의 **실제 절차적 3D 외형과 모바일 회전/확대 뷰어**다. 무기 목록·추첨·전투 물리·피해·검술 보정·특수효과는 변경하지 않는다. 기준 `e09ba2a`.

## 원형과 재현 범위

[Cleveland 1919.71](https://www.clevelandart.org/art/1919.71), *Two-Handed Sword with Flamboyant Blade*, 독일1550–1600. 이번에 공식 페이지·공식 API·유물 사진을 직접 확인했다. API의 trailing slash 경로와 원본 사진 CDN은403, 정상 API 경로와 공식 사이트 사진 리사이즈는200이었다. 접근 제한을 우회하거나 TLS 확인을 해제하지 않았다.

공식 치수: 전체168.9cm, 날118.7cm, 리카소26.7cm, 코등이50.5cm. 날118.7cm 안에 리카소26.7cm가 포함된다. 날을 세운 나머지는92.0cm. 공식 재료는 강철·가죽/목재 손잡이·황동 리벳·청동 폼멜이다. 웹 무게2.98은 단위가 없어 이번에 확정 질량으로 쓰지 않았다.

사진의 촘촘하고 얕은 물결, 긴 곧은 리카소, 앞쪽으로 휜 보조 갈고리, 휜 넓은 코등이와 여섯 열린 말림 장식, 두 구간의 검갈색 손잡이·리벳·각진 청동 폼멜을 반영했다. 기존 게임의 `bladeGeometry`와 금속 환경 재질을 재사용한다. 양날 단면·날 세움·끝으로의 두께 감소를 실제 기하로 만든다. 후광이나 불꽃은 없다.

사진 추정: 물결22주기, 날 밑동 단면6.4mm, 세부 곡률·뒷면 장식. 이 수치는 박물관 실측이 아니다. 부식/손상은 줄여 사용 가능한 무기로 표현한다. 정확한 스캔 복원이나 역사적 평균 무기라는 주장은 하지 않는다. 칼날 때문에 출혈/파손이 자동 증가한다는 효과도 부여하지 않는다.

## 검증과 수정

실제 메시 경계에서 전체 길이1.689m/코등이0.505m와 유한한 기하를 확인한다. 휴대폰320/390/844px, 네 시점·터치 회전·확대/축소·조작 뒤 화면 크기 변경·뒤로가기 캐시용 persisted-pagehide 모의·사진5개 디코딩을 검사한다. 실제 휴대폰/Safari 성능 측정과 전투 검증은 아니다. 독립 검토에서 코등이의 아래 말림2개 연결 공백, 페이지 캐시 복원, 리사이즈 후 임의 시점 초기화를 발견해 수정했다. 사진은 같은 모델의 실제 렌더이며 생성 이미지가 아니다. 초기 합성 회전 직후 확대 탭 검사는 간헐적으로 실패했다. 버튼에 `touch-action:manipulation`을 명시하고 프레임 간격이 있는 터치 입력으로 검사한다. touchstart/end를 관찰하는 진단은 입력 전달에 영향을 줄 수 있어 최종 검사에서는 제외했다. 원인 전체를 확정한 것으로 쓰지 않는다.
