# 김씨 · 한낮의 청람잔도 제안

기준 `444e91269df97821b7c999c372380daba3762314`. 요청은 중국식 절경의 **제안서**다. 게임 무대 제작/전투 변경은 이번 범위가 아니다. 사용자 후속 지시로 이전 ‘비 갠 오전10–11시’를 철회하고 **맑고 화창한 한낮 정오**로 변경했다. 계절은 기존 추천의 초여름을 유지한다.

휴대폰용 정본: [한낮의 청람잔도](https://yoonjl-svg.github.io/halfsword-codex/kim-qinglan-proposal.html). 김씨 소개에서도 연결한다. 그림은 구도 개념도이며 실제 렌더나 완성 모델이 아니다.

- 가상 중국 남부 석회암 협곡. 둥근 탑형 봉우리·옥빛 강·천연 돌다리를 하나의 지형 언어로 묶는다. 특정 실재 명소의 복원으로 주장하지 않는다.
- 대표 장면: 밝은 석회암과 바위문 아래의 깊은 그늘, 구멍 너머로 이어지는 강/먼 산. 거대한 아치 하나에 무대의 인상을 집중한다.
- 정면 협곡, 측면 연결된 잔도, 뒤 암벽과 작은 샘/차양. 전투 공간은 넓은 자연 암반 쉼터다. 맑은 시야와 정오의 짧은 그림자, 밝은 바위 앞 검은 의복의 가독성을 우선한다.
- 근접 정교함은 돌의 광물맥·마모·틈 그림자, 작은 샘 주변의 물/이끼. 큰 폭포·사찰·연등은 추가하지 않는다.
- 음향은 샘물 낙수, 먼 강물, 잎/차양 바람, 드문 작은 새. 구현/청취/성능 검증은 아직 하지 않았다.
- 김씨는 이 길을 지나가는 여행자다. 국적·복식·무기·AI/물리는 바꾸지 않는다. 현재 플레이 입구는 `foe=renji&stage=sacred_grove`다.

제안 검토에서는 실루엣·지질 이미지 혼합·360° 구도·인물 가독성만 독립 점검했다. 일반적인 지형 지식과 창작 설계이며 현장 실측/문헌 연구 성과가 아니다. 외부 UNESCO페이지 조회는403으로 실패했고 읽은 출처처럼 인용하지 않았다. 그림/웹문서 점검은320/390/844px와 공개 파일 해시 대조로 제한하며, 변경 없는 게임 전투 실험을 중복하지 않는다. 전달 상태는 [영수증](kim_qinglan_proposal_release.json)을 따른다.
