# 간장·막야 제작 · 2026-10-10 KST

사용자가110/106cm 제안에서 각각10cm를 줄이고 짧은 막야를 더 무겁게 제작하도록 승인했다. 기준은 `af2e03d`. 검정/흰색의 은은한 후광, 레전드 불괴, 별도 특수 능력 없음, 한 자루 무작위 선택은 이전 결정이다. 춘추 유물의 실측 복원이 아닌 전설 각색이다. 플랑베르주는 이번 범위가 아니다.

| 실제 물리 제원 | 간장 | 막야 |
|---|---:|---:|
| 전체 / 날 / 손→끝 | 100 / 77 / 89cm | 96 / 73 / 85cm |
| 질량 | 0.95kg | 1.12kg |
| 손 기준 COM | 26.127cm | 24.753cm |
| 손 기준 횡회전 관성 | 0.126901kg·m² | 0.136742kg·m² |
| 후광 | 먹빛 투명 아지랑이 | 흰 아지랑이·약한 조명 |

막야는 약17.9% 무겁고 손 기준 관성은 약7.8% 크다. 전체 길이는 폼멜끝−11cm를 포함한다. 칼날 끝은 물리와 동일하고 폼멜 테두리는 수mm 더 보일 수 있다. 질량/COM/관성은 네 부품에서 계산하며 제어 힘에 별도 보상을 곱하지 않는다. 두 검의 베기/찌르기 계수는 동일1.15, 둔타0.95, 레전드 공통 위력1.2다. 갑옷 무시·파손 증폭·패리 뒤 강화 능력은 없다.

간장은 회금 강철·귀갑문, 막야는 은강철·물결결을 기하로 만들었다. 제작 중 사용자 후속 요청에 따라 간장은 밝은 손잡이/어두운 칼날, 막야는 어두운 손잡이/밝은 칼날로 교차한다. 후광·질량·길이는 유지한다. 기존 중국 호심과 원반 폼멜을 사용한다. 새 텍스처 대신 실제 모델의 카드 그림2장만 추가(최종2,250/2,580B)했다. 후광은 엑스칼리버와 같은0.5 세기/교차판2장이다. 먹빛에는 음수 조명이나 주변을 밝히는 조명을 쓰지 않는다. 엑스칼리버 색·세기는 유지하고, 해제 시 원래 재질을 복원한다.

일반 카드 추첨은 등급→독립 묶음→실제 무기 순이다. 간장·막야는 한 묶음이며 같은 판에 둘 다 일반 카드로 나오지 않는다. 카드 공개 전에 실제ID를 정하므로 카드/전투/판 도중의 회복에 같은 검을 쓴다. 다음 새 판은 새 추첨이다. `?cards=ganjiang,moye` 체험은 두 검을 직접 비교하도록 강제로 제시한다. 불괴는 기존legend 파손 확률0 경로를 그대로 쓴다.

검술v2는 범용 one:versatile로 연결한다. 상대 강제 무기에 쓰는 AI 꾸러미도 기존 지안 기술을 공유한다. 그 간격은 청강검 대비 손→끝 길이 비례 **추정값**이며 새로 실측한 표라고 표시하지 않는다. 기존 무기 물리·공통 제어식은 변경하지 않았다.

- `node tools/sim/experiments/legendary_jian_gate.mjs /tmp/fresh-jian-report.json`: native4흐름(각10초), 보정v2·실제질량/관성·몸 유한값·청강검 파손 공격에도 불괴·후광 갱신의 물리 snapshot불변·후광 해제/geometry정리 PASS. 첫 검사 스크립트의 존재하지 않는 Fighter.dispose 호출은 clearLoose로 바로잡았다. 게임의 결함으로 분류하지 않는다.
