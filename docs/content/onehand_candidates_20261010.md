# 중국 한손검 추가 후보 · 2026-10-10

사용자 요청은 후보 추천이며 제작·등급·특수효과 승인이 아니다. 기존 기록에는 월왕구천검이 간장·막야의 비교유물로 등장한다. 나머지는 이번 추가 추천이다. 추천은 외형·소재 구분이며 밸런스/효과 설계는 하지 않았다.

| 후보 | 근거 성격 | 외형 방향 |
|---|---|---|
| 월왕구천검 | 실제 출토유물 | 짧은 청동검, 검은 마름모문과 청색/청록 장식 |
| 칠성용연검 | 고전 명검 전승 | 정통 중국 장검과 칠성 장식; 장식 해석은 창작 |
| 승영검 | 《열자》 명검 전승 | 희미한 검신/그림자에서 착안한 반투명 외형은 창작 |
| 어장검 | 고전 암살·명검 전승 | 물고기에 숨긴 검 이야기에 따른 짧고 조밀한 외형 |
| 의천검 | 김용 《의천도룡기》 | 유명 무협 장검; 조조의 동명검과 구분 |
| 적소검 | 유방 관련 후대 명검 전승 | 붉은색·금장 배색은 창작 가능하나 기존 직선검과 윤곽 중복 |

[후베이성박물관 공식 구천검 소개](https://www.hbww.org.cn/treasureofmuseum/p/5253.html)를 이번에 HTTP로 확인했다. 전체55.7cm·폭4.6cm, 춘추 말기, 검은 마름모문·조전 명문, 앞면 청색 유리질/뒷면 터키석 장식을 명시한다. 이를 긴 장검으로 늘리면 유물 복원이 아닌 각색이다. 다른 후보에는 실측 길이/무게를 배정하지 않았다. 용연·용천 전승과 현대 용천 제검문화 전체를 하나의 출토 실물로 취급하지 않는다.
