# 습지 뱃사공 라트나와 중앙 말레이곰 입상 · 2026-10-13

기준: `a624948f66b36c33d78fb5f397f754ff2ba81c04`. 사용자 승인: 어깨 원숭이, 자연스러운 새치, 황토색 바지, 특수 신발의 습지 감속 면제, 결투장 중앙의 충돌하는 곰 입상. 후속으로 칭호 ‘습지 뱃사공’과 사용자가 제공한 말레이곰 사진의 형상을 확정했다.

## 구현

- 라트나 v2: 작은 원숭이를 왼쪽 어깨에 앉히고, 회색 덩어리를 가는 새치로 바꿨다. 밝은 황토색 무릎바지와 넓은 갈대·나무 밑창. 공통 신체/눈/충돌 크기는 그대로이며 v1을 보존한다. 원숭이는 몸통에 붙는 외형이고 별도 동물 AI/타격 대상이 아니다.
- `terrainTraits.wetlandImmunity`: 캐릭터 신발 능력으로 웅덩이의 자발적 이동 감속을 면제한다. 팔션 이름에 묶지 않는다. 자동 균형, 중력, 공격 힘은 수정하지 않는다.
- 선택형 `sluice` 중앙 [0,0,0]의 말레이곰 입상: 양 앞발을 내린 자세, 작은 귀, 밝은 주둥이와 U자 가슴 무늬를 석재에 표현한다. 고정 충돌체8개로 몸·무기를 막는다. 총알은 기존 world ray 경로에서 차단되며 별도 갑옷/피해 특례가 없다. 가는 귀/표면 흠집에는 세부 충돌체를 추가하지 않는다.
- AI는 실제 이동 입력의 방향만 돌려 석상을 우회한다. 대기·부활·후퇴·정지 공격 입력과 입력 크기를 보존한다. 상대가 회피 여유 반경 안에 있을 때 영구 선회하지 않도록 도착점을 처리한다. 카메라는 석상을 가로지르거나 안으로 들어가지 않게 제한한다.
- 바닥 지지 계측은 접촉력의 상향 성분만 사용한다. 수직 석상/벽에 발을 부딪힌 힘을 체중 지지로 오인하지 않도록 고쳤다. 기존 수평 바닥 fixture의 값은 정확히 동일하다.
