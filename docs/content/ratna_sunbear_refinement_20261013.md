# 라트나 위라세타쿤·회색 말레이곰 보완

기반 `af089db` / 사용자 승인: 짧고 솟은 부처형 곱슬·가는 새치, 원숭이 안쪽 이동, 레이피어, 사진을 닮은 회색 말레이곰. 최종 이름은 **라트나 위라세타쿤**, 칭호 **습지 안내인**. 이전 뱃사공 설정은 오마리와 겹쳐 대체했다.

## 구현

- 기본 외형 v3. v1/v2 기록 유지. 작은 나선형 곱슬과 가는 새치. 원숭이 전체를 목 방향3cm 이동하고 발의 어깨 접촉 높이 보정.
- 레이피어와 기존 해당 무기의 유파/자세 사용. 기존 습지 감속 면제 신발 유지.
- 곰은 사진의 둥근 배·기울어진 어깨·벌어진 다리·낮은 발·긴 발톱, 작은 귀와 짧은 주둥이를 회색 돌로 조형. U무늬는 얕은 부조와 작은 명도차. 착색 동물로 만들지 않았다.
- 가까운 실제 렌더에서 첫 얼굴은 졸린 눈과 웃는 입 때문에 사진과 다르다고 판정했다. 눈썹 막대와 과한 입/턱 볼륨을 제거하고 작은 열린 눈·짧은 입선으로 재수정했다. 고개 회전 후 목 경계 틈과 돌출된 눈알도 실제 렌더에서 발견해, 겹쳐 이어지는 목 전이와 피부에 붙은 타원형 눈으로 고쳤다.
- 중앙 위치/기단과8개 충돌체 계약 유지, 새 몸 비율에 충돌체를 맞췄다. 배가 시작되는 높이가 바뀌어 레이/물체 검사는 실제 배와 다리의 새 위치를 사용한다. 시각적으로 열린 다리 사이를 가짜 충돌로 메우지 않는다.
