# 수상한 세르파 · 2026-10-10

기준 커밋 `5a4e96cb8b7501c8c1f21966797d7c5ee8a3c43f`. 사용자: “무언가 조사하고 있는 수상한 세르파 성별 불상”과 참고 이미지 두 장. 외형을 우선하며 승률 조정은 하지 않는다.

## 설정과 범위

- 성별·이름·나이는 공개하지 않는다. ‘세르파’는 우선 호칭이며 산악 안내인으로 해석했다. 특정 민족 전체의 성향을 설정한 것이 아니다.
- 흰 머리천, 검은빛 머리와 짧은 묶음, 비대칭의 긴 아이보리 숄, 구릿빛 피부, 갈색 바지, 손목 보호대와 흰 각반. 허리 기록장·표본 주머니로 조사자의 역할을 드러낸다.
- 실제 민속 복식 고증이 아닌 사용자 이미지에서 출발한 개인의 창작 여행복이다. 원본 이미지 파일은 배포하지 않는다.
- 별도 `?cards=sain,ice&foe=sherpa&stage=qinglan` 입구. 기존 청람잔도를 임시로 사용하고 캠페인 순서는 그대로다. 기존 세이버·AI 유파를 사용한다. 신규 무기/전용 무대/특수 능력을 만든 것은 아니다.
- 공통 얼굴·눈·신체·손·물리·갑옷 판정을 사용한다. 외형 소품은 충돌체가 없다. 천은 부위별 부착 메시이며 독립적인 천 물리나 모든 자세의 관통 해소를 주장하지 않는다.

첫 시안 실제 촬영에서 각진 몸통과 가는 띠 같은 숄이 참고 인상을 약하게 만들었다. 옷 모서리의 곡면과 목/어깨 천의 폭·주름을 보강했다. 대표 메시의 정체성은 유지하면서 의복 표면만 둥글게 했고 무릎의 바지/각반 겹침을 보완했다. 첫 사진과 검사 결과는 `attempt-1`로 보존하며 최종 검사는 수정 소스로 수행한다.

## 재현과 판정

`node tools/sim/experiments/sherpa_gate.mjs /tmp/halfsword-sherpa-20261010/native.json`

실제 게임 생성 상태의 물리 동일성, 공통 얼굴/눈, 480step 입력과 관절 유효성, 별도 합성 상처 뒤 외형 보존을 검사한다. 전투 승률·자연스러움·미적 수락 근거로 확대하지 않는다.

기존 `tools/browser/new_pair_delivery_20261010.mjs`에 `--encounter=sherpa`를 추가해 같은 모바일 카드선택·터치공격·이동·일시정지·재개·재시작을 사용한다. 로컬/공개는 같은 동결 빌드와 도구/등록 제원 해시를 비교한다. 별도 외형 사진은 게임 메시를 공통 관찰 조명에서 촬영한 것이다.

빌드와 원자료는 `/tmp/halfsword-sherpa-20261010`, 모바일 검사 출력은 `/tmp/halfsword-new-pair-20261010/sherpa-local` 및 `sherpa-public`에 보존한다. 최종 수치·웹 전달·근거 압축본은 [영수증](sherpa_release.json)에 기록한다. 실물 휴대폰 성능 측정과 사용자 미적 평가는 별도다.
