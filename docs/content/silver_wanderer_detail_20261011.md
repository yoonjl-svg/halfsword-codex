## 변경과 판단

- 높은 깃의 문양을 실제 천 곡면에 맞춘 은색 줄기·잎·말림으로 제작. 기존 손배치 선이 표면 안으로 묻히던 부분을 교정하고 망토 가장자리도 곡면에 맞췄다.
- 어깨의 문장 자수, 보라색 손목띠의 반복 문양과 겹친 은색 테두리, 상의 단추, 허리띠 박음질·버클·구멍·고정끈을 추가했다.
- 검집에 금색 입구/끝장식·각인·매다는 고리와 가죽 띠를 추가. 입구는 어두운 내측과 열린 금속 테두리로 구분했다. 뒤쪽 머리에 가는 결, 옷자락·각반에 얕은 장식선을 더했다.
- 흰 몸통의 각진 명암은 이 외형에 한해 곡면 분할을 보강하고 같은 위치의 법선을 평균냈다. 공통 함수/다른 인물/얼굴/눈/신체 물리를 수정하지 않는다.
- 확대 검토 후 이중 고리 문양을 식물형 줄기/잎으로 바꾸었다. 작은 금속선의 과도한 분할을 줄였다. 고해상도 텍스처, 천 시뮬레이션, 새 전투 성능을 추가한 작업은 아니다.

## 재현과 검증

기존 `tools/sim/experiments/silver_wanderer_gate.mjs`를 최종 소스에서 실행한다. 장식 유무 물리 snapshot, 공통 얼굴/눈, 480step 실제 입력과 관절, 합성 상처 후 장식 부착을 검사한다. 브라우저에서 자연 상처를 관찰하지 못한 경우 이 합성 검사와 구분한다.

`CAPTURE_IDS=silver_wanderer CAPTURE_VIEWS=front,threeq,back,detail,fittings CAPTURE_BASE=http://127.0.0.1:4280 CAPTURE_OUT=/tmp/halfsword-silver-20261011/detail/portraits-delivery node tools/browser/native_character_portrait.mjs`

실제 게임의 시작 자세를 같은 관찰 조명/카메라로 촬영한다. 재실행의 정착 프레임 차이는 있을 수 있다. 전후 사진은 이미지 편집으로 모양을 바꾼 것이 아니다. 별도 천 물리나 모든 자세의 관통 방지, 실물 휴대폰 성능과 사용자 미적 수락까지 검증한 것으로 확대하지 않는다.

빌드는 `/tmp/halfsword-silver-20261011/detail/build`, 모바일 검사 출력은 `/tmp/halfsword-new-pair-20261010/silver-detail-local-final`과 `silver-detail-public`. 기존 전달 도구에 같은 7개 사진·전후 보기·카드 선택·터치·이동·일시정지/재개·새 라운드 재시작을 검사한다. 최종 수치·해시·공개 결과는 [영수증](silver_wanderer_detail_release.json)에 남긴다.

개발 서버의 이전4281 포트가 남아 있었고 첫 모바일 검사가 동결 빌드 불일치를 차단했다. 실패 기록을 보존하고 새4290 포트에서 현재 빌드로 재실행한다. 코드의 성공으로 그 실패를 기록하지 않는다.

최종 native8항목·빌드·로컬 모바일1흐름 통과, 가져온192파일 해시 일치·오류0. native 집계112메시/31,274삼각형. 장식선 분할 조정 전39,854에서8,580삼각형 감소했으며 FPS 개선 측정은 아니다.
