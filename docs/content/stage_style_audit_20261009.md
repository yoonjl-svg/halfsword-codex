# 기존 6무대와 신규 3무대의 스타일 비교 · 2026-10-09

판정: 기술 기반은 일치하지만 외형 통일은 미완료다. 신규 이탈리아 회랑·항구는 기존 무대보다 표면의 사용 흔적과 중간 크기 소품이 부족하고, 신목 숲은 잎 표현의 단위가 더 작다. 기존 배경의 큰 면·거친 질감·생활 흔적을 기준으로 신규 배경을 교정하는 것이 적절하다. 이번 작업은 비교 조사이며 외형이나 물리 변경은 없다.

## 범위와 방법

- 소스 HEAD `7bb7235c27257ac352ccfceb77e6ce1c391b3133`, 화면은 기존 공개 검증을 마친 `af98fff`의 보존 빌드(`main-D4tsxxne.js`). 두 커밋 사이 변경은 앞 작업의 문서 영수증이다.
- 우리 저장소에 포함된 기존 poseidon/clearing/temple/castle/poseidon_night/cathedral과 신규 loggia/corsair/sacred_grove를 비교했다. 상대 저장소 최신본과의 일치 여부를 주장하지 않는다.
- 844×390, DPR 1, FOV 55°, 같은 두 검객·롱소드·동일 정지 자세. 정면/90°/180° 27장과 같은 광색·광량으로 바꾼 보조 비교 6장. 보조 비교도 무대별 광원 방향·안개·구운 정점 색을 유지하므로 완전한 중립 재질 렌더는 아니다.
- 원근 비교의 정면 카메라는 `[-5.9445082, 2.4637224, 0.8995614]`, quaternion `[-0.0933650,-0.6413326,-0.0790524,0.7574472]`. 물리 시간 1.3667초에서 멈췄다.
- 별도 배경 전용 계측은 캐릭터/UI/음향 없이 동일 renderer와 고정 카메라를 사용했다. 9개 생성·렌더 완료, 요청 실패/콘솔 오류 0, 소스 해시 불변. SwiftShader이므로 실제 휴대폰 FPS를 판정하지 않는다.

## 현재 비용

삼각형은 인스턴스를 펼친 배경 전체 형상 수이며 시야 밖도 포함한다. 호출은 고정 시점의 컬러 패스만 세었고 그림자는 별도다. 두 값은 같은 개념이 아니다.

- 형상은 고유 업로드 버퍼 바이트 추정이며 인스턴스 행렬/색을 포함한다. 질감은 RGBA8+생성 mipmap 가정이며 그림자·프레임버퍼·PMREM·드라이버 복사본을 제외한다. 실제 전체 VRAM 또는 다운로드 크기가 아니다.
- 회랑은 삼각형 수가 낮아도 반복 구조를 인스턴싱하지 않아 형상 버퍼가 포세이돈보다 크다. 1024² 포장 질감만 약 5.33MiB다. 512²로 줄이면 해당 질감 약 4MiB를 줄일 수 있지만 근접 외형 비교 전에는 축소하지 않는다.
- 항구는 형상/호출이 가장 적지만 바다가 화면의 픽셀마다 noise·반사광을 계산한다. 따라서 삼각형만으로 가장 빠른 배경이라고 판정하지 않는다.
- 숲은 12,740개 잎 평면과 180개 지면 식생 인스턴스, 투명 안개 3개를 사용한다. 적은 호출 수와 별개로 잎 겹침/알파 폐기·안개 반복 그리기가 부담이 될 수 있다. 실제 폰 계측 전 병목으로 확정하지 않는다.

## 다운로드와 질감 방식

기존·신규 모두 배경용 외부 모델/이미지 다운로드 없이 절차적 형상과 CanvasTexture를 만든다. 기존 포세이돈에는 작은 기둥 홈 normal map도 있으며, 새 배경이 고해상도 외부 PBR 자산으로 제작된 것은 아니다. 새 3개는 같은 Kit·vertexColors·재질별 병합을 사용한다.

신규 3소스 원문 합계 65,366B, 파일별 gzip9 합계 21,269B(주석 포함, 공통 코드 제외). 이는 실제 추가 전송량이 아니다. 모든 무대는 정적 import되며 보존된 전체 main 번들은 2,918,650B, 로컬 gzip9 1,074,391B다. HTTP 실제 압축 방식/캐시 상태와 개별 무대 전송 기여는 이번에 계측하지 않았다.

회랑의 1024² 바닥, 항구의 1024×512 하늘은 기존의 256²/512² 중심 표면보다 해상도가 높다. 그래도 화면에서 더 풍부하게 보이지 않는다는 점이 이번 교정의 핵심이다.

## 구체적인 교정 우선순위

1. 회랑: 남색 아치 안쪽의 공간과 명암, 포장 마모/큰 얼룩, 약한 모서리 변화. 건축의 정연함은 유지.
2. 항구: 부두 가장자리·바닥의 사용 흔적, 결투면 밖 밧줄/화물 등의 중경 묶음, 해안 연결. 배의 큰 실루엣은 유지.
3. 숲: 알파 잎을 큰 덩어리로 읽히게 조정, 바닥 낙엽/뿌리 흔적과 중경 명암. 거목·금줄·안개는 유지.
4. 공통 누락: `PX_BACKS`에 신규 3종이 없어 전용 카드 뒷면 대신 classic으로 떨어진다. 기존 디자인 지침의 무대별 카드 뒷면을 보완해야 한다.

위 항목은 조사 후 제안이며 구현/배포 완료 항목으로 세지 않는다. 관중·요란한 효과·전투면 장애물을 추가할 필요가 없다. 기존 산사 등을 줄여 신규의 낮은 밀도에 맞추지 않는다.
