## 간장·막야 · 제작 전 제안 이력

**후속 제작 승인:** 사용자가 아래110/106cm에서 각각10cm를 줄이고 막야를 더 무겁게 하도록 정했다. 현재100/96cm 구현·검증은 [제작 기록](legendary_jian_20261010.md)을 따른다. 아래 표는 대체된 이전 제안이다.

사용자는 짧은 고대 유물 복원보다 긴 전설 무기를 원한다. **레전드, 엑스칼리버 정도의 은은한 후광, 한 자루는 검정/다른 자루는 흰색, 별도 특수효과 없음, 부러지지 않음**을 제작 조건으로 반영한다. 아래 길이는 새 설계 제안이며 아직 게임에 추가한 수치가 아니다. 이전60/57cm 안과 패리 뒤 베기/찌르기 강화 효과안은 폐기한다.

| 새 제안 | 간장 | 막야 |
|---|---:|---:|
| 물리 전체 길이 | 110cm | 106cm |
| 날 길이 | 87cm | 83cm |
| 손 원점→칼끝 | 99cm | 95cm |
| 후광 | 검정, 옅은 먹빛 아지랑이 | 흰색, 은은한 백광 |
| 무늬 | 귀갑 무늬 | 흐르는 결 |

두 검 모두 현재 청강검(물리 전체97cm, 날74cm)보다 길게 제안한다. 치수·색은 전설을 각색한 게임 설계이며 사료의 실측값이 아니다. 질량·단면·무게중심은 장검화한 부품으로 재산출한다. 길이만 늘리고 이전 짧은 검의 관성을 복사하지 않는다.

전승의 두 검은 하나의 레전드 추첨 항목으로 묶고 첫 장착 전에50:50으로 선택한다. 선택한 실제ID는 판 끝까지 보존하고 부활·무기 놓침 때 재추첨하지 않는다. 일반 풀에 따로 두 장을 넣어 등장 비중을 두 배로 늘리지 않는다. 동시 쌍검술은 아니다.

`src/aura.js`의 현재 엑스칼리버는 투명한 교차판2장, AURA_STRENGTH=0.5, 약한 점광원/발광으로 표현된다. 흰색은 이를 재사용하고, 검정은 음수 조명 대신 NormalBlending의 옅은 어두운 막으로 표현한다. 검은 후광에 주변을 밝히는 점광원을 그대로 붙이지 않는다. 동일 수치가 동일 체감 강도를 뜻하지 않으므로 밝은 하늘/어두운 숲에서 엑스칼리버와 나란히 확인한다. 후광은 물리·피해 판정에 관여하지 않는다.

`src/weapons.js`에서 레전드는 `fragility=0`, `breakChance=0`, 공통 `power=1.2`다. 엑스칼리버의 `ability`도 없다. 두 검은 이 공통 규칙을 따르고 공격 강화 발동·갑옷 무시 등 고유 능력을 추가하지 않는다. 큰 충격량에서도 엑스칼리버의 파손 확률0임을 실제 함수로 확인했다.

《오월춘추·합려내전》의 “陽曰干將，陰曰莫耶，陽作龜文，陰作漫理”는 두 검과 무늬를 구별한다. 앞서 확인한 춘추/전국 비교 유물56–58cm는 당시 모든 검의 평균이나 간장·막야의 실측이 아니다. 이번에는 그 길이를 복원하지 않고 **긴 전설의 중국 한손검**으로 각색한다.

- [《오월춘추·합려내전》 원문 전사](https://zh.wikisource.org/wiki/吳越春秋/闔閭內傳): 이전 열람에서 확인한 두 검·무늬 근거.
- [후베이성박물관 월왕구천검](https://hbww.org.cn/treasureofmuseum/p/5253.html): 춘추 말기 약56cm. 구천검은 간장검이 아니다.
- [대영박물관1968,0424.1](https://www.britishmuseum.org/collection/object/A_1968-0424-1): 동주 청동검58.3cm.
- [Met1992.298.2](https://www.metmuseum.org/art/collection/search/44717): 전국 청동·터키석 검56.2cm.

### 청강검 길이 확인

현재 날74cm, 손 원점→끝86cm. 물리 폼멜 끝이 손 원점 뒤11cm여서 **물리 전체97cm**다. 장식 메시 끝은 이보다 수mm 더 나올 수 있어 외형은 약97cm로 표기한다. 기존86cm를 전체 길이라고 설명하면 잘못이다. 실제 `getWeapon('qinggang').buildParts({})`에서 칼끝0.86m·폼멜 중심−0.09m/반지름0.02m를 확인했다.

이것은 청강검의 확정 실측이나 역사 문헌에 명시된 치수로 검증된 값이 아니다. 기존 코드 주석의 일반 지안 날70–80cm 설명도 이번에 역사적 표준으로 입증하지 못했다. 직접 확인한 [Met 한나라 청동검36.25.1483](https://www.metmuseum.org/art/collection/search/31113)은51.1cm, [Met19세기 중국검32.75.308a,b](https://www.metmuseum.org/art/collection/search/27932)는 칼집 제외69.9cm다. 서로 다른 두 표본만으로97cm가 맞거나 틀리다고 판정할 수 없다. 《삼국연의》41회 웹 원문은403/보안 확인에 막혀 이번에 치수 언급 유무를 직접 재검증하지 못했다. 따라서 **청강검은 후대 지안형을 참고한 창작 제원**으로 설명하고 역사적 복원 치수라고 주장하지 않는다. 이번 질문으로 청강검의 길이 자체를 바꾸지는 않는다.

## 플랑베르주

물결날은 특정 크기나 양손 여부를 뜻하지 않는다. 이번 무기군은 독일16세기 후반의 물결날 양손 대검으로 정하고, 치수는 [Cleveland1919.71](https://www.clevelandart.org/art/1919.71) 한 점을 기준으로 한다.

| 항목 | 제안 / 근거 |
|---|---|
| 전체 / 날 길이 | 168.9 / 118.7cm, 박물관 표기 |
| 리카소 / 코등이 폭 | 26.7 / 50.5cm, 박물관 표기. 리카소를 날 길이에 다시 더하지 않음 |
| 질량 | 게임 초기값3.0kg. 박물관 웹의 `Weight:2.98`은 단위 누락이라 2.98kg 확정 실측으로 인용하지 않음 |
| 형상 | 물결 양날·긴 리카소·보조 갈고리·긴 코등이·양손 파지 |
| 에픽 효과 후보 | **파상 얽힘: 실제 칼날 교차 접촉 중 미끄럼 억제** |

효과의 출발 가설은 실제 칼날끼리 30° 이상 교차하여 누르는 동안 접촉 한 쌍의 접선 저항을1.5배로 하는 것이다. 양쪽 검에 같고 반대 방향으로 작용하며, 실제 법선 충격량에 묶는다. 손잡이·몸·갑옷·바닥에는 적용하지 않고 접촉 해제 즉시 끝난다. 두 플랑베르주가 닿아도 배율을 중복 곱하지 않는다. 역사적 계수가 아니라 구현 후 비교할 게임 규칙이다.

체감 목표는 맞댄 상대 검이 쉽게 빠져나가지 않아 눌러 제치는 공방의 기회를 만드는 것이다. 자동 반격·확정 파손·해제 후 숨은 경직을 만들지 않는다. 기존 `bladeClash` 접촉 자료를 활용할 수 있지만 접촉별 저항 구현과 에너지/해제 회귀가 필요하므로 구현비용은 중간이다. 곡선 외형만 만들거나 collider 마찰 한 줄을 올려 구현했다고 할 수 없다.

모노호시자오의 출혈, 청강검의 파손, 라이트세이버의 갑옷 무시와 다른 역할을 권한다. 물결날이 자동으로 출혈·파손을 늘린다는 역사적 설명은 하지 않는다.

- [Cleveland1919.71](https://www.clevelandart.org/art/1919.71): 독일1550–1600 물결날 양손검, 위 치수. 특정 전장에서 사용됐다는 이력은 확인하지 못했다.
- [Met04.3.290](https://www.metmuseum.org/art/collection/search/22002): 약1570 베네치아 **직선날** 양손검160cm/2863g. 질량 규모의 비교만 가능하며 물결날 원형이 아니다.
- [V&A M.184-1921](https://collections.vam.ac.uk/item/O97533/rapier-unknown/): 약1600 물결날 레이피어131.5cm/1280g. 제작 솜씨·외형 및 맨손으로 날 잡기 어려움의 가능성을 신중히 설명하며 자동 상처 증가를 증명하지 않는다.
- [Met04.3.60](https://www.metmuseum.org/art/collection/search/25077):1573 의장용 검195.5cm/4653g. 거대한 의장용 물건을 실전 표준으로 삼지 않는다.

## 사용자 후속 질문: 상처·출혈 목적과 단점

물결날이 더 큰 상처나 출혈을 일으키기 위해 만들어졌다고 확정할 근거를 이번 조사에서는 확보하지 못했다. V&A M.184-1921은 특히 정교한 물결/톱니날 레이피어의96개 돌기를 painstakingly forged라고 설명하고, 장인의 솜씨를 보여주거나 위협적인 외형으로 상대를 동요시키려 했을 가능성을 제시한다. 이 개별 레이피어의 설명을 모든 물결날 양손검의 제작 동기로 일반화하지 않는다. 동등한 조건의 직선날보다 상처/출혈이 크다는 정량 비교 자료는 확인하지 못했다.

굽이마다 날 각도와 윤곽을 맞춰야 해서 제작·연마·손상 수리가 더 까다로울 수 있다는 것은 형상에 따른 공학적 판단이다. 실제 역사적 공임 차이나 수명 감소를 측정한 결과로 제시하지 않는다. 약169cm/3kg 양손 대검의 긴 회수와 좁은 공간 사용 제약은 크기·질량 배분의 문제이며, 물결날만의 단점으로 혼동하지 않는다. 형태만 보고 모든 검이 더 약하거나 무겁다고 단정하지 않는다.
