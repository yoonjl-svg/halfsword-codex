## 간장·막야

전승의 두 검을 하나의 레전드 추첨 항목으로 묶고, 첫 장착 전 50:50으로 한 자루를 선택한다. 실제 선택된 ID를 판 끝까지 보존하고 부활·무기 놓침 때 재추첨하지 않는다. 두 ID를 일반 풀에 따로 넣어 등장 비중을 두 배로 늘리지 않는다. 동시에 두 자루를 사용하는 기능은 아니다.

| 제안값 | 간장 | 막야 |
|---|---:|---:|
| 전체 길이 / 날 길이 | 60 / 48cm | 57 / 45cm |
| 질량 | 0.84kg | 0.79kg |
| 무게중심, 코등이 앞 | 약13cm | 약12cm |
| 외형 | 회금빛·귀갑 무늬 | 은백빛·흐르는 무늬 |
| 특수효과 후보 | 실제 패리 후 첫 베기 강화 | 실제 패리 후 첫 찌르기 강화 |

치수·질량·무게중심·색·능력은 **설계값이며 간장·막야 실측이 아니다.** 질량은 가정한 단면·강철 밀도·자루 부품의 0.62–0.89kg 추정 범위에서 고른 초기값이다. 무늬의 대비만 전승에 직접 근거한다. 특효의 첫 비교값은 실제 칼끼리 받아낸 뒤 1.2초 이내 첫 유효 타격의 피해 계산 +15%다. 허공 자세·자동 명중·갑옷 무시는 포함하지 않으며 실제 접촉 감지와 기존 전설 등급 배율의 중복을 검증해야 한다.

《오월춘추·합려내전》은 “陽曰干將，陰曰莫耶，陽作龜文，陰作漫理”라고 두 검과 무늬를 구별한다. 치수나 불·얼음 능력은 없다. 전승에는 철을 말하는 대목이 있지만 아래 비교 유물은 청동검이다. 따라서 **춘추 오월검 형식을 참고한 전설의 신철검**이라는 창작으로 설명하며 출토품 복원으로 부르지 않는다. 전승의 두 검이라는 사실만으로 동시 쌍검술을 입증하지도 않는다.

직접 확인한 비교 유물은 약56–58cm다. 대표 표본 세 점이 당시 모든 검의 평균이라는 뜻은 아니다. 현재 청강검의 후대 지안형 74cm 날과 구별되는 짧고 단단한 윤곽을 추천한다. 더 긴 82/79cm 지안형도 구현할 수 있지만 후대 형식의 각색이라는 설명이 필요하다.

- [《오월춘추·합려내전》 원문 전사](https://zh.wikisource.org/wiki/吳越春秋/闔閭內傳): 두 검과 귀갑/흐르는 결.
- [후베이성박물관 월왕구천검](https://hbww.org.cn/treasureofmuseum/p/5253.html): 춘추 말기, 55.7cm. 박물관의 다른 소개는55.6cm라 본문에서는 약56cm로 취급. **구천검은 간장검이 아니다.**
- [대영박물관1968,0424.1](https://www.britishmuseum.org/collection/object/A_1968-0424-1): 기원전5–4세기 동주 금상감 청동검, 58.3cm.

## 플랑베르주

물결날은 특정 크기나 양손 여부를 뜻하지 않는다. 이번 무기군은 독일16세기 후반의 물결날 양손 대검으로 정하고, 치수는 [Cleveland1919.71](https://www.clevelandart.org/art/1919.71) 한 점을 기준으로 한다.

| 항목 | 제안 / 근거 |
|---|---|
| 전체 / 날 길이 | 168.9 / 118.7cm, 박물관 표기 |
| 리카소 / 코등이 폭 | 26.7 / 50.5cm, 박물관 표기. 리카소를 날 길이에 다시 더하지 않음 |
| 질량 | 게임 초기값3.0kg. 박물관 웹의 `Weight:2.98`은 단위 누락이라 2.98kg 확정 실측으로 인용하지 않음 |
| 형상 | 물결 양날·긴 리카소·보조 갈고리·긴 코등이·양손 파지 |
| 에픽 효과 후보 | **파상 얽힘: 실제 칼날 교차 접촉 중 미끄럼 억제** |

효과의 출발 가설은 실제 칼날끼리 30° 이상 교차하여 누르는 동안 접촉 한 쌍의 접선 저항을1.5배로 하는 것이다. 양쪽 검에 같고 반대 방향으로 작용하며, 실제 법선 충격량에 묶는다. 손잡이·몸·갑옷·바닥에는 적용하지 않고 접촉 해제 즉시 끝난다. 두 플랑베르주가 닿아도 배율을 중복 곱하지 않는다. 역사적 계수가 아니라 구현 후 비교할 게임 규칙이다.

체감 목표는 맞댄 상대 검이 쉽게 빠져나가지 않아 눌러 제치는 공방의 기회를 만드는 것이다. 자동 반격·확정 파손·해제 후 숨은 경직을 만들지 않는다. 기존 `bladeClash` 접촉 자료를 활용할 수 있지만 접촉별 저항 구현과 에너지/해제 회귀가 필요하므로 구현비용은 중간이다. 곡선 외형만 만들거나 collider 마찰 한 줄을 올려 구현했다고 할 수 없다.

모노호시자오의 출혈, 청강검의 파손, 라이트세이버의 갑옷 무시와 다른 역할을 권한다. 물결날이 자동으로 출혈·파손을 늘린다는 역사적 설명은 하지 않는다.

- [Cleveland1919.71](https://www.clevelandart.org/art/1919.71): 독일1550–1600 물결날 양손검, 위 치수. 특정 전장에서 사용됐다는 이력은 확인하지 못했다.
- [Met04.3.290](https://www.metmuseum.org/art/collection/search/22002): 약1570 베네치아 **직선날** 양손검160cm/2863g. 질량 규모의 비교만 가능하며 물결날 원형이 아니다.
- [V&A M.184-1921](https://collections.vam.ac.uk/item/O97533/rapier-unknown/): 약1600 물결날 레이피어131.5cm/1280g. 제작 솜씨·외형 및 맨손으로 날 잡기 어려움의 가능성을 신중히 설명하며 자동 상처 증가를 증명하지 않는다.
- [Met04.3.60](https://www.metmuseum.org/art/collection/search/25077):1573 의장용 검195.5cm/4653g. 거대한 의장용 물건을 실전 표준으로 삼지 않는다.
