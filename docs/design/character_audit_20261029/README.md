## 해석과 예외

- 위 유파는 서사 문장보다 실제 AI 꾸러미를 우선했다. 이졸데는 피오레 서사가 있지만 실제 독일. 하인리히는 기본 독일/얼터 파펜하이머 이탈리아. 마야는 기본 리볼버 무유파/얼터 세이버 독일. 브론은 칼을 들어도 noSwordsmanship으로 무유파다.
- **광기의 브론 main 버그:** 시트 숙련도는2지만 main의 persona.proficiency가 `{german:2}`여서 실제 사용하는 무유파 숙련도 조회는0이다. 이 표의2는 시트 설정값. wk/saengsa는 실제 꾸러미 유파로 키를 만들고 mainProficiency를 분리하여 이미 수정했다. main에 반영되었다고 보고하지 않는다.
- 보통 얼터는 기본+1, 상한5. 미나미·아르토리아는5→5. 광기의 병마용은 고정5 예외. 롤랑·베르나르도 기본6은 별도 허용 시트다. 무유파 숙련도는 유파 고유 검술이 아니라 AI 실력 계산에 쓰이는 숫자다.
- 생사전 보조 유파 표는 `STATUS='사장님 확인 전'`. 실제로 saengsa_roster → saengsa_proficiency → character_temperament로 카드/빠른 계산에 연결된다. character_temperament 파일 머리말의 '아무 데도 이어지지 않음'은 이 연결에 비해 오래된 설명이다. 일반1:1/AI 전체에 적용된 것으로 해석하지 않는다.
- 생사전 현재 일반 고용 후보는 주 인물12명 중 아르토리아를 뺀11명 + 무명 검객. 특별 동료 목록은 아직 빈 배열.19명을 모두 고용할 수 있다고 말하지 않는다. 얼터가 그 모드의 로스터에 없으므로 생사전 표의 원본 반환을 일반 얼터 숙련도에 덮어쓰지 않는다.
- 플레이어의 숙련도는 고정 인물 시트가 아니다. 생사전 가지는 유파별 학습 스킬에 따라1~5(기본1,2칸→2,5칸→3,비기+특수공격→4,전부→5)를 산출한다.
