# 밤의 봉인의 중정 — 2안 ‘돌아온 것은 말뿐’

**상태: 사용자 “다시 잡아봐”에 따른 새 콘셉트 제안. 서사/제작 미확정이며 실제 게임 구현 전이다.** [1안과 소금사막 중복 검토](CONCEPT_V1.md)는 이력으로 보존한다. 최신 수신 기준은 우화81497436이며 [원문11파일·해시](sources.json)를 유지한다.

## 장면과 사건

**첫 장맛비가 한 차례 지나간 새벽3시. 메말랐던 계단우물에 물이 돌아왔고, 밤사이 주인 없는 군마 두 마리가 중정으로 들어왔다. 안장은 젖어 있지만 기수는 없다.**

마야가 기다리는 동료들은 돌아오지 않았는데, 그들을 태웠을 법한 말들만 물가로 돌아온 장면이다. 말이 실제 그 동료들의 것인지, 마야가 그렇게 믿고 있는 것인지는 단정하지 않는다. 마야의 과거를 새로 확정하지 않고 ‘기다림을 끝내지 못하는 전령’이라는 얼터의 해석을 제안한다.

화면 이름은 ‘밤의 봉인의 중정’ 그대로. ‘돌아온 것은 말뿐’은 제작 콘셉트다. 기존의 봉인된 문은 닫힌 상태로 남긴다. 낮의 마야는 리볼버, 현재 확정된 얼터 마야는 세이버/열린 문서 가방이라는 최신 캐릭터 설정을 바탕으로 한다.

## 핵심1 — 차오른 계단우물

낮에는6.25m 아래에 작게 보이던 물이 밤에는 위쪽 몇 단을 남기고 올라와, 겹겹의 계단 일부를 잠근다. 정확한 수위는 원근/기존 단높이를 보고 정한다. 먼 산/역참 지붕에 내린 첫비가 모이는 장면이며 물은 현재 우물 영역 안에 머문다.

- 위쪽 배수구 한두 곳에서 가는 물줄기가 흘러들어 파문을 만든다. 직전까지 비가 내렸음을 젖은 계단과 처마 물방울로 읽게 한다.
- 물은 어두운 청록/회흑색, 달빛은 수평면의 가장자리와 파문 일부에만 잡힌다. 자체 발광이나 형광색으로 표현하지 않는다.
- 라자스탄 계단우물의 반복되는 계단과 아케이드가 물 위/아래로 이어진다. 월광이 닿는 젖은 단과 물에 잠긴 단이 만나 낮과 다른 큰 형태를 만든다.
- 일반 전투 카메라에서 큰 수면과 남은 계단이 읽히는지 우선 본다. 위에서만 보이는 작은 우물 바닥 소품에 서사를 맡기지 않는다. 중앙 급수정의 윤곽이 수면을 완전히 가리는지 함께 확인한다.

## 핵심2 — 돌아온 군마 두 마리

라자스탄의 마르와리 말을 연상시키는, 귀 끝이 안쪽으로 굽은 말 두 마리. 이는 지역적 생김새 모티프이며 특정 시대 군마/장구의 고증 복원을 주장하지 않는다. 기본 게임의 말 표현을 재사용할 수 있는지도 제작 시 검토한다.

- 첫 말은 계단우물 옆 **평평한 상부 통로**에 서서, 낮은 물통의 물을 마신다. 젖고 빈 안장, 늘어진 고삐, 여행용 수통이 남아 있다. 가파른 우물 계단 아래로 말을 내려보내지 않는다.
- 둘째 말은 맞은편 회랑 끝에서 가끔 고개를 돌려 바깥길을 바라본다. 둘을 한쪽에 모으지 않는다. 가까운 우물/먼 회랑의 거리 차로 중정의 공간을 사용한다.
- 물 마시는 고개·귀·꼬리·호흡만 조용히 움직인다. 말이 전투장을 돌아다니는 새 전투 기믹은 이번 콘셉트에 포함하지 않는다.
- 두 말의 장구는 같은 소속처럼 보이되 특정 확정 군대 문장이나 마야 동료들의 신원을 새로 고정하지 않는다. 피나 시체 대신 빈 안장과 기다리는 행동이 사건을 암시한다.

두 핵심은 ‘첫비로 물이 돌아온 우물에 주인 잃은 말들이 찾아왔다’는 하나의 사건이다. 마야가 동료들의 귀환으로 받아들이는지, 마지막 증거로 받아들이는지는 열린 서사로 남긴다.

## 색·빛·소리

- 새벽3시, 비구름이 갈라진 틈의 달빛. 젖은 사암의 탁한 자주/갈색, 어두운 청록 수면, 모래빛 얼터 마야가 구분되도록 한다.
- 물 반짝임은 하늘이 비친 제한된 구간에, 돌은 모서리/젖은 자국에만 작은 광택. 게임의 거친 저다각형 표현에 맞춰 유리나 거울처럼 번들거리지 않게 한다.
- 밤의 포세이돈을 인물/칼 가독성 비교 기준으로 삼는다. 전투 바닥과 급수정 뒤에서도 인물의 윤곽이 읽히도록 낮은 보조광을 조정한다.
- 물줄기·처마 물방울·말의 물 마시는 소리와 가끔의 콧김. 아래 우물의 울림과 위쪽 말소리의 위치를 구분한다. 상시 비/천둥을 더하는 장면은 아니다.

## 이전안과 달라진 중심

소금사막의 최종 사건은 위장 암살단의 모의와 다라이시가 베어넘긴 직후의 참상이다. 중정은 물이 돌아온 장소에서 **돌아오지 않은 사람을 기다리는 밤**으로 제안한다. 초기 소금길 탈옥안에 있던 열린문/탈출발자국, 1안의 명령서 소각은 새안에 사용하지 않는다.

## 제작 단계의 확인 항목

- 최신 중앙 급수정9충돌·시작Z1.10/1.60·실제차폐·카메라 어깨시점을 보존한다. 밤의 세이버 마야에게 리볼버 전용 행동을 임의 추가하지 않는다.
- 새 `courtyard_night`를 같은 장애물/카메라/환경계열로 연결하고, 낮 해 방향에 구운 그림자와 돌 조명을 밤용으로 분리한다.
- 높아진 수면이 계단/아케이드와 맞물리는지, 말 네발과 물통이 실제 상부 보행면에 닿는지, 말/소품이 전투·카메라 여유 공간 밖인지 확인한다. 추가 수면은 우물 내부다.
- 실제 전투 시점에서 수면/말이 읽히는 것이 첫 기준이다. 물 반사나 소품 개수보다 전체 장면을 먼저 검토한다. 모델/수위/조명 수치와 성능은 아직 실측하지 않았다.
- 사용자 콘셉트 검토 후 실제 시안 제작 단계에서 전투 시점·반대편 회랑·계단우물 상세 스크린샷을 보고한다.
