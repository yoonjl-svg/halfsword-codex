# 방향 1 — 어드벤처: 길 위의 결투

- 작성: 기획 PM, 2026-09-30. 근거: `docs/design/structure_map.md`(main `851d0af`), `docs/decisions.md`. 기준은 지금 본판(팔 베기)이며, R2 온몸 타격 시험판이 나오면 "달라지는 점" 절을 덧붙인다(사장님 질문 Q-S1).
- 비용은 "디렉터 + 워크플로 하위 에이전트" 체제 기준의 어림(주 단위)이다. 상한·하한·시간값은 제안하지 않는다.

## 요약 10줄
1. 어드벤처는 "결투 사이에 무엇이 있는가"의 게임이다. 우리 결투 한 판은 그대로 쓰고, 판과 판 사이에 길·장소·만남·선택을 둔다.
2. 핵심이 그대로 주는 것: 장소마다 그곳 검객(무대↔상대 짝은 이미 있다), 인물 설정집·대사, 무기 카드(전리품의 씨앗), 판마다 새 세계(장면 전환이 싸다).
3. 새로 필요한 것 세 덩어리: ① 여정 지도(노드형)와 이동·선택 UI, ② 판 사이 이어지는 상태(몸·무기·갑옷·소지품·저장), ③ 결투 아닌 만남(대화·거래·쉼) 한 벌.
4. 자유 이동 필드는 권하지 않는다. 물리 지형이 없고(평지+보이지 않는 벽), 칼 조작이 화면 끌기라 탐험 조작과 부딪히며, 비용이 세 배다.
5. 노드형 여정(길 위의 선택 → 장소 도착 → 결투 또는 만남)이 지금 구조와 가장 잘 맞는다. `여정 대화 목업 v3`(캐릭터 PM, 보류 중)가 이 자리의 첫 시도였다.
6. 비용 어림: 노드형 6~8주(지도·상태·만남·저장·UI·무대 2~3곳 추가). 자유 이동은 14주 이상.
7. 핵심을 해치는 지점: 결투 밀도가 낮아져 조작 감각이 식는다, 판 사이 글이 "적막"을 깬다, 몸 상태가 이어지면 "한 수로 끝나는 결투"가 "누적 소모전"으로 읽힐 수 있다.
8. 참고: Kingdom Come(사실 검술+세계), Exanima(래그돌 물리+던전), Slay the Spire(노드 지도), 80 Days·Sunless Sea(글로 하는 여정), 부시도 블레이드(일격 결투+이야기). 우리가 다른 점: 한 수로 끝나는 결투, 체력 게이지 없음, 관중·소음 없음.
9. 첫 수직 슬라이스 후보: "길 하나(노드 5) + 상처가 이어지는 몸 + 쉼 노드" — 새 시스템 없이 newRound가 저장 상태를 읽게 하는 것으로 시작할 수 있다.
10. 사장님이 정하실 것 7가지는 끝에.

## 1. 우리 핵심이 그대로 주는 것
- **결투 한 판**: 입력 → 검술 층 → 물리 → 판정 → 몸 상태 → 승패. 손대지 않는다.
- **장소 = 검객**: STAGE_ORDER·STAGE_FOE로 "그곳에 그 사람이 있다"가 이미 규칙이다. 어드벤처에서는 이 표가 '지도'가 된다.
- **인물**: 시트(출신·바람·유파·기질·대사 3종)와 설정집(`docs/character_lore.md`)이 있다. 만남 장면의 재료다.
- **무기 카드**: 등급·설명 글·뒷면 무늬가 있다. "얻은 무기를 들고 다닌다"로 바꾸면 전리품이 된다.
- **판마다 새 세계**: newRound가 Rapier 세계를 통째로 다시 만든다. 장소 전환·되돌리기·저장 복원이 싸다.
- **헤드리스 시뮬**: 만남·여정 규칙도 같은 방식으로 자동 검증할 수 있다.

## 2. 새로 필요한 것
### 시스템
| 항목 | 내용 | 지금 구조의 이음새 | 비용(주) |

| 죽음의 뜻 | 지면 같은 상대(지금)인가, 길의 앞 노드로 돌아가는가, 처음부터인가 | 사장님 결정 | — |
### 콘텐츠
- 장소 2~3곳 추가(무대 모듈 500~1000줄 + 환경음 + 카드 뒷면): 2~3주. 지금 6곳으로 "여정 하나"는 이미 된다.
- 만남 글: 다섯 인물 + 길 위 낯선 이 2~3명. 캐릭터 PM 몫. 이졸데 부활·마르그레테 대사처럼 "짧고 적막한" 문장.
### UI
- 지도 화면(노드·길·현재 위치), 만남 화면(문장 + 선택 2~3), 상태 한 줄(피·칼 상태), 저장/이어하기. 카드 v2와 같은 화면 문법(어두운 바탕·흰 글씨).

## 3. 대략 비용
- **노드형 여정 수직 슬라이스**(길 하나·노드 5·쉼·상태 이어짐·저장): 2주 안.
- **노드형 여정 한 벌**(지도·만남·전리품·장소 +2·죽음 규칙): 6~8주.
- **자유 이동 필드**(지형 충돌·카메라·걷기 지형 대응·탐험 조작 분리): 14주 이상. 권하지 않음.

## 4. 핵심을 해치는 지점
1. **결투 밀도**: 글과 이동이 길어지면 손가락이 칼 조작을 잊는다. 만남은 짧게(한 화면), 노드 셋 중 둘은 결투.
2. **적막**: 대화·상인·수다는 컨셉과 반대다. 만남은 "말 몇 마디, 선택 하나"로.
3. **소모전**: 몸이 이어지면 "다친 채 다음 결투"가 되고, 이는 긴장을 더할 수도(부시도 블레이드식) 있지만, 회복이 헐거우면 판마다 붙던 일촉즉발이 누적 체력 관리로 바뀐다. 회복은 쉼 노드에서만, 값은 사장님.
4. **조작 충돌**: 칼 조작이 화면 끌기라 이동 탐험을 같은 손가락에 얹으면 둘 다 나빠진다. 노드형이면 생기지 않는다.
5. **온몸 타격 R2·R4 뒤**: 큰 동작이 큰 위험이 되므로(R2는 닻 비틀기만, 서보·끝 자세 버티기는 R4), 다친 몸(팔·다리 기능)이 온몸 베기의 크기에 영향을 주는 것이 자연스럽다(물리로). 새 규칙을 넣지 않아도 된다.

## 5. 참고 게임과 우리가 다를 점
| 게임 | 가져올 것 | 우리가 다른 점 |
|---|---|---|
| Kingdom Come: Deliverance | 사실적 검술을 세계 안에 두는 법, 갑옷·상처가 이어지는 몸 | 우리는 체력 게이지·스태미나가 없고 한 수로 끝난다. 자유 이동 없음 |
| Exanima | 물리 래그돌 전투 + 던전 탐험, 다친 몸이 이어짐 | 우리는 모바일 한 손가락, 1대1, 탐험은 노드 |
| Slay the Spire | 노드 지도·갈림·쉼·전리품 리듬 | 우리는 카드가 무기이지 행동이 아니다 |
| 80 Days / Sunless Sea | 글로 하는 여정, 짧은 선택 | 우리는 결투가 본체, 글은 양념 |
| 부시도 블레이드 | 일격 결투 + 인물별 이야기 | 우리는 물리 판정, 이야기는 길 위 |

## 6. 사장님이 정할 것
1. 여정은 **노드형**(권함)인가, 자유 이동인가.
2. **죽음**: 지면 같은 상대(지금)·앞 노드로·처음부터, 셋 중 무엇.
3. **몸이 이어지는가**: 피·팔다리·갑옷·부러진 칼 가운데 무엇이 다음 판으로 가는가. 회복은 쉼 노드에서만인가.
4. **전리품**: 이긴 상대의 무기를 얻는가, 카드 뽑기를 유지하는가, 둘 다인가.
5. **만남의 양**: 노드 셋 중 결투가 둘(권함)인가, 더 적은가.
6. **장소 추가** 여부와 순서(새 무대는 사장님이 자리를 정하신다).
7. 보류 중인 **여정 대화 목업 v3**를 이 방향의 첫 그림으로 다시 볼지.
