# 용 특별전 고정형 개선판

2026-10-24 사용자 그래픽 이질감/깨짐 피드백과 고정형 대형 용 연구 요청에 대한 개선. 기준 `95c4ed03` (첫 조작판). 개발 가지 `codex/dragon-anchored-20261024`. 자체 포크의 독립 시험이며 일반 여정 소스/저장/우화 저장소는 수정하지 않았다.

[원작 표현·구현 근거와 적용 판단](research.md) / [출처 확인](sources.json).

## 바뀐 전투와 화면

- 몸통은 전장 한쪽 좌표(7.2,0,0)에 고정. 이전2.1배 크기, 네 발 보행/루트 회전·꼬리 공격 자동 선택 제거. 머리·턱·앞발·브레스로 전면/양옆을 공격한다.
- 카메라는 고정 사선 구도. 머리/골반의 흔들림을 따라 확대·회전하던 동작 제거. 기존3D 플레이어 조작과 유파 보법 정의 보존.
- 기존 게임의 색공간/기본 색조와 안티앨리어싱 사용.1000px 강제 축소 제거. 바닥 중첩/회전된 타일 간섭 제거. 목·꼬리를 이어진 표면으로 만들고 구형 브레스를 단일 흐르는 불길로 교체.
- 고정 날개/뒷다리 통합, 동적 불빛 제거, 전체 실시간 그림자 패스 대신 정적/접지 그림자. 정확한 자기 그림자/모든 방향 투사 그림자를 생략하는 절충.
- DPR1에서 시작. 안정적으로 빠른 기기에서만1.25→최대1.5, 느려지면 낮춤(최저1). 반복 재시작 시 그림자 텍스처 해제. WebGL 컨텍스트 상실 시 자동 일시정지/복구 뒤 계속하기.
- 기력300·이동 목표×1.5·약공격 막기 비용12·기존 기력 규칙 유지. 강한 물기 회피, 돌기둥 브레스 엄폐, 승패/재시작/8무기 선택.

## 성능 비교

Chromium SwiftShader,844×390, 순차 실행/40프레임. 실제 휴대폰 FPS가 아니다. 최종 게임 기본 품질과 같은 DPR1 비교:

| 항목 | 첫 판 | 고정형 개선판 |
|---|---:|---:|
| 렌더 호출 |266|89 (−66.5%)|
| 렌더 삼각형 |46,308|32,186 (−30.5%)|
| 프레임 간격 중앙값 |99.9ms|66.7ms (−33.2%)|
| 프레임 간격90백분위 |116.6ms|83.4ms|
| 물리240스텝+마지막 렌더 |209.7ms|178.6ms|

`performance.json` / `tools/dragon/fixed_benchmark.mjs`. DPR1.5는 이 서버에서133.3ms로 오히려 느려져 기본 강제를 폐기했다. 처음에는 단순 메시 통합만으로 호출을164까지 줄였지만 안티앨리어싱·고해상도 그림자로 실측이 개선되지 않아, 그림자 경로를 바꿔89까지 줄였다. 호출 감소를 곧바로 FPS 개선이라고 단정하지 않고 최종 동조건 비교를 따로 했다.

최종 미술 검수에서 성문 아치의 떠 있는 돌을 연속 쐐기돌로 교체했다. 이 정적 장식 수정 뒤 `final-render.json`에서 호출89·삼각형32,222·geometry92를 재확인했다. 위 시간 비교는 장식 수정 직전 측정이며, 수정 후 동일 성능을 다시 실측했다고 주장하지 않는다. 최종 사진은 아치 수정 후 다시 촬영했다.

## 검증 결과

- `scenarios.json`/`contracts.json`: 약한 물기 무방비 피격1, 막기 피격0/성공1/12 단일 청구. 앞발 동일. 강한 물기는 막아도 피격1, 옆 회피는0. 브레스 열린 사선 피격1, 엄폐 시0/차단1.30초 무입력 자동 피해0, 모든 시나리오 몸통 좌표 고정.
- `weapon_probe.log`: 낮춘 회복 자세의 실제 물리 검 궤적에 대표7무기 모두 피해.10초21.3~235.4. 채찍은2타21.3으로 적음. 고정 노출 표적 검사이며 실전 균형 결론 아님.
- `play_probe.json`: 공격 상태를 읽는 자동 입력으로 롱소드54.125초, 레이피어34.683초 처치·사람 생존. 초기판과 플레이어 이동 목표가 달라 직접 난이도 우열 비교가 아님. 사람의 재미/손맛 검증 아님.
- `browser.json`:320×640/390×844/844×390/1280×720 실제 화면·에러0/가로넘침0, 막기 성공1·재도전300/480. 사진은 실제 게임에 통제 입력을 주어 촬영했다.
- `ui.json`: 실제 멀티터치 이동/막기·손길/탭·일시정지/재개·승패/재도전. 최종 컴파일판에서도 확인. 승리창 검사는 직접 생명력 소진 주입으로 상태 전이만 확인, 실제 물리 처치 근거는 위 자동 입력 시험이다.
- `stability.json`:6회 재시작 동안 GPU 텍스처5/geometry92로 유지, 카메라 좌표 불변, 강제 WebGL 상실→일시정지→복구→계속하기 통과.
- 일반 Fighter/Combat/기력/유파/보법 소스 차이0. 이전5관문 결과는95c4ed03에 보존. 이번 전용 용 코드만 바뀌어 일반 관문 재실행은 생략하고 전용 판정/조작/렌더 검증을 수행했다.

완성 밸런스와 미술 확정이 아니다. 실제 휴대폰의 장시간 동작·발열·입력, 전면/측면의 안전지대, 유파별 칼 접촉 특수효과는 후속 검토 대상이다. 원작 리소스 이식/전용 소스 복제는 하지 않았다. 원작의 내부 보스 코드를 확인했다고 주장하지 않는다.
