## 터치 피드백을 반영한 후속 감쇠

질량만 추가한 `mass-only-touch.json`의 실제 CDP 터치에서는 내려긋기 최대 전방 .970→.440m, 가로 .976→.726m로 오히려 줄었다. 손 목표를 직접 움직이는 초기24경로 결과만으로 손맛이 나아졌다고 판단하지 않았다.

회전 감쇠와 굽힘을 바꾼20회(`replay.json`), 같은 기록 입력에 준비시간.25/.40/.55초를 달리한30회(`replay-robust.json`)를 추가했다. 두 기록 모두 고정 입력 원본은 `mass-only-touch.json`의 **before** 손 좌표이며, 측정 시작 전 준비 동작은 명시한 보간이다. 실제 화면 입력 전체 프레임을 정확히 복제한 것은 아니다.

| 준비시간3종×2방향 평균 | 이전650g | 질량만770g | **770g·회전 감쇠.15(채택)** | 770g·굽힘.10 |
|---|---:|---:|---:|---:|
| 몸통 높이(.85~1.80m) 최대 전방 | .481m | .594m | **1.008m** | 1.003m |
| 몸통 높이·전방.7m 이상 유지 | .056초 | .072초 | **.156초** | .110초 |

관절 굽힘.035를 유지하고 회전 감쇠만1.3→.15로 낮췄다. 손잡이 힘/조종 계수·피해 계수는 바꾸지 않았다. 굽힘.10도 유력했지만 준비시간을 달리할 때 몸통 높이의 체류 구간은 낮은 감쇠 쪽이 길었다. 이는 궤적 구간이며 명중률·피해량·승률이 아니다.

최종 실제 터치(`touch-compare.json`)에서는 가로1.045→1.000m, 내려긋기2.124→.754m였다. **내려긋기 도달 손해가 남는다.** 별도 브라우저 실행에서는 입력 처리 프레임/실제 준비 결과가 달라 첫 터치 시험의 절대값과 직접 합산하지 않는다. 터치 사진은 매4번째 표본 중 전방이 가장 큰 순간으로 골랐으며 JSON의 최대값과 정확히 같은 프레임이라고 하지 않는다. 낮은 감쇠에서 입력은 반응하고 움직임은 유지되지만, 모든 인간 동작 개선/완성을 주장하지 않는다.
