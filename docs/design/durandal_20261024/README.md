# 뒤랑달 — 이베리아 레전드

사용자 “롤랑의 듀란달? 뒤랑달? 만들어 이베리아 유파 무기로” → “레전드 무기로” → “아니 새로운 스펙으로”. 처음 제안한 츠바이핸더 규격 재사용은 철회했다. 이름은 프랑스어 Durandal을 옮긴 뒤랑달. 기존 후보 시안(concept.png)의 붉은 감개/금빛 십자 코등이/성물함 끝장식을 실제 절차형 모델로 만들었다.

## 기준과 적용

이미 수신·확인한 우화 main `59deba27b164ba76c85294904d200ddbba052d64` 위의 **우리 포크** `codex/durandal-20261024`. 우화 저장소 쓰기/새 전달 메시지0. 최신 기존31무기, 롤랑v2·베르나르도v2/백린·스킬트리·기력·보법·유파 정의를 보존했다. 롤랑의 임시 츠바이핸더와 AI 무기 꾸러미만 뒤랑달로 연결. 베르나르도 등 다른 인물은 원래대로.

정식 무기 정의/추첨 목록·이베리아 유파/손 파지·실제 모델 썸네일·레전드 기운까지 연결했다. 공개는 별도 `encounters/durandal-20261024/` 검토판이며, 우리 일반 공개 게임 전체를 우화 최신 트리로 교체하지 않는다. 사용자 화면 검토 후 전달한다.

## 모델·기운

11메시/3866삼각형, 재질별 병합. 루트 칼날 Mesh 유지로 피 묻음 연결. 칼날 길이는 지오메트리도112cm(공통 생성기 기본1cm 돌출을 발견해 이 무기만 overshoot0 적용). 장식 판정 차이는 감개 최대.35mm/다른 부품1mm 미만. 관찰 사진의 길이는 물리 범위 끝의 구형 근사 때문에 약6mm 차이 날 수 있다.

레전드 공통 기운 강도.5/상아빛/gain.8, 별도 광선·추가 상태이상 없음. 정상 충돌에서 파손확률0. 개발자 강제 breakWeapon()은 다른 레전드처럼 등급을 우회하므로 절대 호출 불가로 막았다고 주장하지 않는다.
