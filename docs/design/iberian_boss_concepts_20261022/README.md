# 이베리아 중갑 영웅 보스 — 전신 섬네일 시안

사용자: 아르토리아의 뒤를 잇는 화려한 보스급 중갑 기사, 기존 이베리아 서사·전설 참고, 다른 유형의 콘셉트 여러 개 요청. 아래 이름·의상·전투는 모두 제안이며 게임 변경/능력치 확정/우화 전달 없음.

## 1. 추방된 개선장군 — 엘 시드 계열 (추천)

기존 티소나 제작과 『엘 시드의 노래』 조사에서 이어짐. 왕에게 쫓겨났지만 전쟁에서 명예를 되찾는 장군. 창작 확장: 왕국이 지워 버린 공적을 자기 갑옷에 새기고, 왕의 문장을 아직 떼지 못한다.

큰 체격의 중년~노년 남성, 짧은 회갈색 수염. 상아빛 판금·오래된 금장·포도주색 긴 망토. 둥근 대형 어깨판/높은 목가리개/가늘어진 허리와 길게 나뉜 허벅지 판금. 갑옷 넓은 면의 공성전·성문 부조, 머리는 뿔 대신 낮고 넓은 투구 장식. 제작된 티소나(검은 칼몸/상아 감개/옛 금장)를 사용하면 무기와 자연스럽게 한 벌이 됨. 넓고 침착한 쳐내기 뒤 전진하는 이베리아 몬탄테 보스 방향. 실제 새 기술/성능은 미정.

## 2. 사슬의 영웅 — 베르나르도 델 카르피오 계열

스페인 전설의 베르나르도. 롤랑을 꺾는 영웅담, 투옥된 아버지를 풀어 주겠다는 약속과 결국 죽은 뒤의 석방이 핵심. 연대가 맞지 않는 전설을 실존 인물의 확정 행적으로 쓰지 않는다.

청회색 강철·금색 깊은 세로 홈·붉은 안감, 정수리 낮고 어깨/전완이 넓은 육중한 갑옷. 앞치마처럼 펼친 긴 판금 타셋, 짧고 무거운 의장 망토. 아버지의 끊어진 족쇄 한쪽을 왼팔에 묶음(창작). 폐쇄형 투구의 좁은 틈과 짙은 수염/검은 머리. 장식은 녹슨 감옥 옷이 아니라 공적을 치하받은 화려한 갑옷으로 유지. 가까이에서 칼을 받아 옆으로 걷어내며 좁혀 오는 압박형. 과거의 힘 상한 보정 연구를 자동 적용하지 않는다.

## 3. 안개에서 돌아온 왕 — 세바스티앙 계열

1578년 알카세르키비르 전투에서 실종/전사한 포르투갈 왕과, 언젠가 돌아와 나라를 구한다는 세바스티아니즘. '왕만 돌아오고 함께 나간 군대는 아무도 돌아오지 않았다'는 이번 게임용 창작 확장.

검게 처리한 판금·짙은 청록 의장 천·풍부한 금 상감·회백색 큰 깃털. 허리가 긴 날렵한 중갑, 높게 솟은 투구마루/대칭 의장 어깨판. 가슴은 포르투갈 왕실 문장에서 착안한 작은 방패 다섯 개; 실제 문장의 정확 복제 여부는 선택 후 별도 조사. 화려한 앞면과 달리 망토 안쪽에 희미한 군기 자국을 겹침(창작). 첫인상은 젊고 눈부신 왕이며 공포는 인물의 침착함과 혼자 돌아온 사연에서 냄. 예식처럼 정교한 넓은 검 궤적을 쓰는 보스 제안.
