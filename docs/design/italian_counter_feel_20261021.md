# 막아찌르기 손맛·몸꼴 검토 (제안 단계)

사용자: “생각보다 반격으로 찌른다는 느낌이 안 나더라. 발동했는지도 아예 모르겠어. 새 몸꼴 동작이나 스텝 연계가 필요한 부분일지?” KST2026-10-21. 새 구현/실험 착수 지시로 확대하지 않고 현재 소스와 기존 원자료를 확인했다.

## 확인한 사실

- A–D는 접촉 순간의 guardPose 몸통 값을 복사해 유지하며 손·칼 목표를 주로 뻗는다. 일반 수동찌르기처럼 별도 찌르기 몸통 목표로 전환하거나 gait.requestStep을 요청하지 않는다. 몸이 전혀 움직이지 않는다는 뜻은 아니며 기존 자세/물리 반응은 있다.
- 손 목표는28~34cm를0.22~0.26초에 뻗도록 설정된다. 실제 손/칼의 변위나 명중을 보장하는 수치가 아니다. 현재 검 방향을 대부분 유지하고 목표 쪽 회전은15%이므로 접촉 자세에 따라 옆 밀기처럼 보일 가능성이 있다.
- 직전192회 연구 완화판의 조기회수122/203(60.1%). 기존 원자료 재집계: 조기회수군의 발동→회수 시작 실제시간 중앙값 A .1667초/B .1583초/C .1167초/D .1375초. 새 전투 실험 수치가 아니다.
- main.js는 동작이 살아있는 동안 우측상단을 ‘막아찌르기’로 바꾸고, 시험틀은 상단 횟수를 갱신한다. 별도 자동찌르기 전용 접점 발광·소리 연결은 이 경로에서 확인하지 못했다. 일반 칼 충돌 효과와 구별한다.

## 추천 (미구현·미검증)

1. 접촉 순간 칼로 공격선을 가리는 동안 팔을 펴고 칼쪽 어깨·몸통·앞무릎의 체중 이동을 연결한 한 동작. ‘막은 뒤 따로 찌르기’가 아니라 받으면서 뻗기. 몸통은 상대 칼의 공격선에서 약간 비키도록 설계. 새 몸꼴의 머리·목 노출/손길은 검증해야 한다.
2. 접촉 추적이 끊겨도 가림이 유효하고 뻗을 여유가 있는지 판단해 찌르기를 잇는 종료 규칙을 연구. 강제로 무조건 완주시키는 안은 과거 진단에서 명중/실제터치 개선을 입증하지 못했으므로 그대로 재채택하지 않는다. 놓기·직접 공격/후퇴의 취소권 유지.
3. 별도 스텝 비교군: 전진 입력+조금 모자란 사거리에서만 기존 이탈리아 걸음의15~25cm 짧은 내딛기를 연결하는 초깃값. 강제 자동돌진/후퇴입력 무시 금지. 독일/동방 보법을 새로 고치지 않는다. 정지·후퇴 중에는 몸꼴만으로 작동시키는 방향.
4. 접점의 짧은 가는 빛과 별도 금속 마찰음, 발동 문구 잠시 유지. 과장된 피격효과로 명중을 거짓 표시하지 않는다. ‘발동’과 ‘상대에게 실제 명중’ 구별.

검증 순서 제안: 현재C 대 새몸꼴(동일거리/힘/추가충격), 이후 새몸꼴+선택스텝. 사람이 발동을 알아봤는지/찌르기로 보이는지와 실제 칼끝 전진·완주·피해교환1초/5초를 함께 본다. 이번 응답에서는 게임을 바꾸지 않았다.

## 후속 승인과 적용

사용자가 전용 몸꼴과 발동 단서를 승인했다. 실제 적용/실패 후보/확인 내용은 [새 시험 기록](../research/italian_body_playtest_20261021/README.md)에 보존한다. 선택 스텝과 종료 규칙 개편은 이번에 포함하지 않았다. 위 미구현 문구는 승인 전 검토 이력이다.

사용자가 후속으로 ‘전진 입력에만 짧은 스텝 연결 → 이거까지’를 승인했다. [새 스텝 시험](../research/italian_step_playtest_20261021/README.md)에 앞발20cm/0.28초 연계를 추가했고 앞선 스텝 미포함 문구는 그때의 범위 기록이다.
