# 이탈리아 레어 — 후보 제안 이력

**후속 확정:** 사용자가 파펜하이머를 선택했다. CMA1916.697 실물 기준으로 구현 완료. [조사·규격·실제 사진](pappenheimer_20261025/README.md). 아래는 선택 전 제안 이력이다.

사용자: ‘고급 레이피어’로서 신규 레어 찌르기 무기 몇 개 추천. 현재 실추첨 유파×커먼/레어/에픽/레전드 표에서 이탈리아 레어만 비어 있다. 커먼 레이피어→레어 미정→에픽 달타냥→레전드 발리사르다. 이번 후보는 이름·미술/성능 방향 제안이며 실제 무기 추가나 수치 확정 없음.

1. **피치니노** — 우선 추천. 실제 밀라노 제작자 카를로 피치니노(Carlo Piccinino)의 서명이 있는 컵 힐트 레이피어, Met 11.89.2. 1650~75년경, 밀라노 손잡이/솔링겐 칼날. 전체111.8cm·날94.6cm·1048.9g. 실물 사진에서 부조 장식 컵·긴 곧은 십자대·감은 금속선 손잡이·비틀린 홈의 폼멜 확인. 신비한 고유검이 아니라 장인의 고급품으로 레어에 적합하다는 것은 게임 기획 판단. `피치니노`라는 게임 이름 역시 제작자에서 따오는 제안이다. 현행 커먼 날95cm/1.10kg와 길이가 거의 같아 사거리 급증 없이 등급/완성도 차별화 가능. 실물 기준을 채택하려면 질량 분배·관성은 추가 추정/검증 필요.
2. **파펜하이머** — 실존 레이피어 방호구 양식에서 이름을 따오는 제안. 고리 안에 투각판을 둔 복합 방호구가 핵심. 단순 컵형과 다른 실루엣, 약간 묵직하고 손 보호를 강조하는 게임안. 독일권과 연결되는 양식이며 이탈리아 발명품이라고 설명하지 않는다. 이탈리아 유파 사용 가능 여부와 무기 산지는 구별. 특정 실물/스펙 아직 미선정, 모든 파펜하이머가 고급이라는 뜻도 아니다.
3. **검은 백합** — 완전 창작. 먹빛 강철·은빛 날·백합꽃잎처럼 벌어지는 손 보호대. 귀족 결투용 주문품, 고른 찌르기와 절제된 장식. 마법/독 효과 없음. 이름이 특정 역사 유물이나 실존 제작소를 뜻하지 않는다.
