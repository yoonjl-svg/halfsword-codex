# 일본 막기·흘려내기 연구 사전 기록

사용자 2026-10-17 “이제 일본 막기 연구 진행해”. 기준 c7c2131e (수신 코드 89a0996c + 전달한 연구 도구). 공개판/우화 저장소를 변경하지 않는다. 먼저 원인 진단, 소수 후보 선별, 새 씨앗에서 최대 30초 독립 비교 순서다. 수천판 반복은 하지 않는다.

목표: 평균적인 일반 방어 + 일부 흘려내기의 충분한 빈도와 사람이 쓸 수 있는 후속 이득. 동방 수준의 방어율이나 100% 차단을 목표로 하지 않는다. 고노센 자동 연결/기절/추가 피해는 넣지 않는다. 기존 몸꼴·보법은 먼저 그대로 둔다.

기존 연구: 절대 하강 속도 3.5 m/s, 가슴 −0.1 m 위 접촉, 자기 칼끝이 코등이보다 낮음, 새 칼 접촉 조건. 사선 베기에는 하강 속도가 부족하고, 발동해도 대부분 새 반격 여유가 없었다. 초기 도구의 기력 연결 누락은 재사용하지 않는다.

1. 기준 진단: 새 접촉마다 막기 활성/접점 속도/높이/칼 기울기/맞부딪는 속도/상대 단계(기록만)를 구분한다. 발동은 0충격 포함 여부도 구분한다.
2. 후보: diagonal은 기존 발동을 보존하되 하강 ≥1 m/s, 접점 전체 속도 ≥3.5 m/s, 수평 방향으로 방어자에게 접근하는 사선 접촉을 추가한다. 높은 접점/내리막 칼/실제 새 충돌/막기 책 조건은 보존한다. 기존 3.5는 움직이는 칼의 속도였는데 수직 성분에 적용한 제약을 점검하는 가설이며 역사적 실측값은 아니다.
3. 후보: diagonal-strong은 위 추가와 함께 slideK 0.8→1.2를 시험한다. 반작용/팔 손실 증가 가능성을 함께 본다. 무조건 센 흘림이 좋은 결과라고 가정하지 않는다.
4. 입력 후보: release는 버튼 해제/공격 입력에서 흘림 강제 자세를 종료한다. 기존 forceT 0.35초가 베기 반격을 덮는지 먼저 측정한다. 필요한 경우 diagonal-release 조합만 시험한다.

주검사: 실제 피해를 켠 플레이어 명령 대본 + 보통 상대 AI. 기본 우치가타나, 방어 위주/접촉을 보고 반격하는 두 정책. 입력은 관측 가능한 칼 움직임/실제 접촉과 0.16~0.32초 지연만 사용하고 상대 AI 상태·공격 번호를 결정에 쓰지 않는다. 스크립트 재현이며 실제 사람 테스트가 아니다. 기력 controller를 실제 main처럼 연결한다. 사망 시 관측 종료, 생존 시간과 함께 기록한다.

선별 씨앗 501–502, 상대 롱소드·청강검 (각 후보 8조건). 독립 511–514, 상대 롱소드·청강검·츠바이핸더 (각 채택 후보 24조건). 선별 후 독립 결과를 보고 후보 수치를 다시 맞추지 않는다. 필요시 입력 시점/공격 방식·책 없음·다른 유파·버튼 놓기 검사로 범위를 좁힌다.

평가: 사망/출혈/의식 손실/팔다리 기능/무기 상실/상대에 가한 실제 피해, 기력·행동 가능 시간, 0회 판과 발동 수, 접촉 뒤 상대 칼 복귀 및 0.2~0.3초 지연 반격 결과를 별도로 보고한다. 피격 수는 보조. 같은 공격을 강제로 동기화한 단기 실험과 자율 전투 분모를 섞지 않는다. 후보를 고르는 경우 사람의 순이득·손해와 남은 불확실성을 명시한다.

## 진단 뒤 추가한 가설 (독립 표본 전)

기준8조건 143개 새 접촉 중 막기 활성68, 기존 발동3. 활성68 중 수직 속도 미달58/낮은 접점25/칼끝 위24(중복). 엄격한 접근 조건까지 둔 diagonal 추가 기회0이라 이 가설은 빈도 개선 후보로 유망하지 않다. 낮은 문턱만 무조건 풀지는 않는다.

roof-path: 동방 연구의 관측 칼날 경로를 재사용하되 일본의 **중앙 상단 공격만** 기존 우케나가시로 연결한다. 다른 줄·자세·보법은 그대로. 예측0.18초/기존 접촉·이탈 규칙, 최장0.45초, 낮은 위협은 즉시 허용. 과거 칼끝이 높기만 하면 지붕을 세우던 실패안과 달리 실제 상체/팔로 접근하는 칼날 선분만 대상으로 한다. 별도8조건 선별.

release의 찌르기 결과만으로 베기 반격을 판단할 수 없어 같은 선별 씨앗의 swipe 대본도 추가한다. 실제 새 접촉 후0.22~0.32초에 손 패드를 대각 아래로0.20초 동안 초속4.5씩 움직인다. main처럼 빠른 끌기는 막기를 끊으며 강제 자세 잔류를 측정한다. 이 추가 대본은 독립 검증으로 세지 않는다.

선별 뒤 두 추가 후보만: `glance`는 실제 접촉에서 칼끝 방향으로 이미 미끄러지는 상대 속도≥1.5 m/s·법선 속도의35% 이상, 상대 속도≥2.5, 하강≥0.5, vn>0.5일 때 흘림을 허용(높은 접점/아래로 기운 칼 유지). 몸 중심으로의 수평 접근 대신 **접촉면의 실제 미끄러지는 방향**을 쓴다. `free-cut`은 공격으로 막기가 끊겼을 때만 강제 흘림 자세와 잔류 무게를 놓는다. 기존 release는 버튼 해제 전체에 작동했고 잔류 무게를 남겼으므로 구별한다. 순이득 검증 전 출시하지 않는다.

## 독립 검사 확정

선별에서 diagonal/glance는 결과를 개선하지 못했고 strong/roof-path는 사망 증가. free-cut은4개 베기 조건 중 실제 겹침14스텝(약0.117초)을0으로 만들지만 해당 판이23.88→15.43초에 사망해 안전성 확정 불가. **조작 개선과 전투 득실을 구분하려고** 기존에 예약한511–514씨앗/상대3종에 reactive/riposte/slash 세 정책을 사용한다(기준36+후보36조건). swipe 추가12조건은 인간 베기 입력이라는 별도 근거가 있어 수행한다. 어떤 결과든 수치 재조정 없이 보고하며, 이 후보를 선별에서 우월한 승자라고 부르지 않는다.
