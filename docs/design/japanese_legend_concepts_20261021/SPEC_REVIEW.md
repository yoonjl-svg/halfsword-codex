# 양날 신검과 일본 유파 — 예상 사양 검토

2026-10-21. 검토 소스: 자체 포크 `af50f53ce7883958e13f8e7a82e7ce35345607f8`. 우화 최신 코드와 같다고 가정하지 않는다. 사용자 요청은 예상 스펙과 검술 적합성 설명이며, 후보 선택·무기 구현 승인으로 해석하지 않는다.

## 결론

양날 직검으로 양손 베기·찌르기를 할 수 있다는 것과 후대 일본도 검술에 그대로 맞는다는 것은 다르다. 두 시안은 고대 신검의 인상을 강조한 창작이며, 실제 신기의 치수·형태를 복원한 것이 아니다. 신화 무기를 후대 검술로 다루는 게임적 해석임을 명확히 한다.

## 확인한 코드와 수치

- `src/weapons.js` / `weapon_class.js:weaponPhysics`를 실제 Node로 읽어 합산: 우치가타나 날71cm·총1.10kg·두 손 간격20cm·날 시작점 앞 무게중심8.84cm·손 기준 관성0.220507kg·m². 모노호시자오 날90cm·1.15kg·22cm·13.59cm·0.328319kg·m². 후자는 heavy/고유 제어 보정/동작 제외가 있어 단순히 길이만 늘린 무기가 아니다.
- `hiltLength`는 칼 원점에서 날 시작점까지의 좌표이며 완성된 손잡이의 실물 전체 길이와 동일시하지 않는다.
- `src/schools.js:JAPANESE_GUARDTABLE`은 두 무기가 공유한다. 기반 자료는 검도형·오륜서 등의 후대 도검술이며 고대 직검의 독립 복원이 아니다.
- `src/weapons.js`의 `edge:'single'`, `curve:.008`은 외형 설정이다. 현재 칼날 충돌 형상은 직선 상자이고, `src/combat.js`의 베기 정렬은 `Math.abs(perp.dot(edge))`를 써 양 방향을 허용한다. `fighter.js`의 날 세우기도 양날 기준 부호 선택을 한다. 현재 포크는 외날의 무딘 등을 별도 피해 판정하지 않는다. 따라서 신검의 양날을 이유로 새 피해 보너스를 자동으로 붙일 근거도 없다. 이번 검토에서 이 공통 시스템은 변경하지 않는다.
- `src/secret_instant.js:startIai`는 normal/heavy에 따라 발도형 비기의 한손/두손 사용이 달라진다. 틀만 임의로 고정하고 무게분포를 무시하면 안 된다.

## 선택 후 필요한 검증

1. 실제 두 손이 자루에 들어가는 외형과 그립 간격, 관성·무게중심을 맞춘다. 우치가타나와 같은 동작으로 시작한다.
2. 내려베기·사선베기·찌르기에서 실제 접촉 시간/회수/기력과 팔·몸 충돌을 확인하고 무기별 거리 자료를 다시 잰다.
3. 흘림이 날/옆면 어디로 받는지, 직선 양날을 발도형 비기로 움직일 때 그림이 자연스러운지 별도 검토한다. 공통 유파·보법을 먼저 바꾸지 않는다.
4. 인간 입력의 취급성과 짧은 교환을 우선 비교한다. 지금은 새 물리 대련을 실행하지 않았으므로 유파 호환성·성능 우위를 검증했다고 보고하지 않는다.

기존 일본 유파 감각을 유지하는 데에는 쿠사나기처럼 우치가타나에 가까운 길이·질량·균형이 더 보수적인 출발점이다. 직검에 후대 도검술을 쓰는 미학적 이질감 자체를 수치 조정만으로 없앨 수는 없다.
