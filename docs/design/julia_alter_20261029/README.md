# 광기의 쥘리아 크리스테바 · native 외형 검토

사용자 승인: 신체 일부가 기계로 드러나는 얼터 제작. 최신 지시 “서사는 없어. 모든 게 미스테리야. 진행해.”를 우선한다. 출신/제작자/과거/기억/거래에 관한 서사, 새 별칭·대사를 추가하지 않는다. 이전 서사 제안은 폐기했다.

## 외형

기존 Fighter 신체·얼굴·머리·땋은 머리·상인 복식의 비례를 재사용한다. 먹남색 조끼, 회백색 머릿수건·숄·겹치마, 회색 셔츠. 캐릭터 오른쪽(정면 화면 왼쪽) 눈가·광대 일부는 피부 곡면을 따르는 금속 면과 작은 붉은 렌즈다. 동일한 쪽의 검 든 아래팔은 평행 지지대2개/짧은 피스톤/손목 링/손등판으로 구성한다. 몸·팔을 키우지 않았으며 무광 강철·은빛 모서리·소량의 탁한 황동을 사용했다. 공통 얼터 안광과 잔상 효과를 그대로 쓴다.

손등은 실제 기본 손 모듈의 편 손/주먹에 각각 붙고 검을 놓거나 쥐는 상태와 함께 바뀐다. `hands.js`에는 선택적 외형 장식 훅과 정리 코드만 추가했다. 다른 캐릭터는 이 훅을 설정하지 않으므로 동작/입력/그립에 변화가 없다. 기계 팔은 시각적 의상이며 갑옷·콜라이더를 새로 만들지 않는다. 노출 면에 유혈 표현을 추가하지 않았다.

## 검증

`check.mjs`에서 이전46fa690c의 기본 쥘리아와 현재 기본의 전체 외형 버퍼/재질/신체 데이터를 비교했다. 외형해시 31172dcf8c3117b6a8decb430adbc5a197e671342cb1b82c74adae05283a7766 동일. 기본56메시12,552삼각형, 얼터65메시14,832삼각형(손 모듈을 붙인 실제 신체 기준, 무기/안광 별도). 두 캐릭터의 물리값·AI 데이터 동일, 손 쥐기/놓기·장식 해제/자원정리 통과. 최초 비교 실패는 Rapier 벡터 클래스와 JSON의 평범한 객체 간 타입 차이였으며 수치나 게임 코드를 바꾸지 않고 직렬화 형식을 통일해 확인했다.

5관문 모두 통과. fights12/live_battery/finish_thrust/weapon_smoke는 기존 출력해시 동일, corr_s0는12개 IDENTICAL(실행 시간만 달라짐). 빌드 통과. 컴파일 게임에서 플레이어/상대 양쪽 실제 진입, AI4·이탈리아·레이피어·몸판금0 확인. 터치 막기 유지/해제·공격드래그, 신체 유한값·저장 불변, HTTP/JS 오류0.

`front/angle/rear`는 동일 카메라와 조명으로 생산용 Fighter를 촬영한 외형 검수 사진이며 팔을 내려 놓은 검사 자세다. `game-close.png`, `foe-gameplay.png`, `hero-gameplay.png`는 실제 컴파일 게임의 전투 화면이다. 확대 사진은 시점만 이동하고 HUD를 숨겼다. 실제 휴대폰 성능이나 사용자의 미감/손맛을 자동 검증한 것은 아니다.
