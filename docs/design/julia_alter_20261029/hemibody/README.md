# 쥘리아 기계 반신 · 왼쪽 상체 전체 교체

사용자는 앞선 가슴의 작은 노출부가 옷 장식처럼 보인다고 지적했고, 반대쪽의 넓은 상체 영역 전체가 기계 장치로 보이도록 요청했다. 앞선 오른 가슴 패치를 제거하고 **캐릭터 왼쪽(정면 화면 오른쪽)** 쇄골·어깨 연결부·가슴·옆구리·허리 위를 이어지는 기계 몸체로 재구성했다. 기존 오른쪽 얼굴과 검 든 오른팔의 기계 외형은 유지했다.

## 실제 형상 변경

원래 가슴/복부/목의 왼쪽 옷·피부 표면을 삼각형 단위로 잘라 중앙 경계에서 끝나게 했다. 그 위에 패널을 얹는 방식이 아니다. 안쪽의 좁은 차체, 가슴 앞에서 옆/등까지 돌아가는 금속 골격3줄, 회전 연결부, 피스톤, 목의 절반과 어깨 베어링, 허리의 연결대를 몸의 원래 깊이 안에 넣었다. 왼쪽 위팔의 어깨 근처에만 연결 소켓을 이어 붙였고 그 아래 소매와 피부는 남겼다. 원본 머리·땋기·얼굴·기존 오른팔·하반신·전체 신체 치수는 유지했다. 서사·별칭·대사는 추가하지 않는다.

원래 신체 콜라이더/질량/관성/AI/유파·숙련4/생리·출혈/목소리/무기/갑옷 판정은 그대로다. 기계는 외형이며 새 방어 혜택은 없다. 일반 편성·상점·프로필·우화 저장소 미변경. 자체 독립 검토 페이지에 적용한다.

## 검수

정면·기계 쪽 사선·뒤 및 실제 컴파일 전투 촬영. 몸통 원본 메시가 중앙에서 실제로 끝나는지, 새 기계가 얇은 평면이 아닌 몸통 깊이를 갖는지 검사. 기본 쥘리아 외형해시 불변, 얼터/기본 물리값·AI 동일. 손 쥐기/놓기·장식 해제 통과. 신체78메시17,960삼각형(이전70/17,420, 무기/안광 별도). 5관문 통과:4출력해시 동일/corr12 IDENTICAL. 컴파일 양역할 진입·기계 허리 장식 존재·터치 막기/공격·저장불변·HTTP/JS오류0. 실제 휴대폰 성능과 사용자 미감은 자동 검증 결과에 포함하지 않는다.

`front/angle/rear`는 동일 native Fighter의 정형 검사 자세이며 `game-close.png`와 `*-gameplay.png`는 실제 전투 화면이다. 과거 `torso/` 자료는 사용자가 거절한 작은 오른쪽 노출안 이력으로 보존한다.
