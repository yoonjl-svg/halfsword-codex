## 추천 방향: 장부에 없는 상인

익숙한 머릿수건과 땋은 머리, 조끼·겹치마, 작은 미소를 가진 상인이다. 얼굴과 검을 든 팔의 일부에서만 인조피부 아래 금속 신체가 드러난다. 옷색 변경 + 기계 신체 노출이라는 얼터 외형 두 축을 유지한다.

- 복식: 녹색 조끼→짙은 먹남색, 적갈색 머릿수건/숄/겹치마→빛바랜 회백색, 아이보리 셔츠→옅은 회색. 갈색 머리·머리 형태·돈주머니/장부통은 유지한다. 서로 다른 색을 무작정 더하지 않는다.
- 얼굴: 캐릭터 오른쪽(정면 화면 왼쪽) 관자·눈가·광대 약1/4만 기계로 노출. 한쪽 눈의 작은 붉은 렌즈, 눈 주위 금속 고리, 광대를 잇는 얇은 금속 지지대와 턱관절 일부. 나머지 얼굴·코·입을 남겨 쥘리아로 즉시 읽히게 한다. 인조피부 경계는 얇고 불규칙한 가장자리, 유혈/상처 고어는 넣지 않는다.
- 팔: 같은 쪽인 검 든 오른팔의 소매 끝이 닳아, 팔꿈치 아래부터 손등까지 금속 구조가 드러난다. 가는 평행 지지대2개, 짧은 피스톤1개, 손목 회전축, 손등의 작은 관절판. 기존 팔 굵기/손 크기 안에 넣는다. 전투 거리에서도 읽히는 주된 실루엣 포인트.
- 재질: 무광에 가까운 회색 강철·마모된 은빛 모서리, 관절 일부에만 탁한 황동. 거대한 기어/어깨 장식/등의 장치 등은 추가하지 않는다. 붉은 렌즈는 기존 얼터 안광과 비슷한 낮은 밝기, 미세한 일렁임으로.
- 표정: 기본의 작은 미소를 유지한다. 기계가 드러나도 늘 같은 인사를 건넨다는 인상이 중요하다. 과하게 올라간 입꼬리·큰 웃음은 되살리지 않는다.

“그녀의 장부에 없는 거래가 하나 있다. 자신이 처음 팔렸던 날이다.”
