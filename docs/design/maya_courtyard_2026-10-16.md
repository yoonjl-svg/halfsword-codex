# 마야 전용 무대 기획 — 봉인의 중정 (가칭)

상태: **초기 기획안 보존. 사용자 후속 지시로 실제 게임 첫 시안 구현**, [구현·검증·사진](../codex_team/COURTYARD_20261016.md). 일반 여정 편성은 아직 변경하지 않았다. 2026-10-16 사용자가 보여 준 우화 의견 화면과 현재 캐릭터 시트를 바탕으로 발전시켰다. 우화의 새 저장소를 열람하거나 아래 추가 아이디어에 합의한 것은 아니다.

## 중심 장면

우기 직전의 늦은 오후. 라자스탄의 작은 역참에 딸린 계단우물 중정으로 모래바람이 밀려온다. 사람들은 물을 길으러 내려갔고, 전령 마야는 아직 전하지 못한 명령서를 지닌 채 닫힌 문 앞에 남았다.

기존 사막 두 곳의 넓은 지평선과 달리 **사람이 만들고 오랫동안 이용한 깊은 장소**가 중심이다. 모래폭풍은 뒤에 다가오는 상황이며 전투장을 덮어 가리는 장치로 쓰지 않는다.

## 우화 초기안에서 유지할 것

- 5~6월, 우기 직전의 늦은 오후와 다가오는 모래바람.
- 제안 여정 위치는 2막 **산호 항구 → 마야 전용 무대 → 잠든 습지 → 화산섬**. 바다의 폭풍, 비 오기 전 마른 열기, 비 갠 습지, 해 뜨기 전 화산의 흐름이다.
- 사암 건물과 천, 모래, 열기로 다른 무대와 구분한다. 탁 트인 또 하나의 사막 대신 건축 공간을 택한다.

우리 포크의 현재 일반 여정은 아직15무대 순서이고 마야는 붉은 회랑의 추가 상대다. 위2막 배치는 전달받은 기획상의 위치이며 현재 게임에 이미 들어간 순서라고 하지 않는다. 실제 편성은 승인 후 수신 본판의 최신 여정에 맞춘다.

## 공간과 시선

- **전투 바닥:** 약18.4m 지름의 넓고 평평한 황회색 사암 포장. 기존 면적2배 규격과 출발 간격 유지. 기둥·계단·우물 구멍을 전투 원 안에 두지 않는다.
- **한쪽 가장자리:** 층층의 계단이 몇 차례 방향을 꺾으며 내려가는 깊은 우물. 마지막 물은 바닥에서 조금만 반사된다. 오래 내려간 물때 선과 젖은 밧줄 끝으로 수위가 낮아졌음을 읽게 한다.
- **반대편:** 역참의 높은 성문과 작은 회랑. 문은 닫혀 있고, 갈라진 틈과 문턱에 모래가 쌓였다. 마야의 장밋빛 옷 뒤에는 어두운 문 그림자를 둬 실루엣을 살린다.
- **멀리:** 건물 사이로 모래구름이 보인다. 중앙 구조물로 시야를 가리는 대신 뒤쪽 깊이와 낮은 태양으로 긴장을 만든다.
- 장식/깊은 우물은 전투 경계와 카메라 공간 밖에 배치한다. 높은 전경 벽이나 중앙 기둥 없이 360도 회전 시에도 두 사람을 볼 수 있게 한다.

```text
        먼 모래구름 / 역참의 닫힌 문
   낮은 회랑                     천막 그늘

             넓은 평탄한 결투장
             플레이어 ↔ 마야

    계단우물과 물때 선       물동이·급히 벗은 신발
         (전투 원 밖)
```

## 이야기를 읽게 하는 세 가지 흔적

1. **가까운 피난:** 우물로 내려가는 첫 계단 앞에 물동이와 신발이 가지런하지 않게 남았다. 아래쪽 난간에는 방금 걷어 묶은 차양이 있다. 사람을 직접 등장시키지 않아도 급히 열기를 피하러 내려간 장소로 읽힌다.
2. **도착하지 못한 소식:** 역참의 그늘에 작은 전령용 가방과 붉은 봉인 조각. 펼친 종이에 긴 읽기 텍스트를 넣기보다, 마야가 지닌 붉은 봉인과 같은 모양으로 연결한다. 기존 ‘철수 명령을 늦게 전한 전령’ 설정을 되풀이 설명하지 않고 암시한다.
3. **기다리는 문:** 바깥길 쪽 문은 잠겨 있고, 바닥에는 이전에 열고 닫으며 생긴 반원형 마모가 있다. 이번에도 마야가 문을 지키는지, 누군가 돌아오길 기다리는지는 단정하지 않는다.

위 사연은 샛별의 추가 제안이다. 마야가 사람들을 직접 대피시켰거나 특정 동료가 이곳에서 죽었다는 새 사실을 확정하지 않는다. 기존 시트의 ‘먼 성소의 마지막 문’ 문구를 역참으로 바꿀지는 무대 승인 때 함께 맞춘다.

## 바람·빛·소리

| 요소 | 제안 표현 |
|---|---|
| 시간/색 | 늦은 오후, 대략16:30~17:30의 인상. 주황빛 먼 하늘·황토색 벽·밝은 회모래 바닥·우물 아래의 차가운 그늘. 장밋빛은 마야에 남긴다. |
| 바람 | 9~17초의 불규칙한 돌풍, 수초 동안 강해졌다 잦아듦. 천·먼지·밧줄 끝을 같은 방향과 강도로 움직인다. |
| 모래 | 지면 가까이 넓고 얇게 지나가는 먼지띠와 먼 배경의 큰 모래구름. 눈높이 앞을 두껍게 덮거나 총구를 숨기지 않는다. |
| 열기 | 먼 문 바깥과 지붕 위에만 작은 아지랑이. 검·몸·조준 화면에는 굴절 효과를 걸지 않는다. |
| 소리 | 돌 틈을 지나는 마른 바람, 천의 퍼덕임, 가끔 문 고리 부딪힘, 우물 안에서 울리는 작은 물소리. 돌풍 사이에는 잠잠해진다. |
| 총성 | 기존 리볼버 소리를 유지하며 공간의 짧은 반사만 검토. 연속 긴 잔향으로 다음 발을 가리지 않는다. |

비·번개는 이번 낮 무대에 넣지 않는다. 모래 때문에 이동·조준·기력·명중률이 달라지는 규칙도 제안하지 않는다. 리볼버 AI의 별도×1.8 요청은 기존 전달 메모대로 다른 변경이다.

## 구현 순서와 판단 기준

1. 건물 덩어리/계단우물/빛만 넣고 실제 전투 시점·회전 카메라로 구도를 확인한다. 마야가 밝은 바닥과 어두운 문 앞 모두에서 구분돼야 한다.
2. 물때·차양·피난 흔적·봉인을 넣는다. 사용자에게 실제 게임 대표/풍경/상세 사진을 먼저 보고한다.
3. 같은 바람 신호로 천·먼지·소리를 연결하고 짧은 실제 영상으로 보고한다. 소리는 별도 청취 자료를 둔다.
4. 실제 무대 생성/정리 반복, 반경·바닥과 총기 AI의 이동을 확인한다. 승인 후에만 여정의 마야 추가 상대 자리를 전용 무대로 옮긴다.
