## 실물 대조 후속

사용자 질문 후 [실물 대조](historical-comparison.md)를 수행했다. **71cm/1.10kg는 사전에 실물을 검증해 정한 값이 아니다.** TNM 실물66.9cm·휨2.1cm, 보존도검 감정품69.4cm·휨1.9cm를 확인했으며 완성검 질량은 미공개다. 현행 휨·자루·외장도 게임 각색으로 명시. 구현값 변경 없이 검토판에 차이를 표시한다.

## 구현과 사실의 범위

무라마사(村正)는 무로마치 후기 이세 구와나에서 활동한 실제 도공 계열이며 특정 한 자루의 이름은 아니다. 요도·도쿠가와 저주 이야기는 후대 전설로 구별한다. 승인된 적갈색 감개/검은 각형 코등이/불규칙한 물결 하몬은 게임용 외장이며, 특정 유물의 치수·코시라에 복원이 아니다. 이번 길이·무게는 기존 우치가타나의 게임 규격을 따른다. 관련 이전 조사: `b9079383:docs/design/weapon_candidates_20261021/README.md`, `docs/design/dartagnan_20261021/README.md`.

- 일본 레어 `muramasa`, 양손 외날도, 날71cm / 전체 약104cm / 자루 감개 구간30cm / 손 간격20cm / 1.10kg.
- 기존 우치가타나와 물리·질량·관성·사거리·동작/파지 동일. 원본 선언을 raw spec으로 분리해 레어가 커먼의 계산 완료 보정을 상속하지 않도록 했다. 레어 공통 power1.05, durability.85, fragility.032.
- 기본 베기1.2 / 찌르기.9 / 둔타.95. 충돌 속도·갑옷·부위에 따라 실제 피해는 달라지므로 최종 피해율이라고 부르지 않는다.
- 강철 파손 함수는 `.032 * min(1,J/6)^2` (J: 충격량N·s). 충돌 판정 한 번 기준이며 판당 파손률이 아니다. 비파손·저주·상태이상·레전드 기운 없음.
- 검정/흰색의 기존 두 일본도와 달리 적갈색 천이 검은 바탕을 감싼다. 감개는 타원형 자루 표면을 따라 교차하도록 실제 리본 형상으로 만들었다. 검은 모서리 둥근 각형 츠바, 어두운 청동 금구, 더 뚜렷한 물결 하몬.
- `weapon_looks.js`의 선택적 `hamonWave` 인자는 무라마사에만 쓴다. 기존 하몬 기본식/일본도 형상은 그대로다.
- 레어 추첨 목록/테스트 선택/실제 투명256px 섬네일 연결. [수치 원본](specs.json)은 발리사르다와 무라마사를 실제 코드에서 추출했다.

게임 설명:

> 이세의 도공 무라마사 일문의 칼.  
> 적갈색 감개와 거친 물결무늬의 날을 지녔다.

발리사르다 설명:

> 마녀 팔레리나가 마법의 갑옷을 베도록 만든 검.  
> 은과 금의 덩굴이 상아색 자루를 감싼다.
