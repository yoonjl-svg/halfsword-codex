## 적용

- 날71→70cm. 날의 **등 밑동부터 칼끝까지 직선 거리** 기준. 외형 끝의 기존8mm 여분 연장도 제거해 모델 실제 길이와 규격을 일치시켰다.
- 휨은 **그 직선과 칼등 사이의 최대 수직 거리2cm**. 기존 `curve` 값은 칼끝 편향이라 재사용하지 않고, 무라마사 메쉬의 각 단면을 별도로 옮겼다. 하몬·두께·감개·코등이 유지. 공유 무기 형상 코드는 바꾸지 않았다.
- 실제 버텍스 측정: 날0.6999999984m / 소리0.0199999989m. 길이 오차허용0.01mm, 휨0.01mm. [geometry.json](geometry.json)과 실제 같은 축척 전후 [comparison.png](comparison.png).
- 전체 표시104→103cm(103.4cm 반올림), 질량1.10→1.12kg(날660→680g). 자루30cm·양손20cm·레어 및 베기1.2/찌르기.9/둔타.95 유지.
- 손 기준 관성0.1156571→0.1163260kg·m²(약0.58% 증가), 질량중심 손 앞18.958→19.018cm. 1cm 단축과 날 질량20g 증가에 따른 변화이며 공격력 계수를 바꾸지 않았다.
- 단일 직육면체 충돌체는 유지하면서 휘어진 날을 수용하도록 폭30→48mm. 질량/질량중심축은 기존 방식을 유지했다. 외형이 충돌체 밖으로 나가는 최대 거리9.095mm. 곡면을 그대로 따르는 정밀 충돌체는 아니며 근사 판정이다.

## 실물과 게임값

참고 원문은 [도쿄국립박물관 F-20022](https://webarchives.tnm.jp/imgsearch/show/C0084091)(66.9cm/휨2.1cm), [아오이 미술 무라마사 감정품](https://www.aoijapan.net/katana-mumeimuramasa/)(69.4cm/휨1.9cm). **70cm/2cm는 두 기록을 참고한 사용자 확정값**이지 어느 한 유물의 치수 그대로가 아니다. 완성검1.12kg는 실측이 아닌 게임값이다. ## 검사와 실패 기록

- 최초에는 충돌체를 곡선 쪽으로1cm, 이어5mm 옮겨 보았다. 질량의 중심축이 바뀌면서 Rapier 주관성 프레임이 회전했고, 현행 양손 서보를 사용하는 시험에서 비유한 상태가 발생해 모두 제외했다. 주관성축 변경과 제어 계산의 불일치가 원인으로 의심되지만 엔진 차원의 원인까지 확정한 것은 아니다. 최종은 중심축 이동 없이 충돌 폭만 맞췄으며 공격·찌르기·막기·AI·파손 뒤 진행에서 유한 상태를 확인했다. 서보/공통 물리 코드를 우회 변경하지 않았다.
