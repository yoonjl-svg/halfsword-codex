전체/날/코등이/질량이 함께 공개되고 고화질에 준하는 세 방향의 공개 사진을 확인할 수 있는 Cleveland를 **주 기준**으로 정했다. 다른 실물의 길이·장식을 임의로 섞어 단일 유물의 복원이라고 하지 않는다. 독일계 실물을 이탈리아 검술로 쓰는 게임 분류이며, 이탈리아에서 만들어진 이 유물이라는 뜻은 아니다. 박물관의 후원자/제작자 전기·제작연대의 세부 불일치까지 확정한 연구는 아니다.

## 디자인

- 칼날 양면의 긴 금장 띠와 박물관에 전사된 라틴어3줄. 전사 `NEC TEMPARE NEC TIMIDE / INTER ARMA SILENT LEGE / VERITATEM DILIGE ET PUGNA PRO PATRIA`를 사용했다. 읽히지 않는 역사 문자를 임의의 룬으로 바꾸지 않았다. 장식 테두리는 사진의 밀도/배치를 바탕으로 간략화했다.
- 두 장의 투각 방호판, 마름모꼴로 이어지는 구멍, 이를 지지하는 겹친 고리. 실제 두께와 구멍의 벽을 가진 지오메트리이며 불투명한 무늬/알파 텍스처가 아니다.
- 양끝이 휘어진 긴 코등이, 한쪽 손등 고리, 금속선으로 감싼 자루와 양끝 엮은 띠, 여섯 갈래 홈의 둥근 끝장식.
- 검푸른 강철·옅은 금속선·절제된 금장. 임의의 보석/마법 기운/추가 상태이상 없음. 3D 스캔 복원이 아니며 원본의 유니콘 표식 존재는 확인했지만 세부 모양을 정확히 판독하지 못해 가짜 도안을 넣지 않았다.
- 게임 모델을 직접 촬영해 투명256×256 WebP 썸네일 생성. 모델과 썸네일을 다른 그림으로 만들지 않았다. 원본 참고 사진과 새 게임 모델을 분리하여 보관한다.

## 물리와 게임 추정

총길이·날·코등이 폭·질량은 위 박물관 실측. 나머지는 게임용 추정이다. 자루 .09 / 끝장식 .24 / 방호판·고리 .37 / 코등이 .10 / 날 .54kg, 합1.34kg. 날 자체 중심은 길이의36%, 회전반경25%; 손 기준 전체 중심18.165cm, 코등이 기준 앞13.165cm. 박물관이 공개한 무게중심이나 관성값으로 표현하지 않는다.

현재 커먼 레이피어는 날95cm/1.10kg, 달타냥은85cm/1.00kg이다. 이번 것은 날89.2cm로 그 사이이고 더 묵직하며, 코등이의 실폭을 반영한 별도 충돌 상자와 방호부를 가진다. 투각 구멍마다 물리를 풀지는 않는다. 기존 게임의 막힌 구형 방호부 근사(반지름5.5cm)와 실폭21.3cm 가로대가 충돌에 쓰인다. 열린 고리 전체와 손등 고리까지 정밀 충돌하는 모델이라고 주장하지 않는다.

베기.60 / 찌르기1.30 / 둔타.70, 레어 공통power1.05·durability.85·fragility.032. 역사적 실측 효율이 아닌 게임 계수. 커먼보다 항상 빠르거나 모든 상황에서 강하다는 주장은 하지 않는다. 질량/관성 때문에 조작·기력 비용의 차이가 있고, 짧아진 날은 사거리 손해다. 고급 제작품이라는 등급/방호구 차이를 주되 새 능력은 넣지 않았다.

기존 이탈리아 집게 쥠·찌르기·막기 경로·막아찌르기·보법에 연결. `frames.js`에는 새ID를 기존 값에 연결하는 행만 추가했고 기존 동작/값은 바꾸지 않았다. 무기별 AI 간격은 같은 실행의 롱소드로 보정한 현행 측정법으로 새로 잰 값(1.36/1.49/1.08m·.25초), 유파시간.18초. 이는 칼날70%의 내려오는 베기 도달을 재는 기존 규칙이며 실제 찌르기 접촉 시각/모든 공격속도의 측정은 아니다.
