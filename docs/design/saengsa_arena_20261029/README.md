# 생사전 전용 전장 — 수도 근교 여울

2026-10-29 KST · 샛별. 사용자 후속 지시로 명칭을 **수도 근교 여울**로 정하고 [독립 구현판](../capital_ford_20261029/README.md)을 만들었다. 아래는 구현 전 설계의 근거와 추가 검토 범위다. 우화 전달 전.

## 사용자 구상과 해석

사용자: “가운데에 얕은 강이 흘러. 교각을 통해서 빠르게 건널 수 있고 교각을 이용하지 않으면 수로 진흙탕에 발이 빠져서 느리게 건너게 됨. 군데군데 바위와 오크통 같은 게 있고 나무 목책도 있음. 왕실 인근의 결투장.”

교각으로 건넌다는 구상은 **교각이 받치는 낮은 다리 위로 건너는 구조**로 해석한다. 핵심 선택은 빠른 다리/느린 여울 도하다. 사용자의 자연스러운 배치 요구와 일반 전장보다 면적 약1.5배, 최대4인 동시전의 그리기 비용 절감 목표를 유지한다. 이전 [대칭 저수장](superseded_reservoir.md)·[마른 강굽이](superseded_dry_river.md)는 이력이며 새 안에 자동 합산하지 않는다.

## 장소가 먼저 읽히는 배치

왕실 성벽 아래를 흐르는 작은 하천, 성으로 물자를 들이던 오래된 다리와 하역터를 결투 장소로 사용한다. 물길은 전장을 비스듬히 가로지르며 완만하게 휘고, 다리는 원의 정중앙보다 예전 길이 강을 만나는 곳에 놓는다. 양안의 크기·윤곽은 다르게 만든다. 멀리 낮은 성벽과 닫힌 문이 보여 왕실 인근임을 알린다. 군중·병사 행렬은 추가하지 않는다.

- **바위:** 물길이 꺾이며 드러난 암반 주변에 반쯤 묻히거나 침식된 모양으로 드문드문 놓는다. 한 곳은 몸을 숨길 높이, 다른 곳은 낮은 접근 장애물로 다르게 만든다. 모암의 색·층리와 연결한다.
- **오크통:** 다리 진입로의 옛 하역 흔적/목책 안쪽에 작은 묶음으로 둔다. 수레바퀴 자국·닳은 바닥과 위치가 이어진다. 칼·몸을 막는 작은 엄폐/접근 장애물로 쓰며, 모든 통이 전신 엄폐가 되는 것은 아니다. 개수는 아직 확정하지 않는다.
- **나무 목책:** 옛길이나 하역장의 경계를 따라 짧게 이어지고 일부가 벌어져 있다. 길을 돌게 만들되 벽 뒤의 사람을 알아볼 수 있다. 똑같은 조각을 양편에 복제하거나 전장 둘레를 등간격으로 장식하지 않는다. 틈이 있는 그림과 실제 탄환/칼 차단이 모순되지 않게 충돌을 정한다.
- **넓은 강변:** 다리 입구에서 물러나거나 동료와 갈라져 들어갈 공간을 남긴다. 바위·통·목책으로 다리까지 가는 모든 길을 한 사람 폭으로 만들지 않는다.

물길·성으로 향한 옛길·하역 흔적의 세 원인이 배치를 설명하게 한다. 신규 함정/수문 레버/ㄱ자 돌담을 더 얹지 않는다.

## 기대하는 전술과 손익

다리를 점거하면 상대가 빨리 건너오는 길을 견제할 수 있다. 상대는 여울로 옆을 돌아 들어가거나, 한 명이 다리에서 시선을 붙잡고 동료가 물로 건널 수 있다. 후퇴할 때도 빠른 다리로 모일지 느리지만 다른 방향으로 빠질지 선택한다. 다리가 반드시 승리하는 자리나 항상 최선의 길이 되는지는 검증 전이다.

특히 총기 사용자가 여울 전체를 일방적으로 쏘는지 확인한다. 바위 엄폐와 목책의 일부 차폐는 실제 총구/몸 사선으로 검증하고, 필요하면 엄폐 위치·강폭·도하 속도부터 고친다. 약한 동료를 물속에서 붙잡아 무조건 제거하는 구도, 다리 위 몸/무기 끼임, 끝없는 원돌기도 함께 본다. 물살에 의한 추가 밀림이나 다리 낙사까지 넣지 않는다.

## 그리기와 물리

- 흐름은 얕은 수면 메시와 느리게 이동하는 무늬로 표현한다. 실시간 수면 반사·굴절·유체 시뮬레이션·상시 물보라 입자는 사용하지 않는 방향이다. 물결 방향과 돌 뒤 물자국으로 흐르는 느낌을 만든다. 물속 발과 지형 경계가 읽히도록 색/투명도는 실제 화면에서 조정한다.
- 바위·다리·오크통·목책은 첫 버전에서 고정물로 두는 것을 추천한다. 굴러다니는 통·부서지는 목책은 새 동적 물리와 파편 비용이 필요하므로 별도 선택 사항이다. 이 고정물 선택은 사용자의 파괴/밀기 명령을 받은 상태가 아니다.
- 같은 재질의 정적 형상은 합친다. 철테·판자 이음·성벽 틈·바닥 자국은 주로 무늬에 담고, 전투에 닿지 않는 먼 성벽은 단순한 큰 형태로 만든다.
- 바닥·낮은 다리/진입부는 공유된 높이/접촉 정의로 맞춘다. 기존 평지/화산의 단일 지면 높이·발 받침 연결만으로 다리와 아래 강바닥을 무작정 겹치면 물 위 걷기/다리 위 감속이 생길 수 있다. 통행 가능한 상판·강바닥·높이 전환을 명시하고, 다리 밑으로 사람이 걸어가는 이층 통로는 전제하지 않는다.
- 실제 작은 수의 고정 콜라이더, 그리기 횟수, 삼각형 수는 형상 제작 뒤 센다. 과거 제안의8~12회/1만삼각형은 참고 목표이며 새 수면·목책을 추가한 결과의 실측값이 아니다.4인 물리CPU·그리기CPU/GPU·프레임 지연을 따로 비교한다. 물리Hz나 해결 반복수는 임의로 낮추지 않는다.

## AI·카메라·검토 순서

읽은 코드 기준은 우화 main53629cf4 / 생사전 d398b2f8. 이번 기획 수정에서 상대를 추가 열람하거나 쓰지 않았다. 기존 단일 중심 장애물 우회를 다중 경로로 확장해야 한다. 길의 실제 길이뿐 아니라 다리/진흙의 이동 시간을 함께 보고, 다리가 막혀도 모든 AI가 한 입구에 쌓이지 않게 한다. AI에게 항상 최단 정답 경로나 사람만 모르는 지형 혜택을 주지 않는다. 유파 몸꼴·보법의 재설계와는 분리한다.
