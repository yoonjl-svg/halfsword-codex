# 상점 주인 프로필 후보 3종 — 2026-10-29

사용자 요청으로 기존 프로필 규칙에 맞춘 상점 주인 시안 3개를 제작했다. **사용자가 b(활달한 상인)를 선택하고 이름을 쥘리아 크리스테바로 확정했다. 눈 높이와 입매를 고친 [4차 검토판](revisions/b-04/README.md)이 최신이다.** low 미감은 검토 중이며 서사·판매 분야·전투 유파/숙련도는 미확정이다. 상점 기능·게임 연결·우화 전송은 하지 않았다. 아래 세 후보 비교와 검수 표는 최초 제작 기록이며 최신 수치는 b-04 문서를 따른다.

- **1 · 온화한 노장 (`a`)**: 은발, 짧고 풍성한 수염, 가죽 앞치마, 열린 미소. 화면 왼쪽을 향한 3/4.
- **2 · 활달한 상인 (`b`)**: 붉은 머릿수건, 갈색 땋은 머리, 녹색 조끼와 어깨 천, 가벼운 미소. 화면 오른쪽을 향한 3/4.
- **3 · 차분한 상인 (`c`)**: 관자놀이에 은빛이 섞인 검은 머리, 푸른 옷과 검은 어깨 덮개, 작은 황동 매듭. 정면에 가까운 왼쪽 3/4.

## 기존 프로필과 같은 제작 규칙

고화질 인물을 먼저 생성하여 별도 보존하고, 기존 공통 액자1을 **동일 파일·동일 좌표**로 합성했다. 최종 원본/low/grid는 모두 **1254×1254 RGBA**다. 상반신과 배경 alpha를 유지했다.

low는 **22×22셀, 셀당50px, 원점(77,77), 1100×1100 인물 영역**으로 고정했다. 128은 기존 실험에서 정한 스타일 이름이며 셀 크기128px를 뜻하지 않는다. 인물은 셀마다 단색·alpha0/255이고 액자는 원래 고해상도 장식을 유지한다. 한 셀 안에 작은 보조 픽셀이나 흐림을 넣지 않았다.

최종 원본에서 얻은 색면 초안을 그대로 축소본으로 쓰지 않았다. 눈·눈썹·코·입·수염·머리카락·의복·버클·매듭을 **209회 셀 편집**했다. 이는 같은 셀의 후속 변경을 포함한 작업 횟수다. 2안의 먼 눈은 머리 경계에 합쳐져 보이던 문제를 보완하여 별도의 피부 한 셀을 확보했다. 최종 셀은 `sprites.json`에 보존했고 일반 빌더는 그 결과만 재합성한다.

| 검수 | 1안 | 2안 | 3안 |
|---|---:|---:|---:|
| 얼굴 핵심 폭 | 9셀 | 8셀 | 9셀 |
| 턱 기준 행(0부터) | 13, 수염은14까지 | 14 | 14 |
| 눈 위치(x,y) | (7,8), (10,7) | (13,9), (15,10) | (7,9), (10,8) |
| 눈~턱 거리 | 5·6셀 | 5·4셀 | 5·6셀 |
| 아래 변 몸체 | 22셀 | 22셀 | 22셀 |

얼굴 크기·턱·눈 좌표는 시각 검수용 수동 기준이며 자동 얼굴 검출값이 아니다. 1안은 얼굴 턱선 아래에 수염 한 행이 더 이어진다. 원본도 같은 턱/상반신 기준에 가깝게 맞추기 위해 인물 영역 안에서 20/65/70px 아래로 배치했고 잘려나가는 부분은 상반신 하단뿐이다. 머리 장식 때문에 얼굴을 줄이지 않았다.

`qa.json` 확인: 9개 PNG 디코드·정사각형, 공통 액자 완전 불투명 픽셀 전부 동일, low 모든 셀 단색/50px 경계, 배경 투명, 두 눈 존재·6–10셀 얼굴 폭·상반신 크롭 통과. 기존 공통 액자 해시는 `8d6ec8d1290906183aabf1ab03db477d12a0cf922dece76f2e0053efc1b41a54`. 기존 승인 캐릭터 파일은 읽기만 했고 변경하지 않았다. 로컬 HTTP 갤러리는 390/1280px에서 원본·low·격자 전환 및 9개 이미지 디코딩, 가로 넘침 없음, JS 오류 없음 확인했다(`browser-qa.json`). 최초 file:// 접근은 브라우저 관리 정책으로 차단되어 HTTP로 재검증했다.

기준 문서: `docs/art/pixel_profiles_strict_20261018/README.md`, `docs/art/hero_profiles_20261023/README.md`. 기존 4배 low는 생성하지 않았다. 검수 통과는 사용자의 미감 승인과 다르며 세 안 모두 피드백을 받을 후보이다.

## 재현

Pillow와 NumPy가 설치된 Python 환경에서:

```sh
python3 build.py   # 최종 sprites.json + 보존된 원본 + 공통 액자에서 재생성
python3 verify.py  # 같은 규칙·파일 검사
```

`refine.py`는 초안에서 209회 편집을 다시 적용하는 이력 재현용이다. 원본 생성 그림은 게임 화면 캡처가 아니다.
