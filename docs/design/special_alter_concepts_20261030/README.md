# 강한 특별 얼터 · 후보 제안

사용자가 이졸데의 약함을 언급하며 기계 콘셉트처럼 특별하고 강한 얼터 후보를 요청했다. 다음은 제안이며 대상 캐릭터·외형·수치·새 능력은 아직 선택/구현하지 않았다. 현재 쥘리아의 전투 수치나 서사는 변경하지 않는다.

- 살아 있는 갑주: 투구 속 희미한 얼굴, 갑옷 틈의 빈 어둠. 넓은 판금 보호·강한 버티기를 활용하는 중갑 검사. 기존 판금 체계 활용이 가능하나 정확한 보호 범위·보정과 전투 강함은 별도 검증해야 한다.
- 백색 기생체: 한쪽 어깨/등/팔을 덮는 창백한 섬유질. 수축하는 구조와 빠른 검술을 결합. 검 든 팔의 힘·회수 능력 강화가 후보이며 새 동작 표현과 과도한 충격/무기 파손·인간 상대 체감 검증이 필요하다.
- 균열 난 도자기 인형: 유약을 바른 얼굴/몸과 검은 관절, 고정된 표정. 강한 외피가 깨지며 보호를 잃는 단계 전투. 신체 외피·단계 파손의 추가 구현이 필요하다.

시각적 독특함은 백색 기생체, 기존 시스템으로 강함을 구현하는 확실성은 살아 있는 갑주를 우선 추천했다. 구현 우선순위를 제안한 것이며 실측한 승률/전투 이득은 아니다. 이졸데의 기존 검술을 유지하는 방향을 제안했으나 현재 이졸데/유파/보법/AI 수정0, 우화 메시지0.
