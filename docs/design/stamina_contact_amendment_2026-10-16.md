# 기력 공격 템포 — 접촉 기준 확정

2026-10-16 사용자 직접 답변: **“실제 타격 구간에서 상대에게 닿는 시점으로 맞추기 (추천)”**.

첨부 설계의 ‘칼날 70% 지점 최고 속도 시각’은 닿는 시간의 대리값이었으나, 준비·회수 운동이 최고로 잡혀 실제 타격과 어긋났다. 사용자 선택에 따라 아래 기준으로 바꾼다. 첨부 원본은 보존한다.

- 시작: 사람의 공격 입력 시작 / AI `startStrike`(찌르기·폼멜·비기는 실제 동작 진입).
- 끝: **그 공격의 타격 구간에서 공격용 무기 부위가 상대에게 처음 실제로 접촉한 물리 스텝**. 베기·찌르기·비기는 칼날, 폼멜은 손잡이 부위를 별도 식별한다.
- 준비 중 접촉과 회수 중 접촉은 제외한다. 시작 전부터 겹친 표적은 부적합한 시험으로 표시한다.
- 표적은 실제 게임의 몸 충돌체를 사용한다. 같은 무기·동작·조종 방식의 세 기력 단계에서 출발 자세·거리·입력·표적을 고정한다. 기준 거리 선정은 생생한 단계만 보고 먼저 확정한다.
- 기준 공격이 빗나가면 시간 비율은 **측정 불가**다. 지친 공격만 빗나가면 **실패**다. 0초나 최고 속도 시각으로 대신하지 않는다.
- 목표는 생생한 때 대비 지침 **1/0.7**, 심한 지침 **2.0**, 상대오차 ±7%를 유지한다. 실제 접촉 부위가 달라진 경우 표시하여 같은 목표에 대한 비교인지 검토한다.
- 칼날 최고 속도, 실제 스텝 이동 속도, 접촉 에너지 J는 진단값으로 함께 보존한다. 에너지에 별도 보정은 하지 않는다.

계기: `tools/sim/stamina_contact_probe.mjs`. 준비 중 충돌이 기준 자세를 바꾸지 않도록 상대와 떨어져 준비하고, 정지한 게임 표적을 정해 둔 거리로 옮긴 뒤 측정한다. 이는 고정 표적 실험이며 실제 대련 검증과 구별한다. 아직 전 무기 목표 통과를 뜻하지 않는다.
