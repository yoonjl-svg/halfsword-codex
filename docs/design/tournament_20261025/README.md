# 생사전 — 3인의 맹약: 동시전 검토판

사용자 요청: 대기실 이벤트를 생사전으로 바꾸고, 3인 팀에서 매 대진 1~2명을 골라 출전하는 토너먼트 테스트 페이지. 사용자가 동시전을 선택했다. 이 문서는 운영안과 실제 구현을 구분한다.

- 자체 작업 기준: `2fa0b2aed7c8c70ef02d7f620a927c4b24340cde` (이미 보존한 최신 자체 전달본, 수신 기준 `069104fa58b158778870a46584c68ec860657ed7`). 이번 추가 상대 열람·쓰기·메시지 없음.
- 소스 가지: `codex/life-death-tournament-20261025`.
- 검토 주소: https://yoonjl-svg.github.io/halfsword-codex/encounters/tournament-20261025/

## 이번에 작동하는 것

기존 대기실의 픽셀 숲·공통 액자·폰트·색 위계를 재사용했다. 가운데 생사전 버튼, 오른쪽 3인의 맹약 설명·팀명·동료 두 명 선택, 패널 하단 생사전 입장을 연결했다. 신청 뒤 팀 구성은 고정한다.

대진표는 8팀/3라운드다. 대진을 누르면 상대 두 명과 무기를 보고, 아래 세 카드에서 1~2명을 선택한다. 선택 순서의 첫 캐릭터를 사람이 조작하고 두 번째는 AI다. 플레이어 캐릭터를 쉬게 하고 동료만 내보내도 된다. 조작 캐릭터가 전투불능이 되면 살아 있는 아군으로 조작을 넘긴다.

카드는 혈액량 기준 체력, 부상, 다섯 유파 숙련도, 지급/보유 무기를 표시한다. 원래 대표 유파 숙련도는 유지하며, 다른 유파는 사건 전용 임시 배분(대표 숙련도 이하, 최대 3)이다. 지급 무기는 생성 시 한 번 정해 저장하므로 새로고침으로 바뀌지 않는다. 현행 대기실의 보유 무기 목록(나뭇가지·드루이드의 채찍)을 사용하고, 지정한 무기를 실제 Fighter 생성자에 전달한다. 같은 보유 무기 한 자루를 두 명에게 동시에 주지 못한다. 채찍도 기존 마디 물리를 재사용한다.

실제 전투는 기존 포세이돈 무대 한 곳에서 1:2 또는 2:2로 진행한다. Fighter/AI/Combat/유파·보법 정의는 수정하지 않았다. 사건 전용 TeamCombat에서 서로 다른 적 쌍의 칼 접촉 기록을 분리하고, 아군 간 충돌·피해를 제외했다. 양 팀 칼 잔상은 별도 두 슬롯씩 사용한다. AI는 현재 든 무기의 유파 및 카드 숙련도를 읽는다. 사람은 기존 막기·찌르기·긋기, 숙련도에 따른 고유 공격·비기·패시브를 연결한다. 대상 전환 버튼/Tab으로 상대를 바꿀 수 있다.

판 종료 시 결과를 즉시 저장한다. 저장 실패 시 완료로 간주하지 않고 다시 저장할 수 있다. 중복 결과는 대진을 두 번 진행하지 않는다. 패배/우승 뒤 마지막 상태와 기록을 보여 준다. 부상·혈액·의식·사지 기능·상처·통증·절단·무기 파손은 다음 대진 상태에 반영된다. 기절과 전사 표시는 구분하되, 이번 시안에서는 둘 다 해당 대회 출전 불가다. 일반 계정에서 캐릭터를 삭제하지 않는다.

## 시각과 저장 규칙

모든 표시는 한국시간이다.

- 접수: 매일 22:00 포함 ~ 다음 날 02:00 미포함. 자정 전후 접수는 같은 날 아침 10:00 대회로 묶인다.
- 개막: 10:00. 플레이어는 정해진 시각 이후 언제든 입장 가능하며 지각 기권이 없다.
- 다음 경기: `max(대회 시작 + 라운드×2시간, 직전 내 결과 저장 시각 + 2시간)`.
- 예: 첫 경기를 16:10에 마치면 준결승은 18:10 이후다. 다음 날에 돌아와도 내 대진을 진행할 수 있다.
- 전투 중 약 3초의 시뮬레이션마다, 일시정지 시 즉시 중간 상태를 저장한다. 재접속은 같은 경기 ID/장비/부상/기력을 유지한다. **이번 시안의 재접속은 시작 위치에서 재개하며 물리 엔진의 모든 자세/동작 타이머를 복원하는 완전 리플레이 저장은 아니다.**
- 대기 중에는 출혈을 진행시키지 않는다. 이미 생긴 부상은 유지한다. 휴식 회복량·치료 비용은 아직 넣지 않았다.

별도 키 `stillness.tournament.preview.v1` 및 시험 시각 키를 사용한다. 기존 대기실의 프로필/장비 모듈은 `stillness.tournament.sandbox:` 네임스페이스 안에서만 저장한다. 본게임의 경제·전적·계정 저장을 바꾸지 않는다. 새 대회 초기화는 이 시험 저장만 대상으로 한다.

## 검토 도구와 아직 정식 기능이 아닌 부분

화면 왼쪽 아래 **시험 도구**에서 신청 시간 → 생사전 입장 → 개막 시각으로 진행하면 기다리지 않고 체험할 수 있다. 경기 뒤 다음 경기 시각으로 이동하면 2시간 대기도 넘길 수 있다. 승리/패배 결과 시험은 별도 모의 결과임을 기록한다.

**이 페이지는 기기 로컬 저장을 사용하는 테스트판이다.** 서버 접수·계정 간 동기화·온라인 PvP·공식 경제 보상·고용료는 연결하지 않았다. 다른 NPC 팀끼리의 대진은 고정 시드의 모의 결과다. 직접 출전한 경기만 실제 물리 전투다. 새 정식 토너먼트 참가/지난 대회 보관은 아직 시험 도구 초기화로 대신한다. 대회별 보상/AI 참가 선정/부상 치료/무기 내구도 재지급 정책은 후속 결정 사항이다.

모바일 입력은 기존 손 이동 보정 1.35를 재사용한다. 기본 화면/전투는 폰 가로를 권장하고 세로에서도 카드와 대진표를 확인할 수 있다. 실물 iPhone에서 성능·손맛을 검증한 결과는 아니다.

## 제안

1. 정식 접수는 서버가 대회 날짜·접수 창·결과 시각을 판정하고 계정당 진행 대회 하나만 허용하는 편이 좋다. 저장은 경기 ID별 한 번만 확정하고, 결과 확정과 다음 입장 시각 생성을 같은 서버 트랜잭션에 넣는다. 지각 참가를 허용하므로 모든 참가자의 진행 시각을 하나로 강제하지 않는다.
2. 상대 출전자는 내 선택 전에 공개하는 쪽을 추천한다. 상대 무기와 내 숙련도·부상을 비교해 1명만 내보낼지 결정할 수 있다. 후속에는 대기한 동료의 소량 회복 또는 치료 선택을 검토하면 한 명 출전의 가치가 더 분명해질 수 있다. 수치는 아직 미적용이다.
3. 전사와 기절은 다른 사건으로 표시한다. 이번 시안은 둘 다 대회 출전 불가지만, 정식 운영에서는 기절은 다음 대진 휴식 후 복귀 가능한 규칙을 검토할 만하다. 대회 중 사망을 보유 캐릭터 영구 삭제로 확대하지 않는다.

## 검증과 한계

- `tools/tournament/state.test.mjs`: 접수 경계·자정/개막·늦은 경기의 다음 대기·1~2명 제한·지급 무기 저장/지정 장비 강제·중복 결과·우승/탈락·다른 창 충돌/저장 실패 등 8개 테스트. 결과 `state-tests.txt`.
- `tools/tournament/physics.mjs`: 실제 기존 엔진으로 1:2/2:2, 유효 좌표·아군 타격 0·다른 네 적 쌍 판정·무기/유파 연결·부상 재접속·조작 이전 검사. `physics.json`. 소수 기능 검사이며 팀전 밸런스 비교로 해석하지 않는다.
- `tools/tournament/browser.mjs`: 실제 컴파일판 1280/844/390/320 폭, 이미지/스크립트 로딩, 출전·장비·막기 입력·재접속·자동 결과 저장·대기 잠금·1:2·패배·본게임 저장 격리. 자동 저장 검사는 적 상태를 검사 코드로 종료시키는 fixture이며 자연 대전 승리 실측이 아니다. `browser.json`.
- `tools/tournament/touch.mjs`: 모바일 CDP 실제 터치 입력으로 조이스틱 전진/해제, 베기 드래그, 목표 전환, 일시정지와 채찍 장착을 확인했다. `touch.json`.
- 공통 기존 5관문 종료코드 0, `corr_s0` 12/12 동일, 무기 smoke FAIL/NaN 없음. 원문과 해시는 `gates/`. 과거 10/15 해시와 현재 기준의 다른 수치를 신규 사건 변경 탓으로 보지 않는다. 일반 엔진/설정은 이번 기준 커밋과 바이트 동일하다.
- 검수 중 자동 결과 저장 뒤 이전 대진 선택이 남아 다음 입장이 비활성화되는 문제를 발견해 다음 내 대진을 선택하도록 고쳤다. 초안의 잘못된 빈 승자 표시, 적 2명의 잔상 누락, 지급 무기와 AI 유파 불일치도 수정했다.
- 현재 팀 AI는 대인 AI가 각자 적을 맡고, 대상 전투불능 시 살아 있는 적으로 전환한다. 협공/포위·우선 보호·전술 명령과 자연스러운 아군 회피는 다음 과제다. 성공한 입력/저장 검증을 전투 밸런스 완성으로 주장하지 않는다.

## 재현

```sh
node --test tools/tournament/state.test.mjs
node tools/tournament/physics.mjs
node_modules/.bin/vite build --config vite.tournament.config.js
cp -a public/ui public/fonts public/sfx dist-tournament/
python3 -m http.server 5469 --directory dist-tournament
TOURNAMENT_URL=http://localhost:5469/tournament.html node tools/tournament/browser.mjs
```

정적 게시 시 `dist-tournament/tournament.html`을 해당 독립 경로의 `index.html`로 이름만 바꾼다. `publication.json`에서 최종 원격 발행 확인을 별도로 남긴다.
