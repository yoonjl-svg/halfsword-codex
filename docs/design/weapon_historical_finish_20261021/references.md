# 환도·크리그스메서 실물 기준 조사 — 2026-10-21

## 결론과 범위

**조사 후 사용자 결정: 환도 칼날72cm 확정.** 실물47cm로 단축하는 선택은 하지 않는다. 기존 검토판이 이미72cm이며, 이번 결정은 실물보다 길게 만든 게임용 사양의 승인이다. 아래 실물 치수와 역사적 한계는 그대로 유효하다.

사용자가 환경을 다시 게시한 뒤 박물관·제조사 원문에 정상 접속했다. 기준품을 선정하고 실물 사진까지 확인했다. 이전 접속 차단·선정 미완료 상태는 이번 결과로 대체한다.

- 환도: **부산광역시립박물관 ‘군용 환도’, 구입 10194**. 조선 원유물이며 군용이라는 설명과 부위별 치수가 있다.
- 크리그스메서: **Albion Knecht Mark II**. 시대 유물을 조사해 설계한 현대 제작검으로 길이·질량이 공개되어 있다. 특정 박물관 유물 한 점의 정확한 복제품이라는 뜻은 아니다.

이번 요청은 실물 기준 조사다. 게임 코드·모델·성능을 자동 변경하지 않았다. 현재 시안 수치는 게임 추정값이다. 원문 URL·보존 HTML 해시는 [historical_sources.json](historical_sources.json)에 기록했다.

## 1. 환도 — 부산박물관 군용 환도

[공식 소장품 페이지](https://www.emuseum.go.kr/detail?relicId=PS0100300500101019400000)

| 항목 | 박물관 공개 내용 |
|---|---|
| 명칭 / 다른 명칭 | 군용 환도 / 小環刀, 軍刀, 刀劍 |
| 소장처 / 번호 | 부산광역시립박물관 / 구입 10194 |
| 시대 | 한국–조선 |
| 칼날 | **47.0cm** |
| 손잡이 | **14.5cm** |
| 칼집 | **52.0cm**, 너비5.4cm |
| 기타 표기 | 전체길이67.0cm, 길이61.8cm, 전체너비7.1cm |
| 질량 | **미공개** |

67.0cm와61.8cm가 각각 칼집 포함/제외인지는 항목에 명시되지 않았다. 날과 손잡이를 합하면61.5cm여서 그런 해석은 가능하지만 확인된 구분으로 쓰지 않는다. 전체너비7.1cm도 날 폭으로 옮겨 쓰지 않는다.

박물관은 전형적인 조선 군용 칼의 형태·규격을 반영하고, 짧고 가벼워 휴대하기 편했다고 설명한다. 다만 **원소유자의 계급은 확인되지 않는다.** 병졸용 게임 무기의 기준으로 군용 실물을 선정한 것이며 특정 병졸의 지급품이라는 근거까지 확보한 것은 아니다. ‘소환도’ 한 점의 치수를 조선 전체의 통일 규격으로 일반화하지 않는다.

### 형태와 장식

공식 사진8장을 대조했다. 소장품 설명과 사진 관찰을 구별한다.

| 부위 | 확인 내용 | 구현 시 보존할 특징 |
|---|---|---|
| 칼날 | 사진에서 **완만하게 휜 외날** | 짧은 외날과 약한 휨. 사진 원근 때문에 정확한 곡률cm는 확정하지 않음 |
| 코등이 | 설명에 **삼엽문·칠보문 등의 투각**. 사진은 납작한 타원형 판과 뚫린 문양 | 장식 없는 작은 원반보다 투각 몇 곳이 읽히는 윤곽 |
| 손잡이 | 14.5cm. 갈색 감개가 비스듬하게 촘촘히 감기고 틈으로 어두운 바탕이 보임 | 현행 녹색보다 갈색이 기준품에 가까움. 섬유 종류는 미확인 |
| 칼집 | 검은 표면, 닳은 곳의 목재 바탕, 황동색 입구·띠·끝 금구 | 검은 칼집과 황동색 금구의 대비. 합금 분석 없이 황동 재질로 확정하지 않음 |
| 끝 금구 | 경계에 꽃잎처럼 굴곡진 윤곽 | 작은 윤곽 장식으로 반영 가능. 특정 상징의 뜻은 미확인 |
| 패용 | 사진에 두 군데 고리 달린 띠가 남음. 박물관은 고리에 끈을 묶어 휴대했고 **띠돈은 결실**되었다고 설명 | 남은 칼집 고리와 없어진 허리 연결 장치를 구별. 온전한 띠돈은 별도 참고 필요 |

실용 군용품에도 소박한 장식이 있다. 핵심은 **짧고 약하게 휜 외날·갈색 감개·투각 코등이·검은 칼집·황동색 금구**다. 박물관의 투각에 따른 저항 감소 설명을 게임의 정량적인 물리 효과로 검증한 것은 아니다.

### 기존 문헌 기록

[무예도보통지 권2 예도 판독 기록](../../motion/schools/muyedobotongji_vol2.md)에는 今制環刀의 날3척3촌·자루1척·무게1근8냥이 있다. 이전 판독 기록이며 이번 조사에서 원본 스캔을 재대조하지 않았다. 적용 척·근과 포함 부위를 확정하지 않고 현대 단위로 환산해 실물 제원인 것처럼 쓰지 않는다. 교범의 규격과 특정 유물의 치수는 별개다. 옛 무기 조사 문서의 ‘환두대도(조선 환도 자료로 대체)’는 명칭이 혼합되어 이번 근거에서 제외했다.

## 2. 크리그스메서 — Albion Knecht Mark II

[제조사 원문·사진·제원](https://albion-swords.com/old_albion_site/swords/albion/nextgen/sword-kriegsmesser-knecht-mark-II.htm)

| 항목 | 제조사 공개 제원 |
|---|---|
| 전체 | **113cm** |
| 칼날 | **85cm** |
| 날 뿌리 폭 | **4.45cm** |
| 질량 | **1.38kg** |
| CoG / CoP | 11.4cm / 54.3cm. 표에 측정 원점이 명시되지 않아 게임 좌표로 직접 대입하지 않음 |

전체에서 날 길이를 빼면28cm이지만 코등이·머리 장식 등을 포함할 수 있어 실제 파지 가능한 그립 길이로 단정하지 않는다.

제조사는 15세기 말~16세기 초 전투용 큰 칼에서 영감을 받았고 Peter Johnsson의 시대 원유물 직접 조사를 바탕으로 설계했다고 설명한다. **유물에 근거한 현대 재현 제작검**이며 특정 소장번호 유물과 동일하다고 소개하지 않는다.

- 긴 외날, 날 길이 약2/3의 가늘고 깊은 홈, 얇아지는 끝부분.
- 두 판으로 구성한 손잡이를 관형 리벳으로 고정한 칼식 구조.
- 한쪽 손등을 보호하는 돌출부 **나겔(Nagel)**.
- Mark II는 구형보다 나겔이 넓게 벌어지고 슴베를 감싸는 구조로 바뀐 판.
- 사진의 갈색 긴 손잡이·리벳·곧은 가로 코등이·외날 윤곽을 디자인 기준으로 사용할 수 있음.

**구형과 혼합 금지:** [구형 Knecht](https://albion-swords.com/old_albion_site/swords/albion/nextgen/sword-kriegsmesser-knecht.htm)의 날84.77cm·1.43kg는 별도 판이다. 이번 기준은 Mark II의85cm·1.38kg다. 제조사의 빠른 취급성 설명은 제조사 평가이며 게임 공속·승률 검증이 아니다.

## 3. 현재 게임 시안과 차이

| 무기 | 현재 시안 | 이번 기준품 | 의미 |
|---|---|---|---|
| 환도 | 날72cm·전체92.8cm·0.90kg | 날47cm·손잡이14.5cm·질량미공개 | 시안 날이25cm, 약53% 길다. 유지하면 이 실물의 확대 각색이며 실물 규격 그대로는 아님 |
| 크리그스메서 | 날100cm·전체131.2cm·1.65kg | 날85cm·전체113cm·1.38kg | 기준품으로 옮기면 날15cm·질량0.27kg 감소. 롱소드급이라는 목적에 맞는 출발점 |

크리그스메서는85cm·1.38kg의 실제 제작검을 중심으로 다시 설계하는 것을 추천한다. 환도는 외형 근거가 충분하지만47cm로 맞추면 현재 시안과 역할이 크게 달라진다. 실물 충실 복원과 게임용 길이 확대를 구별해 보고했고, 사용자는 칼날72cm의 게임용 확대를 선택했다. 치수 변경 뒤에는 파지·질량분포·사거리·기존 유파 동작을 다시 확인해야 한다. 이번에는 값이나 모델을 변경하지 않았다.
