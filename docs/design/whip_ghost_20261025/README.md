## 2. 광기의 병마용

- 기존 숙련도3→5, 실제 동방 proficiency 표도5. 명시 override로 원본+1 초기화에 되돌아가지 않음. 고유동작/비기 해금은 기존5단계 규칙. 추가 광기20% 강화는 넣지 않았다. 무기 월왕구천검·성향·보법/기술 정의는 그대로.
- `physiology`를 human/bleeds:true/deathRequiresHeadDetachment:false로. 보통 인간처럼 출혈·의식상실·머리 치명상·마무리로 죽는다. 머리 관절이 붙어 있어도 사망 가능. 별도 HP/기력 배수나 신규 사망 공식 없음.
- 흰 피는 피해자별 palette. 튀는 피·지속 핏방울·바닥 잔류·상처/옷 번짐·검에 묻는 피·머리/사지 단면과 분출까지 연결. 붉은 피와 흰 피 재질을 분리하여 같은 판에서 다른 인간의 피까지 하얗게 변하지 않음. 피 끄기는 입자/분출·회색 단면의 기존 흐름 유지.
- 기존 창백한 인간 얼굴/갑옷/흰 망토·무음 voice:silent 유지. 피격 신음·사망 목소리 없음. 몸이 쓰러지거나 무기가 닿는 소리까지 무음으로 만들지는 않음.
- 기본 병마용은 토우/출혈0/참수 조건/숙련도2 그대로. 나머지34개 캐릭터 정의·모든 무기표 동일(scope.json).
