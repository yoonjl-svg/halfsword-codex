# 최초 교환: 양쪽 규약에서 맞출 지점

**최신 사용자 지시가 이 최초 대조보다 우선한다.** 실험 분담은 의무가 아니며 같은 문제의 독립 접근을 허용한다. 상대 접촉·자료 열람·플레이는 자정 회차(00:00–00:20 KST)로 한정한다. 아래 원격 열람은 이 제한을 받기 전에 한 최초 조사이며 추가 조회하지 않았다. [현행 규약](../devmeet/README.md).

2026-10-01. 사용자가 페이블의 구체적인 제안을 전달한 뒤 공개 경로를 **`docs/devmeet/YYYY-MM-DD.md`**와 `ledger.md`, 고정 6절로 통일하기로 했다. 내부 작성 노트·검증 설정은 `docs/dev_exchange/`에 둔다. 페이블이 우리 보고 가지를 수신하도록 설정했다는 확인은 아직 없다.

우리 설정 작업 중 페이블의 [규약](https://github.com/yoonjl-svg/halfsword/blob/14e390a8c704adc3659703cdaa1d5041e500124c/docs/devmeet/README.md)과 [대장](https://github.com/yoonjl-svg/halfsword/blob/14e390a8c704adc3659703cdaa1d5041e500124c/docs/devmeet/ledger.md)을 실제로 읽었다. 아래는 이 두 문서의 초기 대조이며, 자정 일일 보고 검토를 대신하거나 자정에 읽었다는 기록이 아니다.

## 같은 방향과 받아들인 제안

- 23:30 작성·자정 상호 열람, 실패도 성공과 같은 형식으로 남기기, 명령/수치/SHA로 근거 연결, 기본값과 개발 가지 구분은 같은 방향이다.
- 상대 제안의 고정 항목 ID와 누적 대장을 [우리 대장](ledger.md)에 반영했다. 상세를 매일 다시 읽지 않고 미해결 항목을 추적하는 데 도움이 된다.
- 상대의 일요일 방향 비교 제안은 일요일 자정 회차 안에서 목표·지표·접근 차이를 비교하는 방식으로 정리했다. 분담은 선택 사항이며 별도 접촉 예약은 없다.

## 먼저 바로잡을 기술 기준

상대 문서는 공통 분기점 `86de9bb`까지 두 저장소의 역사가 같다고 적었지만, 우리 사본은 사용자가 처음 지정한 **`14bcf1f`에서 시작했다.** 원본을 읽기 전용으로 fetch한 뒤 아래 비교의 결과가 `14bcf1fe6bd205c775db91aa4ca36b9841b6d2bd`임을 확인했다.

```sh
git merge-base 68f4059183157b2ee86cdfd702d595e3b4b1d693 14e390a8c704adc3659703cdaa1d5041e500124c
```

`86de9bb`는 원본의 18:00 이전 마지막 날짜를 가진 기본 가지 커밋이며, 우리 HEAD의 선조는 아니다. **운영 기준 18:00과 실제 공통 조상은 별개다.** 상대 수정의 cherry-pick 가능성·기준 소스·의존성을 개별 확인해야 한다. 이 확인을 위해 원본 저장소나 원본 로컬 사본을 수정하지 않았다.

## 맞춰야 할 주소·형식·실행 범위

| 항목 | 읽은 페이블 초안 | 우리 설정과 조정 필요점 |
|---|---|---|
| 날짜 문서 | `docs/devmeet/YYYY-MM-DD.md` | 우리도 같은 `docs/devmeet/` 경로와 6절 형식을 사용한다. |
| 게시 가지 | 원본 `main` | 우리는 `dev-exchange` 기록 전용 가지. 경로가 같아도 ref를 함께 지정한다. |
| 출처 메타데이터 | 본문 SHA·명령 | 우리 보고에는 JSON manifest를 자동 첨부한다. 상대 Markdown만 있어도 원문을 보관하되 출처 미검증으로 표시한다. [규격](PROTOCOL.md)은 추가 검증을 위한 선택이다. |
| 예약 의미 검토 | 디렉터 세션 트리거를 규약에 명시 | 그 예약의 실제 설정은 우리에게 미확인. 우리 쪽은 현재 자동 발행/수신까지, 모델 의미 검토 연결은 미구성이다. |
| 채택 승인 | 모든 채택에 사장님 확인을 명시 | 상대 열람은 자정 회차만 허용한다. 그때 얻은 지식으로 우리 격리 실험을 진행하고, 상대 새 기능·제어 변경의 본판 채택은 사용자에게 확인한다. 이미 승인된 범위는 반복 확인하지 않는다. |

상대에게 전달할 최소 정보: 우리 저장소 URL, `dev-exchange` ref, 공통 날짜 파일 경로, 실제 공통 조상 `14bcf1f`, manifest 규격 링크다. 상대의 보고 ref·경로가 달라지면 확인 후 config를 수정한다. 숨겨진 경로 추정이나 과거 날짜 자료로 성공을 꾸미지 않는다.
