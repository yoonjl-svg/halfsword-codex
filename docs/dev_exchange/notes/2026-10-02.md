## 3. 실패에서 배운 것

- 유한값·순힘0·최종 stand로 누운 기립의 안정성을 보장하지 못했다. 낙하 시작부터 다른 제어를 적용한 비교는 시작 자세도 달라지므로 회복 자체의 개선과 구별한다. upright만 끄면 관절 연결이 붕괴했고, 관찰 자세 문턱만으로 stand 전환을 막으면 두 조건 모두 getup에 갇혔다. 두 해법은 기각하고 재현 자료로 남긴다.

- 수직 외력을 내부 반작용으로 바꾸면 기존 지지·기립 제어의 조율 문제도 드러난다. 첫 기하 문턱 통과를 회복 완료로 세지 않는다. 새 후보는 stand 선언 뒤 다시 낮아지는 구간이 있었고, 마지막 안정만으로 이 후퇴를 숨기지 않는다. levH 종료가 서로 다른 두 창의 수치 비교도 개선 근거로 쓰지 않는다.

- 순힘0만으로 내부 힘이 정당하다고 볼 수 없다. 서로 다른 점의 감쇠력이 순토크를 남겼다. 반대로 적용 순토크0도 유한 dt solver의 각운동량 잔차0을 보장하지 않는다.
- 입력 종료는 자유회전이 아니었다. 현재 복귀/유지 제어가 누적각 이동량을 크게 바꾼다. 이를 순수 감쇠 계수 하나의 효과로 해석하지 않는다.
- 장부 잔차에 native 모터·upright·접촉/감쇠·변하는 질량이 포함된다. 미계측을 엔진 오류나 잃어버린 에너지로 단정하지 않는다.
- 초기에 body probe의 위치 인수를 `--out=`으로 잘못 호출한 1회는 결과 파일 저장 단계에서 실패했다. 올바른 위치 인수로 재실행해 최종 기록했다.
