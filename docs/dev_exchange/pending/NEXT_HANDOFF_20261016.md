# 다음 우화 전달에 포함할 메모 — 아직 보내지 않음

2026-10-16 사용자 직접 지시. 상태: **사용자 화면 검토/컨펌 대기**.

## 후속 작업 요청 (현재 게임에는 미적용)

1. 냉동 참치(`frozen_tuna`) 둔타 계수 **2.6 → 2.4**.
2. 고무 닭(`rubber_chicken`) 둔타 계수 **1.6 → 1.2**.
3. **AI 한정** 리볼버 발사 간격을 현재의 **1.8배**로 늘린다. 플레이어는 적용하지 않는다.
   - 현재 공통 GUN.cooldown=.8초, 인물 gunCooldownK가 곱해진다. 사미라1.5이면 현재1.2초 →2.16초. 배율 없는 AI는.8초→1.44초. 이는 기본 재발사 대기시간 기준이며 실제 발사는 겨눔/거리/상태에 따라 더 늦을 수 있다.
   - 기존 인물 배율을 유지하고 그 위에 AI×1.8을 곱한다. 공통 GUN.cooldown을 바꾸어 플레이어까지 느려지게 하지 않는다.
   - 첫 발 대기·8초 전체 장전·피해량/명중률 변경 지시는 아니다. AI 소유 여부로 적용해야 하며 fighter.index나 상대 자리라는 이유로 적용하지 않는다.
   - 플레이어 쿨다운/장전 동일, AI 일반/사미라 간격1.8배, 재시작/무기 교체 후 배율 중복 적용 없음 검증을 요청한다.

모르겐슈테른1.6과 형의 칼1.6은 이번 후속 메모에서 변경하지 않는다. 형의 칼 최종 구현은1.6kg·둔타1.6·파손0이다.

## 이번 포크에 적용했고 다음 전달에 포함할 변경

- 찬다의 호칭을 **식물학자**로 변경한다. 원본/얼터 모두이며 이름·전투 수치 변경은 아니다.
- 김씨의 형의 칼(`brothers_sword`)은 **황약사의 검 / 에픽 한손 둔기**로 정식 카드 추첨에 포함한다. 특수능력 줄은 정확히 **취생몽사: 몽롱한 일격**. 별도의 혼란·몽롱·수면 등 상태이상이나 발동 효과는 없다. 기존 묵직한1.6kg/둔타1.6을 표현한 명칭이다.
- 파손0/손~끝.93m/날·가시·베기·찌르기·갑옷 무시 없음 유지. 에픽 공통 공격 배율1.1(이전 레어1.05)을 적용하며 둔타 계수 자체를 더 올리지는 않았다. 원본 김씨는 기존 철퇴, 얼터는 황약사의 검. 내부ID를 유지하여 기존 저장/URL도 유지한다.
- 최신 사용자 확정 설명: “흰 천으로 감싸진 검. 오랫동안 아무도 풀지 않은 듯 단단히 매여 있다.” 다음 줄에 “사람의 가장 큰 번뇌는 기억력 때문이라 하더군.”을 인용문으로 표시. 이전 취생몽사라는 무기명/황약사라는 능력명을 위 이름으로 대체했다. 사용자가 제안한 ‘묶여’는 아직 선택하지 않았으므로 확정 문장의 ‘매여’를 유지한다.
- 마야 무대는 [봉인의 중정 기획안](../../design/maya_courtyard_2026-10-16.md)만 작성했다. 사용자 첨부의 우화 초기 의견과 샛별 추가 제안을 구별했다. 무대/여정/마야 설정은 아직 변경하지 않았다.

## 전달 전 필수 순서

사용자가 ‘내가 컨펌 안 하고 우화에게 넘길 순 없어’라고 재확인했다. **실제 게임 스크린샷/변경 보고 → 사용자 컨펌 → 받는 쪽 최신main 재확인/전달 가지 동기화·검증 → 이 메모를 포함해 보냄** 순서다.

밤5차 공개 시안 c5c2c8c8, 준비 가지7f3b0f29는 우리 포크에만 있다. 우화에게 새 메시지 발송/상대 저장소 수정/새 두쌍 채택은 없다. 준비 가지를 발행했다고 사용자 검토나 전달 승인이 끝난 것으로 취급하지 않는다. 실제 전송 후에만 이 문서에 수신 대상·메시지/결과SHA를 추가한다.
