# 다음 우화 전달 메모 — 탈진 변경 확정 / 흘림 보상 검토

상태: **사용자 확정 사항을 기록함. 게임 구현·배포·우화 발송은 아직 하지 않음.**

사용자 요청: “좋아 그렇게 하겠다. 우화에게 전달할 때 같이 전해.” 다음 전달 때 아래 탈진 변경을 반드시 포함한다. 이는 지금 즉시 메시지를 발송하라는 요청과 구별한다. 이전 콘텐츠 전달 메모 `NEXT_HANDOFF_20261016.md`는 발행 완료된 별도 이력이다.

## 확정: 탈진은 자연회복 속도로 −35에 도달할 때까지

- 진입 기준과 기력 바닥은 **−70** 유지.
- 고정 2.5초에 −70→0을 회복하는 기존 방식, 그리고 대안인 고정 3초 방식은 이 결정으로 대체한다.
- 탈진 중 이동·공격 불가. 막기 버튼 유지 여부와 관계없이 **즉시 강제 회복**한다. 별도 0.6초 대기는 두지 않는다.
- 회복 속도는 기존 자연회복과 동일: **AI 초당 15 / 플레이어 초당 21**.
- **기력이 −35 이상이 되면 탈진 해제**. 0으로 올려주지 않으며 추가 최소 탈진 시간도 붙이지 않는다.
- −70에서 시작할 때 계산상 AI 약 **2.33초**, 플레이어 약 **1.67초**. 바닥이 고정되어 있으므로 같은 회복 속도에서는 시간이 일정하다. 이는 전투 실측값이 아니다.
- 탈진 해제 후에도 기력 단계의 감속 유지. 기존 단계 복귀 여유 15를 유지하여 **−20에서 심한 지침 해제 / +15에서 정상 복귀**.
- 탈진 완료 직후 불필요한 회복 대기를 새로 주지 않는다. 이후 공격·막아 받기·막기 유지 등은 기존 자연회복 규칙을 따른다.
- 목적: 탈진 자체가 자연회복보다 빠른 재충전 수단이 되는 문제를 해소하면서, 행동 재개 뒤에도 피로를 남긴다.

이 문서는 설계 확정 기록이다. 실제 이식 시에는 최신 수신 main의 기력 상태 전이·몸 자세·입력 잠금·HUD가 새 종료 조건과 일치하는지 확인하고, 구현·검증 여부를 별도로 보고해야 한다.

## 흘림: 인간 피드백과 아직 확정하지 않은 후보

- 사용자는 기존 0.36초 팔/손목 제어력 저하 시험에서 “거의 차이를 느끼기 힘들었어”라고 보고했다. 유의미한 이익을 확정하지 않았다.
- 원자료의 입력 전환만 vs 입력 전환+0.36초를 다시 비교하면 사망 16→13/24이지만, 두 조건 모두 사망한 세 짝은 후보에서 더 일찍 사망했다. 개별 손해만으로 자동 탈락시키지 않고 약30초 종합 득실·인간 이득 기준을 유지한다. 상세 자료는 [일본 흘림 연구 인계](../../codex_team/JAPANESE_RECOVERY_20261017.md).
- 사용자는 대안으로 흘림당한 공격자의 추가 기력 소모를 제안했다. **추가 18(비교 12/24), 같은 공격 한 번, 우선 고정값**은 샛별의 시험 제안이며 확정 수치·검증 완료로 전달하지 않는다.
- 기력 단독을 먼저 권한 것은 실험 순서다. 기존 팔 제어력 저하의 독립적인 인간 체감 이득이 약하고, 피로 단계 하락에 따른 팔 힘/공격 템포 저하와 겹칠 수 있으므로 단독 효과부터 분리한다. 동시 적용이 반드시 나쁘다는 결론은 아니다.
- 결합안은 기력이 넉넉할 때도 즉각적인 틈을 제공할 가능성이 있다. 다만 추가 기력만/팔 제어력만/결합을 같은 조건에서 비교한 결과는 아직 없다. 향후 단독안의 순이득과 체감이 부족하면 더 짧고 약한 제어력 저하를 결합한 후보도 검토할 수 있다.
- 위 탈진 변경 확정을 흘림 패널티 수치 확정이나 기존 시험판 교체 승인으로 확대하지 않는다.
