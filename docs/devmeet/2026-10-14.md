## 3. 실패에서 배운 것

「월인가」는 연정의 노래이며 복수 군가가 아니다. 와신상담 성어 전체를 사기의 직접 기록이라 단정하지 않는다. 첫 수레의 말끔한 실루엣/균일 점선은 조형 보완했고, 구 촬영 URL의 양측 무기 강제 지정은 일반 카드 경로로 교체했다.

85cm 변경 후 두10초 AI 대련의 새 상처가0건이었다. 임의 시드/성능 보정을 반복하지 않고 별도 고정 접촉으로 피해 연결을 검증했다. 이 검사는 명중률이나 장기 성능 개선의 증거가 아니다.

병마용의 첫 손은 정점 색이 없는 형상에 정점 색 재질을 재사용해 검게 보였다. 캐릭터 재질만 수정하고 실제 양손/잡기 모드를 native 검사에 포함했다. 둔황 첫 절벽·벽화는 너무 평평하고 깨끗해 침식/마모를 보강하고 실제 게임 사진을 다시 확인했다. 음향은 오래된 개발 서버의 기본 무대를 읽어 검사에 실패했으며 현 체크아웃 소스 일치까지 확인해 다시 통과했다.

에트나의 일정10도 경사와 상단 평지는 전체 산비탈 체감에 부족했다. 함수의 정점 높이만 맞아도 삼각형 내부가 다른 격자라면 발/그림/충돌이 어긋날 수 있다. 같은 삼각형과 내부 보간을 쓰고 실제 Rapier 광선으로 검증했다. 전달 도구에서 JSON의 −0→0 저장 차이로 준비 검사가 실패했으며, 계약값을 정규화하고 동결 빌드의 로컬 검사를 다시 실행했다.

에트나 첫 용암은 밝은 격자처럼 보여 검은 껍질/불규칙한 열점으로 다시 만들었다. 경사 지면은 발·몸 높이뿐 아니라 접지 마찰·카메라·발소리·낮은 마무리 판정까지 같은 높이/법선을 써야 한다. 물리 실험은 화면 없는 실제 Fighter/Rapier로, 브라우저는 터치 입력과 고정 빌드 전달을 확인한다.

작은 흰 소금 둔덕/선명한 얼룩은 어색하다는 사용자 판단으로 철회했다. 별도 덩어리 대신 먼 연속 지면의 넓고 약한 색 변화로 바꾸고, 내부 문짝·벽돌·직물 짐 디테일을 추가했다. 첫 v6의 매끈한 삼각형 앞머리 면과 묻힌 땋음도 확대 검토 뒤 교정했다. 기술 통과와 조형 채택은 구별한다. local02는 전투 화면 캡처에서 시간 초과라 실패로 보존하고, 최종 브라우저 검사는 순차 실행한다.

첫 반묶음(v5)에 이전 머리의 솟은 두 갈래 앞머리가 남아 사용자가 거부했다. 해당 덩어리와 강조선을 제거하고 두피를 따르는 넓은 한쪽 쓸림으로 교체했다. 신체/얼굴 동일성 및 유한 형상 확인, 실제 모델 사진 교체. 공개 판정은 전달 영수증을 따른다.

정지·부활·후퇴 입력까지 우회로 덮어쓰면 기존 전투 의도가 깨진다. 이동 입력의 힘은 유지하고 접근 방향만 고친다. 회피 여유 반경에 상대뿐 아니라 AI 자신이 들어간 경우도 우회 종료 조건에 포함해야 한다. 근거와 재현은 링크 문서에 보존한다.

이전 도감의 직접 Fighter 생성에 공식 손 외형 후처리가 빠져 있었다. 촬영기는 선택한 소스의 손 연결을 확인하고, 제공 JS 전체를 디스크 스냅샷과 해시 비교한다. 출처 카탈로그와 이미지 SHA를 묶어 잘못된 소스 재촬영을 막는다.
