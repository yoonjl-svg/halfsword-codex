# 서로의 본판과 시험판 플레이

두 팀은 상대의 조작감과 화면을 직접 확인하고, 계측 기록과 사람/에이전트의 관찰을 구분한다. 공개 게임은 변경될 수 있으므로 방문 시각·정확한 URL·쿼리·배포 SHA(확인 가능할 때)를 함께 적는다.

**상대 본판·시험판 플레이와 상대 배포 SHA 조회는 자정 정기 열람 회차(00:00–00:20 KST)에만 한다.** 미리보기·연결 확인도 같은 제한을 따른다. 우리 게임의 개발·검사는 이 제한 대상이 아니다.

| 팀 | 본판 | 별도 시험 |
|---|---|---|
| 페이블 · 애칭 **우화** | [적막 본판](https://yoonjl-svg.github.io/halfsword/) | `/corr/` 등은 우화가 해당 일지에서 소스·조건을 지정한 경우에만 비교한다. |
| Codex · 애칭 **샛별** | [독립 본판](https://yoonjl-svg.github.io/halfsword-codex/) | [받침·균형 비교](https://yoonjl-svg.github.io/halfsword-codex/support-lab.html), [모르겐슈테른·사지 절단 시험](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html) |

휴대폰은 가로로 돌려 **싸움 시작**을 누른다. 일반 본판에 무기 카드가 뜨면 먼저 고른다. 기본 터치 조작은 왼쪽 스틱 이동, 나머지 화면 드래그로 무기 조작, 탭으로 찌르기다. 팀별 설정/조작이 바뀌면 그 판의 안내를 우선한다.

초기화 비교용으로 무기를 고정할 때는 양쪽 본판에 `?weapon=longsword&foeWeapon=longsword&foe=default`를 붙인다. 이 URL은 무기를 고정한 조건이며 무작위 카드 경로까지 검사했다는 뜻은 아니다.

플레이 기록은 최소한 다음을 남긴다.

- 언제·어떤 빌드·어떤 기기/브라우저·어떤 입력으로 무엇을 관찰했는가.
- 재현 가능한 입력 순서와 기대/실제 결과. 실제 휴대폰 체감, 데스크톱, 모바일 크기 브라우저 자동화를 구별한다.
- 상대에게 묻고 싶은 한 가지와 필요하면 화면/영상 링크. AI 자동 플레이의 상태값·승률로 인간의 자연스러움을 수락하지 않는다.

게임 실행을 위해 상대 코드를 우리 본판에 합칠 필요는 없다. 직접 플레이와 수치 비교는 별개이며 상대 게임의 수정·배포 권한을 행사하지 않는다. 질문은 [남김말](notes/README.md)과 일지 ④·⑤절을 연결한다.
