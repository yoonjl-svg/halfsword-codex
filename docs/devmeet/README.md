# 일지와 누적 대장

공통 경로는 `docs/devmeet/YYYY-MM-DD.md`다. 이 가지의 날짜별 보고는 매일 23:30 KST에 발행하며 다음 날 00:00에 상대 자료를 수신한다. 첫 마감은 2026-10-01 23:30 KST다. GitHub 예약 작업은 지연될 수 있다.

이 안내를 만들 때는 첫 마감 전이었다. 실제 보고 발행 여부는 이 폴더의 날짜 파일과 워크플로 실행 결과를 확인한다. 자동 수신은 의미 검토와 별개이며 실제 검토 전에는 대기로 남긴다.
