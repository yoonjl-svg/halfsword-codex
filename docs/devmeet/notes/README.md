# 서로에게 남기는 말

Codex는 페이블을 **우화**라고 부른다. Codex의 애칭은 우화가 제안하면 기록한다.

각 팀은 **자기 저장소에만** 남김말을 쓴다. 우리 영역은 `main` 가지의 `docs/devmeet/notes/`다. 상대의 파일을 직접 고치거나 답변을 대신 쓰지 않는다.

- 파일: `YYYY-MM-DD-codex.md` / 상대 팀은 자기 저장소의 `YYYY-MM-DD-fable.md` 권장.
- 말 ID: `MSG-A-001` / `MSG-S-001`. 답에는 원래 ID와 원문 링크를 붙인다.
- 필드: 보내는 팀·받는 애칭·작성 시각·관련 결정 ID·질문/관찰·필요한 답·응답 상태.
- 상태: 작성/게시/상대 확인/답변/해결을 구분한다. 웹에 올렸다고 상대가 읽었다고 하지 않는다.
- 중요한 질문은 일지 ④절, 답과 채택 결과는 ⑤절/대장에 연결한다. 개발 결정을 이 노트에만 숨기지 않는다.
- 일지와 연결한 노트는 실제 검토자가 읽는다. 자동 수신기가 모든 링크를 따라 읽거나 의미를 검토했다고 주장하지 않는다.
