## 동작 설명

1. 이베리아 막기 책이 있고 실제 highL/highR 막기가 켜진 상태에서 새 칼 접촉을 받음(접촉 age≤1.1dt, impact>0.1, cover weight>0.15).
2. 상대 칼을 가슴 밖으로 보낼 수 있는 법선인지 검사. 바깥 방향 점수에서 나온 gain이0.25 미만이면 **기존 막기 그대로**; 빈 쓸기나 추가 유지도 걸지 않음.
3. 내 손/칼 목표를0.18초 동안 짧게 옮김 →0.10초 받침 →0.20초 회수. 최대 손 이동9.6cm, 방향 벡터 보정0.24 후 정규화. 시작 간격 최소0.65초.
4. 버튼 해제·공격 전환·새 위협·탈진·사망/무장해제에 취소. 기존 팔·손목 모터로 움직이며 상대 칼의 속도/위치 쓰기, 추가 충격, 힘 상향, 기력 페널티, 파손 면제 없음.
5. AI는 별도 어댑터가 이미 선택한 방어만 대상으로 하며 판단/반응/공격/보법을 바꾸지 않음. 사용자 손맛 평가는 **약간 차이 있음**; 더 좋은 막기라는 확정 승인은 아님.

역사상 특정 기술명을 복원했다고 하지 않는다. 기존 탈류/레베스 받기를 보조하는 연구 동작의 임시이름이다. 유파 지도에도 미채택 연구로 기록했다.
