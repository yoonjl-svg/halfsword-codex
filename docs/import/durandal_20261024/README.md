# 뒤랑달155cm — 승인된 이베리아 레전드 전달

사용자 “우화에게 보내” 승인. 원래 츠바이핸더 재사용 제안은 철회했고, 새 독립 규격으로 제작한 뒤 전체 길이155cm를 반영한 최종판이다.

## 기준 → 적용 단위

- 수신 최신 main `9b6c5745f990f171a78ec7190ac3fd8b295a1c92` 위에 뒤랑달 변경만 적용했다.
- 전달 가지 `codex/durandal-handoff-20261024`, 기능 커밋 `c039bcc7b93691e64b94c854eda292d3ef962af8` (6파일). 이 인계서·시험 자료는 그 다음 문서 커밋이다.
- 승인 제작 원본 `360c27aae15edef2a30bee98c2c784d9b22b6319`. 최초151.1cm안 대신 **155cm** 최종 규격을 사용한다.
- 최신 채찍 설명/시작 지급, 베르나르도v2b 외형·프로필, 대기실/저장/기력/유파 동작/보법은 보존했다. 상대 저장소 쓰기0.

붉은 감개·금빛 십자 코등이·팔각 성물함 끝장식, 옅은 상아빛 레전드 기운. 별도 상태이상/갑옷 무시 효과는 없다. 정상 충돌 파손확률0이며 개발자 강제파손 함수는 기존 레전드처럼 등급을 우회한다.

설명:
> 롤랑이 바위에 내리쳐도 부서지지 않았다는 성검.
> 금빛 자루에는 성인들의 유물이 봉해져 있다.

전승을 바탕으로 만든 창작 치수이며 실존 검 실물 복원은 아니다. 롤랑의 임시 츠바이핸더를 뒤랑달로 교체하고 AI 무기 꾸러미도 함께 연결했다. 인물 외형/능력치/기술 취향은 그대로다. 플레이어 무기 추첨에도 포함. 기본 편지 가중치 없는 추첨에서 첫 장1.2%, 두 장 중 하나 이상2.4%; 기존 등급 확률표는 그대로.

## 파일과 의존 연결

- `src/durandal_details.js`: 실제 절차형 모델, 기존 swordKit/Three.js/병합 도구 사용.11메시/3866삼각형, 칼날 Mesh 루트로 피 묻음 유지.
- `src/weapons.js`: 정의/분류/물리/무기 목록 등록. 길이/질량/관성은 부품별 독립 계산. 다른31무기 보존.
- `src/aura.js`: 공통 레전드 기운 프로필.
- `src/weapon_measured.js`: 새 칼 실측 AI 거리/시간만 추가.
- `src/character_roland.js`: 장착과 `ai.persona.school`을 뒤랑달로.
- `public/ui/weapons/durandal.webp`: 실제 모델에서 렌더한256² 투명 썸네일.

패키지 추가나 저장 스키마 변경 없음. 명시적 heavy/cut/iberian과 기존 resolveSwordArt 경로를 사용한다. 모델/충돌/썸네일/길이 표기를 따로 구형으로 되돌리지 않는다.

문서 커밋도 함께 가져오면 위 시험 명령을 그대로 실행할 수 있다. 최종 결과 SHA/두 커밋은 발행 메시지에 고정한다. 이후 수신 main이 움직였다면 변경 범위를 먼저 확인한다. 기능 되돌림은 `git revert c039bcc7b93691e64b94c854eda292d3ef962af8`로 롤랑/무기등록/기운/AI 측정/썸네일을 함께 되돌린다. 뒤랑달을 저장한 테스트 세이브는 별도 보존하고 되돌린 버전에서 새 무기ID 사용은 피한다. 문서 커밋은 게임 동작에 영향 없다.
