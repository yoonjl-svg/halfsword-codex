## 최신 한손 자세와 측정 한계

**MEASURED `[1.36,1.49,1.08,.25]`, CUT_TIME_30 `.18`은 제작 기준82461ad4에서 얻은 값을 유지했습니다. 최신 자세의 실제 찌르기 사거리를 새로 확정한 값이 아닙니다.**

받는 쪽 최신판에서 기존 `weapon_measure.mjs`(zornhau 한 번, 날70%가 머리 높이를 내려오는 동안의 전방거리)를 다시 돌리자 레이피어1.44→.82m, 파펜하이머1.40→.46m로 바뀌었습니다. 테스트 프로세스 안에서 **새 팔 제한 두 설정만 함께 끄면** 종전1.44/1.40이 재현됐습니다. 입력활성 표시를 보완한 별도 측정에서도 .76/.43으로 비슷한 민감성이 남았습니다. `measurement-diagnostic.json` 및 재현 코드.

따라서 이 내려베기 표본을 실제 이탈리아 찌르기 거리로 간주해 AI 간격을 .45m로 급감시키지 않았습니다. 최신 팔 제약은 게임에서 그대로 켜 두었습니다. 일반 플레이/AI 전투 우열은 별도 재평가 대상이며, 새 한손 제약에 맞춘 **실제 찌르기 접촉·고유 자세별 거리 측정**이 후속 후보입니다. 기존 무기의 간격표도 이번 전달에서 바꾸지 않았습니다. 단순 입력 누락만이 원인이라고 결론내리지 않습니다.
