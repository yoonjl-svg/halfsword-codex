## 병합 중 보완

9파일의 충돌을 기능 단위로 해결했다. 최신 상점 세 상품·지갑·갱신, 이탈리아 보법, 고노센/공격 입력, 엄지 접촉과 대검 제어를 보존했다. 사람 입력 함수를 분리한 동시 전투 루프에는 **최신 main의 입력 본문**을 옮겼다. 문서의 새 결정은 양쪽을 남기되 같은 확인표 항목은 최신 본판 설명을 유지했다.

자연 바인드는 여러 전투자의 칼을 따로 관리하도록 가져오면서, 최신 본판의 콜라이더별 원래 반발·마찰 보관 맵 초기화를 함께 보존했다. 이를 빠뜨리면 자연 바인드 기본 활성화 상태에서 오류가 난다. 기존 단위 검사의 접촉 주입도 전투자별 접촉 시각에 맞추고, 두 칼만 맞닿을 때 나머지 두 칼의 재질을 바꾸지 않는 2:2 회귀 검사를 추가했다.

쥘리아 성향 표는 이전 생사전 초안 당시의 빈 AI 시트를 전제했다. 실제 AI를 바꾸지 않고 최신 본판 AI 손잡이를 기존 `AXES.read` 식으로 환산해 표와 검사를 맞췄다. 숙련도·전용무기·고용 규칙은 유지했다.
