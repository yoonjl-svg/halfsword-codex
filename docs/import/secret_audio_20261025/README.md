## 기준과 적용 단위

- 받는 쪽 main `069104fa58b158778870a46584c68ec860657ed7`에서 독립 전달 가지 `codex/secret-audio-handoff-20261025` 준비. 마지막 원격 확인과 결과 커밋은 전달 메시지/영수증 참고.
- 새 `public/sfx/secret/` 6음원 + 연결표 + 출처만 실행 에셋 위치에 추가. `src/`·설정·저장·기존 음원은 기준과 동일합니다.
- 이번은 음원/지시 전달이며 **실제 발동 연결과 최종 음량은 MSG-S-015대로 우화 담당**입니다. 이 가지를 가져오는 것만으로 게임에서 자동 재생되지는 않습니다.
- 받은 쪽 최신판에 맞춘 가지의 독립 커밋만 cherry-pick합니다. 원래 제작 가지 전체를 병합하지 않습니다. 되돌림은 이번 독립 커밋 revert(새 에셋/자료 제거); 저장 데이터 변경 없음.

## 최신 연결부 확인과 주의

최신 `src/sound.js`는 `new URL(`sfx/${f}.mp3`, document.baseURI)` 방식으로 읽고 Web Audio로 디코딩합니다. 선택 MP3 이름은 `secret/g1-clank`, `secret/g2-dry`입니다. 새 라이브러리가 필요하지 않습니다. `mapping.json`은 연결표이며 기존 게임이 자동으로 읽는 설정 파일은 아닙니다.

`src/main.js`의 `secretBurstsSeen`은 `(ai.secretBursts ?? 0) + player.skill.secretBursts` 합계를 화면 슬로모에 사용합니다. **유파별 소리 선택에는 합계만 쓰지 말고 발동한 전투자를 식별**해야 합니다. 플레이어와 AI 각각의 비기 실행 카운터/실제 성공 순간에 연결해 한 비기당 한 번 재생하십시오. 이베리아 AI는 `skill.secret`와 AI 실행 경로 모두 지나므로 두 경로에 동시에 연결하면 중복될 수 있습니다. 이 부분은 코드 열람으로 확인했으며 새 런타임 연결 테스트를 수행했다는 뜻은 아닙니다.

`instantArc`에는 비기가 아닌 일반 고유 동작 흔적도 들어가므로 모든 새 잔상을 발동음으로 취급하지 않습니다. 준비 `!`/`secretReady`/준비자세가 아닌 실제 비기 발동에 연결합니다. 화면의0.4배 슬로모와 별개로 소리는 `playbackRate=1` 권장. 일본/이베리아의 최신 비기 후 굳음1.2초 등 전투 값은 보존했습니다.

우화 연결 후 확인할 항목: 사람/AI 각5유파의 성공 순간1회, 실패/준비창에서0회, 한 비기 여러 타격에서 중복0, 동시 양측 발동의 유파 선택, 음소거/일시정지/새 판의 카운터 초기화와 잔여 재생 처리, 뒤따르는 타격음과 최종 음량. 이번 전달에서 확인한 것은 에셋/재현/빌드/기존 코드 보존이며 이 이벤트 연결 항목을 이미 통과했다고 주장하지 않습니다.

## 출처·가공·재현

외부 원료3종 모두 **CC0 1.0**, `public/sfx/secret/LICENSE.txt`와 `sources/evidence.json`에 URL·페이지확인/파일해시, OGA readme 보존. Freesound2종은 HQ MP3 미리듣기이며 업로드 WAV 원본이라고 표시하지 않습니다. 일본도 실제 발도 소리를 역사적으로 복원했다고 주장하지 않습니다.

48kHz 모노, WAV24bit+MP3+OGG, WAV 피크−8dBFS. 채널 평균/필터/짧은 이탈 클릭·금속층·인출 마찰을 합성, G1 꼬리는120ms 뒤 감쇠해99%에너지 약179ms. G2는약226ms. 최종 믹스는 우화가 담당합니다.

재현: 이 폴더에서 `python prepare.py`. Python3+NumPy+SciPy+FFmpeg 필요. 원료를 포함하므로 네트워크 없이 실행할 수 있습니다. `exports/`에 두 음원의3형식이 생성됩니다. 원본 파형 동일성/압축 해시는 `validation.json` 참고. 압축 결과 바이트는 인코더 버전에 따라 달라질 수 있습니다. 조사 당시 전체 evidence에는 미선택 후보도 있으나 이번 최종 출력에 쓰는 원료는 위3종뿐입니다.
