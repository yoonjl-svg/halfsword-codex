## 무엇을 만들었나

1. **기준 동작 v0** (`tools/motion/lib/cuts.mjs` → `node tools/motion/build_clips.mjs`)
   - 베기: 분노의 베기 Zornhau, 위에서 베기 Oberhau, 가로 베기 Zwerchhau, 사팔뜨기 베기 Schielhau, 아래에서 베기 Unterhau.
     제안: 정수리 베기 Scheitelhau, 굽은 베기 Krumphau. 디렉터 목록에 있어 가운데 베기 Mittelhau 도 같이 냈다.
   - 크기 셋: **작게 = 지금 게임의 팔 베기**(자세표 `src/guards.js` 를 그대로 이음 — 헤드리스로 돌린 지금 게임 Zornhau 칼끝 17.4 m/s, 작게 클립 19.6 m/s 로 가깝다. 작게 벌의 시작·끝 자세는 게임 자세표와 손 자리가 같다(0 cm)),
     **크게 = 온몸 베기**, **보통 = 크게 벌을 겨눈 선 자세 쪽으로 줄인 것(몸·손 75%, 칼 각 85%, 시각은 작게와 크게의 가운데)**. 디렉터 설계의 S(싣기)가 "같은 클립의 작은 벌과 큰 벌 사이를 섞는다"(redesign §2-2)와 같은 구조다.
   - 좌우: 오른쪽에서 벤 것을 거울로. 작게 벌의 왼쪽은 게임의 왼쪽 자세 값을 그대로 쓴다.
2. **몸 모형** (`tools/motion/lib/body.mjs`): 게임 뼈대 치수(발목 0.08 · 무릎 0.50 · 엉덩이 0.93 · 허리 1.06 · 가슴 1.33 · 어깨 1.43, 위팔 0.30 + 아래팔·손 0.265, 어깨 가슴 틀 (0, 0.1, ±0.2), 부위 무게)로 만든 막대 인형.
   팔·다리 두 마디 IK, 날개뼈(팔을 60° 넘게 들면 어깨가 최대 6 cm 올라감, 뻗으면 4 cm 나감), 롱소드(칼끝 1.18 m, 빈손 −0.14 m).
3. **운동 사슬**: 골반·가슴 돌림을 두 최소 저크 곡선의 합으로 둔다 — 빠른 돌림(최고 각속도를 칼이 겨눈 선보다 **130 ms / 90 ms 앞**)과 느린 지나가기 돌림.
   겨눈 선에서는 저작한 자세(가슴이 정면에서 15~20° 넘어감)를 지키고, 나머지 돌림은 지나가기에서 한다(골프 임팩트 때 가슴이 거의 정면인 것과 같다).
   칼 방향은 월드 틀의 "베는 면" 안의 각으로 저작해서 몸통이 먼저 돌고 칼이 늦게 따라오는 늦춤이 저절로 생긴다.
4. **측정**: 칼끝·손 빠르기, 골반·가슴 각속도, 최고 시각 순서, 칼끝 빠르기 중 몸통 몫, 동작 범위(가슴·골반 회전, 척추 비틀림, 감기 손 높이·앞뒤, 어깨 들림, 지나가기 손 옆 거리, 손·칼끝 길),
   허점 어림(앞이 빈 시간, 칼끝이 몸 뒤에 있는 시간, 돌아선 각, 무게중심 옮김), 팔·다리 길이 넘침 검사. redesign §2-6 목표표와 같은 항목이다.
5. **비교 화면**과 **게임 기록 도구**(`tools/motion/record_game.mjs` — `tools/sim/harness_m.mjs` 로 지금 게임을 헤드리스로 돌려 랙돌 관절을 같은 좌표로 적는다).

## 핵심 결과 (v0, 오른쪽에서, 롱소드) — 자세한 값은 `spec_table.md`

| | 작게 (지금 게임) | 크게 (온몸) | 사람 자료 |
|---|---|---|---|
| 칼끝 최고 m/s | 11~20 | **34~37** (작게의 1.8~2.3배, Unterhau 3.3배) | 힘 뺀 베기 약 20 (SwordSTEM 한 건). 최대를 잰 자료는 아직 없다 — 전에 적은 33.5(ARMA)는 계산 예시였다 |
| 감기 끝 → 칼이 겨눈 선 | 0.28 s | 0.29 s | 골프 내려치기 약 0.25~0.3 s [기억, 확인 필요] |
| 운동 사슬 (겨눈 선 기준 최고 시각) | 거의 한꺼번에 | 골반 −129 → 가슴 −79 → 손 −71 → 칼끝 −25 ms (Zornhau) | 골반 → 가슴 → 팔 → 채, 간격 20~40 ms (골프) |
| 골반 / 가슴 최고 각속도 | 130 / 380 °/s (Zornhau) | 300 / 640 °/s (Zornhau) | 골프 480±82 / 605±87 °/s |
| 가슴 / 골반 회전 범위 | 84° / 32° | 140° / 75° (Zornhau) | 골프 백스윙만 어깨 90°·골반 50° |
| 손이 움직인 길이 | 1.1~2.1 m | 2.7~3.6 m | — |
| 앞이 빈 시간 (허점 어림) | 0.16 s | 0.77 s (Zornhau) | — |

- **크게 할 때 걸리는 시간은 거의 같다.** 감기만 길어지고(0.2 → 0.36 s), 풀기 → 겨눈 선은 0.28~0.29 s 로 같다. 칼끝이 더 긴 호(몸 뒤에서 앞으로 약 300°)를 같은 시간에 도니 빨라진다.
- **칼끝은 칼이 겨눈 선을 지나기 25~33 ms 앞에서 가장 빠르다**("닿기 몇 인치 앞에서 최고" — SwordSTEM). 그때 가슴은 자기 최고 각속도의 71~77% 로 이미 서는 중이다. 몸통이 먼저 서면서 팔·칼에 넘겨 준다.
- **다섯 비밀 베기의 "덮는" 성질이 숫자에 나온다.** Schielhau·Scheitelhau·Krumphau 는 크게 해도 앞이 빈 시간이 0.13~0.20 s 로 짧다(칼이 상대 쪽 선 위에서 끝남).
  Zornhau·Zwerch·Mittelhau·Unterhau 는 크게 하면 0.77~0.79 s 로 길다 — 온몸의 값이 허점으로 나온다.
- **redesign §2-6 목표와 대조** (크게 벌):
  - 닿는 것: 칼끝 1.45배 이상(1.8~3.3배), 에너지 비 2배 이상(빠르기² 3.3~10.8배), 가슴 130°·골반 70°(사선·가로 베기), 손 길 1.8 m, 감기 손 높이 +0.10 m 이상(머리 위 베기), 어깨 들림 100° 이상, 사슬 순서.
  - **관찰 — 지나가기 −0.35 m 는 게임 팔(어깨→칼자루 0.565 m)로 가로 베기만 닿는다**: Mittelhau −0.40, Zwerch −0.35, Unterhau −0.33, Zornhau −0.32 m(칼자루가 왼 엉덩이 바깥, 엉덩이 높이 — 팔을 다 뻗은 자리). 사람 팔은 약 0.63~0.66 m 다 [추정: 위팔 0.33 + 아래팔 0.27 + 손 가운데 0.06]. 목표를 어떻게 할지는 디렉터·사장님 몫이다.
    (재는 식은 디렉터 `mx.mjs` 의 hand_side_min 과 같다: 가슴 가운데 기준, 머리 방향 틀 옆 거리. 2026-09-29 오후에 골반 틀 값에서 바꿨다 — 골반과 함께 도는 틀은 같은 자세를 더 작게 쟀다.)
  - **관찰 — 사람 가슴허리 돌림은 약 45° (AAOS, 참고·한도 아님).** 크게 Zornhau·Mittelhau 가 45° 다. redesign 의 40~55° 는 끝값이 크기를 막지 않도록 "40° 이상, 사람 참고 약 45°" 처럼 적기를 제안한다(사람 값은 천장이 아니다 — 게임이 넘으면 관찰로만 적는다).
  - **칼끝 최고 순간의 몸통 몫 30% 이상**은 사선·가로 베기(30~37%)만 닿고 굽은 베기는 24%, 세로 베기는 8~17% 다. 몸통이 먼저 서며 넘겨 주는 채찍 동작에서는 칼끝 최고 순간의 몸통 몫이 원래 작다 — "몸통이 칼끝 운동량에 얼마나 보탰나"는 베기 전체로 재는 편이 맞다(디렉터와 정할 것).
- **지금 게임 팔 베기 기록과 겹쳐 보면**(비교 화면, 칼끝 최고 시각 맞춤): 크게 Zornhau 와 손 위치가 평균 0.45 m 다르다. 게임 손은 머리 꼭대기 위로 올라가지 않고(−0.05 m, 기준 +0.11 m), 칼끝이 몸 뒤로 가는 거리는 0.47 m(기준 1.40 m)다.
  작게 클립과 게임 기록도 0.20~0.45 m 다르다 — 자세표 목표와 랙돌이 실제로 간 길의 차이다.
  (게임 기록은 게임과 같은 다리 체중 걸음(hybrid)으로, 시작 자세에서 2 s 서 있다가 휘두른 것이다 — 9/29 오후에 다시 기록. 처음 기록은 시뮬 기본 걸음(levitate)·0.5 s 였다.)

## 파일 형식 (게임이 읽을 것)

`docs/motion/clips/<베기>_<right|left>_<small|medium|large>.json`

```text
format: 'stillness-motion-clip/1'
id, cut, nameKo, nameDe, family, desc, side, size, hz(120), weapon('longsword'), handedness('right')
marks: { t0, tw, tr, tc, tf, tg }         // 초. 준비 · 감기 끝 · 손목 풀림 · 칼이 겨눈 선을 지남 · 지나가기 끝 · 복귀
phiMarks: { t0:-1, tw:0, tr:0.55, tc:0.85, tf:1.6, tg:2.2 }   // redesign §2-1 의 φ 와 맞춤
sources: [{ id, kind, cite, url, read, license }]
provenance, summary(측정 요약 — spec_table.md 와 같은 값), joints(관절 이름), bones(막대 인형 뼈)
data: { n, width, cols }                  // 열 단위: cols[채널] = 표본 n 개 (벡터는 3칸씩 평면)
```

채널 (`data.cols`):

| 채널 | 틀 | 뜻 |
|---|---|---|
| `t`, `phi` | — | 시각(초), 위상 φ |
| `pelvis.yaw/pitch/drop` | 월드 | 골반 돌림°(+ = 칼 쪽으로 감음, 게임 guards.js 부호), 숙임°, 낮춤 m |
| `chest.yaw/xFactor/lean/side` | 월드 | 가슴 돌림°, 척추 비틀림(가슴−골반)°, 몸 숙임 합°, 옆굽힘° |
| `handS`, `handO` | 가슴 | 칼 든 손·빈손 [앞, 위, 칼 쪽] m (원점 = 가슴 가운데, 게임 guards.js 손 원점과 같음) |
| `sword`, `edge` | 가슴 | 칼 방향 단위 벡터, 앞날이 향하는 쪽(칼끝 속도에서 칼 축 성분을 뺀 방향 — 저작 값이 아니라 결과) |

| `feet.L/R.yaw/lift` | 월드 | 발끝 돌림°, 뒤꿈치 들림 0~1 |
| `com` | 월드 | 무게중심 (게임 부위 무게 + 칼) |
| `ang.*` | — | 관절각°: pelvisYaw, chestYaw, xFactor, lean, shoulderElevS, elbowS, elbowO, wrist(아래팔-칼), kneeL, kneeR |

| `speed.tip/hand` | 월드 | m/s |
| `J` | 월드 | `joints` 순서 관절 위치 (막대 인형·발 자리·칼끝): hipC, waist, chest, neck, head, shS, elS, hS, shO, elO, hO, hipL, kneeL, ankleL, heelL, toeL, hipR, kneeR, ankleR, heelR, toeR, pommel, tip |

- 월드 = 클립 시작 때 골반 밑 땅, x 앞(상대 쪽) · y 위 · z 칼 든 쪽. 오른손잡이 기준이고 발 이름 L/R 은 해부학적 왼발·오른발이다(게임 `F`/`B` 는 칼 쪽 발/반대 발 — 오른손잡이면 F = 오른발).
- redesign §2-2 atlas 채널과의 대응표는 `clip_format.md` §3-6 (clip/2 에서 빠진 채널을 채움 — balanceAssist 만 없음).
  balanceAssist·openness 는 아직 채널로 내지 않았다(openness 는 `summary.opening` 의 어림 시간만).

## 한계 (솔직히)

- **사람 값은 참고이지 한도가 아니다.** 이 폴더의 모든 사람 수치(관절 범위, 칼끝 빠르기, 손목 각)는 기준 동작을 사람답게 만들 때만 쓴다. 게임이 사람 범위를 넘으면 "관찰"로만 적고, 줄일지는 사장님이 정하신다.

- **v0 는 모션 캡처가 아니다.** 교본의 시작·끝 자세·걸음 규칙과 스포츠 생체역학의 운동 사슬 순서·빠르기 범위로 저작한 것이다. 사람 모캡과 대조한 오차는 아직 없다(`sources.md` — 롱소드 다섯 베기 모캡은 공개되지 않았다).
- **손목 각(아래팔-칼)**: 사람 어림 [추정, 측정 자료 없음] = 망치 쥐기 약 90° + 손목 옆굽힘으로 약 135°, 손목 폄(최대 70°)까지 보태면 약 160°. 크게 벌은 최대 114~163° 로 거의 160° 안이다(가로 베기 감기만 0.02 s 넘음). 보통 벌은 섞은 탓에 165~177° 까지 간다. 몸 모형에 한계를 걸어 칼을 끌어오는 방법(한 표본씩, 시간으로 부드럽게 두 가지)을 시험했으나 감기 중 칼이 튀어(칼끝 순간 37~80 m/s) v0 에서는 끄고 적기만 한다(`spec_table.md` §4, `tools/motion/lib/clip.mjs` wristLimit).
- **보통 벌**: 처음(v0)에는 작게와 크게를 그냥 반씩 섞었더니 게임 자세와 온몸 자세의 모양이 달라 사이 자세의 손목이 165~177° 까지 갔다. **게임에서 S 로 작은 벌과 큰 벌을 곧게 섞어도 같은 일이 생긴다.** 그래서 보통 벌을 크게 벌에서 줄여 만들었다(v1: 칼끝 24~26 m/s, 크기 재는 값 대부분이 작게와 크게 사이). 섞을 때는 보통 벌을 사이에 두고 두 구간으로 섞기를 권한다(작게↔보통, 보통↔크게). 보통 벌도 감기에서 손목이 160° 를 잠깐 넘는 베기가 있다(0.06~0.16 s).
- 칼끝 34~37 m/s 와 견줄 사람 최대 측정 자료는 아직 없다(전에 인용한 ARMA 33.5 m/s 는 칼자루 힘 셈의 가정 예시였다 — 연구 ASS 표본 점검 9/29). 모캡 수치를 얻으면 사람 기준 동작 쪽을 다시 맞춘다는 뜻이고, **게임 빠르기의 한도가 아니다**(사장님: 빠르기·세기에 위쪽 한도 없음).
- 작게 벌의 왼쪽 바꿈·바보 자세는 게임 자세표 값 그대로라 칼끝이 땅 높이까지 내려간다(게임에서는 땅이 막는다).
- **크게 벌의 감기(0.36 s)가 빠른 편이다.** 칼이 쟁기에서 등 뒤까지 약 240° 를 돌아 감기 중에도 칼끝이 최고 약 20 m/s 다. 골프는 백스윙이 다운스윙의 약 3배 길다(대중서 "Tour Tempo" [기억]).
  칼 베기는 준비를 더 빨리 하지만, 준비가 읽히려면 감기 0.4~0.5 s 도 검토할 만하다(조작 반응성과 맞바꿈 — 디렉터·사장님 판단).
- 어깨·손목 "최고 시각"은 방향 변화율로 재서 흔들린다. 운동 사슬 판정은 골반 → 가슴 → 손 → 칼끝으로만 하고, 120 Hz 표본이라 10 ms 안의 차이는 같은 때로 본다.
- **운동 사슬 순서(골반 → 가슴 → 손 → 칼끝)는 보통·크게 32벌 모두 맞는다**(9/29 오후 고침). 처음에는 크게 세로 베기 둘과 보통 벌 11벌에서 손 최고가 골반보다 앞섰다 — 손목 풀림 때 손이 너무 먼저 앞으로 나가 손 빠르기가 두 봉우리였다. 크게 세로 베기는 손 키를, 보통 벌은 몸통 앞섬을 크게 벌과 같게 하고 풀림 키의 손을 30% 되돌려(`MED.TR`) 고쳤다. 칼끝 빠르기·손목은 거의 그대로다.
- **겹침 검사** (`node tools/motion/qa_clips.mjs`): 칼이 머리·몸통·다리를 지나가는 클립은 없다(가장 가까워도 0.10 m). 아래팔이 몸통을 뚫던 것(빈 팔이 오른 엉덩이·오른 어깨로 건너갈 때 팔꿈치가 아래·뒤로 가서, 가장 깊게 96%)은 9/29 오후에 팔꿈치를 어깨→손 축 둘레로 돌려 몸통을 비키게 고쳤다(`lib/body.mjs` clearArm — 손·칼은 그대로라 빠르기·손목 값은 안 바뀜). 남은 것: 크게 감기 초반 등 8벌에서 0.01~0.22 s 동안 25~40% (쥔 손 자체가 가슴 앞에 가까워 팔꿈치로는 못 비킴 — 키를 고칠 거리).
- 물리가 없다. 칼 관성·근력 한도·균형은 게임(Rapier)이 정한다. 기준 동작은 "사람이면 이 모양·이 시간표로 움직인다"만 말한다.
- 롱소드만 냈다. 흐름은 8자(분노의 베기 좌우) 하나, 런지는 사람 기준 표(`lunge_flow.md`)만 냈다. 세이버(팔꿈치 축 moulinet)·레이피어 런지 클립·츠바이핸더는 다음 차례다.

## 무기 PM 과 나눈 일

- 무기 PM(`claude/pm-weapons-balance`, `docs/weapon_motions.md`·`src/motion_library.js`) = **무기가 무엇을 하나**: 몸 틀별 자세표, 싸움 방식별 기술 길, 덧씌우기(런지·흐름·날 세우기) 값.
- 동작 연구 PM(여기) = **몸이 어떻게 움직이나**: 사람 기준 동작, 관절·시간 사양, 운동 사슬, 평가 기준, 비교 화면.
- 겹치는 자리(무기 PM §6-3): 런지 몸 낮춤과 흐름의 손목 제동. 여기서는 사람 기준 수치만 낸다(펜싱 런지: 길이 1.24 m(0.88~1.86), 엉덩이 속도 1.97 m/s, 몸통 앞기울기 17.5° — `sources.md`). 게임 값에 넣는 것은 무기 PM·디렉터 몫이다.
