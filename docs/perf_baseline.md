# 성능 기준 폰과 측정 기록

재는 법: 주소에 `?fps=1`을 붙이고 한 판을 싸운다. 왼쪽 위에 초당 프레임(평균·느린 5%), 물리·그리기 시간, 게임 속도(100% 아래 = 슬로 모션), 그리기 호출·삼각형이 나온다 (`src/perfmeter.js`).

## 기준 폰
- **아이폰 17e** (사장님 폰)
- 최신 세대의 보급형이라 칩은 빠른 편이다.
- 오래된 보급형 안드로이드는 아직 재지 않았다. 여유를 남겨 두고 판단한다.
