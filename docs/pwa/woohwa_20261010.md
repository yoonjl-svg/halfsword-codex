# 우화 원본용 PWA 전달 · 2026-10-10

기준 `yoonjl-svg/halfsword@f3792633f5fbb9f66ff643f89879e911c3f75415`. [전달 소스·적용 안내](../../integrations/woohwa-pwa/README.md). 게임 소스와 lockfile 일치; 기존 index.html/package.json 연결2개와 새 파일8개만 필요하다. 의존성 추가 없음. 우리 게임은 PWA 등록하지 않는다.

검증: 원본 Vite 실제 빌드, Chromium 모바일844×390·터치·Service Worker 실제 실행9묶음 PASS. 오프라인 신규 진입/음원 응답/전투/재시작, 전투 중 무새로고침·동일 body/설정 보존, 두 번째 창이 열린 동안 업데이트 대기, 창 종료 뒤 전환, 다른 게임 캐시 보존, 손상된 새 파일 거절/이전판 유지, 캐시 접근 실패 때 검증된 온라인 응답. [기계 판정·한계](../../integrations/woohwa-pwa/verification.json)에 근거를 보존했다. 원본 물리를 바꾸지 않아 전투 대량 반복 검사는 하지 않았다.

설치 도구의 dry-run/충돌/심볼릭링크/별도 빌드 거절·백업·반복 적용을 확인했다. inline body 닫힘 위치 때문에 성공처럼 끝나던 누락을 발견해 수정하고 재검증했다. 초기 브라우저 검사의 incognito 설치 불가와 이벤트 전 UI 판정은 검사 조건 문제로 구분했다.

현재 오프라인 대상238파일4,791,875바이트. 과거 독립 실험판4경로 제외;30MiB 초과 시 검토 필요. 경로별 cache namespace, 전체 빌드 해시 검증, 네 개 동시 다운로드, skipWaiting/claim/reload 없음. 실제 OS 홈 화면 설치/저장 보존·청취는 원본 배포 후 실기기 확인이 필요하다.

완료 기준은 다운로드 파일의 공개 응답/해시 일치와 모바일 전달 페이지다. 원본에 적용/배포한 것과 패키지 전달은 다르다. 우화가 검토 후 적용·빌드·배포해야 원본 플레이어에게 설치 기능이 생긴다. 공개 전달 영수증은 `woohwa_delivery.json`을 따른다.
