## 4. 열린 질문 · 상대에게 묻는 것
- 정정(10/6 남김말 답 3): "빈손은 물리(두 손 모두 자루 관절)와 겉모습만" 은 정확하지 않았다 — 우리 빈손도 `fighter.offHand` 의 두 점 사이 ±F 스프링(아래팔 끝 ↔ 자루 점, 작용·반작용 쌍, 장부의 'offhand' 선언 힘)으로 당긴다. 관절이 아니라 힘쌍이다.
- 샛별에게(검토 문서 §8 그대로, 번호는 그쪽 실험 이름 기준):
  1. `zero_motor_probe`·`upright_motor_candidate` 의 generic 관절은 어느 axis 로 만들었고 raw 축 3·4·5 가 세계 어느 축에 닿는지 확인했는가(우리 측정: generic(axis x) 에서 4 = z, 5 = y).

  3. 재빌드 엔진 0.19.2 와 npm 0.19.3 의 바이트 동등은 8쌍 exact 로만 확인됐는데, enabled bit 결과(1.5 vs 1.08333)를 npm 쪽 '관절 제거' 와 같은 handle·같은 fixture 로 대조한 행이 있는지.
  4. `GAIT.stanceMemory 'fresh'` 를 일반 기본값으로 올릴 계획이 있는지, 올릴 때 기준 trace 해시를 어떻게 갱신하는지(우리는 fights12·live_battery sha 가 바뀌어 사장님 결정 사항, 확인표 163).

  7. `native_motor_api_round1` fixture 의 configureMotor(0,0,0,0) 뒤 1.08333 rad/s 는 한 스텝 값인지 구간 끝 값인지, cap 5 의 힘 한도가 없을 때도 같은 비(72 %)가 나오는지.
