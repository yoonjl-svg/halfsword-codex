# 사람용 짧은 확인

[연습 페이지](https://yoonjl-svg.github.io/halfsword-codex/encounters/attack-balance-20261101/)에서 기술 하나를 고릅니다. 본판 저장과 연구 저장은 분리돼 있습니다. 설치/오프라인 워커도 사용하지 않습니다.

1. `단발 조건 연습`에서 `조건 준비`를 누른 뒤 `기록 시작`을 누릅니다. 화면의 조건 설명과 부족조건을 보고 원래 이동/막기/칼 입력으로 시도합니다. 준비 버튼은 거리/시작 자세를 준비할 뿐 기술을 강제로 실행하지 않습니다.
2. 기술이 나갔는지, 겨눈 곳에 닿았는지, 받은 피해를 감수할 가치가 있었는지 짧게 확인합니다. 횟수를 채울 필요는 없습니다. 자동 동작은 내가 원하지 않을 때도 나가는지 살펴봅니다.
3. `기록 끝`과 `JSON 받기`로 원본을 보관할 수 있습니다. 자동 업로드하지 않습니다.
4. `자연30초`는 준비 기능 없이 원래 전투에서 봅니다. 실제 일시정지 시간은 빼고, 먼저 패배하면 실제 종료 시간을 남깁니다.

기록에는 누름/이동/칼 입력, 요청과 실제 동작, 접촉·양측 상태·기력과 시간이 들어갑니다. 누름 수가 공격 횟수나 성공률은 아닙니다. 기회가 없었던 시도와 입력이 거절된 시도도 구별해 봅니다. 사람이 느끼는 가치와 손맛은 이 자동 기록만으로 확정할 수 없습니다.
