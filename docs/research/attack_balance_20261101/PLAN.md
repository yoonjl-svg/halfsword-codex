# 유파 공격 밸런스 시험 계획 · 2026-11-01

기준은 생사전 병합 본판 `88a96061e8dd93e8f107b7b0df647a341e73fa5d`이다. 사용자가 별도 에이전트와 병행 연구를 요청했다. 현재는 코드 조사와 시험 설계만 완료했으며 아래 숫자는 앞으로 실행할 시험 수다. 측정 결과나 밸런스 변경으로 보고하지 않는다.

## 대상과 현재 규칙

실제 공격 비교는 무유파를 제외한 5유파, **비기5 + 특수5 + 일반 고유9 = 19계열**이다. 격살의 네 받은 자세에 따른 결과처럼 한 계열 안에 다른 동작이 있으면 하위 시나리오로 나눈다. 개별 이름·해금·발동 조건·구현·기존 도구의 한계는 [확인된 코드 조사](source-audit.md)에 고정 SHA 링크와 함께 보존했다.

| 유파 | 비기 | 특수 공격 | 일반 고유 공격 |
|---|---|---|---|
| 독일 | 죽음의 일격(모르트슐라크) | 겹치기 | 실하우, 비껴 딛는 가로베기 |
| 이탈리아 | 안다레 리솔루토 | 비껴서며 찌르기(인콰르타타) | 내려 찌르기(임브로카타), 칼끝 돌려 빼기(카바치오네) |
| 이베리아 | 싱지르 | 정수리 가르기(알티바슈 포르트) | 나선 걸음 베기 |
| 일본 | 고노센 | 제비 베기 | 비껴 베기, 손목 치기(코테) |
| 동방 | 격살 | 날개 접기(염시) | 허리 베기(요격), 끌어 딛고 허리 베기(체보요격) |

사람 비기는 기본 판당1회, 동방3회이며 현재 기력>0 조건이 있다. 특수5종은 동작과 해제 뒤 실제3초 식힘이 있다. 일반 고유9종에는 이 특수 식힘이 없다. 사람 겹치기는 현재 맞댐 누적 뒤 자동 발동이다. 이탈리아·동방 AI 비기가 닫혀 있으므로 AI 미발동을 사람 비기의 약함으로 집계하지 않는다. 속도 몫은 피해 배율로 해석하지 않는다.

## 0. 기록부와 독일3종 파일럿

먼저 죽음의 일격·겹치기·실하우의 실제 조건→입력→발동→접촉→양측 결과를 각각 확인한다. import와 기술 ID, 현재 기본 조건, 해금, 판당 제한, 특수 식힘 시작, 사람용 기력 규칙, 시계, 기록 전후 동일성을 검증한다. 같은 공격을 매 스텝 여러 번 세거나 수락된 요청만으로 실제 실행을 셌다면 이후 수치는 버린다.

현재 `special_balance.mjs` 등은 조건/분류가 옛 버전이며, 일부 `unique_study_*`는 사라진 모듈을 참조한다. 오래된 도구 전체를 복구하지 않고 필요한 공통 기록부와 최신 입력 운전만 작게 정상화한다. 상대 상처·넘어짐을 막는 옛 drill 모드는 실제 위력 시험에 사용하지 않는다. 기술을 직접 호출하는 시험은 경로/잠재 위력 확인용으로 표시하고 조작성·자연 빈도와 분리한다.

파일럿에서 새 몸 생성·조건 준비·실행·회수·기록에 드는 시간을 실제로 재서 전체 일정과 동시 실행 수를 정한다. 첫 중간 보고 목표는30~45분이지만 전체 연구를 그 안에 끝낸다고 확약하지 않는다.

## 1. 한 번의 공격 위력과 교환

기술마다 같은 유파·같은 무기·같은 입력에서 기술 보정을 켠 판과 끈 판을 짝으로 비교한다. 대조군은 실험용 효과 분해이며 정상 육성 상태로 부르지 않는다. 서로 다른 한손/양손 몸꼴을 유지하기 위해 한 무기를 모든 유파에 강제로 쓰지 않는다. 대표 무기는 롱소드·레이피어·츠바이핸더·우치가타나·환도를 출발점으로 하되 실제 기술 호환성을 파일럿에서 확인한다.

**초기 최소량: 19계열 × 가까움/보통/사거리 끝3조건 × 입력/시드6개 × 켬/끔2 =684개 새 몸 시험(342쌍).** 거리는 기술별 정상 조건과 실제 도달 범위를 기준으로 정하고 기록한다. 기회 준비 실패도 결과로 남기며 성공할 때까지 교체하지 않는다. 격살4갈래와 실하우·코테·요격·카바치오네의 심화 효과 등은 별도 하위 행으로 추가한다. 여섯 시드의 탐색으로 작은 확률 차이를 확정하지 않는다.

같은 상대 몸·방어구·기력·숙련·자세·출발 상태에서 시작하고, 준비부터 회수까지 실제 상처를 적용한다. 방어구·상대 무기·서로 다른 자세를 동시에 바꾸지 않고 후속 민감도 시험으로 하나씩 확장한다. 완성형 키트 성능은 아래 자연판에서 별도로 본다.

- 나와 상대 각각의 상처 심각도·출혈·의식 손실·사지 기능 손실, 맞은 부위, 방어구에 막힘.
- 사망·기절·일시 넘어짐·무장 상실을 각각 기록. 즉사와 지연 사망도 구분.
- 준비 시작→실제 몸 접촉, 동작 종료→손/발 제어 복구, 준비·회수 중 받은 피해.
- 지출 기력, 최저점, 탈진, 다음 행동에 필요한 회복 시간. 준비·접근 비용도 포함.
- 발동 후1초·5초의 양측 피해와 교환. 드문 비기를 판 전체 승패 하나로 평가하지 않음.

에너지는 원인 진단용이다. 최고 칼끝 속도나 단순 에너지 배율을 실제 피해/치명률로 바꾸지 않는다. 실제 상처와 생리 상태 변화가 결과다. 공격 자체에 새 시간 상한을 넣지 않는다.

## 2. 실제 입력 경로의 발동 여유

현재 게임의 터치·조이스틱·키·마우스 경로를 통과하는 입력 운전기를 만든다. 창의 참값을 보고 정확히 한 번 입력하는 상한 시험과, 실제 화면 단서에 반응하는 운전기를 구분한다. 강제 `Skill.secret()` 호출을 이 단계에 사용하지 않는다.

**초기량: 19계열 × 정확/작은흔들림/큰흔들림3묶음 × 입력시드8개 =456회.** 기술에 맞춰 시점 지연, 긋는 방향/길이, 원 입력의 끊김, 스틱·탭 동시성, 손 떼는 시점을 변화시킨다. 기술에 없는 타이밍 제한을 새로 가정하지 않는다. 흔들림 크기는 실험 설정과 원본 궤적에 남기며 사람 입력 기록이 생기면 그 분포로 보완한다.

이 결과의 명칭은 **자동 입력의 발동 내성**이다. 실제 인간 성공률로 보고하지 않는다. 자동 겹치기는 맞댐 유지를 만드는 난이도·원치 않는 발동·후속 위치를, 자동 격살은 막기/전진 시도와 받은 피해를 함께 본다. 추가 탭이 없다고 입력 노력이0이라고 보지 않는다.

사람에게는 기술별 조건 연습·현재 입력 설명·기록 다운로드가 있는 시험 링크를 제공한다. 사용자에게76회 같은 대규모 수동 입력을 선행 조건으로 요구하지 않는다. 원하시는 기술을 짧게 직접 시험한 결과를 별도 사람 기록으로 받으며, 봇 내성과 손맛 판단을 합산하지 않는다.

## 3. 30초 동안의 기회와 실제 사용 횟수

사람과 같은 규칙의 입력 운전기로 자연 선택과 기술 노림을 나눈다. **5유파 × 두운전방식 × 압박형/거리유지형 상대2종 × 시드6개 =120판**이 최초 탐색안이다. 모든19종 이벤트를 기록한다. 이는 봇으로 추정하는 빈도이며 실제 인간의 판당 빈도와 구별한다. 실제 사람 플레이 기록이 생기면 별도 층으로 추가한다. 후보의 인과 이득은 기술 켬/끔 짝 실험으로 확대 검증한다.

정상 해금·보조 효과를 갖춘 완성형 키트와 대표 무기를 사용한다. 기술을 직접 강제 호출하거나 비기 횟수 제한을 풀지 않는다. 자연 운전과 노림 운전은 다른 실력/초능력 시야가 아니라 같은 관찰·반응 조건에서 우선순위만 다르게 한다. 기회를 만들려고 공격·이동·막기를 한 비용과 포기한 보통 공격도 포함한다.

판마다 다음을 독립 에피소드로 센다:

`사용 가능 → 조건 기회 → 의도된 입력 시도 → 요청 수락 → 실제 발동 → 칼/몸 접촉 → 유효 상처·의식/사지 손실`

조건 부족·식힘·비기 소진·기력 부족·입력 오인·다른 기술 우선·막힘·사거리·취소를 실패 사유로 남긴다. 동일 접촉을 여러 프레임에 걸쳐 여러 기회로 세지 않는다. 내 명령으로 조건을 만드는 공격과 외부 공격을 기다리는 반응형 공격의 기회 분모를 같다고 취급하지 않는다.

사람 판은 활성 벽시계30초, 헤드리스 판은 `TIME.k`를 반영한 기준30초로 명시한다. 메뉴/백그라운드 정지와 실제 전투 연출을 구분하고 벽시계·물리 시간·기준 시간을 모두 기록한다. 일찍 죽으면 실제 종료 시각을 남기며 사망 뒤 시간을 가짜 미발동으로 채우지 않는다. 판당 횟수와 생존 시간당 빈도를 함께 낸다.

## 4. 후보 확대와 보고

전체19종을 같은 지표로 먼저 훑는다. 이후 강점/약점이 큰 후보부터 시드20~30개, 다른 상대 자세·방어구·길이/질량·기력 경계·좌우 자리로 하나씩 확대한다. 한 번 세게 맞힌 결과나 작은 확률 차이로 바로 패치하지 않는다. 시드/입력 기록을 공유한 짝 차이, 원수, 관측 범위와 충분한 표본에서의 구간을 제시한다. 완전히 같은 결정론적 재실행은 독립 표본으로 세지 않는다.

최종 표는 **단발 양측 결과 / 준비·회수 / 기회·시도·발동·적중 / 판당 빈도와 제한 / 비용·탈진 / 조작 내성·실제 사람 의견 / 상대·장비 민감도**를 나란히 둔다. 원시 JSONL은 빌드·시드·장비·해금·부위·시간·실패 사유와 입력 궤적을 재현할 수 있게 저장한다. 미측정·해당없음은0이 아니라 null이다.

판정은 **우세·열세·장단점 상충·발동/표시 문제·특정 상대/장비 한정·표본 부족**으로 한다. 자신도 맞았다는 이유만으로 기각하지 않으며 더 큰 유효 피해와 반격 기회를 주면 공격적 교환의 이득으로 검토한다. 치명적이지만 드문 기술은 피해를 먼저 올리지 않고 기회·조작·자원 어디에서 막히는지 찾는다. 낮은 빈도만으로 유파의 개성을 없애거나 모든 공격을 같은 위력으로 만들지 않는다.

첫 결과는19종 현황표·원본 자료·재현 명령·시험 링크·문제 후보와 근거로 제출한다. 임의 가중치로 한 점수에 합치거나 표본 부족인 기술까지1~19위로 억지 정렬하지 않는다. 밸런스 수치 변경은 그 결과에 근거한 다음 단계다.
