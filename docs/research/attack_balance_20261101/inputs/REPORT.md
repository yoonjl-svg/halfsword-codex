## 파일럿에서 확인한 기록상 주의점

- 모르트슐라크는 기본2초 가까움→정상 창→실제 톡→요청 수락→secret/iai 동작→둔타 접촉을 확인했다. 작은흔들림 보완의 상대 `causeOfDeath`는 **기절**이고 `state`는 `dead`, 의식은 약−0.219다. 엔진의 dead 상태명을 생리적 사망으로 바꾸어 쓰지 않는다. 비기1회 소진·비기 기력35 지출을 확인했다. 상처 severity0/wounds없음과 의식 손실은 동시에 발생할 수 있다.
- 초기 가시 렌더의 모르트슐라크는 창까지 정상 열렸으나 의도45ms 탭이 CDP/소프트웨어GL 지연으로 실제 약518ms가 되어 탭 입력에서 탈락했다. 이를 비기 약함으로 세지 않았다. 운전기는 이후 송신 시각이 렌더 응답을 기다리며 늘어나지 않게 사건을 순서대로 큐에 넣고 실제 전달 시각도 기록한다.
- 자동겹치기는 실제 준비 긋기→맞댐 유지 뒤 자동 발동을 관측했다. 별도 목표판이 실패해도 다른 기술 뒤에는 나왔으며, 같은 판에서 식힘 후2회 나온 파일럿도 있다. 준비 긋기·맞댐을 유지한 시간과 칼/스틱 입력을 노력에서 제외하지 않는다. 원치 않은 후속 자동발동도 다른 기술의 피해로 합산하지 않는다.
- 가시/초기 렌더 파일럿의 연속 가로긋기에서 게임 자체가 두 새 긋기 객체로 읽은 경우가 있었다. 최종 probe는 실제 cur/동작 객체별 `episodeId`와 onset 요청을 적어 프레임 중복과 분리한다. 하나의 DOM 손짓이 두 게임 에피소드로 읽히는 현상도 원본에서 지우지 않는다.
- 초기 probe는 ordinary tap의 `motion_start.technique`에 해당 유파 비기명을 fallback할 여지가 있었다. 최종 probe에서 이 fallback을 secret channel에만 제한했다. 아래 발동 판정은 ordinary tap 이름을 쓰지 않고 실제 secret 요청/새 sec/burst 또는 unique 이름과 새 동작을 함께 확인했다. [소스 스냅샷](source-snapshot/)을 보존했다.

## 한계와 미측정

- Chromium/헤드리스·조건 참값을 보는 운전이다. 실제 폰 Safari/Android 장치, 촉각, 사람 손맛·성공률, 화면 단서 반응 운전은 미측정이다.
- 조건 연습은 거리와 시작 자세를 준비하고 일부 상대 AI를 정지시킨다. 자연 전투 빈도로 쓰지 않는다. 19종을 한 상대 하인리히/자기 무기와 한 초기 시드에서 훑은 자료다. 상대·장비·방향 민감도를 일반화하지 않는다.
- 원본 callback은 최소 에너지 판정을 통과한 접촉이다. 문턱 아래 기하 접촉 전체를 측정하지 않았다. 물리 중간 phase는 rAF 관측 사이에 지나갈 수 있으므로 요청과 동작 객체·원본 몸 결과를 함께 본다.
- 자동 검증의 `FAST_GEOMETRY=1`은 scene 가시성만 잠시 끄고 물리·실제 Input 경로를 유지한 true-state 상한 운전이다. PNG 전에 렌더를 복원했다. 소프트웨어 렌더 부하와 송신/전달 시각 차이도 원본에 남아 있다.
- 별도 clock 검사와 빌드·검증 명령은 재현 README 및 clock JSON을 참조한다. 상처·의식·다리 기능·무장·기력·소진을 하나의 점수로 합치지 않았다.

## 자연 모드 시계 확인

자연 모드에서 키보드 후퇴 운전과 후퇴+막기 운전을 각각 확인했다. 약2.2초의 실제 일시정지 동안 활성 벽시계와 물리 시간은 모두 증가0이었다. 두 판은 플레이어가 각각 활성27.066초·28.315초에 패배해 조기 종료됐고, 사망 뒤를30초까지 가짜 미발동으로 채우지 않았다. 자연 모드의 조건 준비는 거절됐다. 이 두 판에서는 정확히30초 한도에 도달하는 분기와 백그라운드 전환을 직접 관측하지 못했다. [후퇴 원본](clock-retreat.json.gz), [후퇴+막기 원본](clock-guard.json.gz).

연구 패널은 입력 시도(누름)·기술 요청·실제 실행 확인·양측 접촉 결과를 따로 보여 준다. 현재 부족조건도 거리·칼 맞댐 누적·비기 소진·기력·특수 식힘·내 베기 중 접촉 제외·이른/지난 탭 기회·스틱 방향 등 관측 가능한 항목으로 표시한다. 상대 반응 조건을 만들지 못한 경우에는 조건 대기로 표시한다.
