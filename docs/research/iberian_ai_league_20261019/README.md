# 이베리아 AI 대련: 탈류·레베스 대 바깥 밀어내기

사용자 최신 정정대로 **두 쪽 모두 추가 힘 감소·제어력 감소 혜택 없이** 동작 자체를 비교했다. 기존안이 1패 적지만, 이 짧은 시험에서 새 동작의 우위를 입증하지 못했다. 발동 표본이 너무 작아 일반적인 우열 확정은 불가하다.

## 방법

- 본 비교 144판: 다섯 유파 120판 + 무유파 철퇴 24판. 방식마다 72판, 각 상대 12판.
- 실제 AI 대 실제 AI. 보통 난이도·숙련도 5, 공격/방어/이동 모두 기존 AI 판단. 스크립트 플레이어나 가만히 서 있는 과녁이 아니다.
- 시험자 무기 츠바이핸더/플랑베르주 × 씨앗 3101~3103 × 두 시작 자리. 상대 무기 롱소드/레이피어/츠바이핸더/우치가타나/청강검, 보조 모르겐슈테른. 같은 외형과 방어구·시작 간격 2.6 m·벽.
- 각 30초 또는 한쪽 패배까지. 30초 무결판은 무승부, 임의 HP 점수로 승자를 정하지 않았다. 유파 대표 무기 조합이며 모든 캐릭터·무기·숙련도의 전수시험은 아니다.
- 원래 탈류/레베스는 기존 AI 몸꼴을 유지한다. 바깥 밀어내기는 기존 outward24를 AI가 이미 선택한 방어에만 붙인다. 실제 칼 접촉, highL/highR, 몸 바깥 방향 조건은 양군 관찰 기준이 같다. 모터/추가 충격/기력 페널티 어댑터를 설치하지 않았다.
- 기존 일본 흘림 등 본판 효과는 양쪽 실험에서 그대로 유지. 원본 엔진 63ec5864 및 연구 기반 4b6cb953. 사전 계획 커밋 d51fec16. 이번 변경은 tools/docs만.

## 피해·발동

다섯 유파의 각 짝에서 먼저 끝난 시점까지 같은 시간만 비교했다. 사지 기능 손실·의식 손실·추가 출혈률은 서로 다른 단위이며 합산 HP가 아니다.

| 공통 노출 시간 피해 | 기존 | 밀어내기 | 변화 |
|---|---:|---:|---:|
| 받은 사지 기능 손실 | 23.9088 | 24.0548 | +0.6% |
| 받은 의식 손실 | 12.7975 | 13.7418 | +7.4% |
| 받은 추가 출혈률 | 5.4630 | 5.5498 | +1.6% |
| 준 사지 기능 손실 | 18.9537 | 18.3322 | -3.3% |
| 준 의식 손실 | 12.8498 | 12.0934 | -5.9% |
| 준 추가 출혈률 | 2.1725 | 2.2081 | +1.6% |

- 72짝 중 발동은 3짝뿐(다섯 유파 기준 3/60). 나머지 69짝은 건강·지속시간이 정확히 동일했다. 144판이 있어도 동작 효과에 관한 독립 관측이 풍부한 것은 아니다.
- 독일 상대 case 11: 발동 26.5917초, 두 방식 모두 약29.37초 승리. 자기 피해 동일.
- 이베리아 상대 case 26: 두 방식 모두 30초 무승부. 밀어내기는 자기 사지 손실은 줄었으나 의식 손실·출혈은 늘어 혼합 결과.
- 일본 상대 case 38: 5.4667초 발동. 기존은 30초 생존·무승부, 밀어내기는 19.45초 출혈 패배. 밀어내기에서 발동 뒤 +1.225초 가슴 베임, +2.775초 목 베임이 새로 생겼다. 추가 패배는 즉시 기절이 아니다. 이후 궤적·AI 판단이 갈라진 한 사례이며 모든 일본 공격에 취약하다는 결론은 금지.
- 첫 발동 후 최대5초 공통 구간은 3짝, 완전5초는 2짝(독일 상대는 먼저 결판). 사지 손실 0.8010→0.7567, 의식 손실0.2714→0.3051, 추가 출혈률0.01373→0.09205. 역시 표본3개로 일반화하지 않는다.
- 재생에서 실제 쓸기 21프레임(약0.175초)을 세 사례 모두 확인. case38은 받침3프레임 뒤 끝나 회수 단계가 없었다. AI가 방어를 유지할 때만 동작이 실행되는 설계이므로, AI 판단과 동작 지속의 연결은 후속 조사 대상이다. 이 사실만으로 패배 원인을 확정하지 않는다.

## 검증·판단

- 양군 72짝 전부 첫 발동 시각과 발동 전 물리 해시 동일. 실험 힘/제어 효과 0, 어깨 비틀기 축소 프레임0.
- 최초 관찰 무간섭 검사 2회 + 발동3짝의 원래 AI/기존 관찰/새 동작 총9재생. 원래 AI와 기존 관찰 결과 정확히 같고, 새 동작도 원자료 정확 재현. 따라서 단순 미설치·미작동으로 같은 결과가 나온 것은 아니다.
- 실제 본 비교 실행은 100.871초. 사용자 요청부터 분석·보고까지10분 이내를 목표로 했고, 실행/분석 원자료·실패 없는 검증을 보존했다.
- **현재 일반 AI에 붙여 놓는 것만으로 밀어내기가 더 강해진다는 근거는 없다.** 작은 차이는 기존안 쪽. 기존안보다 확실히 약하다는 결론 역시 3발동으로 내리지 않는다.
- 인간 입력 연구를 대체하지 않는다. 일반 게임/기존 테스트 링크/우화 원본·메시지 변경 없음. 정식 채택하지 않음.

## 후속: 기존 탈류·레베스 사용 빈도

사용자 질문에 따라 기존 72판만 읽기 전용 관찰로 재생했다. 72판 모두 건강/피해/승패/시간/무기 파손/AI 모드/공격수/최초 발동·물리해시가 원자료와 정확히 일치했다. 판을 추가로 선정한 별도 승률 표본이 아니다.

다섯 유파 60판에서 실제 자세 적용은 **13회(탈류8·레베스5), 사용한 판11판(18.3%), 판당0.2167회**. 방어 선택 시점과 실제 몸꼴 적용 구간의 횟수가 같았다. 한 자세를 유지하는 동안은1회, 중간에 풀거나 좌우 자세를 바꾸면 새1회로 센다. 몸꼴 적용은 기존 cover 소유·혼합가중치0.15 초과 기준이며 물리적으로 완벽히 목표 자세에 도달했음을 뜻하지는 않는다.

그 자세를 실제 방어로 유지하며 칼이 새로 맞닿은 것은 **7회, 4판**이었다. 방어를 푸는 중 남은 몸꼴까지 포함하면10회·5판이다. 접촉은 깨끗한 막기 성공/상처 예방/칼을 바깥으로 쳐냄을 보장하지 않는다.

무유파 포함72판: 자세16회(탈류11·레베스5), 사용14판, 판당0.2222회. 방어 중 접촉은 동일7회.

밀어내기3회는 이 기존 방어 자세에 붙이는 후속 동작의 좁은 조건 통과 횟수다. **기존 자세13회와 밀어내기3회를 같은 단계의 성공률로 나누어 비교하지 않는다.** 기존도 사용 빈도가 낮았으며, 밀어내기는 실제 접촉·바깥 방향·방어 유지 등 조건으로 한 번 더 제한된다. 이번 계측으로 특정 제한 하나가 주원인이라고 확정하지 않았다.

원자료 native-usage-0/1.json.gz, 집계 native-usage-summary.json. 재현: `SHARD=0` 및 `SHARD=1 node tools/sim/iberian_native_usage.mjs`, 그 뒤 `python3 tools/sim/iberian_native_usage_summary.py`. 기존 승패 결과와 공개 게임 변경 없음.
