## 3. 초기 약한 충격과 복귀 보정 비교 이력

초기에는 완성된 몸꼴·몸 쪽으로 들어오는 칼만 허용했다. 24조건 중 발동1조건으로 지나치게 드물었다. 쳐내기는 상대 칼 옆면을 때리는 접촉도 포함하므로, 실제 상대 칼 움직임+접근 충돌을 보되 몸꼴 전환 중도 허용했다. 이 경우 같은24조건에서 발동4조건이었다. 준비 동작을 완벽하게 구별하는 판정으로 확정한 것은 아니다.

28°는 눈에 더 보였지만30초 표본의 치명 피해가 늘었다. 40°는 한 입력 조건에서 새 베임도 만들었다. 따라서 강하게 할수록 좋은 방식으로 판단하지 않는다.

칼 접촉0.25초 뒤 긋기로 전환하는 별도12조건도 비교했다. 방어자 손상은 같았고 상대 베임 조건은 기존5/12→초기16°3/12→직접충격6의5/12, 상대 기능 손실 합0.119→0.004→0.507. 초기16°가 반격을 돕는다고 단정할 수 없고, 직접충격6은 이 반격 대본에서는 손상 증가 신호가 있다. 이 대본은 공격자의 다음 전술 판단을 재현하지 않으므로 실제 반격 성공률로 일반화하지 않는다.

따라서 **첫 인간 시험은 직접 충격6으로 추천을 갱신한다.** 16° 목표 보정은 기본값에서 빼고 비교 이력으로 보존한다.

- 인간의 이득: 기존 버튼과 입력으로 접촉한 칼을 밖으로 젖히는 효과. 직접충격6의 작은 표본에서 치명 피해/출혈/막기 지출 개선 신호.
- 인간의 손해: 방어자도 반작용을 받음. 직접충격6의 독립 표본에서는 의식 손상이 증가. 잘못된 방향/접촉 상황을 모두 해결하지 못함.
- 30초 종합: **직접충격 최대6N·s를 사람에게 시험할 후보**로 추천. 확정 채택/최적 밸런스 선언은 보류.
- 발동 빈도 자체를 크게 넓힌 연구가 아니다. 현재 자세가 닿지 못하는 공격에는 작동하지 않는다. 이베리아의 평균적 방어 + 쳐내기 특성을 유지한다.
- 실제로 반격을 넣기 충분한지, 사람의 공격을 부당하게 빼앗는지, 복귀 보정이 자연스럽게 느껴지는지는 인간 검증이 남았다. 이 부분을 자동 입력 시험으로 대신했다고 하지 않는다.

## 6. 코드·재현·보존

- `src/iberian_beat.js`: 연구 모듈, `installIberianBeat(combat)` 호출 시에만 설치. 일반 게임은 호출하지 않음.
- `src/combat.js`: 실제 강철 접촉을 전달하는 선택형 hook1곳.
- `src/fighter.js`: 선택형 팔 힘/목표 보정 hook. 최신 추천값의 두 옵션은 모두0. 기각된 후보 재현용 옵션은 보존.
- 최신 직접충격안만 향후 게임에 이식한다면 `combat.js` 접촉 hook+`iberian_beat.js`+새 판에서의 명시적 설치만 필요하다. `fighter.js`의 목표/팔 힘 hook은 초기 후보 재현용이며 직접충격안의 필수 의존이 아니다.
- `tools/sim/iberian_beat_probe.mjs`, `iberian_beat_live.mjs`, `iberian_health.mjs`: 입력/전투 실험과 실제 피해 계측.
- `raw/`: 원자료 전체. gain0의 `beats`는 **적격 접촉 진단**이며 실제 추가 충격0. 후보의 발동 횟수와 구별한다.
- `summary.json`: 원자료 집계. `flows/postFlow`는 과거 일본 하니스의 잔여 계측으로 이번 결론에 사용하지 않음.
- `replay/paired.json`: 같은 접촉의 실제 강체 변환. `tools/browser/iberian_replay.html`은 이를 게임 캐릭터 모델로 재생. 원 게임 스테이지 촬영이나 인간 플레이 영상으로 표시하지 않음.
