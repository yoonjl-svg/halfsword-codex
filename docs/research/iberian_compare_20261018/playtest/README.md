- 내 방어=츠바이핸더/상대 롱소드. 내가 공격=롱소드/상대 츠바이핸더. 포세이돈 무대, 유파 책1·2급. 비기로 차이가 가려지지 않게 플레이어 비기를 잠근다.
- 반복 공격은 기존 AI에 zornhau 시작을 약2초 주기로 요청한다. 준비·타격·회수 경로·공격 비용·실제 접촉 조건을 유지한다. 실제 발동을 강제로 만들거나 무적으로 바꾸지 않는다.
- 공격자 반복 연습의 상대는 실제 `PlayerParryGuard`를 계속 누르는 방식으로 방어한다. 일반 AI의 낮은 발동 빈도 때문에 손맛 비교용으로 분리한 대본이며 보통 대련은 원래 AI로 돌아간다. 일반 AI 전투 개선의 증거로 쓰지 않는다.
- 화면의 ‘추가 효과 나:상대’ 횟수가 실제 양의 충격 발생이다. 기존군은0. 단순 칼 소리나 접촉마다 특성이 발동했다고 오인하지 않게 한다.
- 마우스/터치/키보드는 실제 게임 입력을 쓴다. 기존 저장·로그인을 읽거나 쓰지 않도록 local/sessionStorage를 탭 메모리로 격리했다. 자체 PWA등록/manifest를 제거했고 원래 게임의 precache에서 encounters가 제외된다.
