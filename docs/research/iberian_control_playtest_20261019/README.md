## 이번 결과

최신 확인 기준 `54af75f4` 위에 독립 시험판을 제작했다. 모두 같은 outward24 동작이며 **쓸기만 / 상대 잔여 제어10% 0.12초 / 10% 0.60초** 세 조건이다. 두 페널티 모두 뒤에0.24초 smoothstep 복구가 붙어 총0.36초 / 0.84초다. 동작의0.18초 쓸기·0.10초 받침·0.20초 회수는 바꾸지 않는다. 사용자 입력/이동을 잠그거나 추가 충격을 주지 않는다.

‘처음 더 세게 튕김’보다 **상대가 칼을 되돌릴 때 제어가 약한 상태가 오래 남는 느낌**이 예상된다. 이것은 물리 관찰에 근거한 가설이며 인간 손맛 검증을 완료했다는 뜻이 아니다. 과도하게 칼이 말을 듣지 않는 불편함으로 느껴지는지도 공격자 역할에서 확인해야 한다.

## 궤적 관찰

이전 최신판 확인 실험의 첫 발동5조건을 재분석했다(새 대량 대전 없음). 발동 전 상태 해시가 짝마다 같다. 두 조건의 검 방향 차이 중앙값은 발동0.1초 뒤0°,0.36초 뒤9.5°,0.5초 뒤24.3°,0.6초 뒤35.2°. 첫 충돌 뒤에 차이가 벌어진다. **이 값은 서로 다른 궤적 사이의 차이이지, 바깥으로 더 튕긴 각도·반격 여유·입력 지연을 뜻하지 않는다.** 원자료/재현: `paired-motion.json`, `tools/sim/iberian_control_motion.py`.

5초/30초 피해 결론은 [기존 재분석](../iberian_control_duration_20261018/WINDOWS5.md)을 유지한다. 긴 안은 짧은 안보다 첫5초 사지 손실이약80% 적었지만, 최대30초는 의식+10.5%·출혈+8.5%였고 패배2→2. 따라서 장기 종합 상향/정식 채택을 확정하지 않는다.

- 844×390 터치 화면: 세 조건 설정값, 양 역할 무기/학교, 반복연습/보통대련, 재시작, 정지, 가로 넘침 없음, 기존 저장격리, PWA등록 제외 확인.
- 수비자: 실제 쓸기1회 → 상대10% 총0.84초 → 정상복구 확인.
- 공격자: 실제 마우스 베기로 상대쓸기1회 → 내 팔10% 확인. 실제터치 막기/해제·베기 드래그 확인.
- 브라우저 오류/404 없음. `browser-smoke.json`, `touch-and-attacker.json`, 실제화면4PNG 보존.
- 자동 입력 검증이며 인간 직접 플레이/주관적 손맛 평가는 아직이다. 반복연습은 상대가 기존 성난 베기를 반복하거나 실제 플레이어 막기를 유지하는 드릴이고, 보통대련은 기존AI결정을 유지한다.
- 페널티는 유리한 방향의 실제접촉으로 **바깥 쓸기가 시작될 때** 부여한다. 별도의 ‘완료된 쳐내기 성공’ 판정을 추가한 것은 아니다. 같은 공격 중복/효과 연장 금지 규칙은 원 연구 어댑터와 같다.

## 사람 비교 순서

1. 상단에서 쓸기만 →10%0.12초 →10%0.60초를 바꿔 같은 조건으로 재시작한다.
2. 수비자: 쓸기 횟수가 올라간 직후 막기를 놓고 베거나 찌르기. 칼 복귀 전 공격의 여유/안전감 확인.
3. 공격자: 상대가 쓸어낸 직후 반대쪽으로 베거나 칼 되돌리기. 제어 상실이 자연스러운지, 답답하게 잠긴 느낌인지 확인.
4. 쓸기 횟수0인 구간의 차이를 이 효과로 판단하지 않는다. UI의 팔%로 실제 발동을 확인할 수 있다.
