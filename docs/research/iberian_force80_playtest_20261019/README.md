# 바깥 밀어내기 — 80% 감소, 0.60초 유지 + 0.40초 복구

사용자가 이 조합의 가능성을 우화에게 전달하고 직접 양쪽 입장에서 시험할 링크를 요청했다. **단기 이득과 손맛 차이가 생길 여지가 있는 후보**이며, 이 정확한 수치의 5초/30초 전투 우위나 인간 손맛을 입증한 결과는 아직 없다.

## 수치와 비교 조건

|조건|남는 힘 상한|유지|복구|총 지속|
|---|---:|---:|---:|---:|
|쓸기만|100%|—|—|—|
|이전 −75%|25%|0.60초|0.24초|0.84초|
|새 안 −80%|20%|0.60초|0.40초|1.00초|

모두 같은 바깥 밀어내기(outward24), 실제 접촉·몸 바깥 방향 조건을 쓴다. 손길은 0.18초 쓸기 + 0.10초 받침 + 0.20초 복구 그대로. 상대 힘 상한의 복구는 smoothstep 곡선이며 발동 후 0.60초에20%, 0.80초에60%, 1.00초에100%. 별도 추가 충격·기력 비용·피해 보정은 없다. 같은 공격의 중복 발동/효과 연장 금지, 종료 후0.12초 여유. 실제 쓸기가 시작되는 접촉에서 효과를 붙이며, 완성된 쳐내기 성공을 따로 판정하는 것은 아니다.

정확한 변경은 두 팔 관절의 `max`와 손목 `maxAimTorque`뿐. 입력/추종k·d/속도 설정은 유지한다. 감쇠·중력보상·양손 그립 등은 기존 경로이므로 모든 물리적 팔힘이 정확히20%가 된다는 뜻은 아니다. [힘 상한 원연구](../iberian_force_cap_20261019/README.md).

## 근거와 한계

앞선120전은75% 감소·0.60초 유지·0.24초 복구의 첫5초 수비 사지손실−30.8%, 의식손실−51.3%, 추가출혈−20.5%를 보였다. 그러나30초 사지손실+9.9%, 의식−21.2%, 추가출혈+12.0%, 패배4→4이고 새12조건에서는 이득이 일관되지 않았다. 큰 손실 한 사례·관측창에 민감하다. 이 숫자를 새80%안의 성적으로 옮겨 쓰지 않는다. 전체 자료와 실패·민감도는 원연구에 보존했다.

새 안은 더 약한 상한과 긴 복구로 칼을 되돌리기 어려운 차이를 느낄 가능성을 높인다. 동시에 제동 약화로 생기는 후속 궤적/피격 위험도 커질 수 있다. 우선 공격자·수비자의 인간 체감을 확인한다. 1초는 안전한 반격 보장 시간이 아니다.

## 최신 본판 호환성

수신 본판 `63ec58647c677e44d5ba6a7429cb40b5e957964d`에 먼저 병합했다. 이름/설명 방침 업데이트를 보존했고 `src`는 수신판과 동일하다. 기술 열쇠 zornhau, PlayerParryGuard와 cover/feel 접촉, 관절·손목 상한 연결을 유지한다. 새 세 비교군은 모두 이 같은 최신 엔진을 쓴다. 기존 공개75%/제어력 시험판은 변경하지 않았다.
