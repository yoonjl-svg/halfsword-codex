## 결과 — 96전과 늦은 발동 2조건의 8회 연장 재현

96전은 약 60초에 완료했다. 24조건 중 11조건에서 첫 공통 발동이 있었다(기존 5, 새 6). 발동하지 않은 13조건도 30초 전체 집계에 남겼다. 최초 발동 시각과 그 이전 물리 해시는 24조건 모두 같았다. 두 혜택군의 최초 발동에는 실제로 페널티가 적용됐다. 기존 바깥 밀어내기 대조 12조건은 과거 원자료와 피해·입력·파손·손길·종료가 정확히 같았다.

26.82초와 28.77초에 처음 발동한 두 조건은 30초 마감 때문에 5초 관찰이 잘렸다. 결과와 무관한 ‘최초 발동 >25초’ 규칙으로 네 군 모두 35초까지 다시 추적했고, 기존 30초까지 피해와 입력이 정확히 재현됐다. 원래 raw를 보존하고 연장 결과는 extended/에 따로 저장했다. 30초 성적에는 연장분을 넣지 않았다.

첫 5초 주 비교는 11조건, 짝별 공통 관측시간 50.108초다. 9조건은 5초를 완주했고, 2조건은 어느 한쪽의 조기 사망으로 짧다. 사망은 별도로 빠짐없이 집계했다.
