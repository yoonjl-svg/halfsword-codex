# 막아찌르기 — 새 몸꼴과 흘림 발동 단서

사용자 승인: “1번 해봐. 3번 ‘단서’도 바로 추가해. 우화가 만든 흘림 이펙트가 있다던데 그거 똑같이 해봐.” KST2026-10-21. 전용 몸꼴과 단서만 적용하며 선택 스텝은 이번 범위에 넣지 않는다.

## 적용

별도 시험 경로 `encounters/italian-body-20261021/`. 기존 A–D 경로는 그대로 보존. C의 손길·기력·일회 충격·완화된 접촉 조건을 공통으로 놓고 **새 몸꼴 / 기존 몸꼴**을 고른다. 방어자 브론 사인검 / 공격자 연습 모두 제공한다.

- 현재 접촉 자세를 기준으로 골반 회전 +10°, 가슴 회전 +12°, 숙임 +2°, 낮춤 +2cm를 0.12초 동안 부드럽게 연결. 실제 몸통/팔 물리 제어를 거친 목표값이며 강체를 순간이동시키지 않는다. 몸통·손의 회수/놓기 취소는 기존 찌르기와 함께 작동한다. 자동 걸음 없음.
- 우화 `43bdd57d764a3fa3bdee8b62bb1fcff89f262886`의 흘림 효과를 확인했다. `Particles.flowSparks`(22개, 32cm 줄)·`Sound.flow`·35ms 멈칫·haptic(.5)를 같은 코드로 호출한다. 두 효과 소스는 시험 기준 `9a8f4bcc`와 바이트가 같았다. 원문과 해시를 upstream/에 보존했다.
- `touch.opposition`으로 실제 시작 이벤트를 전달한다. 일본 흘림 판정이나 기력 페널티를 거짓으로 발생시키지 않는다. 발동 비용으로 탈진해 동작이 시작되지 않았다면 단서도 없다. 동일 발동 중 재충돌로 중복 재생하지 않는다.
- 우측 상단 ‘막아찌르기’는 시작 후 최소0.65초 표시한다. 불꽃/문구는 **발동** 알림이며 상대에게 명중했다는 표시가 아니다.
- 수치상 우월성의 확정이 아니라 사람이 찌르기 동작과 발동을 인지할 수 있는지 확인하는 후보이다. 추적이 끊겨 일찍 회수되는 기존 문제는 남아 있다.

## 검증

52개 합성 접촉/해제/중복/휴식/탈진/동작 제한 검사. 두 몸꼴, 양 역할, 터치 누르기·놓기, 재시작, 충격 켜기/끄기, 저장 격리, 모바일 넘침 검사 통과. 실제 Chromium 터치로 막기를 누른 채 자연스러운 브론 AI 접촉에서 발동했고, 불꽃22개 1회와 켜진 AudioContext의 flow음 1회를 확인했다. 가짜 접촉을 주입하지 않았다. 손을 놓자 찌르기 취소 확인. 이것은 자동화된 실제 입력 검사이며 인간의 손맛 평가와 구별한다.

실제 게임의 발동 순간 스크린샷: [기본 카메라](browser-cue/actual-touch.png), [접점·측면 카메라](browser-flash/side-contact.png). 정지 캡처를 위해 발동 뒤 물리 시간을 멈췄으며 효과/피격을 합성하지 않았다. 플래시 사진은 디버그 모드에서 입자 시간도 멈춰 남긴다. 측면 사진은 관찰 카메라만 옮겼으며 실제 몸과 칼의 자세는 그대로이다. 일반 시험은 정지/입자 시간 변경 없음.

### 소규모 물리 비교

4시드×3입력 대본(누른 채 유지/재입력 접근/직접 반격)×2몸꼴 =24회. 플레이어 입력 대본과 실제 브론 AI를 비교한다. 첫 발동 직전 강체/체력 해시가 같은 11쌍을 기준으로1·5초 피해를 비교했다. 표는 같은 피해 종류 안에서만 비교한다. 표본이 작고 같은 시드가 반복되므로 통계적 확정이나 인간 평가가 아니다.

첫5초 전투불능1→1. 사지 맞교환은 약간 좋아지고 의식 손실은 줄었지만 출혈 맞교환은 악화했다. **전체 이득 확정 금지.** 실제 가슴 회전 차이의 최대값을 각 쌍에서 구한 중앙값6.48°. 설정각12° 자체가 실제 회전차는 아니다.

판 전체 참고: 각12판 발동15→24, 자동찌르기 중 피해 접촉4→11, 조기회수10→13, 플레이어 패배12→9(승리0→0). 최대30초이며 패배 시 종료한다. 30초 합산만으로 채택하지 않는다.

첫 고정각 후보(골반−18°/가슴−32°/숙임10°/낮춤10cm)는5초 패배1→3·출혈 악화로 제외했다. 상대적인 몸꼴로 수정했으며 실패 코드/원자료/분석을 rejected/와 raw.tar.gz에 보존했다. 추가24회는 이 수정 확인을 위해 실행했다(총48회; 기준판은 재실행되어 독립48조건이 아님).
