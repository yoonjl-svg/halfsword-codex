## 선택한 동작

- 막기 버튼을 새로 누르면 한 번 시작. 접촉/상대 공격 번호/타이밍 창을 기다리지 않음. 짧게 놓아도 한 번 마치며 길게 눌러도 연속 공격하지 않는다. 사망·탈진·넘어짐·무장해제·다른 수동 기술에서 중단한다.
- 칼 든 쪽 **위팔**을 우선 겨눈다. 손은 현재 위치에서 읽은 방어선 쪽으로40%만 정렬한다. 매번 정해진 자리로 손을 크게 되돌리는 손실을 줄였다.
- **정렬0.10초 / 뻗기0.28초 / 끝 유지0.12초 / 회수0.16초**, 정상 기력에서 총0.66초. 정렬 중 손을10cm 당기고 목표축으로42cm 뻗는 명령이다. 실제 팔 길이·관절·충돌 제약은 그대로이므로 실제 이동42cm를 보장하지 않는다.
- 첫 정렬에서 목표의 현재 이동 속도로0.15초 앞을 예측하되 추가 이동은20cm 이내. 뻗는 손길의 축은 고정하고, 칼끝만 그 축에서 최대12도 범위·초당약60도 이내로 보정한다. 회수는 마지막 겨눔에서 자연스럽게 풀린다. 가짜 명중·고정 피해·순간이동·추가 충격 없음.
- 주는 칼날 상처/둔타 피해 에너지는 일반의60%. 받는 쪽은65% 감소(비교45%/0%). **회수 끝까지0.66초 보호**, 기력 감속 시 실제 시간 상한0.85초. 입력을 유지하거나 재입력해도 진행 중 보호를 갱신하지 않는다.
- 기존 흘림과 같은 피해 단계의 보정이다. 날 상처 심각도·둔타 피해 에너지가 줄며, 날의 물리 충격·옷/갑옷 마모·통증·휘청임까지65% 줄어드는 것은 아니다. 총알 등 Combat.analyze를 통하지 않는 공격은 이번 범위 밖이다.
- 일반 찌르기1회 기력(이번 레이피어5.8041)으로 받는 접촉 비용까지 포함. 걷기/클린치·유파 보법·AI 정책은 그대로. 새 자동 스텝 없음.

## 제외한 후보와 근접 한계

원자료 전체는 `raw.tar.gz`, 실행 수·각 설정·원자료 해시는 `experiment-manifest.json`.

- 실제 칼자루 기준 정렬, 몸통 겨눔만으로는 새 조건5초 손해가 남았다. 위팔 겨눔/현재 손 위치 유지/예측·작은 겨눔 보정/짧은 회수를 조합했다.
- 더 빠른 뻗기, 길어진 회수, 몸통을 원래 방향에 더 남기는 안은 이득이 안정적이지 않았다.
- 피해 감소65%만으로 해결된 것이 아니다. 같은 최종 경로에서 감소를 없앤160xx 비교는 첫 교환과5초 사지/출혈 손해가 커졌다. 45%도 비교 버튼에 남겼다.
- 실제 상처 직후 빨리 거두는 안은 일부5초 이득이 있지만 초기 교환과 다른 시드의 출혈·사지 손해가 늘어 기본에서 제외했다.
-1.45m 근접4조건은 개선안의 작은 접촉3/4이나 의미 있는 상처0/4. 더 당기거나 칼끝 보정을20도로 넓히는 후보도5초 손해가 커서 제외했다. **칼끝이 이미 지나간 밀착 거리의 해법으로 주장하지 않는다.** 이 별도4조건을 위75.6% 분모에 몰래 합치거나 삭제하지 않고 따로 공개한다.
- 초기 겨눔 보정(aiming/combine)은 각속도 제한 없는12도 범위였고, 이후 validation5/6/final은 초당60도 제한과 회수 중 마지막 겨눔 유지까지 포함한다. 재현 시 초기 두 묶음만 `steerRate:0`, 나머지는60. 원자료와 최종판 지표를 혼합하지 않는다.
