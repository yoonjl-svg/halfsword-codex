# 막아찌르기 — 전진 입력에만 짧은 스텝 연결

사용자 “전진 입력에만 짧은 스텝 연결 → 이거까지” 승인. KST2026-10-21. [직전 몸꼴](../italian_body_playtest_20261021/README.md)과 같은 C 손길/몸통/흘림 단서에 선택적 스텝을 붙였다. 자체 포크의 별도 경로 `encounters/italian-step-20261021/`. 이전 두 시험 경로와 생산 src/우화 저장소는 그대로다.

## 동작

실제 막아찌르기가 시작될 때 스틱 전진 값>0.2이고 실제 이동 명령도 앞>0.1이면 기존 `gait.requestStep`의 **앞발 lunge**를 한 번 요청한다. 앞발 착지 목표20cm, 뜬 시간0.28초. 몸이 반드시20cm 이동한다는 뜻은 아니다. 서 있고, 발이 묶이지 않았고, 상대와1.05m 이상 떨어졌으며 다른 기술 걸음/끌어붙임이 없을 때만 요청한다. 기존 이탈리아 보법·힘·속도를 바꾸지 않는다.

걷던 발이 떠 있으면 최대0.28초 기다린다. 전진 입력 해제/후퇴/막기 해제/반격 종료·중단 시 대기 요청을 취소한다. 이미 발을 뗐다면 착지 목표를 유지하면서 추가 전진 보조만 `push=0`으로 끝낸다. 다른 기술이 걸음 요청을 교체했다면 그 요청은 건드리지 않는다. 반격이 일찍 중단되거나 발이 안전하게 준비되지 않으면 스텝 없이 끝날 수 있다.

새 추가 기력 비용은 없다. 전진 입력 중 실제 이동한 거리는 기존 걷기 비용(거리 기준)에 포함된다. 정상 찌르기 비용/접촉 조건/상대 힘·피해/흘림 효과는 유지한다.

상단에서 **새 몸꼴+전진 스텝 / 새 몸꼴 / 기존 몸꼴** 선택. 방어자 브론 사인검, 공격자 연습 제공. 두 손가락으로 왼쪽 스틱을 앞으로 밀면서 오른쪽 막기 버튼을 누른다. 다음 발동을 준비하려면 막기를 놓았다 다시 누른다.

## 확인

- 조건·중복·너무 가까움·기력 소진·다른 걸음 보존·대기 취소·공중 발 착지 보존 등22개 합성 검사. 실제 전투 성공률과 구별한다.
- 3모드/양역할/충격 켜기·끄기/모바일 누르기·놓기/저장 격리/재시작 검사 통과.
- 실제 Chromium 터치 두 손가락으로 막기+전진. 실제 칼 접촉으로4.7167초에 자동찌르기 시작,4.9250초에 앞발 스텝 시작. 가짜 접촉/강제 다리 자세를 넣지 않았다. 전진 입력 .35294, 간격1.39m. 놓으면 입력0·막기해제·소유요청해제, 이미 뜬 발의 request.push0 확인. 기기의 진동을 사람이 직접 느꼈다는 뜻은 아니다.
- 실제 화면: [기본 카메라](browser-touch-final/actual-touch.png), [측면](browser-touch-final/side-contact.png). 자세 관찰을 위해 발이 뜬 순간 물리와 입자 시간을 정지했고 측면 사진은 카메라만 옮겼다. 일반 플레이에서는 정지하지 않는다.
- 첫 대기0.18초판 실제터치2회는 모두 대기 만료로 내딛지 못했다. rejected/에 보존하고0.28초로 보정했다. 반격이 끝난 뒤 요청만 남아 자동 전진하는 방식은 사용하지 않는다. 추가로 발이 뜬 지0.07초 장면을 잡으려던 촬영은 반격 종료와 겹쳐 포착하지 못했다. 해당 실행에서도 stepStarted는 기록되었으며, 촬영 실패를 스텝 미발동으로 세지 않는다(rejected/later-snapshot).

## 소규모 비교와 한계

4시드×5입력 대본×스텝 끄기/켜기=최종40회. 스텝 켬20판에서 막아찌르기27회 중 스텝 요청6회·실제 내딛음2회·취소4회였다. 대부분 정지/후퇴/접근 후 멈추기/피격 중단 등이 섞인 조건이므로 이 비율을 인간의 일반 발동 확률로 해석하지 않는다. 정지·계속 후퇴8쌍은 전체 원자료가 스텝 스위치 값 외에 완전히 같았다.

첫 스텝 요청 직전 상태 해시가 같은6쌍 기준,1초 사지 받은 피해.0344→.0642(준 피해 .0225 동일).5초 사지 받은 피해.1866→.1276, 의식 .1893→.2326, 출혈 증가 .1603→.0106. 준 피해는 같았다.5초 전투불능2→1. **사지/출혈과 의식의 방향이 다르고 표본이 작아 전투 우위 확정 없음.** 전진 스텝은 손맛 비교 후보다. 최대30초 판 결과는 각20판 패배12/승리2로 동일하며 참고만.

예비0.18초판24+16회와 계측 재현40회, 최종0.28초40회 원자료를 함께 보존했다. 같은 조건의 반복을 독립 조건으로 세지 않는다. 기술이 보였거나 스텝이 시작됐다는 사실을 실제 명중이나 인간 손맛으로 대신하지 않는다.
