# 사용자 후속 지시 — 막아찌르기는 이탈리아 유파 전체

“막아띠르기는 특정 무기가 아니라 이탈리아 유파 전체가 쓰도록 전달해.”

따라서 레이피어/달타냥 ID 허용 목록을 두지 않는다. 현재 무기의 실제 유파 `f.swordArt.tradition === 'italian'`와 막기 책 사용/정상 행동 상태로 판정한다. 새 이탈리아 무기가 추가되어도 ID를 수정할 필요가 없다. 인물의 서사에 적힌 국적/유파가 아니라 실제 전투에 연결된 유파다. 다른 유파가 레이피어 ID만 빌렸다고 발동하지 않는다.

이번 전달본의 수신판 접촉형 `src/italian_opposition.js`는 이미 이 조건으로 수정하고50검사를 통과했다. 조건 변경 이외에 입력창/손길/피해를 바꾸지 않았다. 사람·AI 검술 전체를 새로 재설계한 뜻도 아니다. 기존 모듈은 플레이어 막기 컨트롤러의 기능이며, AI에 같은 입력 기능을 새로 붙였다고 보고하지 않는다.

앞서 C-IT-RESEARCH-20261021로 전달한 **입력형 press-v2 연구**에도 같은 지시가 적용된다. 최종 연구 원문 `docs/research/italian_press_v2_20261021/overlay/src/italian_press_research.js`의 eligible에 남은 레이피어ID 조건도 제거해야 한다. [최소 패치](input-research-school-wide.patch)를 동봉했다. 이 패치는 과거 원자료를 덮어쓰거나 현재 접촉형을 입력형으로 바꾸는 것이 아니다. 입력형 채택 시 적용할 후속 패치이며 해당 입력형 전체 재실험은 이번 무기 전달에서 하지 않았다. 원 연구 기준과 새 적용 범위를 구분해 보존한다.
