# 강베기 청취 후보 1차 · 2026-10-02

사용자가 현재 적용된 강베기음에 충분히 만족하지 않아, 과거 요청 기록을 찾아 새 샘플을 만들고 직접 듣고 결정하겠다고 요청했다. **청취 후보이며 게임 기본값에 반영하지 않았다.**

## 확인한 요청

기준은 우리 저장소에 이미 인계된 [사운드 PM 기록](../handoff/pm-sound-impact.md)의 31/33/34/35차다. 상대의 새 자료를 조회하지 않았다.

- “전자 파리채로 모기 잡는 소리 같아.”
- “둔기 소리나 죽도 소리 같은데 … 고기가 날카로운 금속에 베이는 소리가 나야.”
- “사무라이 쇼다운의 피격음”, “하오마루나 갠주로나 한조의 강베기 소리처럼”.

현재음은 `SOUND.fleshHit='samsho'`의 35차다. 독립 파일명 `slash35_heavy`를 찾은 것이 아니라 당시 구현에 대응한다고 판단해 적용한 경위는 [기존 인계](../handoff/sound_pm_state.md)에 남아 있다. 이번에도 해당 상용 게임의 실제 음원을 새로 청취하거나 복제하지 않았다. 기록의 요구와 우리 소리 코드에 근거한 독립 합성이다.

## 들어보기

각 파일은 **같은 140 J 강베기 세 번**, 0.25/2.05/3.85초에 난다. 동일한 세 seed와 실제 `Sound.cut()`의 이벤트·버스·리미터 경로를 썼다. 배경·목소리·잔향은 제외했다. 실제 전투 녹음은 아니다.

- [현재 35차](samples/2026-10-02/00-current.mp3)
- [A — 선명한 베기](samples/2026-10-02/01-A-sharp-cut.mp3): 짧은 칼날 어택과 불규칙한 절삭 결, 짧은 젖은 마무리.
- [B — 두꺼운 강베기](samples/2026-10-02/02-B-deep-cleave.mp3): 중역의 갈라짐을 더 두껍고 길게, 몸통 저음은 짧게.

새 합성은 공통 고정 변조·3표본 유지 대신 불규칙하게 겹친 잡음 입자와 이동 필터를 쓴다. 금속성 공명·전기 클릭·지속적인 저음 붐은 추가하지 않았다. 긴 피 잡음은 분리된 짧은 방출로 바꿨다. 기존 `cut`의 별도 wet 층은 A ×0.2/B ×0.3, body 층은 A ×0.35/B ×0.45로 줄였다. 따라서 뱅크 하나만 바꾼 시험이 아니라 **베기 소리 전체 조합의 후보**다. 기존 body 녹음은 Kenney CC0 자료이며 [출처](../../public/sfx/LICENSE.txt)를 유지한다.

## 검증과 한계

세 강베기 묶음의 integrated loudness를 EBU R128로 측정하고, 후보별 **고정 gain 하나**로 맞췄다. 추가 마스터링 압축은 없다. 최종 192 kbps MP3는 현재/A/B 각각 **−21.04/−21.03/−21.07 LUFS**, true peak **−3.04/−3.03/−2.47 dBTP**다. 개별 타격마다 인간이 느끼는 크기가 같다는 뜻은 아니다.

15개 렌더(3안 × 강베기 3 seed·보통 베기 90 J·통과 베기 110 J)는 finite audio와 브라우저 오류 없음, 녹음층 로딩을 확인했다. 90 J/통과 베기는 원자료로만 보존하며 별도 청취 수락은 없다. 초기 MP3 변환 뒤 음량이 목표를 벗어난 후보가 있어 **최종 MP3 측정값에 맞춰 고정 gain을 보정**했다. 최초 실패를 무시하거나 허용 오차를 넓히지 않았다.

청취의 우수성·실제 폰 스피커의 타격감·반복 피로감은 미판정이다. 숫자로 사용자 취향 충족을 선언하지 않는다. 일반 게임 `src/config.js`·`src/sound.js`·`src/soundgen.js`·`src/soundlab.js`는 변경하지 않았다. 독립 읽기 감사는 실제 cut 경로/후보 격리/음량 설명 범위를 확인했으며 주관적 청취를 수행하지 않았다.

## 재현

기준 소스 `79ce8201c28841284c337015b9aba7a74981384f`. Python numpy/scipy, ffmpeg, Playwright/Chromium 필요. 브라우저 경로는 `PW_CHROMIUM`으로 지정할 수 있다.

```sh
npm run dev -- --host 127.0.0.1 --port 4198 --strictPort
node tools/audio/render_slash_review.mjs http://127.0.0.1:4198 /workspace/halfsword-sound-review/2026-10-02
python3 tools/audio/package_slash_review.py /workspace/halfsword-sound-review/2026-10-02
```

원자료/실행 로그는 위 출력 폴더. [측정값·소스/음원 해시](slash_review_round1_metrics.json)를 보존했다. renderer의 `peak`는 양수 최대값이므로 클리핑 근거로 사용하지 않는다. 최종 포맷의 true-peak 측정이 해당 검증이다. 채택은 사용자 청취 뒤 결정한다.
