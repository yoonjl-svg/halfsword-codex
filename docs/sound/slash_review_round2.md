# 길게 끌리는 절삭음 청취 후보 2차

2026-10-02. 사용자: 이전 후보가 기존음보다 조금 낫지만 여전히 둔기 타격처럼 들린다. ‘텅 텅/팍 팍’보다 금속 날이 살을 베며 이어지는 ‘쉬이익’이 필요하다. 사무라이 쇼다운 강베기를 참고 방향으로 다시 제시했다. **청취 후보를 수정했으며 기본 게임음은 아직 바꾸지 않았다.**

## 들어보기

각 파일에 같은 140 J 강베기 세 번이 0.25/2.05/3.85초에 난다. 세 seed를 고정했고 실제 `Sound.cut()`의 이벤트·버스·리미터 경로를 썼다. 배경/목소리/잔향 없는 합성 비교이며 전투 녹음이 아니다.

- [A2 — 길고 매끈한 절삭](samples/2026-10-02-round2/02-A2-drawn-edge.mp3): 약 .39초의 연속 마찰 중심. 별도 몸통 타격층은 0, 기존 wet층은 .025배.
- [B2 — 더 길고 거친 절삭](samples/2026-10-02-round2/03-B2-drawn-fiber.mp3): 약 .49초에 불규칙한 찢김 결을 더한다. 몸통 타격층 .035배, wet층 .06배.
- [A2 → B2 → A2 → B2](samples/2026-10-02-round2/04-A2-B2-comparison.mp3)
- [이전 A → A2 → B2](samples/2026-10-02-round2/05-previous-A-A2-B2.mp3)

길이는 합성된 강베기 원본의 마찰 구간이며 실제 재생률·꼬리/에너지 분포와는 다르다. 보통 베기/통과 베기도 함께 렌더했지만 별도 사용자 수락은 없다.

## 무엇을 바꿨나

1차에는 앞부분의 짧은 날 소리와 80~125Hz 저음 덩이가 남았고, 별도 body 경로에서도 타격 녹음이 섞였다. 2차는 저음 발진을 없애고 부드러운 진입부터 통과까지 연속적인 절삭 마찰을 만든다. 그 위에 겹치는 짧은 잡음 입자를 얹어 살결 저항을 표현하려 했다. 고정 주파수의 긴 금속 울림, 주기적인 전기 떨림, 끝의 별도 강한 타격은 추가하지 않았다. 실제 피부/검의 녹음이나 상용 게임 샘플을 사용하지 않은 독립 합성이다.

같은 음량의 첫 seed에서 에너지 5~95% 구간은 이전 A/B .098/.117초 → A2/B2 .249/.315초다. 첫 20ms의 에너지 비중은 7.06/2.78% → .06/.02%, 100ms 이후 비중은 17.3/32.9% → 77.3/83.5%다. 35~300Hz 필터 에너지 비율도 7.30/12.92% → .003/.018%로 줄었다. 이것은 시간·주파수 설계의 확인이며 실제 절삭감/사실감을 입증하지 않는다.

## 검증

- 이전 A/B와 새 A2/B2 각각 강베기 3seed·보통·통과, 총20렌더. 유한 오디오, 브라우저 오류 없음, 동일 source 해시, 녹음층 로딩 확인.
- 네 후보의 세 타격 묶음에 고정 gain 하나씩 적용했다. 추가 압축기 없이 EBU R128를 맞추고 최종 192kbps MP3를 다시 측정했다. 목표 −21.05LUFS; 이전 A/B −21.03/−21.07, A2/B2 **−21.06/−21.04LUFS**. 새 후보 true peak **−8.90/−8.68dBTP**. 소리 길이/어택이 달라 순간 체감 음량까지 동일하다는 뜻은 아니다.
- 채택 시에는 합성 함수와 레이어 비율뿐 아니라 청취본의 고정 음량 보정(새 후보 약 −6.8dB)도 게임 안에서 다시 확인한다. 함수만 복사하면 현재 청취본보다 커질 수 있다. 연결 비교 파일 전체의 LUFS는 네 개 개별 3회 청취 파일과 같게 맞춘 값이 아니다.
- 이전 렌더와 새 renderer의 A/B 원자료는 byte-exact가 아니다. 10개 모두 최대 절대 차이 2.3842e−7, 상대 RMS 차이 최대 4.0165e−7이었다. 원자료 비교 수치를 그대로 보존했다.
- 사람 또는 모델의 실제 청취, 폰 스피커/전투 내 반복 피로도 판정은 하지 않았다. 사용자 청취로 결정한다.
- `src/`와 기본 설정은 변경하지 않았다. 후보 함수는 렌더 도구만 import한다. 부상/베기 판정·소리 문턱도 바꾸지 않았다.

## 참고 자료에서 확인한 범위

[Chivalry 2 공식 오디오 인터뷰 요약](https://chivalry2.com/2022/06/24/chivalry-2-audio-with-buckley-twitch-stream-recap/)은 여러 소리층, 연속 반복을 피하는 변주, 무기별 공격 유형의 고유 소리를 설명한다. 실제 살 절삭음의 길이·음색은 이번 조사에서 청취/측정하지 않았다. 이 방식은 현재 게임의 층/seed 구조와도 양립한다.

[SNK 사운드 팀 Yasumasa Yamada 인터뷰](https://www.vgmonline.net/yasumasayamadainterview/)는 Neo Geo 효과음 샘플링/채널 제약을 확인하는 자료다. 사무라이 쇼다운 강베기를 ‘쩌억+쿵+피’라고 특정하는 근거는 아니다. 기존 인계 문서도 당시 실제 청취 불가를 명시하고 있으므로 그 음색 설명을 확인된 상용 게임 분석으로 재사용하지 않았다.

[사무라이 쇼다운 The Sound 영상](https://www.youtube.com/watch?v=yfpJYBJinG4)은 직접 접근 HTTP403으로 청취하지 못했다. 이번 후보는 사용자의 청취 설명을 기준으로 설계했다. Kingdom Come/Mordhau의 구체적 음색은 검증한 근거가 없어 비교 결론에 넣지 않았다.

## 재현

게임 기준 `917c08444db2db9488bacc4e381d8a228f4aaaf5`. Python numpy/scipy, ffmpeg, Playwright/Chromium 사용. 기존 원자료를 덮지 않도록 새 출력 폴더를 지정한다.

```sh
node tools/audio/render_slash_draw.mjs http://127.0.0.1:4201 /tmp/slash-draw-new
python3 tools/audio/package_slash_draw.py /tmp/slash-draw-new
```
