# 베는 순간과 통과음을 연결한 청취 후보 3차

2026-10-02. 사용자 피드백: “이번 건 약간 뱀 소리 같아. 그렇게 먀냥 끌리기보다는 강약이 좀 더 있어야 해. 베는 소리, 베고 지나가는 소리가 연결되게.”

2차는 느린 진입과 길게 유지되는 고음 마찰로 초반 절삭이 약했다. 3차는 **진입에 힘을 싣고, 저항 구간을 거쳐, 빠져나가는 꼬리로 약해지는 연속 동작**을 만들었다. 청취 후보이며 게임 기본음은 변경하지 않았다.

## 샘플

- [B3 — 중간 저항을 더 남긴 베기](samples/2026-10-02-round3/03-B3-linked-heavy.mp3)

각 개별 파일은 같은 140J 강베기 세 번(0.25/2.05/3.85초, seed71/172/273)이다. 실제 `Sound.cut()` 이벤트·버스·리미터를 거쳤고 배경·목소리·잔향은 제외했다. 실제 전투 녹음이 아니다.

## 변경

새 [합성 함수](../../tools/audio/slash_linked_candidate.mjs)는 하나의 잡음 흐름과 필터 상태를 유지한다. 부드럽지만 빠르게 진입하고, 줄어든 소리에 중간 저항의 작은 굴곡을 만든 뒤, 저항층을 얇게 하며 빠져나간다. A3/B3 강베기의 설정된 흐름 길이는 .285/.345초다. 층 사이에 무음을 넣거나 독립적인 두 번째 마찰음을 덧붙이지 않았다.

정현파 저음·몸통 타격층은 0이다. 기존 wet층은 .025/.035배로 작게 유지했다. 날 소리 아래 중역 절삭 결을 더해 고음 마찰에만 의존하지 않도록 했다. 작은 찢김 입자는 진입/저항 구간에 겹치며, 끝의 별도 타격으로 쓰지 않는다. 실제 원음이나 상용 게임 샘플을 사용하지 않았다.

## 확인한 범위

이전 A2/B2와 새 A3/B3 각각 강베기3seed·보통90J·통과110J, 총20렌더. sourceStable, finite audio, 브라우저 오류 없음, 녹음층 로딩 확인. `src/`·기본 설정은 미변경이며 후보는 렌더 도구만 import한다.

| 같은 3회 파일 | 최종 LUFS | true peak dBTP | 강베기 진입/통과 RMS 차이(3seed) |
|---|---:|---:|---:|
| 이전 A2 | −20.98 | −8.78 | −2.71~−.74dB |
| 이전 B2 | −21.02 | −8.79 | −4.49~−2.57dB |
| A3 | −21.02 | −4.47 | +15.09~+17.16dB |
| B3 | −20.99 | −4.92 | +11.39~+13.20dB |

진입은 실제 렌더 시작 후20–60ms, 통과는180–280ms의 고정 측정 창이다. 실제 게임 이벤트의 재생률·리미터를 포함하며 생리적 절삭 단계의 실측값이 아니다. A3의 최대10ms RMS는40ms, B3는50ms 또는120ms였다. B3 한 seed에서는 중간 저항 구간이 더 컸으므로 모든 후보의 최대가 진입에 있다고 하지 않는다. 이전 A2/B2는100–130ms였다. 중간20–180ms의 최소10ms RMS도 저장했지만, 이것만으로 사람이 연결된 한 동작으로 듣는다고 판정하지 않는다.

네 개별 3회 파일의 평균 음량은 목표−21LUFS에 맞췄다. 고정 gain 하나씩만 사용했고 추가 마스터링 압축은 없다. 새 후보의 gain은 A3 약+2.21dB/B3 +.17dB다. 채택 시 합성/레이어 비율과 함께 이 청취 음량 경계를 게임에서 다시 확인해야 한다. 연결 비교 파일 전체의 LUFS와 순간 체감 음량까지 같게 맞춘 것은 아니다.

연결성 관찰은 한 이벤트 파형 안의 진입→저항→통과에 한정된다. 실제 전투에서 연속 `cut()`/through 이벤트가 겹치거나 전환되는 상황은 이번 단일 이벤트 렌더로 검증하지 않았다.

사람 또는 모델이 청취한 판정은 없다. 이번 수치는 설계 변화·출력 정상 여부의 근거이며 절삭감·자연스러움·폰 스피커 수락은 사용자 피드백으로 결정한다. 상용 게임 참고 자료는 [2차의 확인 범위](slash_review_round2.md)를 유지하며 새 청취를 했다고 하지 않는다.
