# 캐릭터 목소리 중복 정리 · 2026-10-11 KST

사용자는 비슷한 나이/분위기는 공유하되 눈에 띄는 중복부터 교체하도록 선택했고, 세르파는 이번 제작에서 제외했다. 기준은 `8a7c37d`다. 원본 halfsword와 PWA 인계 묶음은 변경하지 않는다.

14인물(하인리히 변형 포함)이5개 NPC 녹음 묶음을 사용했다. 확장8명은 모두 기존 묶음을 그대로 사용했다. 기본 녹음37파일은36개의 서로 다른 녹음으로, 서로 다른 묶음 사이의 동일 파일은 없었다. 가장 큰 중복은 파일 복제가 아니라 인물의 배정이었다. 슈바르츠의 ko/bleed 동일 녹음은 이전 사용자 선택을 유지한다.

NPC 묶음5→7, 최대 공유 인물5→3. 새 성우7명이 아니다. 토메는 기존 HaelDB 녹음군을 별도 배정한 것으로64세 연기의 적합성을 확인했다는 뜻이 아니다. 새 여성군은 사용자 승인 보관 음원2개를 그대로 사용한다. gasp는 피격/ko 공통, sigh는 출혈이며 녹음 변주가 충분한 완성 세트는 아니다. 기본 재생 속도를 낮춰 노인/여성 음색을 흉내 내지 않는다.

새 MP3는15,932바이트뿐이다. 샘플 로더에 명시적 파일 목록을 허용해 토메 음원을 다시 복사하지 않는다. 다운로드 실패로 비어 있는 배열은 다시 시도하도록 고쳤다. 기존7프로필·원본 음원·플레이어 숨소리·무기/자연 효과음·서사·전투 수치는 유지한다.

[인물 비교 화면](https://yoonjl-svg.github.io/halfsword-codex/voices.html)은 실제 게임 Sound.hurt/death를 사용하며 이전/새 배정을 누르는 즉시 비교한다. 한 번에 하나만 울리고 정지/백그라운드 전환 때 멈춘다. 게임 설정은 쓰지 않는다. 세르파 버튼은 없고 배정도 유지한다. 각 인물 플레이로 이동할 수 있다.
