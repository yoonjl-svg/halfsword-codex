## 확인 근거

- `CHARACTERS_BY_ID` 실제 voice 해석으로 여성6명 배정 확인. `src/characters_expansion.js`에 사미라/영만의 isolde 배정이 명시돼 있으며 우발적 fallback 문제가 아니다.
- `src/sound.js` isolde는 피격2·KO1·출혈1·부활1. soft_female는 피격과 KO가 동일 `reitanna_gasp`, 출혈 `reitanna_long_sigh`.
- 직전 파일 재선택 방지가 이미 있으나 1개짜리 이벤트는 반복을 피할 수 없다. 이 기능을 중복 구현하지 않는다.
- 녹음 경로의 실제 차이는 원본 연기·gain·rate다. 합성용 f0/tract만 바꿔 새 녹음 음색을 만들었다고 하지 않는다.
- 이번에는 음원을 새로 청취하거나 후보를 확보하지 않았다. 연기/음색 설명은 제작 목표이며 완성 평가가 아니다.

## 실행 범위와 순서

1. 신규 성인 여성 녹음군 후보 최대2개만 선별한다. 재사용 가능한 출처/상업 이용 조건을 확인하고 같은 연기자의 일관된 피격·기절·출혈을 우선한다. 기존 이졸데 녹음의 음높이 변조만으로 새 세트를 대체하지 않는다.
2. 사미라용 피격2·기절2·출혈2를 목표로 짧게 편집한다. 적합한 연기 확보를 우선하며 불필요한 음원을 채우기 위해 억지 가공하지 않는다. 사미라에는 현재 부활 설정이 없으므로 부활 음원 제작은 필요 없다.
3. 기존 `voices.html` 비교 화면을 사용해 음량을 맞춘 이전/후보 청취를 제공한다. 새 비교 UI·로더를 만들지 않는다. 사용자는 짧은 A/B 청취 한 번으로 연기 적합성을 판단한다.
4. 신규 파일 디코딩/클리핑·게임 피격/사망 연결·모바일 입력/재시작·공개 파일 반영을 변경 범위에 한정해 확인한다. 사미라 새 세트를 적용하면 이졸데 공유는3→2명이며 두 갈래로 분화된다.
5. 사미라 분리 이후에도 반복이 두드러지면 에이라군 피격/기절에 서로 다른 take를 추가한다. 추가 배우/전 캐릭터 재녹음은 현재 범위에 넣지 않는다.

예상 실행: 비교 청취판까지45–75분(재사용 가능한 녹음 확보 기준). 적합한 원음이 없으면 확보 단계의 소요/대안을 별도 보고하며 근거 없이 품질/비용 절감률을 확언하지 않는다. 게임 물리·외형·다른 사용자 선호 음성은 변경 대상이 아니다.
