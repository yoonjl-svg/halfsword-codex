# 회복 중 팔이 몸 뒤로 도는 현상 · 10/08

**한손 근접무기의 주팔 목표 오류를 교정해 일반판에 적용했다. 양손 무기는 후보의 새 몸통 겹침 때문에 보류하고 기존 동작을 유지한다.** 전체 팔 오류나 기립 자연스러움의 해결을 선언하지 않는다. 기준은 `2671561ceb765a008c6622322507319bb8d5f02c`. 공개 전달 완료 여부는 [전달 영수증](arm_recovery_geometry_release.json)을 따른다.

## 원인과 채택 범위

손 목표를 수평 방향(yaw)으로 만든 뒤 실제 기울어진 가슴 좌표로 바꾸면서, 높은 가드를 유지한 기립 중 목표가 가슴 뒤로 들어갔다. 세이버 준비 누움에서 요청 X 최저 −.573m, 실제 상완의 후방 지표는 getup 241프레임 중55프레임이었다. 실제 팔 강체를 그대로 표시하므로 손 외형만의 문제가 아니었다. 이번 재현은 고정 팔꿈치 pole의 특이점에 근접하지 않아 기존 pole는 바꾸지 않는다.

주팔 IK에 들어가는 가슴 좌표의 목표 X만 최소 .16m로 제한한다. 가슴 반두께 .11m＋전완 반지름 .04m＋여유 .01m에서 정한 **목표 선택 여유**이며, 해부학 한계나 팔 전체의 비접촉 보장이 아니다. 실제 팔 위치·속도를 덮어쓰지 않고 기존 근력·중력·검 방향·피해 계산을 유지한다.

기립 상태명이 stand로 바뀌어도 원래 목표가 앞쪽으로 돌아오기 전에는 제한을 유지한다. 원래 목표가 .16m 이상이 된 순간 해제해 경계 점프를 막는다. 회복 이력이 없는 정상 선 자세에는 비개입이다. 적용은 이름 목록이 아닌 `twoHand`/`gun` 기능으로 나누며, 한손 근접무기의 주팔에만 연결한다.

## 실제 결과와 한계

아래는120Hz 실제 게임 코드에서 가슴 좌표 상완 단위방향 X<−.5인 getup 프레임 수다. 의학적 가동범위 판정이나 모든 후방 팔 자세의 정의가 아니다.

| 준비 장면 | 기준→채택판 |
|---|---:|
| 세이버·누움·높은 가드 | 55→0 |
| 세이버·옆 넘어짐·옆 가드 | 27→0 |
| 레이피어·누움·높은 가드 | 27→0 |
| 모르겐슈테른·옆 넘어짐·높은 가드 | 6→0 |

각 장면의 getup은241프레임이며 세 무기·네 장면의 한정 검사다. 같은 첫 stand 시각을 인간 기립 성공으로 해석하지 않는다. 준비 장면은3초에 knockDown과 가슴55N·s 충격을 한 번 준 조건이며 신체 위치·속도 대입은 없다. 자연 장면은 실제 AI와 피격을 사용한다. 접촉으로 갈라진 뒤의 결과를 동일 공격력·승률 비교로 읽지 않는다.

모르겐슈테른의 초기 matrix는 공개 시험판의 fresh/bounded 정책을 누락했으므로 탐색 근거로만 남긴다. 최종 표는 정확한 공개 정책으로 다시 실행한 `mace-policy-baseline/adopted`를 사용한다. 이 쌍의 getup 후방 팔은6→0이나, 전체 관찰의 주팔 중첩 최대는 .0409→.0516m로 소폭 증가했다. getup 및 첫 stand 후2초에는 주팔5cm 초과 중첩이 없었다. 모든 몸통 겹침을 없앴다는 판정은 아니다.

관찰을 끈 `observer-control`과 r3 세이버 높은 가드의 native snapshot 해시1106개·상처·상태 전환이 일치했다. 최종판의 양손6장면은 `adoption-equivalence.json`에서 각 baseline의 native trace와 완전히 일치한다. 한손 기존4장면도 r3와 일치하며, 모르겐 최종 정책 검사는 위 별도 쌍으로 교체한다. 반복 baseline이나 도구 무영향 확인을 독립 효능 표본으로 더하지 않는다.

## 기각한 후보를 보존한다

- **r1 · .08m, 상태명만으로 제한:** 기립 팔 후방은 줄었으나 자연 두손 장면에서 stand 전환 때 가슴은38.9° 기울고 원래 목표 X는 −.314m였다. 즉시 해제로 목표 약.99rad 점프와 보조팔 후방38프레임을 만들었다. 기각.
- **r2 · .08m＋목표 복귀까지 유지:** 경계 해제는 교정했지만 준비된 양손 회복에서 주팔 몸통 중첩이 약.144m까지 증가했다. 기각.
- **r3 · .16m＋유지, 양팔 공통:** 준비된 양손 장면은 좋아졌으나 실제 피격 뒤 기립·재입력에서 보조팔 최대 중첩이 .069→.154m로 증가했다. stand 후10cm 초과19프레임이 생겼다. 5cm 초과 지속은205→46프레임, 적분은.112→.088m·s로 줄었지만 깊은 순간 악화를 상쇄하는 근거로 쓰지 않는다. tick1886의 기록 자세를 게임 메시에 표시하니 보조 상완이 몸통에 들어가 사라지는 듯 보여 **양손 일반 적용을 거절**했다.
- **r4 · r3에서 보조팔 제한 제거:** 자연 재입력2034개 native snapshot·상처·상태 전환이 r3와 완전히 같았다. 보조 IK 제한만 없애서는 해결되지 않았다.

양손의 후방 팔·교차 가드 중첩은 미완료로 남긴다. 광범위한 자기 충돌·어깨 힘 변경이나 기각된 swivel/전신 지지 후보는 추가하지 않는다. 손목 목표만 바꾸면 실제 팔꿈치 경로·두손 결합까지 안전해진다는 가정이 실패한 것이다.
