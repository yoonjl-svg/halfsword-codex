# 팔 목표 자세·속도 분리와 팔꿈치 회전면 연구 2차

2026-10-03 KST. 기준 `d410ed0`. **팔꿈치 후보는 일반 게임에 채택하지 않았다.** 목표 자세와 목표 속도를 나누어 끄는 것만으로 입력 추종과 제동이 함께 좋아지지 않았다. 후속으로 찾은 검 날 방향 문제는 [별도 연구](intent_edge_round1.md)로 분리했다.

## 조건과 실행 근거

보정0, paired grip, 같은 외부 손 입력·준비 상태를 사용했다. 첫 분리는 양손 사선의 .075초 같은 native/선택 제어 prefix에서 개입했다. 이후 연구도구는 실제 게임 Fighter/Rapier를 실행했으며 몸의 자세·속도를 직접 덮어쓰지 않았다. 임시 메서드의 관찰 대조·입력 hash·실행 전후 소스 SHA를 확인했다. 관찰된 반응은 전체 native 모터 일의 측정이 아니다.

[기계 판독 기록](arm_target_terms_round2.json)에 10개 원자료, 실행 명령, 정확한 파일 SHA와 해당 파일을 복원하는 커밋을 남겼다. 기록이 완성된 비교 실행48회 중 첫 기하 관문 실패4회를 제외한44회가 각 계측 관문을 통과했다. 이는 후보 수락44건이나 독립 표본44개를 뜻하지 않는다. 서로 다른 외부 베기는 양손 사선·올려베기와 한손 내려베기3개다. 측정 wall time 합37.152초는 설계·구현·감사 시간을 제외한다. 초기 재귀 오류로 중단한 harness 시도는 이 완성 기록 수에 포함하지 않는다.

실행 예:

```sh
node tools/sim/experiments/arm_target_terms_probe.mjs --level=0 --out=<새경로.json>
node tools/sim/experiments/elbow_swivel_probe.mjs --level=0 --base=coupled --out=<새경로.json>
node tools/sim/experiments/elbow_task_velocity_probe.mjs --level=0 --out=<새경로.json>
```

나머지 세부 옵션은 JSON의 개별 command가 기준이다. 원자료는 저장소 밖 로컬 evidence에 있으며 Git bundle에는 포함되지 않는다.

## 목표 항 분리: 한 항 제거로 해결되지 않음

아래는 같은 양손 사선의 입력 종료 뒤1.2초 구간이다. 축 이동은 검의 긴 축 방향 이동량이며 축 둘레 비틀림과 다르다.

| 조건 | 종료 뒤 축 이동 rad | 마지막 방향 오차 rad | 마지막 검 운동에너지 J |
|---|---:|---:|---:|
| 원래 게임 | .620039 | .079971 | .000379 |
| 앞선 coherent 팔 후보 | 1.261209 | .016397 | .051292 |
| 후보의 어깨 목표 속도만0 | 1.584104 | .010102 | .164037 |
| 후보의 팔꿈치 목표 속도만0 | 1.401118 | .013039 | .067555 |
| 후보의 어깨 목표 자세 힘 제거 | .697441 | .070616 | .005751 |
| 후보의 팔꿈치 목표각을 현재각으로 | 1.357445 | .063426 | .037525 |

어깨 자세 항을 없애면 종료 이동은 줄지만 베는 중 최대 방향 오차가 .377401→.407402rad로 나빠진다. 어깨의 twist 자세 항만 제거한 후속도 종료 검 에너지가 .308404J로 증가했다. 실제 k=0인 팔꿈치 시험 역시 축 이동1.356780rad로 해결책이 아니었다.

팔꿈치 목표각을 현재각으로 바꾸는 시험은 **목표 오차만 중립화**한 것이다. native implicit stiffness가 남으므로 stiffness-off라 부르지 않는다. 별도 k=0 시험에서만 이를 제거했다. 어깨의 중력/실제 각속도 감쇠/목표 이력과 반작용은 보존했다. Hill 한도 공식은 유지해도 반응이 달라져 수치 한도까지 같지는 않다.

## 같은 손 끝점에서 실제 어깨 자세에 가까운 팔꿈치 회전면

상완·전완 길이 .3/.265m와 기존 후보의 팔꿈치 각을 보존하고, 실제 어깨에서 필요한 최소 회전으로 같은 목표 손 끝점에 도달하는 후보를 만들었다. 회전 quaternion 정규화 뒤의 끝점 일치는1e-12m 이내였다. 최초4행은 native quaternion의 미세한 비정규화 때문에1.63e-7m 오차로 관문 실패했다. 이를 숨기지 않고 정규화 전/후 오차를 함께 기록했다.

양손 사선에서는 coupled 후보의 종료 축 이동1.022→.789rad, 마지막 검 에너지 .825→.00233J로 줄었다. 그러나 원래 게임의 .620rad보다 이동이 크다. 한손 내려베기는 베는 중 방향 오차 .0675→.0859rad, 최대 관절 틈 .627→2.048mm로 후퇴했고, 양손 올려베기도 방향 오차 .241→.348rad·종료 이동1.046→1.126rad로 후퇴했다. **사선의 좋은 결과만으로 채택하지 않는다.**

## 목표 각속도의 ‘끝점에 영향 없는 성분’ 해석 정정

raw 목표 각속도에서 손 도달 방향과 평행한 성분을 제거할 때, **제거한 각속도 변화량(before−after)**과 도달 벡터의 외적은0이다. 전체 목표 각속도의 외적이0이라는 뜻은 아니다. 그러나 실제 manualMuscle은 먼저 상완 축에 수직인 평면으로 각속도를 투영한다. 그 뒤 변화량의 외적은 일반적으로0이 아니다. 처음의 ‘끝점 속도 보존’ 해석을 철회하고 관문 이름과 관측을 고쳤다.

재실행6행의 물리/제어 trace는 수정 전과 전부 같았다. combined에서 투영 뒤 차이 외적 최대1.815m/s 상당, 목표 속도 feed-forward 차이108.673Nm였다. 이는 실제 손 끝점의 측정 속도나 native 모터 일이 아니다. 이 필터는 종료 축 이동 .789→1.207rad, 검 에너지 .00233→.39045J로 후퇴해 기각했다.
