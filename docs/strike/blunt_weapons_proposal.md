# 둔기(메이스·모닝스타·망치) 제안 + 밀치기 물리 의견 — 무기 PM (9/30, 문서만)

## 1. 둔기 후보 (레어 기준 · 수치는 사료 일반값[출처 미대조] → 게임 스펙은 측정 뒤)
| 후보 | 상징성 | 실물 | 몸 틀·방식 (weapon_class) | 둔기 판정 |
|---|---|---|---|---|
| **플랜지드 메이스** (고딕 메이스) | 15세기 판금 시대 기사의 "판금 깨는" 무기. 바이외 태피스트리의 오도 주교 곤봉 | 한손 약 0.6 m · 1.2~1.6 kg, 무게가 끝(머리)에 몰림 | C 한손 · ④ 때리기 (`edged:false` 면 저절로) | mBlunt 높음. 날이 없어 Q13 에서 늘 둔기 → 판금 위로 `E×T` 전달 + 갑옷 닳음 |
| **모르겐슈테른** (모닝스타) | 14~15세기 독일·스위스 민병. 가시 달린 철구. 영국 별명 "홀리워터 스프링클러" | 한손~한손반 0.7~0.9 m · 1.5~2 kg (긴 민병용 1.5 m+ 는 자루 무기라 제외) | C 한손 또는 두손 짧은 자루 · ④ | 가시: 둔기 + 약한 찌르기(mThrust 작게). 무게로 판금 전달 가장 큼 |
| **호스맨스 해머** (전투망치) | 기사의 말 위 망치. 앞 망치머리 + 뒤 부리(픽) | 한손 약 0.6 m · 0.9~1.2 kg | C 한손 · ④, 부리 쪽은 찌르기 부품 | 망치 면 = 둔기, 부리 = 판금 뚫는 찌르기. 한 무기로 둘을 고른다 |
- 대안: 페르나치/셰스토표르(동유럽 날개 철퇴, 헤트만 권위의 홀 — "권력" 상징이라 에픽이 어울림). 헨리 8세 "총 달린 모닝스타"는 권총과 겹쳐 제외. 추천 순서: 메이스(가장 상징적·판정 단순) → 망치(둔기·찌르기 고르기) → 모닝스타(메이스와 겹침 큼).

**자리**: `weapons.js` 에 스펙만 넣으면 `classifyWeapon` 이 `frame:'one'`·`style:'blunt'`("메이스 = C④", `docs/weapon_types.md`). 무기 층 `WEAPON_LAYER` 둔기 칸을 그대로 쓰고, 판정은 `mBlunt` → combat.js 둔기 상처 + Q13(`q13_values_proposal.md`: 판금 위 `E×T`, 몸통 30/60/120 J, 닳음 `E/wear`) + 부위표 시제품 `blunt_zones.mjs`.

**측정 근거**: 시제품 `tools/sim/proto_weapons.mjs` 메이스 1.2 kg(머리 0.9 kg 이 0.52 m, 쥔 곳 기준 관성 약 0.26 kg·m² — 롱소드 0.27 과 비슷, 길이는 절반)이 롱소드 상대 **0~10%**(24~48판, 라이브러리·부위표 켬/끔 모두; 같은 도구로 세이버 33%). 팔 힘만으로 머리 무거운 무기를 돌리는 지금 모델 탓(`docs/weapon_motions.md` §5) — 온몸 타격이 들어와야 선다.

**순서**: ① Q13 구현 → ② R6 무기 계열 → ③ 시제품 다시 재기(`node tools/sim/hybrid.mjs proto_weapons.mjs proto_mace 48 off zones`) → ④ 롱소드 상대 승률·판금 상대(마르그레테) 우위로 질량·mBlunt 정하기 → ⑤ 로스터(레어). 위 kg·m 는 사료 범위일 뿐, 게임 수치는 ③~④ 측정에서 나온다.

## 2. 밀치기 물리 의견 (입력 방식 제외)
**지금**: `fighter.shove()` 는 0.75 m 안에서 뒤로 당기거나 몸이 닿으면 가슴에 `BODY.shoveForce` 320 N × 근육·힘·팔 상태를 매 스텝, 같은 힘을 반대로 내 가슴에. 고정 힘이라 얼마나 빨리 부딪쳤는지와 무관하다. 갑옷은 몸 질량에 없다(질량 칸 없음). 몸 75.1 kg · 가슴 16.2 kg(harness 실측).

**제안 — 고정 힘 대신 충격량 J = m_eff·Δv, 실제 몸 속도에서 나오게**
- **몸통 부딪기**: 골반·가슴의 상대 쪽 속도 × 몸통 유효 질량 → 상대 가슴에 `applyImpulse(J)`, 나에게 −J. 붙은 채면 작고, 한 걸음 디디며 들이받으면 크다 — 걸음이 곧 세기.
- **발 밀어차기**: 차는 정강이·발 속도 × 다리 유효 질량 → 상대 골반·배에 J. 닿는 시간이 짧아 순간 힘이 크고, 반작용이 외다리에 걸려 차는 쪽도 균형을 잃는다 — 부딪기와 쓰임이 자연히 갈린다.
- **갑옷 무게**: 판금을 몸 질량에 더하면(부위별, 20~25 kg 일반값[출처 미대조]) 같은 J에 덜 밀리고, 입은 쪽이 들이받으면 더 민다. 쿨다운 없이 물리만으로 "무거운 기사는 잘 안 밀린다"가 나온다.
- **긴 칼 대 짧은 칼**: 밀치기는 0.75 m 안에서만 되고, 붙은 거리(ai.js MEASURED clinch)는 롱소드 1.25 · 츠바이핸더 1.32 · 세이버 1.07 m. 되돌릴 거리가 롱소드 약 0.5 m · 세이버 약 0.3 m 라 같은 J 라도 **긴 칼 쪽이 더 얻는다**. 짧은 칼·메이스에겐 상대의 밀치기가 곧 반격 기회.
- **이음**: 지금 shove 는 "살짝 떼어내기"로 남기고, 부딪기·차기는 새 동작이 만든 몸 속도에서 J를 계산한다.
- **재볼 것**: 들이받은 뒤 상대가 떨어지는 거리, 넘어지는 비율(판금 유무), 롱소드 대 세이버에서 밀친 뒤 첫 베기까지.
