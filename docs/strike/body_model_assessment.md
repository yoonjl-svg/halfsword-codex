# 신체 모델과 전신 협응의 한계

2026-10-01. 기준 `36bd9e039ce0a740ad3c8a456717bfb75278786f`. 사용자는 기립 같은 세부 동작도 상위 물리 개선을 뒷받침하며, 팔 길이·손가락·관절 수·몸통 두께·뒤틀림·전신 연속 수행에 모델 자체의 한계가 있는지 확인하도록 했다.

## 결론

현재 모델은 실제 관절로 연결된 전신 강체이고 몸통·팔·다리의 연동도 있다. 다만 사람 몸의 일부 움직임과 접촉을 생략했고, 서로 연결된 자세 목표가 실제 힘 전달에 맞춰 동작 전체를 조율하는 단계까지는 확인되지 않았다. 모델의 표현 한계와 제어의 간섭을 함께 조사해야 한다. 관절을 많이 추가하는 것만으로 힘 전달이 좋아지는 것은 아니며, 현재 단순화가 어느 과제를 막는지 먼저 분리한다.

## 전신 연속 수행은 어느 정도 있는가

`guardAt`은 같은 입력에서 손·검·골반·가슴의 목표를 함께 만든다. 몸통은 거르기 전 손 입력을, 손은 필터를 거친 목표를 따라가므로 골반/가슴을 먼저 움직이려는 구조가 있다. 관절은 실제 각도·상대 각속도를, 보행은 실제 발 위치·접촉 하중 등을 피드백한다. 각 부위의 힘은 한 물리 스텝에서 함께 계산되므로 서로 독립된 인형 조각은 아니다.

그러나 `updateBodyPose`는 발의 하중 이전, 몸통·손의 실제 추적 지연, 각 부위의 일과 에너지 전달을 읽어 동작 전체의 진행을 재조정하지 않는다. 몸통이 목표에 먼저 도착해 멈추거나 팔이 heading 기준 목표를 유지하려고 몸통 회전을 되돌릴 수 있다. 함수 호출 순서나 골반/가슴 목표의 선행만으로 실제 타격의 협응을 입증할 수 없다.

이 문제는 이전 팀도 [전신 재설계 기록](../whole_body_redesign.md)에서 조사했다. 그 문서의 `4b5c56a` 측정과 W4c/W5·`/wb/` 구현 기록은 현재 본판과 구분한다. 당시 속도·에너지·시간 숫자를 이번 모델의 측정값으로 옮기지 않고, 실패한 추적 방식과 사용자 평가를 다음 실험의 근거로 사용한다. 현재 본판에 그 별도 구동 모듈 전체가 들어 있다고 주장하지 않는다.

## 개선 우선순위

1. **신체 사양과 표현 한계부터 맞춘다.** 관절점·분절 길이·질량·관성·손잡이점을 한 기준으로 관리한다. 현재 IK와 실제 연결점의 차이, 발 추가 질량, 관절 제한/자기 충돌 정책을 도구로 드러낸다. 관절 모델의 문제와 제어 이득의 문제를 뒤섞어 조정하지 않는다.
2. **하나의 타격 과제로 협응시킨다.** 준비, 체중 이동·몸통 추진, 팔 전달, 검의 진행, 제동·회복을 공통 목표로 연결한다. 실제 접촉·부하·추적 지연·막힘에 맞춰 진행하며 사용자의 계속된 입력을 받는다. 모든 부위가 정해진 시각에 차례로 움직이는 고정 애니메이션이나 강제 입력 잠금으로 대체하지 않는다.
3. **막히는 자유도만 추가한다.** 어깨띠의 유효 이동, 전완 회전, 손바닥/손목과 파지의 분리는 우선 검토할 후보이다. 기존 관절로도 가능한 과제인지와 추가 비용을 먼저 비교한다. 관절점을 순간이동시켜 도달 범위만 늘리면 새로운 힘·에너지가 생길 수 있으므로 질량·반작용도 함께 설계한다.
4. **손가락은 필요한 수준부터 표현한다.** 전신 베기에서는 손바닥 방향·양손 사이 거리·파지 강성·미끄럼·비틀림·놓침을 먼저 다룬다. 손가락 외형은 이 상태에 맞춰 움직이게 할 수 있다. 손가락 하나하나의 물리 접촉은 세밀한 잡기/손가락 손상 등 필요한 과제가 생길 때 별도 검토한다. 시각용 뼈와 물리 관절은 비용과 역할이 다르다.

과제 세트는 머리 위/어깨 뒤 준비, 몸을 가로지르는 베기, 반대쪽 낮은 마무리, 팔을 뻗은 찌르기, 양손 교차 파지, 무릎 기립으로 구성한다. 같은 시작 상태·입력에서 도달 불가능 목표의 비율, 손–그립 간격, 관통, 발 지지·미끄럼, 실제 골반/가슴/손/검의 속도와 일, 막힘·헛침 후 회복을 본다. 큰 동작을 더 자연스럽게 수행하면서 휴대폰의 물리 계산 시간·입력 반응도 유지하는지 함께 검증한다.

기립은 상위 목표에서 제외하지 않는다. 같은 신체·지면·근력 체계가 체중을 지탱하고 이동시키는지 확인하는 필수 과제다. 수치 통과만으로 자연스러움을 선언하지 않고 모바일 플레이 피드백과 실제 사람 동작 자료를 함께 사용한다. 이번 회차에는 연구 도구·문서만 추가했으며 신체 구조와 일반 게임 물리는 바꾸지 않았다.
