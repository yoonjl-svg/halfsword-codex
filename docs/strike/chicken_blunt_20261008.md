# 고무닭 둔타 계수 조정 · 10/08

사용자가 고무닭이 너무 강하다고 판단해 둔타 계수를 **2.6→1.6**으로 지정했다. 플레이어/상대 모두 같은 무기 정의를 사용한다. 같은 접촉 상태의 둔격 에너지 배율은 이전의61.54%지만, 상처·기절·승률까지 같은 비율로 줄어든다는 뜻은 아니다. 길이·질량·파손·소리·검술보정·보조팔 연결은 그대로다.

`chicken` 별칭과 정식 `rubber_chicken`으로 실제 Fighter를 생성해 양쪽 `weaponCfg.mBlunt=1.6`을 확인했다. 새 물리/승률 실험과 테스트 코드는 추가하지 않는다. 빌드와 실제 공개 폰 규격 브라우저의 진입·플레이·재시작은 [전달 기록](chicken_blunt_release.json)을 완료 기준으로 삼는다. 기준 커밋 `1628db8b33eb8632325608d425e9d817b091b161`, 원자료는 저장소 밖 `/workspace/halfsword-handoff/chicken-blunt-20261008/`에 보존한다.

사용자의 두 무기 v2 보류 질문은 기존 기록만 검토했다. [10/05 일반 승격](swordsmanship_power_20261005.md) 당시 기존 심한 축 회전으로 두 무기를 제외했다. [10/06 시작 힘점 교정](spin_closure_20261006.md)은 일반판 반영을 완료했지만 기존 보정0.7로 검증했으므로 v2 승격을 함께 하지 않았다. [10/07 연장 관찰](spin_followup_20261007.md)도 v2를 켠 검사가 아니다. 현재는 옛 시작 결함이 계속 미해결인 상태가 아니라 수정된 기반에서 v2 재비교·승격 후속이 남은 상태다. 기존 보정은 유지한다. 이번 수치 조정에 두 무기의 v2 적용이나 새 연구를 포함하지 않았다.
