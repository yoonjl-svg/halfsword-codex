## 2. 근접 밀치기 — 몸통 부딪기 하나, 발차기는 둘째
- 동작 PM: Meyer 1570 Ⅰ.42r·61~63 — 근접 기법은 바인드/뛰어든 순간에, 발→체중→팔 순서, 밀고 곧장 벤다. 클립 키 4개 약 0.45 s, 감기 없음. 발차기는 한 발 서기라 넘어짐 잦음.
- 무기 PM: 고정 힘(320 N) 대신 충격량 J = m_eff·Δv 를 실제 몸 속도에서. 갑옷 무게를 몸 질량에 더함(쿨다운 없이 "무거운 기사는 덜 밀림"). 되돌릴 거리 롱소드 0.5 m·세이버 0.3 m → 같은 J 에 긴 칼이 더 얻음. 지금 shove()는 살짝 떼어내기로 유지.
- 캐릭터 PM: 새 동작은 AI 가 고르는 행동. 조건 = 상대가 clinch 거리(롱소드 1.25 m) 안. 브란 자주·넘어뜨리기 / 이졸데 밀고 곧장 베기(막힌 뒤만) / 랴오 드물게 발차기 / 하인리히 물러서지 않고 칼자루로 누름 / 마르그레테 거의 안 씀, 쓰면 Nachreisen. 시트 persona.close = { rate, kind, then }.
- 디렉터 결론: 입력 = 바인드에서 상대 가슴 쪽으로 짧게 미는 손가락 획(손짓 층에 'push' 판정 추가). 물리 = 무기 PM 안. AI = 캐릭터 PM 시트. 시간 제한·쿨다운 없음. 착수 = R2 첫 시험판(10/2) 뒤 첫 작업(R5 앞당김).

## 3. 둔기 — 레어, 플랜지드 메이스부터
| 후보 | 상징성 | 실물 | 판정 |
|---|---|---|---|
| 플랜지드 메이스 | 15세기 판금 시대 "판금 깨는" 기사 무기, 바이외 오도 주교 | 한손 0.6 m·1.2~1.6 kg, 머리 무거움 | 둔기(mBlunt), Q13 판금 둔기 충격 |
| 모르겐슈테른 | 14~15세기 독일·스위스 민병, 가시 철구 | 0.7~0.9 m·1.5~2 kg, 한손~두손 | 둔기 + 가시 |
| 호스맨스 해머 | 기사의 말 위 망치, 망치머리+부리 | 한손 0.6 m·0.9~1.2 kg | 망치면 둔기, 부리 찌르기(한 무기로 둘) |
- 대안 페르나치(권위의 홀)는 에픽. 추천 순서 메이스 → 망치 → 모르겐슈테른. 시제품 메이스는 롱소드 상대 0~10%(Q13 전). 순서: Q13 구현(디렉터, R3) → R6 무기 계열 → 다시 재기 → 로스터.
- 디렉터 의견: 플랜지드 메이스 레어 먼저. 판금 상대에 강하고 맨몸 상대에 롱소드에 밀리는 상성은 물리 그대로.
