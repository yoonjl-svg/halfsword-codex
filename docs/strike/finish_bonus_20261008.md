# 갑옷 보호와 내려찍기 보너스 제안 · 10/08

**후속 수치 검토:** 사용자는 추가 상한 없는2배·2.5배를 질문했다. 현재 디렉터 추천은 **추가80J 상한 없는2.5배**다. 아래3배/+80은 최초 제안 이력이다. 36.283J 입력의2·2.5배는 기존 검사에서 상한이 작동하지 않아 재실험 없이 각각72.566/90.7075J 근거를 재사용한다. 강한80J 입력은160/200J,120J는240/300J가 된다는 산술 비교이며 해당 무상한 실제 접촉은 미검증이다. 제거 대상은 추가 보너스 상한뿐이며 기존 속도·마무리 자격·갑옷 판정은 유지하는 설계다. 배율은 상처 심각도가 아닌 실효 에너지에 적용한다. 수치 질문을 확정 승인이나 일반판 적용으로 기록하지 않는다.

사용자는 B의 갑옷 보호 원칙을 선택하되, 무조건 즉사 대신 쓰러진 상대에게 온 힘을 싣는 강한 보너스를 요청하고 적정 수치를 물었다. **첫 제안은 실효 찌르기 에너지 3배, 추가분 최대80 게임J**다. 수치 승인·일반판 적용·플레이 검증 완료를 뜻하지 않는다. 일반판 및 기존 B 비교판 코드 변경0이다.

## 확인과 판단

현재 B도 갑옷이 상처를 막지 못하면 `finish=true`로 즉사한다. 새 방향에서는 이 특례를 제거하고 보너스를 갑옷 문턱 **앞**에 적용한 뒤 기존 상처·사망 규칙을 사용해야 한다. `E' = E + min(2E,80)`에서 E는 무기·감정 등을 반영한 게임의 실효 찌르기 에너지다. 실제 힘(N)이나 운동 에너지가 세 배가 된다는 설명은 하지 않는다. 기존3.5kg 찌르기 보조와 energyScale2를 다시 높이지 않는다.

10/07 실제 통제 접촉에서 측정된 롱소드36.283J를 수치 입력 기준으로 재사용했다. 현재 게임의 Combat→strike→applyWound→updateVitals로40개 구성요소 조건을 검사했다. 갑옷·부위·혈액·down/tap·접촉 속도를 명시적으로 준비한 검사이며, 이전 native 장면을 재생하거나 새 실제 전투를 수행한 결과가 아니다. 실제 코드의 계수를 바꾸지 않고 Combat 사본 두 곳만 메모리에서 치환했다. factor1도 **즉사 특례를 제거한 무보너스 대조**이며 현재 B 자체가 아니다.

| 보너스 | 실효 에너지 | 온전한 판금 가슴: 30초 혈액 손실 |
|---|---:|---:|
| 1.5배 |54.42|4.01%|
| 2배 |72.57|13.82%|
| 2.5배 |90.71|23.62%|
| 3배 |108.85|33.42%|

모두 건강한 판금 가슴 상대는 단독 타격 뒤 생존했다. 초기 혈액70%인 별도 통제 조건은3배에서10.83초 뒤 출혈사,2·2.5배에서는30초 생존했다. 다른 상처나 후속 타격 없이 출혈·응고만 진행한 결과다. 3배라도 같은36.283J 입력은 케틀햇120J 문턱에 막히며, 맨머리에는 기존 치명상 규칙으로 사망한다. 더 강한80J 입력은 추가분80J 상한을 받아160J가 되어 케틀햇 위 머리에도 치명상이다. 약한10J 입력은30J로 판금을 뚫지 못한다. 보통 공격에는 보너스0을 확인했다.

**3배 선정 이유:** 2배의 대표 몸통 결과는 사용자가 원한 강한 마무리 기회에 비해 작다. 3배는 몸통의 상당한 출혈과 이미 다친 상대의 사망 가능성을 주면서도 해당 투구 보호를 남긴다. +80 상한은 높은 기본 위력을 무제한 증폭하지 않기 위한 설계 제안이다. 보편적 최적값·역사적 실측·모든 무기의 검증된 균형값이라고 주장하지 않는다.

## 구현 전 남은 좁은 검증

- 가속·질량·중력·물리 충격 자체를 배수로 늘리지 않는다. 실효 피해만 강화하더라도 관통 여부가 달라져 후속 물리는 바뀔 수 있다. 관통 저항/박힘·갑옷 마모와의 일관성을 실제 접촉으로 확인한다.
- 이번 프로브는 energy·질량을 직접 배수로 키우지 않았다. 다만 보너스로 문턱을 넘으면 기존 비보조 둔격 전환을 거치지 않아 반환 energy·통증·갑옷 마모·저항도 달라질 수 있다. 게임 구현 완료본이 아니며 이 차이를 실제 접촉에서 함께 검증한다. 독립 검토에서 이 설명을 정정했으며 원래 실행 소스/결과를 보존했다.
- 대상이 down이라는 이유만으로 모든 공격을 강화하지 않는다. 현재 실제 탭 내려찍기·전진 중 칼끝·머리/몸통 조건에 한정한다. 부상 팔·비스듬한 접촉이 모두 검증됐다고 하지 않는다.
- 기존 즉사 원인 `내려찍기`만 부활을 금지한다. 자동 사망 제거 뒤 부활 캐릭터의 기존 의도까지 우연히 바뀌지 않도록 별도로 검토한다.
- 다음 구현 관문은 현재 실제 내려찍기 장면의 맨몸/판금 대조와 강한 머리 접촉, 최소한의 경계/보통 공격 회귀다. 일반 기본값을 지금 바꾸지 않았다.
