# 내려찍기 진입·접근 교정 · 10/08

사용자가 [기립·내려찍기 조사](recovery_finish_audit_20261008.md)의 개선 실행을 지시했다. 이번 내려찍기 후보는 현재 일반판을 기반으로 **실제 낮은 대상에게만 특수 공격을 시작하고, v2에서도 필요한 거리까지 접근하게 하는 교정**이다. 일반판 승격과 선택형 비교판 전달은 구별한다. 실제 전달 상태는 [전달 영수증](finish_entry_fix_release.json)을 따른다.

## 동작 계약

- 상대가 down/getup이고 가슴·골반(둔기/파손은 머리도)이 충분히 낮을 때 시작한다. 현재 평평한 전투 바닥 기준 진입 높이는 기본 골반 목표의70%인.665m, 진행 중 이탈은 여기에.10m를 더한다. 공격자 가슴보다 최소.20m 낮아야 한다. 이 값은 캐릭터 치수와 높은 kneel/낮은 넘어짐을 구별하는 게임 설계값이며 인체 실측 한계가 아니다.
- 새 시작은 엄격한 조건을, 이미 수락된 동일 상대의 공격만 완화된 이탈 조건을 쓴다. 상대 교체·공격 불능·실제 상승·거리 이탈은 부드럽게 취소한다. down→getup이라는 상태 이름 변경만으로 취소하지 않는다. 자세 보간량 `amt`가 공격 허가를 늦추지 않는다.
- 명시적 자동 접근은 옛 검술 보정 강도0과 분리한다. 전진 요청.63은 기존 기본값.9×.7을 재사용했다. 무기 힘/속도 가중치가 아니다. 걸어 충분한 관통 거리를 얻을 수 있으면 그 거리까지 접근하고 실제 디딤을 마친 뒤 찍는다. 대상이 스스로 사거리 안으로 들어오면 불필요한 다음 디딤 사건을 기다리지 않는다.
- 짧은/파손 무기는 몸 안쪽 끝 목표에 못 닿아도 표면 접촉이 가능하면 시도할 수 있다. 걷지 않는 AI 명시 탭·공격자 kneel은 현재 표면에 닿는 경우만 제자리 특수 공격을 시작한다. 후퇴/진전 없는 디딤으로 접근을 끝냈는데 여전히 닿지 않으면 허공을 찍지 않고 거둔다. 높은 kneel이나 적격하지 않은 대상의 탭은 기존 보통 찌르기다.
- 자세·AI 접근·접촉 보너스가 같은 낮은 자세 판정을 사용한다. 접촉 때 몸의 현재 위치를 다시 보고, native 예측 훅에서는 직전 물리 스텝 준비의 JS 캐시만 읽는다. 예측 중 엔진 호출·캐시 누락 시 native fallback·상태 변경을 금지한다. 현재 실제 접촉은 도달 증거이므로 초기 손 자세의 완전 관통 사거리를 다시 강제하지 않는다.
- 상한 없는2.5배·갑옷·정상 상처·자동 즉사 제거, 검술 보정 v2·중력·일반판 무기 정책을 유지한다. 새로운 조건은 선택형 `finishEntryModel='low'`에서 양쪽 검객에 적용하며 일반판과 이전 A/B는 기존 진입을 유지한다.

## 실제 게임 코드 비교

기준 `4b010726c6e234de072786dbea7073eb1ccd36cc`, 도구 `tools/sim/experiments/finish_entry_20261008.mjs`. 실행 전에 소스·도구를 외부에 복사하고 전후 해시를 확인한다. 플레이어 unified/manual/fresh/bounded, 양쪽 linked/power, 플레이어 centerline, 중력9.81·절단ON이다. 각 A/B는 같은 생성 상태와 요청 입력을 사용한다.

준비 장면은 적 AI 입력을 멈춘 상태다. 전환 장면은2초에 knockDown을 호출하고 같은 tick에 탭했다. 지속 누움은 생성부터 down을 유지하고 초기.25초 동안 가슴/머리에 각40Ns를 가해 눕혔다. 이후 일반 이동 입력으로 접근한 뒤 탭한다. 무릎 장면의 다리 기능.2, 파손 장면의 실제 breakWeapon 호출도 준비 조건이다. 몸 위치/속도를 강제로 바꿔 실제 접촉을 만들지 않았고, 자연 전투 발생 빈도나 승률 실험이 아니다.

롱소드 대표 가슴 접촉의 실효 에너지75.54J/상처 문턱25J, 배46.02/18J였다. 레이피어는94.48/19.03J로 **맞은 곳은 판금 흉갑이 아닌 골반**이다. 이를 갑옷 전 부위의 실제 접촉 검증으로 확대하지 않는다. 낮은 getup에서 공격이 시작된 사례는 상대가 일어서면서 취소됐고 상처는 없었다. 회복 중 상대를 반드시 맞히도록 회복시간·힘을 조정하지 않았다.

별도 실제 Fighter/Skill/Combat 준비 fixture는 높은 몸·새 입력·유지 여유·상대 교체·재입력·후퇴·도달·디딤·캐시·갑옷/2.5배 경계를 검사한다. native step을 실행하지 않는 연결 검사이며 위 실제 물리 비교와 합산하지 않는다. 최종39검사/42fixture와 기존2.5배 피해58검사를 통과했다. 고유 검사 수·최종 실행·소스 해시·공개 모바일 결과는 영수증에 기록한다. 최종 native 비교는14실행·18,480step이며 마지막 제자리 사거리 상실 방어 추가 직전 소스다. 이 비교의 특수 공격은 모두 stand/walkOk여서 그 추가 분기가 노출되지 않는다. 마지막 방어의 무이동 AI·무릎·접근 중 무릎 전환은39검사에 포함한3경계로 검증했고 최종 native 재실행으로 주장하지 않는다.

## 실패와 한계

- 최초 접촉 실행에서 새 자세 판정이 native 충돌 예측 중 몸 위치 API를 호출해 엔진 재진입 오류를 냈다. 캐시 전용 경로로 교정했고, native API가 호출되면 실패시키는 회귀 검사와 실제 접촉 재실행을 추가했다. 중단 실행/불완전 원자료를 성공으로 세지 않는다.
- 최초 표면 도달안은 롱소드가 너무 일찍 접근을 멈춰 실효15.32J로 상처 문턱25J에 못 미쳤다. 힘을 올리지 않고, 걸어서 완전한 관통 거리까지 들어갈 수 있을 때 그 접근을 우선하도록 수정했다.
- 최초 청강검1.2m 준비는 기존 범위 밖이라 특수 공격이 노출되지 않았다. 제외하지 않고 범위 거절 근거로 보존하고, 실제 가까운.6m 장면을 별도 준비했다.
- 완전 기립 순서 개선은 별도 후보다. 내려찍기 성공을 기립 개선 성공으로 보고하지 않는다. 휴대폰 크기의 브라우저 검증과 사용자 실물 폰의 자연스러움 판단도 구별한다.
