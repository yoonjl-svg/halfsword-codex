# 내려찍기 2.5배 일반 적용 · 10/08

사용자가 **추가 상한 없이2.5배**를 선택했다. 실제 탭 내려찍기가 쓰러진 지정 상대의 몸통/머리에 찌르기로 닿으면 실효 피해 판정 에너지를2.5배로 만든 뒤 갑옷·상처·관통을 계산한다. 일반판은 양쪽 검객에 같은 규칙을 사용하며 무기명으로 제한하지 않는다. 자동 즉사는 제거했다. 실제 배포 여부는 [전달 영수증](finish_power_release.json)이 기준이다.

## 바뀌는 범위

- 무기의 실제 속도·질량·중력·모터 힘을2.5배로 만들지 않는다. 보너스는 실효 찌르기 에너지에 한 번만 적용하며 추가80J 상한은 없다. 이미 계산한 무기/감정 효과는 보너스 앞에 포함된다.
- 겨누기/접근/복귀·보통 베기·둔격·서 있는 상대·팔다리에는 이 보너스가 없다. 갑옷에 막히면 기존 비보조 둔격 전환이 남는다. 문턱을 새로 넘으면 관통과 그 뒤 저항·갑옷 마모도 달라질 수 있으므로 물리 결과가 완전히 같다고 하지 않는다.
- 즉시 치명적인 머리/목 마무리 상처는 기존 부활 금지를 유지한다. 살아남은 타격은 부활 금지 상태를 남기지 않으며, 나중의 출혈·기절사는 일반 부활 규칙을 따른다. `finish=true` 자동 사망은 보존용 이전 비교판에서만 남는다.
- 일반 게임 링크는 최신 규칙이다. 기존 `finishV2=baseline/armor` 링크는 이전 A/B 규칙으로 남기고 메뉴와 시험실에 그 사실을 표시했다. 검술보정 등 명시적인 옛 연구 URL도 기존 비교 조건을 보존한다.

## 유보 과제 질문의 판정

**다음 우선순위는 보조팔의 실제 파지와 힘/제동/타격 도움의 연결이다.** 보조손을 잃으면 그립 힘은 이미 사라지지만 손목 한도는 주팔만, 접촉의 팔 도움은 고정값을 읽는다. 한손/양손 공통22N·m 자체는 승인된 보상 설계로 오류라고 재정의하지 않는다. [기존 실제 진단](arm_function_question_20261007.md)을 재사용했다.

최소 아이디어는 양손 도움에서 보조손 몫만 분리해 현재 팔 기능과 파지 가능도에 연결하는 것이다. 실제 보조손 힘 상실과 중복 감산하지 않으며 속도/피해를 일괄 반감하거나 이미 생긴 관성을 지우지 않는다. 공통 파지 상태를 제어 전에 계산해 이전 프레임의 상태를 읽지 않아야 한다. 건강/부분손상/파지상실의 롱소드·츠바이핸더에서 제동 넘침·재베기·실제 접촉을 좁게 비교하고 절단/부활/재시작 상태 초기화를 확인하는 계획이다. 구체적 분담 비율은 미정이며 이번에 수정하지 않았다.

**모노호시자오·라이트세이버 v2는 후순위 승격 검토다.** 옛 시작 급회전은 [축 위 힘점 교정](spin_closure_20261006.md)으로 이미 해결했다. [잔여 회전 연장 관찰](spin_followup_20261007.md)도 재사용한다. 예전 폭주를 현재 미해결 결함으로 다시 보고하지 않는다. 승격 시 현재 축점에서 v2 유무의 준비→반전→복귀와 실제 접촉을 짧게 비교하면 된다. v2 제외 자체를 게임 진행의 필수 해결 조건으로 삼지 않는다.
