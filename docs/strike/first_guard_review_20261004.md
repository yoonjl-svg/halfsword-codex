# 한손검 첫 자세의 근거 확인 · 2026-10-04

사용자가 어깨 가까운 높이에서 팔을 앞으로 내민 첫 자세가 검술 근거를 갖는지 물었다. 작업 시작02:47:28 UTC, 예상10–15분. **앞으로 뻗어 겨누는 가드는 실재하지만 현재 공통 시작 자세를 검술 표준의 재현으로 검증한 근거는 없다.** 이번에는 원인·근거를 조사했으며 게임 코드와 기본값은 변경하지 않았다.

## 실제로 확인한 원전

Richard F. Burton, *A New System of Sword Exercise for Infantry* (1876), [공개 원문](https://www.gutenberg.org/cache/epub/59336/pg59336.txt). 이번 디렉터가 II장 Stand on Guard, §4 Engaging Guards, §5 Guards/Parries의 해당 문단을 직접 읽었다. 전체 책·모든 검술 유파·청강검 교본을 읽었다고 확대하지 않는다.

- 기본/밖 가드: 폼멜을 오른 가슴 앞에, 칼끝을 상대 오른눈으로, 오른팔을 내밀되 팔꿈치는 “an easy bend”로 설명한다(보존 텍스트581–588·848–857줄).
- High Tierce: 손을 어깨 위~오른눈 높이로 올리는 별도의 머리 방어 자세이며 칼은45°(946–949줄). 낮은 가드는 팔을 접고 손을 내린다(951–954줄).

이는 앞쪽으로 팔을 내민 자세의 존재를 뒷받침한다. 청강검/세이버/레이피어에 같은 손 높이와 방향을 기본 대기값으로 주어야 한다는 근거는 아니다. 옛 [한손 문헌 조사](../weapon_motion_sources_one_pole.md)의 Fabris/terza 서술은 검색요약 단계였고 모든 좌표·각도는 추정이다. [기존 모션 출처](../motion/sources.md)의 Burton moulinet 본문 열람은 앞선 담당자의 기록이며 정지 준비 자세와 구분한다.

## 코드와 실제 초기 팔

생성 순간 주팔이 완전히 앞으로 뻗어있는 것은 `partDefs`의 관절 기준 자세다(`fighter.js`57–64줄). 코드 주석의 목적은 엔진의 기준 각도이며 검술 선택의 근거가 아니다.

선택형 B는 첫 패드(.15,.10)를 사용한다. 칼 하향−6.30°를 수평으로 바꾸려 y를0→.10으로 올렸고, 같은 y가 raw 손 높이에도 들어간다(`fighter.js`815·1885–1904줄). 이후 어깨 기준 거리 비율을 곱한다. 따라서 검날 수평을 확인한 것만으로 팔 높이·뻗음까지 적절하다고 할 수 없다.

| B · 보정끔 · 시작1.9초 | 손목이 어깨보다 높은 양 | 실제 팔꿈치 굽힘(직선0°) | 어깨→손목 |
|---|---|---|---|
| 청강검 | 8.28cm | 48.03° | .516m |
| 세이버 | 8.17cm | 50.60° | .511m |
| 레이피어 | 8.33cm | 47.99° | .516m |

명목 팔 길이는.57m이며 이 시점은 약90% 도달, 완전히 편 팔은 아니다. 생성 순간은 공통 수평·직선이다. 사진에서 높게 앞으로 내민 느낌과 실제 팔꿈치 굽힘을 구분한다. 일반 legacy 전부/입력 후 자세로 수치를 확대하지 않는다.

## 재현과 판정

[설정·수치·파일/원문 해시](first_guard_review_20261004.json)가 단일 지도다. 현재 `164a204398e6b9bbf677a06a9a69e493b58b1cba`의 실제 Fighter/Skill/Rapier를 첫1.9초3회 관찰했다. 기존 첫 자세16종을 다시 검사하지 않았다. 새 관찰3회는 기존 forward-ready 원자료의 해당 native trace와3/3 exact다. 이는 새 팔 관측을 추가한 좁은 재생이며 개선 효과 실험이 아니다. 원래 반응형 적AI가 있고 플레이어 입력·강제 자세/힘/상처는 없다.

동결 probe는 저장소 밖 원자료 경로에서 JSON의SHA로 확인한 뒤 해당 환경의 절대 import 경로를 매핑해 사용한다. Node24·locked Rapier/Three, 실행 당시 명령은 raw.command에 있다. 당시 고정 소스에서 새 출력 경로를 쓰며 이미 기록한3실행을 관례적으로 반복하지 않는다.

현재 판단은 **무기별 준비·겨누기·방어의 기능을 구별해 초기 자세를 다시 설계할 필요가 있다**는 것이다. 손 높이/도달과 칼 방향을 함께 검사하고, 조작 중에는 사용자의 손 목표를 보존한다. 원문 재현·사람 자연스러움 수락을 선언하지 않고, 일반판 메이저 변경은 구체적인 비교 뒤 사용자 확인을 받는다.
