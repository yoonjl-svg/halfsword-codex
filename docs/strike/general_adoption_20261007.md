# 승인 성과의 일반판 채택

사용자는 “변경안의 테스트에서 특별히 이상한 점을 찾지 못했어”, “지금까지의 성과 전체를 일반판에 적용하자”라고 지시했다. 승인 기록일은2026-10-07 KST(10-06 UTC), 정확한 메시지 시각은 미기록이다. 이미 준비·공개한 후보의 일반 승격이며 새로운 힘/보정식 실험은 아니다.

| 일반 플레이어 무기 | 새 기본 설정 |
|---|---|
| 츠바이핸더 | 회복fresh＋절삭 반작용centerline |
| 롱소드 | 절삭 반작용centerline＋재베기bounded |
| 청강검 | 재베기bounded |

기존 단일 검술 보정v2 근접12종과 수동 팔, 모바일 세로 입력, 사운드 및 일반 오류 수정은 유지한다. 두 얇은 양손 무기의 시작 축점 수정도 유지하며 해당 무기의v2 제외는 바꾸지 않는다. 일반 진입·카드 무기·재시작마다 정책을 다시 계산하고 적/저장 선호/옛A/B에는 새 기본값이 새지 않도록 분리한다.

명시적인 연구 URL은 기존 조건을 유지한다. 잘못된 strict 비교 URL은 이미 정해진 계약대로 현재 일반값으로 복귀한다. 별도 청강검profile/transported/armorCausal 조합은 과거12종 일반 채택에서도 제외됐던 연구다. transported는 현재bounded의 적용을 막으므로 이 조합을 이번 일반 성과에 무검증으로 섞지 않았다. 중력15/25%·철회 지지/절삭·기각 감쇠 후보도 채택하지 않는다.

사용자 지시로 **재베기 개입 후 실제 능동 절삭 위력(청강검 접촉 포함)**과 **일부 전투 중 잔여 축회전**은 후속 검증으로 유보한다. 기존 원자료/실패/다음 노출 조건은 [재베기 기록](recut_closure_20261006.md)·[회전 기록](spin_closure_20261006.md)을 재사용한다. 이번에 두 연구를 재실행하거나 통과로 바꾸지 않는다. 회복 후 실제 수동 타격과 부상 재입력의 기존 통과 범위를 다시 미완료로 되돌리지 않는다.

검증은 적용 범위·비교판 격리와 실제 빌드의 일반 진입/터치/재시작에 집중한다. 물리 공식·상수는 동일하므로 이전 개별 물리 검사와 원자료를 재사용한다. 롱소드의새일반 조합이 과거개별A/B와 같은 전투결과를 낸다는 주장은 하지 않는다. 최종 소스·공개 코드·모바일크기 Chromium 및 공유보고 발행은 [전달 영수증](general_adoption_release.json)을 따른다. 실물iPhone 검증은 아니다.
