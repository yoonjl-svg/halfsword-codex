# 기존 회복 B에서 중력만 바꾸는 임시 비교

사용자가 중력9.81·검술 보정v2·기존B에서 중력만15%/25% 높인 임시판을 요청했다. 기준 소스는 `7f902cd6724f5391cd436d333fea0174f37d3df8`이다. 기존B는 최근 회복 비교의 츠바이핸더 `stanceV2=fresh`로 고정한다. 별도 타격 반작용B와 아직 검증 중인 통합 후보를 섞지 않는다.

| 주소 설정 | 세계의 아래쪽 중력 크기 |
|---|---:|
| `gravityV2=base` | 9.81 |
| `gravityV2=plus15` | 11.2815 |
| `gravityV2=plus25` | 12.2625 |

셋 모두 플레이어 츠바이핸더·현재 단일 검술 보정v2·수동 팔·회복fresh, 상대 롱소드/보통·기존 제어, 기존 절삭/지지다. 바꾸는 값은 새 Rapier World의 gravity.y 하나다. 중력은 상대와 떨어진 물체에도 적용된다. `PHYSICS.gravity`, 보행/균형/팔의 기존9.81 힘 계산, 토크·피해 배율·시간 간격은 바꾸지 않는다. 따라서 중력을 높였을 때 기존 지지·보정이 충분한지는 이번 체감 비교의 대상이다.

첫 생성·재시작에 같은 값을 적용하고 저장 선호는 바꾸지 않는다. 잘못된 값·중복·다른 시험과의 혼합은 일반판으로 돌아간다. 일반판 중력은9.81, 일반판 회복/절삭은기존값이다. 이 요청은 임시 시험 공개이며 새 일반판 기본값 승인으로 해석하지 않는다.

검증·실제 전달은 [영수증](gravity_v2_release.json)을 기준으로 한다. 기존 B와 기준판의 같은 입력/상태 일치, 세 중력의 실제 실행, 모바일 진입·조작·재시작·일반판 복귀 및 공개 바이트를 구분해 기록한다. 유한한 실행이나 정상 진입을 자연스러움·높은 중력의 우수성으로 주장하지 않는다.

플레이 확인은 걷기·베기·옆 디딤·넘어진 뒤 일어서기를 같은 방식으로 비교한다. 어느 값이 덜 뜨는 느낌인지와 무게감/조작의 부담이 지나치게 커지는지만 먼저 받는다. 무기 전체 확대나 중력에 맞춘 힘 재설계는 이번 범위가 아니다.
