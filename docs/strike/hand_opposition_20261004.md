# 쥔 손 엄지 방향 정정 · 2026-10-04

사용자가 앞선 청강검 사진의 엄지를 “오른팔에 왼손”처럼 보인다고 지적했다. 이전 좌우 거울·finite·물리/RNG 검사는 해부학적 엄지 방향 검사가 아니었다. 작업 시작02:29:58 UTC, 예상20–30분. 기준 `c23398e01b722ec9f28398cd576f68e49cf2fe04`.

## 원인과 수정

쥔 손은 손바닥−X/손잡이쪽+X·검지쪽+Y를 기준으로 오른손 손가락이+Z에서−Z 끝으로 감긴다. 이전 대칭 캡슐은−Z에 놓여+Z로 뻗어 엄지의 맞감김이 반대였고 뿌리와 끝도 구분되지 않았다. 이제 엄지 뿌리/두툼한 손바닥→관절→끝을 연결하고+Z에서−Z로 감싼다. 왼손은Z를 거울로 만든다. 빈손의 기존 올바른 기준까지 통째로 뒤집지 않는다.

일반 손 표시만 변경했다. 실제 손목 앵커·무기/팔 물리·한손 선택형·시작 입력·힘·감쇠는 변경하지 않았다. 기존 무기별 엄지 펴기와 빈손 선택을 유지한다. 표시 메시는 기존 병합을 거쳐 draw 수가 늘지 않는다.

## 확인과 한계

- 실제 게임 손 켬/끔3쌍(청강검·롱소드·권총)의 native 초기/전체궤적·body/collider/joint 수·다음 난수가 exact다. 첫1.9초 관찰이며 실제 절단/낙검 전투 수락으로 확대하지 않는다.
- 완성 빌드 청강검·세이버·레이피어·롱소드·권총5종, 양손의 바깥/반대측20장과 mobile portrait 진입·trusted Start/Pause·새 Fighter 재시작을 확인했다. 추가 손바닥 시점은 가려진 엄지 뿌리를 확인하기 위한 화면 검사다.
- 독립 검토에서 명백한 역감김/분리 엄지는 발견하지 못했다. 청강검 바깥 실루엣은 수정 부위가 가려 변화가 작다. 권총 손목/손잡이 사이V형 틈은 외형 한계로 남는다. 이 화면 통과를 사용자 체감 수락이나 실제 기기 성능 인증으로 쓰지 않는다.
