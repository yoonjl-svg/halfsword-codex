# 관성과 조작의 사실감 · 감독 기준

2026-10-03 사용자 지시 반영. **목적은 반응을 빠르게 만드는 것이 아니라, 무거운 검을 몸으로 다루는 결투를 플레이어가 느끼게 하는 것이다.** 의도된 지연·멈추기 어려움·큰 베기 후 빈틈은 개선 대상이 될 수 있고, 물리와 사람 동작이 유지된다면 더 두드러지게 만드는 후보도 허용한다. 오류를 입증해야만 개선 후보를 만들 수 있다는 제한은 두지 않는다.

## 디렉터가 먼저 결정할 것

매 후보는 플레이어에게 전달할 경험과 바꿀 한 가지 제어/물리 경로를 먼저 적는다. 예를 들어 ‘힘을 실어 벤 뒤 쉽게 방향을 바꾸지 못해 다음 행동을 준비해야 한다’가 목표라면, 목표 오차나 멈춤 거리가 커졌다는 이유만으로 기각하지 않는다. 반대로 지연이 커졌다는 이유만으로 관성 구현 성공이라고 하지 않는다.

디렉터는 검의 가속·계속 진행·제동 부담이 무기 질량 분포·근력·접촉·몸의 반작용과 연결되는지 판단한다. 순간 위치/속도 변경, 피해 배율, 근거 없는 입력 대기 시간을 붙여 무게감을 대신하지 않는다. 입력 거리/속도 보정은 폰의 조작 공간 문제이며 검의 질량·근력을 키우는 것과 구분한다.

실험의 역할은 원인과 실제 개입을 확인하고 붕괴를 걸러내는 것이다. 실제 게임 실행·관찰 불변성·기존 설정 대조에 이어, 발사·관절 벌어짐·비정상 회전·반작용 불일치·실제 접촉 후 반복 조작을 검사한다. 기존 대비 정상 범위의 변화와 새 오류를 구별한다. 관절 제약 안에 있다는 이유만으로 인간다운 동작이라고 판정하지 않는다.

디렉터는 실제 화면에서 검과 팔만 보지 않고 몸통·다리·회복 동작을 함께 검토한다. 숫자가 유한하거나 AI가 이겼다는 사실은 이 판단을 대신하지 않는다. 화면 관찰 역시 인간 동작의 실측 검증과 같다고 주장하지 않는다.

## 체감으로 결정할 것

공학 검사를 통과했지만 무게감과 다루기 어려움의 균형이 수치로 정해지지 않으면, 비교 가능한 폰 플레이판을 제공하고 사용자에게 짧은 비교를 요청한다. 전체 물리를 완성할 때까지 체감 검증을 미루지 않는다. 디렉터가 후보를 고르고 실제 조작과 화면을 확인한 뒤 요청하며 원인 진단을 사용자에게 맡기지 않는다.

체감 질문은 하나로 좁힌다. **‘더 설득력 있게 무거운 검을 몸으로 다루는 느낌인가, 아니면 명령이 늦고 몸이 이상하게 움직이는 느낌인가?’** 같은 무기로 들어 올리기·힘을 실은 내려베기·급한 방향 변경을 짧게 비교한다. 사용자는 수치·상처 프레임·세부 재현 조건을 제출할 필요가 없다.

두 판은 어떤 경로가 다른지 확인 가능해야 한다. 입력 보정·검술 보정·다른 물리 후보를 한꺼번에 섞지 않는다. 상대까지 바꿨다면 적의 행동 변화도 포함된 비교라고 명시한다. 주플레이어의 저항을 먼저 보는 비교와 상대도 같은 규칙을 쓰는 실제 결투 회귀를 구분한다.

감각 수락이 있어도 명백한 오류나 사람답지 않은 붕괴를 유지하지 않는다. 공학 통과만으로 사실감을 확정하지도 않는다. 사용자 의견과 실험이 엇갈리면 디렉터가 원인·위험·게임상의 이득을 설명하고 도입/수정/보류를 판단한다. 메이저 일반판 반영은 구체적인 비교 결과 뒤 사용자 확인을 받는다.

지금 추가 테스트 요청은 없다. 기존 실패 지지·절삭 후보의 철회는 유지한다. 이 감독 기준은 실패 후보를 되살리는 승인이나 새 일반판 기본값 변경이 아니다.
