## 구현과 적용 범위

- **수평 시작은 선택형 B만:** 기본 패드(.15,0)가 raw 방향에서−6.30°를 명령했다. 최초 패드와 Skill 초기 상태를(.15,.10)로 함께 초기화하여 목표0°로 만든다. player/manual/비사격 한손/첫 입력 전만 적용한다. native 자세·속도·힘을 직접 바꾸지 않는다. 실제 청강검은1.9초에−6.278°→+0.010°로 추종했다. 처음 실제 검을 즉시 수평으로 고정한 것이 아니다.
- **엄지 손은 일반판·두 검객:** 기존 구체를 숨기고 같은 재질의 미튼·엄지·커프를 붙인다. 무기별 엄지와 빈손 표현, 실제 권총 손잡이 축, 좌우 거울·양손 쥠·낙검/분리 표시를 분기한다. 실제 전완 손목에 고정하므로 보조손을 자루 목표로 순간이동시키지 않는다. 손마다 보이는 draw2개. 기존4구체 대비 전체4손 draw4개 증가다. 실제 기기 성능 점수는 측정하지 않았다.
- 무기별 쥠은 원본 저장소의[손 v2](https://github.com/yoonjl-svg/halfsword/commit/0b141acac19dcfe171d283c411ac164143d57962) a/b/t/off를 참고했다. 해당 모듈은 확인한 main `bcf581d`에 연결돼 있었고 공개 웹은 방문하지 않았다. 우리 geometry·손목 고정·권총 축은 별도 구현이다. 원본 저장소를 수정하지 않았다. Three 생성의 게임 난수 소비를 별도 시드로 격리했다.
