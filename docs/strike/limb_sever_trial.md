# 사지 절단: 관절 단위 시험안

2026-10-01 사용자 요청으로 준비한 독립 시험이다. 일반 게임은 `COMBAT.limbSeverTrial=false`이며 `?limbTrial=1` 접속에서만 켜진다. [휴대폰 시험 화면](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html)은 앞서 비교한 B(받침 .1 / 균형 회복 보조 on·1)를 쓴다. 본판 기본값이나 전신 물리 개선의 수락을 의미하지 않는다.

## 구현 범위

- 양쪽 팔꿈치에서 아래팔, 양쪽 무릎에서 정강이+발을 기존 실제 관절로 분리한다. 어깨/고관절 절단이나 임의 위치의 피부·옷·판금 메시 절삭은 구현하지 않았다.
- 실제 `Combat.strike`의 통과 베기이며 박히지 않은 상처, 심각도 1.2 이상, 적중 부위의 실제 관절 앵커에서 8.5cm 이내가 조건이다. 부모/자식 부위 모두 검사한다. 이 수치는 **게임 시험용 가정**이다. 인체 조직 파괴 실험이나 스포츠 논문에서 얻은 절단 문턱이 아니다.
- 분리 순간 몸체의 질량·선속도·각속도와 위치를 보존한다. 새로 날리는 힘을 더하지 않는다. 원래 접촉 처리의 이번 스텝 저항은 실행한다. 떨어진 조각의 후속 절삭 캐시는 없애고, 여전히 붙은 위팔/허벅지는 이후 접촉에도 저항한다. 기존 drag를 이용하며 조직 파괴에너지/완전한 에너지 보존 모델을 구현한 것은 아니다.
- 분리된 관절의 활성 모터를 끄고, 정강이와 발 사이의 내부 관절은 수동 제한만 남긴다. 전완에 따로 걸던 중력 보상도 차단한다. 공격 팔을 잃으면 무기를 놓고 반대팔을 잃으면 양손 잡기를 중단한다.
- 분리 부위를 본체 COM·보행 기준 체중에서 제외하고 보행의 무게 캐시도 갱신한다. 물리 몸체 자체의 질량은 지우지 않는다. 원래 보행의 추가 발 질량(지지 발당 2kg)은 다리 분리 시점 그대로 동결한다. 이 기존 안정화 장치까지 현실적이라고 판정하지 않는다.
- 다리를 잃은 경우 기존 두 다리 보행·기립·골반 받침·upright 보조를 중단하고 동적으로 쓰러진다. 한 다리로 버티기, 기기, 부축받아 일어나기는 아직 없다. 일반적인 다리 부상의 기립 문제까지 해결한 것으로 간주하지 않는다.
- 떨어진 부위의 기존 출혈 예산은 없애고 절단을 일으킨 상처의 출혈을 남은 쪽 단면에 한 번만 귀속한다. 분리 부위는 바닥과만 충돌하며 새 근접 피해·총알 피해 대상에서 제외한다. 총알과 레이저는 조각을 건너뛴다. 분리 후 부활/재생은 없다.
- 양쪽 단면과 짧은 초기 분출을 표시한다. 피 끄기는 회색 단면으로 표시하고 분출을 끈다. 시각 효과 자체는 전용 난수로 만들어 전투 난수 흐름을 소비하지 않는다.

## 전투와 시연의 구분

`limbTrial=1`만 지정한 전투는 실제 접촉과 기존 타격 판정을 통해서만 절단한다. 모르겐슈테른은 `edged=false`여서 이 절단을 만들지 않는다.

`limbDemo=armS` / `limbDemo=legF`를 추가한 별도 시연은 싸움 시작 1초 뒤 상대에게 합성 상처를 한 번 준다. 표기와 이벤트 `source='synthetic-preview'`로 구분한다. 이는 절단 후 몸·조각·무기의 움직임을 곧바로 확인하는 용도이며 실제 베기 강도나 절단 발생률의 근거로 사용하지 않는다.

## 검증과 수락

기준 커밋은 `1eaa1e25497a12f121fcb054f5921cd100867f07`이다. 실제 Rapier 합성 상처 검사와 브라우저 시연, 실제 접촉 경로를 구분해 검증한다. 독립 감사에서 절단 순간 저항 생략, 총격 피해 우회, 일반 무장해제의 비의도적 변경, 보행 체중 캐시 잔존을 발견해 수정했다.

- `node tools/sim/limb_sever.test.mjs`는 기본 off·네 절단 루트·거부 조건·질량/속도 보존·사지 제어 차단·출혈 귀속·총격 배제·부활 차단·5초 후 상태를 검사한다. 별도로 실제 Rapier 접촉→기존 Combat 경로의 전완/정강이 절단을 검사한다. 후자는 초기 위치/속도를 정해 놓은 접촉 시험이며, 사람의 입력으로 그 타격을 만들 수 있다는 증명은 아니다. 원자료는 기본 `/tmp/halfsword-limb-sever.json`에 쓴다.
- 모바일 크기 Chromium에서 네 링크를 실제 탭하고 가로로 회전해 싸움 시작 뒤 2초 넘게 실행했다. 네 경로의 무기·B 설정·절단 옵션·시연 이벤트·단면 생성·유한한 물리값을 확인했고 JS/HTTP 오류는 없었다. 실제 휴대폰 성능/사용자 체감 청취는 별도다.
- 다리 시연의 2/4/6초 관찰에서 분리 부위는 바닥에 가라앉고 4/6초 속도 0이었다. 본체 골반은 약 .884m에서 .443m로 내려갔지만 6초에 완전히 옆으로 눕지는 않았다. 자동으로 자연스러운 쓰러짐을 수락하지 않는다.
- 이전/현재 소스로 실행한 기본 off 양쪽 AI 3초의 전신 위치·회전·속도·상태 추적이 같았다. 기존 받침 관련 세 검사도 통과했다. 기존 `decap_check.mjs probe`는 양쪽 모두 단독 실패 `못 지나간 목 베기` 조건 획득 실패로 exit 1이었으며 전체 로그가 바이트 단위로 일치했다. 새 회귀로 관찰되지는 않았지만 전체 참수 검사 통과라고 부르지 않는다.

일반 게임 적용은 사용자의 플레이 확인 뒤 결정한다. 단면의 자연스러움·부상 후 대응·전투 발생률은 자동 검사의 유한성이나 상태 이름만으로 수락하지 않는다. 전신 힘 생성·전달 연구는 [스포츠 생체역학 연구](sports_biomechanics_research.md)와 [물리 개선 계획](physical_realism_plan.md)에서 계속한다.
