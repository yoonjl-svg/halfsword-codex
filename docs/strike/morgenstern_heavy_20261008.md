# 무거운 한손 모르겐슈테른 · 2026-10-08 KST

사용자가 한손으로 쓰는 무거운 철퇴, 우화 방식의 조건부 가시 찌르기, 갑옷 무시 없는 타격 차별화를 요청했다. 후속 지정은 **철구 지름8cm·전체71–72cm**다. 구현값은 **71.65cm·2.2kg**, 선택형만 전달한다. 일반 뽑기에는 넣지 않는다. 현재 공개 확인은 [전달 영수증](morgenstern_heavy_release.json)을 따른다.

## 역사 자료와 재구성의 경계

- [Royal Armouries VIII.70](https://royalarmouries.org/collection/object/object-1470): 헝가리, 약1600년, **64.8cm·2.1kg**, 손잡이21cm, 16개 날개형 머리·속 빈 강철 자루·나무 손잡이. 짧은 형태로 한손 사용을 추론하지만 해당 목록은 한손이라고 명시하지 않는다. 이것은 가시 구형 머리가 아니다.
- [Met14.25.171](https://www.metmuseum.org/art/collection/search/26199): 독일16세기, **73.2cm·822g**, 강철·나무, 소켓 포함 머리 길이21.6cm. 긴 치수와 나무 자루 결합 구조의 참고다. 무거운 표본의 근거와 같은 유물이 아니다.
- [Royal Armouries VII.898](https://royalarmouries.org/collection/object/object-31359): 나무 구형 머리·철 띠·12개 가시와 위쪽 가시, 자루 보강대. 가시 철퇴의 구조 변형이 실제로 있었음을 보여준다. 현재 자루는 목록에서 현대 것으로 표시돼 있어 그대로 실측 원형으로 삼지 않는다.

우리의8cm 강철 머리·71.65cm·2.2kg 조합은 **설계 재구성**이다. 이 조합 전체가 실물로 확인됐거나 역사상 한손 무기의 최대치라고 주장하지 않는다. 2.1kg 실물보다4.8% 무겁고10.6% 길어, 실물과 같은 취급성을 입증한 것도 아니다. 큰 장대 무기·총 결합 무기·19세기 복제품의 무게를 한손 한계로 사용하지 않았다.

## 질량과 외형

꽉 찬8cm 강철 구는 밀도7800kg/m³에서2.09104kg다. 이를 가벼운 구로 취급하지 않는다. 자루가 들어가는 **반경17mm·깊이75mm의 막힌 소켓**을 두고 윗부분5mm는 강철로 남긴 설계다. 소켓 원리는 자료에 있지만 이 치수는 가정이다. 빈 껍질로 소급 설명하지 않는다.

13개 가시는 돌출25mm·밑반경7mm 원뿔로 계산한다. 자루가 들어오는 아래 축에는 가시가 없다. 최대 가시 폭13cm, 끝 좌표+0.615m, 마개 최저점−0.1015m다. 강철 머리 관성은 구에서 소켓의 체적 관성을 빼고 각 가시의 자체 관성·평행축 이동을 더했다. 머리 COM 기준 휘두름 관성0.0012493731, 축 관성0.0014672537kg·m²다. 나무는 원뿔대 체적 적분을 썼다. 메쉬의 다각형 표면·작은 겹침은 계산상 회전체의 시각 근사다.

실제 엔진: 총질량2.20000005kg, COM y0.49056929m, 손 기준 휘두름 관성0.58168082kg·m². 옛1.8kg판의0.43604965보다 약33.4% 크다. 토크 상한·근력·중력은 올리지 않는다. 무게에 따른 느린 회수와 짧은 사거리가 비용이다.

충돌 머리는 반경53mm 구 하나다. 개별 가시 사이 빈 공간·국소 압력은 모델링하지 않는다. 따라서 정확한 가시 재료역학/관통 깊이의 검증이라고 부르지 않는다. 자루 콜라이더는 사각 단면, 겉모습은 원형이다. 부위별 재질 API가 없어 나무 자루 소리·반발도 현재 강철 재질을 상속하는 제한은 남는다.

파손선은 y0.48675m로 머리와 고정대 아래다. 중간 설계에서 칼 기본 파손선이 철구 가운데를 지나 물리 철구가 남는 결함을 발견해 `breakAt=.05`와 길이 구분을 맞췄다. 최종 실제 파손 후 질량0.34062901kg, 손 관성0.02178407이며 머리·고정대의 충돌 그룹은0이다. 48스텝 격리 검사의 잔류 접촉·충격은0; 온전한 무기의 같은 접촉은0.06586N·s였다.

## 가시·타격·조작

우화의 검토된 `646319e8f0f38ef17b886b0abe508caed1a7ece0`에서 **날 없는 온전한 머리의 앞쪽 축방향 접촉을 찌르기로 다루는 원칙**을 참고했다. 갑옷 무시 특례는 옮기지 않았다.

- `spike=true`, `edged=false`, `mCut=0`, `mThrust=.35`. 온전한 머리 접촉, 축방향 정렬>.75, 머리 구간 t>.8일 때만 찌르기를 시도한다. 측면·자루·파손 후는 둔타다. 찌르기검의 넓은 판정창·갑옷 틈 보정은 받지 않는다.
- 살·옷·갑옷 저항을 넘지 못하면 가시 상처와 특례 마무리 즉사를 모두 막는다. 관통 실패가 둔격 효과까지 없애지는 않는다. 보통 무기 마무리 규칙은 바꾸지 않는다.
- 구형 머리 옆면이 닿는데 중심선 예측만 앞끝 찌르기라고 판단하는 실제 오판을 재현했다. 새 가시는 **첫 실제 접촉의 물리 응답을 유지**하고 그 접촉점이 관통 가능한 때만 후속 겹침을 연다. 다음 스텝에도 실제 접촉/저항을 다시 확인한다. 이것은 첫 충격 뒤 계속 관통할 운동이 남음을 보장하지 않는다.
- 직접 시험 주소에서 플레이어의 현재 manual 팔·검술 보정v2·fresh 회복·bounded 재공격을 사용한다. 저장 설정은 고치지 않는다. 옛 `supportProbe` 비교 주소/명시적 legacy는 해당 제어 설정을 유지한다. 시험 무기의 제원 자체는 최신값으로 바뀌었으므로 옛 URL을 과거 빌드 재현이라고 부르지 않는다.

## 참치와 둔타 계수

게임의 에너지는 실제 접촉 유효 질량/속도로 계산한 에너지에 공통 배율과 무기 계수를 곱한다. 이는 실제 상해 역학의 J 보정식이 아니다.

- 둔타1.5에서6자유 휘두름＋8격리 접촉＋6짧은 AI를 실행했다. 계수2.1 변경 후에는 영향받는8접촉만 다시 검사했다. 무접촉6휘두름은 질량·제어·입력이 같고 둔타 계수가 사용되지 않아 재사용한다.
- **6 AI 결과는 밸런스 근거에서 제외한다.** unified 플레이어를 AI 손 목표로 구동하면서 실제 폰 입력 계약을 연결하지 않았고, 반대 자리의 절삭 대상 포인터도 빠졌다. 당시5패/1시간초과를 유효한 승률로 보고하지 않는다. 실제 코드 실행/유한값 참고 자료로만 남기고 승률을 높이려 계수를 맞추지 않았다. 재현 도구의 후속 AI 모드는 양쪽 기존 AI 제어로 바로잡았지만 이번에는 재실행하지 않았다.
- 폰 크기 브라우저는 실제 터치·이동·중단/재개·재시작2회, 저장 설정 유지, 일반 롱소드와 옛 연구 제어를 검사한다. 실제 공개 빌드의 바이트 일치·실행 결과는 전달 영수증에 별도 기록한다. 실물 휴대폰 장시간 성능이나 사람이 느끼는 무게감은 미확인이다.

최종 사람 확인은 **큰 머리와 앞쪽 무게가 칼과 구별되고, 휘두른 뒤 회수가 납득되는지**다. 일반 채택·전용 AI 유파·둔기 전신 골절·개별 가시 접촉은 완료 범위에 넣지 않는다. 실패한 지지·절삭 후보나 전신 물리 변경을 되살리지 않는다.
