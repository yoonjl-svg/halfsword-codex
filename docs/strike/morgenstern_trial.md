# 고정 철구 모르겐슈테른 시험안

> **이 문서는 초기1.8kg/79cm/찌르기 없음 설계의 보존 기록이다.** 2026-10-08 사용자 지정8cm 철구·71–72cm 길이 이후 현재 제원·검증·제한은 [무거운 한손 시험안](morgenstern_heavy_20261008.md)을 따른다. 아래 과거 수치를 현재판으로 사용하지 않는다.

사용자가 요청한 둔기를 고정 가시 철구와 나무 자루의 한손 무기로 구현했다. 사슬이나 별도 머리 관절은 없다. `src/weapons.js`의 `morgenstern`은 기존 단일 무기 강체·구형 머리 콜라이더·손 관절을 쓴다. 기존 `Fighter`의 실제 질량, COM, 관성을 이용하며 타격 배율을 올리지 않았다.

## 선택과 범위

- 주소에 `?weapon=morgenstern&foeWeapon=longsword`를 붙이면 기존 본판의 무기 선택 경로에서 시험할 수 있다. 기본 롱소드와 일반 카드 15종 목록은 그대로다. `trialOnly` 후보는 `TRIAL_WEAPON_LIST`로 별도 노출한다.
- 강제 카드 `?cards=morgenstern,longsword`도 기존 id 선택 경로로 해석되지만 카드용 WebP는 아직 만들지 않았다. 첫 시험은 위 고정 무기 URL을 쓴다.
- 한손 자세(`oneHandStance`)는 기존 경로를 쓴다. `motion_library`는 본판에서 비활성이라 둔기 기술표/날 비틀기 제거가 자동 적용되지는 않는다. AI는 기존 롱소드 유파와 미측정 무기의 길이비 간격 보정을 사용한다. 전용 유파나 새 AI 수치는 넣지 않았다.

## 제원: 대표 설계 가정과 계산값

특정 박물관 유물이나 제작사 표본의 실측 제원이 아니다. 아래 치수·재료별 질량은 **대표 설계 가정**이며 역사적 표준이라고 주장하지 않는다. 관성은 그 가정에서 계산했다.

| 부품 | 질량 kg | 손 원점 기준 중심 y m | 콜라이더 |
| --- | ---: | ---: | --- |
| 나무 자루 | 0.40 | 0.210 | box 반치수 0.022 / 0.310 / 0.022m |
| 끝 장식 | 0.05 | -0.115 | ball 반경 0.025m |
| 철 고정대 | 0.10 | 0.480 | box 반치수 0.028 / 0.035 / 0.028m |
| 철구와 고정 가시 | 1.25 | 0.550 | ball 반경 0.090m, index 3 |

보이는 철구 반경 0.080m, 가시 돌출 0.020m다. 여섯 축 방향과 여덟 대각선에 총 14개 가시를 결정적으로 그린다. 머리 표면과 가시 끝은 충돌 외피에서 각각 약 1cm 차이이며 개별 가시 콜라이더는 없다. 이 외피는 둥근 강체 충돌의 시험 근사이고 가시의 국소 응력·관통을 모델링하지 않는다. 자루부터 가시 끝까지 약 0.79m이며 게임의 앞쪽 도달 축 길이(`hiltLength + bladeLength`)는 0.65m다.

철구 관성은 1.10kg 반경 0.08m의 구와 총 0.15kg 가시를 반경 0.09m에 놓은 대칭 점질량 근사로 계산했다. 총 설계 질량 1.8kg, COM은 손 원점 앞 0.452083m, 손 기준 휘두름 관성은 0.4360496kg·m²다. 실제 Rapier 결과는 질량 1.79999995kg, COM y 0.45208338m, COM 기준 주관성 x/z 0.06816678 및 y 0.00381983kg·m², 손 기준 휘두름 관성 0.43604965kg·m²다. 손 기준 관성과 COM 기준 관성을 혼동하지 않는다.

## 판정과 현재 제한

머리는 기존 접촉 이름 `blade`, 자루/고정대/끝 장식은 `hilt`로 기록된다. 이것은 충돌 부위 구분용 기존 API 이름이다. 무기 전체 `edged=false`, `mCut=0`, `mThrust=0`이므로 어느 부품도 베기·찌르기·관통·마무리 즉사·사지절단 판정을 만들지 않는다. `mBlunt=1`, common 등급 기본 power/토크/파손 확률을 그대로 상속한다.

현재 재질·반발·음색은 무기 전체에 하나만 지정한다. 머리 때문에 `steel`을 쓰므로 나무 자루 충돌도 강철 재질/음색으로 처리된다. 부위별 재질은 별도 공통 API 작업이다. 기존 둔기 판정은 severity 0이며 머리·목의 의식 저하와 통증·균형 감소를 적용한다. 팔에 큰 에너지로 닿아도 베기식 상처나 사지 건강 저하를 만들지 않는 것이 현재 경로다. 모르겐슈테른만 배율을 키워 이를 가리지 않았다.

기존 `Fighter.trimSword`가 box만 정리하던 제약은 루트의 ball 제거 수정으로 해결했다. 머리 index 3, local y=0.55m, radius=0.09m의 최저점은 0.46m이며 기본 파손선은 0.385m이므로 전체 제거 대상이다. 루트는 이 ball의 collider를 비활성화하고 질량/관성을 0으로 만들고 충돌 그룹도 0으로 지운다. 기존 box 정리는 변경하지 않았다. 시험 무기의 fragility를 0으로 만들지 않았다. 아래 정상 전투 표본에는 파손이 없었으므로 별도 실제 `breakWeapon()` 호출로 파손 경로를 검사했다.

## 파손과 기본 off 짧은 회귀

후속 명령: `node /workspace/halfsword-hybrid-evidence/morgenstern_break_probe.mjs`. 최종 종료코드 **0**, 약 **1.78초 wall time**. 원자료 `morgenstern-break.json`, stdout/stderr는 같은 이름 접두사의 로그에 저장했다. 실행 전후 소스 SHA256 동일성을 확인했다. 처음 비활성화+질량0만 적용한 루트 수정에서는 격리 충돌의 실제 solver impulse 0.173333N·s가 남아 수락 실패했다(`morgenstern-break-failure.json`). 루트가 제거 ball의 충돌 그룹을 0으로 만든 뒤 같은 검사가 통과했다. 이 기록은 최종 통과 원자료와 구분한다.

실제 `breakWeapon()`을 호출한 결과:

| --- | ---: | ---: |
| 실제 총 질량 kg | 1.79999995 | 0.36290324 |
| COM y m | 0.45208338 | 0.10702221 |
| COM 기준 휘두름 주관성 x/z kg·m² | 0.06816678 | 0.00903548 |

잘린 자루의 남은 질량 0.31290323kg과 끝 장식 0.05kg이 전체 질량을 이룬다. 원래 box 고정대는 기존 경로대로 비활성화되어 총 질량에 포함되지 않는다. 파손 후 실제 양쪽 AI `G.step` 360스텝(3초)은 finite였고 머리 명중이 없었다. 이는 접촉 기회가 없는 경우를 포함할 수 있어, 별도로 원래 철구가 머리 강체를 확실히 지나가는 4m/s 격리 조건도 확인했다. 모든 그룹 설정·초기 물리 등록 뒤 파손을 적용하고 비활성화된 머리의 충돌 그룹을 이후 복원하지 않았다. 해당 조건에서 머리 접촉 manifold/solver contact/impulse가 모두 0, 표적 속도는 정확히 0, 자유 무기 속도는 4m/s 그대로였다. 이 확인은 파손 콜라이더 제거 검사이며 연결된 팔의 사람 타격 시험은 아니다.

기본 기능 off 회귀는 공유 checkout을 되돌리지 않고 HEAD `1eaa1e25497a12f121fcb054f5921cd100867f07`의 **전체 src와 원래 harness**를 `/tmp/morgen-defaultoff-regression`에 `git archive`로 풀어 별도 import했다. 설치된 같은 node_modules를 썼다. 이전 소스와 최종 작업 소스 각각 양쪽 AI normal / seed7 / longsword 대 zweihander를 360스텝(3초) 실행했다. `COMBAT.limbSeverTrial=false`이고, 두 인물의 몸 강체 14개와 무기의 translation/rotation/linvel/angvel 및 상태·체력 관련 추적값 SHA256이 모두 `8af01fdee038cdb9a6e939e3b97fd8cb964fe0e2bd7f87f7f502e3a80ce546b3`로 일치했다. 이 3초 회귀는 모든 장시간 전투·사지절단·파손 상황의 동등성을 주장하지 않는다.

다음 수락은 실제 시험판에서 철구와 자루 접촉, 한손 무게·되튐을 확인하는 것이다. 일반 카드 편입, 전용 그림·부위별 음색, 전용 AI/둔기 부상 모델은 이번 대표 시험에서 완료했다고 부르지 않는다.
