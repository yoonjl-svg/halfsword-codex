# 보조팔 부상과 양손 무기 연결 · 10/08

사용자가 보조팔 연결 교정을 승인했다. **일반판 양쪽 검객의 양손 무기**에 실제 파지·팔 기능에 따른 그립 힘과 타격 도움을 연결한다. 무기 이름으로 제한하지 않으며, 한손 무기의 힘/타격과 두 보류 무기의 검술보정 v2 승격은 별개다. 실제 공개 상태는 [전달 영수증](offhand_support_release.json)을 따른다.

## 교정 범위

- 보조손은 이미 실제 힘으로 검을 가속·제동한다. 손목 모터 한도까지 추가 감산하지 않는다. 실제 질량·관성·속도·중력과 검술보정은 그대로다. 따라서 보조팔을 잃었다고 모든 순간의 검 속도를 강제로 낮추지 않는다. 제동이 약해지면 순간 속도나 잔여 운동은 오히려 커질 수 있다.
- 기존 그립은 힘에 부상 배율을 곱한 뒤250N에서 잘라, 큰 힘 구간에서 부분 부상 효과가 가려졌다. 새 상한도 같은 부상 배율을 적용한다. 결과는 `부상 배율 × clamp(도달·근력 적용 힘,250N)`이며 부상 효과를 두 번 곱하지 않는다. 팔 기능0.6에서 포화 힘250→200N, 비포화30→24N은 기존과 같다.
- 접촉의 가상 팔 도움을 주팔/보조팔 절반씩 배분하고, 보조팔 몫에 현재 파지 도달도·근력·부상 기능을 연결한다. **이 절반은 게임 모델의 배분이며 해부학적 실측값이 아니다.** 보조손을 완전히 못 쓰면 베기 도움0.3→0.15kg, 찌르기 도움3.5→1.75kg이다. 검 자체의 유효질량은 감산하지 않는다.
- 같은 도움을 관통 예측·실제 상처·박힌 검의 저항에 사용한다. 박힘에는 베기 도움을 쓰며 찌르기 도움을 잘못 더하지 않는다. 최신 상처/절단은 즉시 반영하고 회복은 새 상태 표본을 기다린다. 접촉 필터에서는 엔진을 호출하지 않는다.
- 건강하게 완전히 잡으면 기존 도움이다. 건강해도 손이 덜 닿거나 떨어져 있으면 보조손 몫이 줄 수 있다. 기존 팔 기능0.3 이하 파지 해제 문턱은 유지한다. 모든 팔/몸 상태를 포괄하는 새 유효질량 모델은 아니다.
- 원래 요청 주소에서 일반 진입을 판별해, 보존용 연구·A/B 주소와 잘못된 연구 주소에도 이번 교정을 섞지 않는다. 재시작은 새 검객에 같은 정책을 적용한다.

## 검증과 판정

구성요소13검사·24개 생성 라운드에서 포화/비포화, 건강/부분손상/파지 상실, 같은 스텝 손상, 실제 절단 API, 부활, 새 라운드, 한손 유지, 박힘3경로를 확인했다. 이 라운드 수는 전투 횟수가 아니라 통제 fixture 수다. 기존 내려찍기2.5배 피해58검사와 이전 A/B 입구6검사도 통과했다.

**실제 게임 비접촉12실행·8,928step:** 롱소드/츠바이핸더 × 건강/부분손상/심한손상 뒤 절단 × 기존/교정. 같은 생성·입력·부상 준비에서6쌍의 실제 운동이 모두 정확히 일치했다. 이 입력은 새 그립 상한에 닿지 않았다. 따라서 제동 개선을 실증했다고 하지 않는다. 기존 부상 때의 실제 그립 상실을 보존하고 중복 감산하지 않았다는 근거다. 첫 실행의 계측 직렬화 오류는0step 실패 기록으로 보존했으며 게임 오류와 구별한다.

**실제 접촉8실행·10,560step:** 같은 두 무기의 건강/보조팔 기능0.2 × 기존/교정. 상대를 쓰러뜨린 통제 준비와 실제 탭/이동 입력을 사용했다. 모든 실행이 유한했고 실제 접촉까지 진행했다. 네 쌍의 생성·입력 및 최초 유효한 판정 차이 전 물리/제어가 일치했다.

| 보조팔 기능0.2의 첫 실제 접촉 | 기존→교정 실효 에너지 | 기존→교정 상처 심각도 |
|---|---:|---:|
| 롱소드 몸통 |106.16→66.44|1.353→0.691|
| 츠바이핸더 목 |57.51→40.20|0.692→0.403|

롱소드의 같은 상태 접촉에서 검 자체 유효질량1.17746kg은 동일하고 팔 도움만3.5→1.75kg으로 바뀌었다. 츠바이핸더는 관통 예측 단계부터 궤적이 갈라져 이후 두 실행을 같은 궤적이라고 부르지 않는다. 교정판이 첫 목 타격은 생존했지만 뒤에 출혈로 사망했으므로 생존율 개선으로 해석하지 않는다. 건강한 츠바이핸더는 전체 물리 일치, 건강한 롱소드는 근력의 부동소수점 차이로 실효 에너지 약4e−7 차이가 생긴 뒤 접촉 궤적 해시가 갈라졌다. 모든 건강한 전투가 비트 단위로 같다는 주장은 하지 않는다.

독립 코드 검토에서 차단급 결함은 발견하지 못했다. 검토가 제시한 원래 연구 주소 판별 문제는 일반 진입 배선에서 반영했다. 자연 전투 부상 빈도·모든 무기의 밸런스·실물 폰 장시간 체감까지 검증한 것은 아니다. 휴대폰 크기 브라우저의 실제 공개 진입·입력·재시작은 영수증에 별도로 기록한다.

로컬 모바일 검사에서 롱소드/츠바이핸더의 터치·이동·중단·재개·재시작·재입력, 청강검 한손 메뉴, 보존용/잘못된 연구5메뉴를 통과했다.648응답/145종 자료가 동결 빌드와 같고 오류0이었다. 공개 웹에서도 같은 조작/재시작과 메뉴 검사를 통과했다.648응답/145종 자료가 같은 빌드와 일치하고 오류0이었다. 실행 계획92,031바이트도 실제 공개 해시를 확인했다. 상세 근거는 영수증을 따른다.
