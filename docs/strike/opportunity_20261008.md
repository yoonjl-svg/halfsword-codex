# 무너진 상대의 급소 공략 · 10/08

사용자는 높은 무릎/어중간한 넘어짐의 위험을 실제 공격 기회로 표현하고, 베기는 목·둔기는 머리·찌르기는 목이나 얼굴을 노리도록 승인했다. **명중이나 참수 확률을 직접 올리지 않고, 준비와 목표 선택을 개선하는 선택형 비교**다. 실제 전달 상태는 [영수증](opportunity_release.json)을 따른다.

## 적용 범위

- A/B 모두 현재 일반 물리·검술 보정v2·양쪽 보조팔 연결·중력9.81·절단ON과 앞선 내려찍기 진입 B를 사용한다. B만 급소 공략을 추가한다. 일반판 기본값 승격과 기립 다리 순서 교정은 포함하지 않는다.
- 상대가 kneel/down/getup이고 실제 가슴이 공격자보다.12m 이상 낮거나 상체가30도 이상 기울었을 때 후보가 된다. 똑바로 서서 낮추기 입력만 하는 상대는 대상이 아니다. 완전히 낮은 몸은 기존 내려찍기가 담당한다. 앞쪽·도달 거리·목/머리 근처의 방어 무기를 함께 검사한다.
- 베기 능력이 있으면 목, 둔타는 머리, 명시 찌르기는 목을 먼저 선택하고 가려진 경우 보이는 얼굴을 검토한다. 무기 이름 대신 실제 절삭/둔타/찌르기 기능을 사용한다. 총·완전 파손·머리 상실은 제외한다.
- 플레이어는 느린 준비 입력에서만 높이/각도 보조를 얻는다. 손 높이 최대.24m·각도.28rad·준비.4초가 설계 예산이며 인간 실측값이 아니다. 빠른 공격은 준비 시간을 기다리지 않는다. 좌우 입력·역방향 베기를 유지하고 공격 확정 뒤 움직이는 상대를 추적하지 않는다. 탭 찌르기는 선택한 세계 좌표를 고정한 뒤 기존 힘과 시간으로 뻗는다.
- AI는 기존 반응 지연이 있는 관측을 사용한다. 준비 중 재평가하고 실제 공격 개시 때 목표를 고정한다. 같은 위기 구간에서 최대2회이며 빗나가거나 막혀도 센다. 준비 취소는 세지 않는다. 짧은 상태 변화나 거리 이탈로 횟수가 채워지지 않고 안정된 기립.45초 또는 새 상대/새 판에서 초기화한다. 두 번 뒤에도 일반 공격은 계속한다.
- 추가 힘·속도·피해 배율·강제 사망은 없다. 완전히 낮은 상대의 기존2.5배 내려찍기와 새 급소 공략은 구별한다. 투구/갑옷·충돌·날 정렬·기존 상처 문턱을 그대로 따른다.

## 검증 방법

기준 `8c732d410bc9c6d9e89e7ec1d365b1df47e10109`. 실제 게임+Rapier는 `tools/sim/experiments/opportunity_20261008.mjs <새 외부 경로> [장면,...]`로 실행한다. 소스/도구를 외부에 동결하고 SHA를 남긴다. seed7, 같은 생성 스냅샷과 같은 요청 입력의 A/B이며 적 AI를 멈춘 준비 장면과 실제 AI 공략 장면을 구별한다.

준비 장면은2초에 다리 기능을.2로 낮추고 knockDown을 호출한다. 몸 위치·속도를 순간 이동시키지 않는다. Open 장면은 같은 순간 실제 dropSword를 호출한다. 플레이어는5.5초부터 천천히 손을 옮긴 뒤6초에 수평 베기/탭을 입력한다. AI는6초부터 일반 판단을 실행한다. 이는 재현용 부상·입력 조건으로, 자연 전투 발생률이나 승률 조사가 아니다.

구성요소 검사는 실제 Fighter/Skill/AI/Combat 연결을 사용하지만 native step은0이다. 이를 실제 접촉으로 세지 않는다. 브라우저는 공개 코드 바이트, 실제 터치, 진입·플레이·재시작을 검사하며 실물 폰의 체감 판단과 구별한다.

## 실패와 보존

- 최초 AI 상태 이름이 기존 opportunity 메서드를 가렸던 오류를 수정했다. 실제 AI.update 검사를 추가했다.
- 초기 플레이어 준비안은 베기를 시작하는 반전을 취소로 해석했다. 유효 반전은 목표를 고정하고 사용자의 반대 방향 베기를 그대로 이어가도록 수정했다. 미세한 반전이 공격을 조기 확정하지 않게 했다.
- 초기.16초 준비 예산은 높이.24m를.75m/s로 준비하기에 부족했다. .4초로 늘리되 빠른 공격은 즉시 확정하도록 한다.
- r3의 준비 칼끝 기준은 목을 겨누었다고 기록하면서 실제 수평 베기를 더 낮춰 빗나갔다. 같은 장면 A는 가슴 절상92.63J, B는 본 베기 접촉0이었다. 이 결과는 폐기하지 않고 교차 높이 기준 교정의 근거로 보존한다. r3 둔기 B의 실제 머리 둔타19.81J와 별개다.
- AI의 기존 상단 기술 선호는 목 목표에서도 머리부터 들어갔다. 가로/완만한 대각 기술을 실제 경로 형상으로 고르도록 변경했다. 단순히 기술 선택만 바꾼 r4의 낮은 패드 보조도 팔/다리에 닿아 목표 좌표만으로 성공을 선언할 수 없었다.
- r1의 찌르기 목 접촉과 r2의 머리 찌르기, 이후 일반 공격의 목 접촉은 서로 다른 조건이다. AI 특별 공격이 끝난 뒤 일반 공격이 목에 맞은 것을 특별 공략 성공으로 합산하지 않는다.
- r1–r3의 프레임별 AI 횟수는 살아 있는 상태 객체 참조를 저장해 최종값으로 덮이는 계측 오류가 있었다. r4부터 값 복사와 실제 특별 공격 구간·기술을 기록한다. 과거 최종 통계와 접촉은 보존하되 프레임별 횟수를 근거로 쓰지 않는다.

AI의 실제 공격 개시 두 번과 이후 일반 전투 복귀를 확인했다. 팔이 있는 실제 물리 장면에서는 목베기가 팔에 먼저 닿았고, 찌르기도 첫 특별 공격에서 머리 둔타로 닿거나 빗나갔다. 피해자가 무기를 놓고 낮은 손 입력을 받은 추가 장면에서도 이 한계가 남았다. 실제 특별 AI 목 절삭·목/얼굴 관통 성공은 미입증이다. 과거 준비 명령 높이의 수mm 오차를 실제 명중 정밀도로 설명하지 않는다.

AI의 패드 높이 역산은 교본에 남은 위쪽 칼끝 방향을 바꾸지 못해 폐기했다. 최종은 기존 자세 계산 뒤에 같은 손 높이/고도각 예산을 준비 중 더하며, 명시 찌르기/내려찍기와 중복하지 않는다. 획득한 명령 보조를 공격 시작 때 고정하고 이후 상대를 추적하지 않는다. 비용이 큰 높이 탐색은 최종 코드에 남기지 않았다.
