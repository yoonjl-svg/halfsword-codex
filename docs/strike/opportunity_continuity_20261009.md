# 거리 준비 발동·연속 찌르기 ·10/09

목표는 무너진 상대에게 거리를 맞춘 뒤 끊김 없이 찌르는 조작이다. 사용자가 기립 B 일반 적용과 빠른 연속 동작 비교를 요청했고, 이어 에스톡에서 거리 조정이 느껴지지 않는다고 제보했다. 기준 `356dd6b172fed7fecfd5c70ee5c0f2aab12298b7`, 정확한 변경 소스·엔진·명령·원자료는 [실험 지도](opportunity_continuity_20261009.json)에 둔다.

발동 취소 경로 하나를 재현했다. 손떨림·자동 자세 복귀가 섞인 `handOffset` 변화로 새 사용자 입력을 판정해 거리 준비를 취소할 수 있었다. 실제 손가락 움직임 기록으로 취소를 분리했다. 수정 전 회귀 실패와 수정 후14계약 통과를 보존한다. 사용자 장면의 유일한 원인으로 확정하지 않는다. 스틱·새 드래그 우선권은 유지한다.

기존 통제 장면의 실제 공격10건(플레이어8·AI2)은 거리와 정렬이 준비된 스텝에 바로 찔렀다. `.11초` 겨누기는 빈 대기가 아니라 팔을 거두는 동작이다. B는 준비 이동·손잡이 정렬 목표만1.2배, AI의 별도 준비 대기만 제거한다. 공격 시간·힘 설정은 유지하지만 실제 접촉 에너지는 바뀔 수 있다.

| 첫 탭→공격 | A | B |
|---|---:|---:|
| 가까운 레이피어 |1.233초|1.017초|
| 가까운 에스톡 |1.800초|1.492초|
| 먼 레이피어 |.467초|.517초|
| 먼 에스톡 |.850초|.942초|

핵심14실행18,720step에서 가까운 거리는 빨라졌지만 먼 거리는 늦어진 반례가 있다. 중간 레이피어 실제 급소 상처를 낸 공격2→1, AI1→2; 먼 레이피어1→0, 에스톡0→1이다. 전체20% 단축·명중률 향상으로 일반화하지 않고 선택형으로 둔다. 피해는 실제 충돌/갑옷 판정이며 강제 명중하지 않는다.

바로 반복할 연습판은 상대 AI만 멈추고2초 뒤 다리 기능 저하·실제 넘어짐 제어로 무릎 상태를 만든다.6초 뒤 탭 안내와 재시작 버튼을 제공한다. 첫 무장해제 fixture4실행은2장면에서 준비만 수락하고 공격하지 못해 폐기했다. 무기를 유지한 수정 fixture4실행4,800step은 모두 첫 탭→실제 준비 공격을 확인했고 기존 quick4행과 native 스냅샷이 같다. **인위적 연습 상태이며 자연 전투 빈도·실물 폰 수락이 아니다.** 실패 포함 누계22실행28,320step. 기립은 [승인된 일반 승격](getup_adoption_20261009.md)으로 별도 처리한다.
