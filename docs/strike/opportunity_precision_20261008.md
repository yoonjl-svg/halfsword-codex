## 후보와 보존 조건

- 급소 v2 찌르기는 실제 검 위치에서 선택한 고정 목·얼굴점으로 향하는 조준선을 사용한다. 기존 명령 손 위치의 선으로 목표 너머를 만든 뒤 다른 실제 검 위치에서 겨누던 기하 불일치를 분리한다.
- 준비 후퇴는 실제 시작 칼축을 참고하고, 준비 뒤에는 잠근 겨눔선으로 연속 전진하도록 설계한다. 시간 설정·도달거리·힘·피해 한도를 유지해 실제 입력→접촉 시간과 속도 변화는 별도로 측정한다.

## 사용자 추가 기준: 100%를 목표로 하지 않는다

사용자는 모든 급소 시도의 성공을 요구하지 않았으며 넘어지면 자동으로 죽는 게임을 원하지 않는다고 명시했다. 시도당 의미 있는 급소 타격30%를 **잠정 관측 목표**로 삼고, 범주별 성공률·위기 한 번의 최소1회 성공·실제 사망률을 나눠 평가한다. 30%가 독립적으로 두 번이면 최소1회 성공은 `1-(1-.3)^2=.51`이며60%도 보장된 최소치도 아니다. 같은 상대에게 이어지는 두 시도는 부상·회피·방어에 의해 상관되므로 실제 위기별 관측값을 우선한다. 급소 명중과 사망도 같지 않다.

성공 정의는 직접 applyWound의 실제 목 베기 또는 목/머리 찌르기에서 severity>0, 둔기는 머리 둔타의 의미 있는 통증·균형·건강 변화다. 얼굴 선택목표를 얼굴 명중으로 부르지 않는다. 피해·명중에 임의 확률을 삽입하지 않고 기존 물리 결과를 계측한다. 이미 있는 seed7 결과를 재사용하고9개 추가seed를 같은 통제된 AI3장면에 적용해 표본을 늘린다. 이 관측 비율은 자연 전투 전체의 발생률이나 확정된 성공률 하한이 아니다.

베기는 잠정30% 점추정 목표를 넘었고 찌르기는 미달이다. 둔기는 무장해제된 부상 상대에게 너무 높은 성공을 보이므로 높은 수치만으로 채택하지 않는다. 일반판 적용 전 무장·방어·회피가 가능한 상대에게도 대응 기회가 남는지 확인해야 한다. 성공률을100%로 밀어올리거나 목표 숫자를 맞추려고 피해/명중 확률을 넣지 않았다.

특수 타격의 applyWound 안에서 바로 발생한 사망은 모든 범주0이었다. 그러나 이것이 특수 타격의 사망 기여0을 뜻하지 않는다. 표의18초 사망에는 후속 일반 공격과 지연 사망이 들어 있고, 기존 A는 각각0/10·3/10·10/10이었다. 전체27사망 중23은 계측으로 직접 원인을 확정하지 못한 지연/기타 사망이다. 현재 증거만으로 ‘무조건 죽지 않는다’는 밸런스 검증 통과를 선언하지 않는다.

## 후속 제안: 목·머리 영역을 찌르기 표적으로
