P5 기본값은 승인된9/30 갑옷 독립 마무리 예외다. 이것을 우발적 버그로 부르지 않는다. 새 선택형은 `bareThreshold < eff <= threshold`, 갑옷 기여 및 armor-ignore 아님을 함께 요구하며 `pass=false`만으로 막힘을 판정하지 않는다. 실패 찌르기는 기존 둔격/기절/마모 경로와 원래 유효질량으로 돌아간다. 피해 관찰의 ‘상처 없음/상처 있음’과 규칙 즉사를 분리했다. 의도적으로 down/tap/접촉 상태를 준비한 실제 Combat/Fighter 구성요소 검사이며 자연 전투·실물 폰 수락과 다르다.

폰 [통합 비교](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#integrated-combat-comparison): A는 manual/profile+기존 찌르기/마무리, B는 manual/profile+기존 선택형 transported+새 armorCausal다. 플레이어만 바꾸고 같은 하인리히/롱소드·보정 끔 조건을 쓴다. 두 변경의 복합 시험이므로 단일 변수 인과 비교가 아니다. 이전 두 B 선호는 새 통합 B의 수락으로 이어 붙이지 않는다. 실패한 지지/절삭/손 후보 및 전체 native 모터 이전은 포함하지 않는다.

소스·도구/원자료SHA·CLI·실제 회귀·웹 검증은 [수치/이식 지도](p456_batch_20261005.json)와 [전달 영수증](p456_batch_release.json)을 따른다. 저장소 밖 보존 root는 `/workspace/halfsword-handoff/p456-batch-20261005`; 외부 raw와 npm 엔진이 필요한 재현은 현재 checkout만으로 모두 제공되지 않는다. `finish_rule.test.mjs <fresh-json>`, `input_lifecycle.test.mjs`, `recut_plane_observer.mjs`의 기록된 argv, `run_checks.py --out <fresh-root> --force`, `integrated_combat_trial.mjs --base=<own-base> --out=<fresh-dir>`가 재개 입구다. 과거 적정 기록/물리는 반복하지 않았다.

최초6회귀PASS 뒤 실제 두 손가락 일시정지가 클릭을 만들지 않는 결함을 찾았다. 버튼에 터치 직접 처리를 추가한 최종6회귀PASS(157.92초·fresh/sourceStable)와 구성요소61·Input12/매핑51, 로컬/공개 모바일 각각6흐름을 확인했다. 구현 `9567947b9b91524112be6c484f7b2d177be7a8da`의 Pages37219403970 성공·공개8파일 exact·trusted 베기/탭/재베기/두손가락Pause/새 객체 재시작·일반판 복귀를 전달했다. 첫 실패/회귀 원자료는 보존하며 독립 효능 표본으로 세지 않는다. 센서 시험의 사용자가 고른 tilt 저장 변경과 이후 대체 동작의 저장 bytes 보존을 구분한다. 포커스 검사는 손을 뗀 뒤 실제 탭 전환을 시도했지만 공개 headless에서 qualifying 전환을 관측하지 못해 end-to-end는 미검증이다. 누른 손 취소는 DOM/일시정지 경로 근거다. 초기 저장 tilt로 시작·실물 센서/기기도 별도 미검증이다.
