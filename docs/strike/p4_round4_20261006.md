# P4 · 실제 접근 후 첫 베기 접촉, 연구 보존

**롱소드 후보의 살아 있는 상대 접촉과 이후 1초 붕괴 선별만 통과했다.** 반전 구간의 후퇴와 후보에서만 생긴 목 피격이 남아 공개 보류를 유지한다. 전체 P4의 완료도 기각도 아니다. [수치·실패·SHA·재현 명령](p4_round4_20261006.json).

기준 `7f902cd6724f5391cd436d333fea0174f37d3df8`, 현재 v2-r2/manual, LS 대 츠바이핸더, seed7, 일반 시작거리5.6m와 중력9.81을 고정했다. [기존 명령 면 후보](p4_command_plane_20261005.md)를 그대로 재사용하고 게임 소스 대신 해시를 보존한 외부 사본에서만 선택했다. 힘·관성·감쇠를 바꾸거나 기각한 평면/속도 후보를 되살리지 않았다.

첫2행은 시작 후2초 발 잠금을 일정에서 빠뜨린 fixture 실패였다. 전진 입력을 줬어도 첫 베기/반전 때 거리는5.65–5.71m, 재베기 끝에도4.25m였다. 후보79frame 개입·동일 입력은 확인했지만 접촉0이었다. **이1440step은 보존하며 다시 돌리지 않는다.** 접촉이 없어 원 raw의 빈 경계 비교가 true인 부분은 접촉 동등성 증거가 아님을 JSON에 명시했다.

허용된 마지막 한 쌍은 기존 잠금240step 뒤 정상 전진 스틱으로 접근했다. 실제 몸 중심 거리≤2.8m인 tick420에서 양쪽 native/제어 상태가 같았고, 그때부터 같은 기존 touch tape를 공급했다. 거리 문턱·seed를 탐색하거나 몸을 옮겨 놓지 않았다. 후보는 생성부터 선택했지만 첫 개입은555였다. 0–554 native/제어/입력 exact, 전체0–696 플레이어 입력 동일, 상대 입력은640부터 달라졌다.

tick576에 양쪽 모두 살아서 서 있는 상대의 머리에 빠른 베기가 닿아 실제 양의 절삭 반작용이 나왔다(기준3쌍/후보2쌍). **접촉 직전 native 상태는 이미 달랐으므로 동일 충격 조건의 위력 비교는 아니다.**

| 첫 베기552–581 | 기준 → 후보 |
|---|---:|
| 각자 명령 방향 진행 적분 | .987 → 1.025m |
| 실제 이동에 대한 날 면 오차 평균 | 16.09 → 12.74° |
| 칼끝 평균 속도 | 5.567 → 5.738m/s |

명령 방향은 실제 가슴 움직임을 포함하며, 날 오차는 step 뒤 검축·같은 step 명령을 사용한 기존 정의다. 낮은 각속도 하나로 효과를 판정하지 않았다. 접촉 뒤1초 동안 양쪽 생존·기립·무기·그립을 유지했고, 플레이어 최대 관절 간격은2.12→2.38mm였다. 그러나 후보에서만 tick603에 목 절상(31.26J, severity .0990)이 생겼다. 이는 상대 입력이 갈라지기 **전**이며 단순히 AI 분기 탓으로 제외하지 않았다. 이어 반전의 진행은1.403→1.331m, 축 누적회전은.785→1.354rad로 바뀌었다.

정정 한 쌍은 사전 약속대로 첫 접촉+120step인696에서 끝나 tap의 앞19step까지만 관측했다. 뒤 재베기·놓기 접촉이나 사람 체감까지 통과한 것은 아니다. **총4실행·2834step·물리19.07초**, 준비 전용 사본의 물리 실행0, P4 runtime·공개 변경0이다. 도구 구문·sourceStable·입력/접근/개입 관문을 확인했다. 추가 실행은 하지 않는다.

이번으로 LS 첫 베기의 실제 접촉 미노출은 닫는다. 다시 검토한다면 보존한 정상 접근 조건에서 접촉 뒤 의도한 반전·재베기/복귀의 교환관계 하나를 다룬다. 시작 잠금 실패·gain 탐색·기각 후보·거리/seed 탐색은 반복하지 않는다.
