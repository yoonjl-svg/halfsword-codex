# P5 · 절삭 반작용 중심선 후보

절삭 때 검과 맞은 부위가 서로 다른 양·작용점의 충격을 받는 불일치를 좁게 교정했다. **실제 2장면의 첫 접촉 후 1초 선별을 통과했고, 롱소드·츠바이핸더 선택형 A/B의 공개 웹과 모바일 진입·조작·재시작도 확인했다. 일반판 적용·P5 전체 완료는 아니다. 실제 공개 웹/모바일 확인은 [전달 영수증](phase2_v2_release.json)을 따른다.** [수치·소스·명령·해시](p5_centerline_contact_20261005.json)가 재현 입구다.

기준은 `e0ed9e5af85037a7bdd2644e35090a8936da9f60`와 검술 보정 v2다. 기존 절삭은 검 중심선 pA에 −J, 피해자 뼈 중심선 pV에 +0.8J를 준다. 뼈/검 축 투영은 과도한 축회전을 막으려는 의도였지만, 0.8의 별도 설계 근거는 찾지 못했다. 실제 두 호출 직전·직후만 관찰하여 후속 관절·충돌·되튐과 분리했다.

새 `centerline`은 **기존 검 중심선 pA를 두 물체의 공통 작용점**으로 쓴다. 요청 J·기존 J×s 예산 차감·체류시간·피해 판정은 유지한다. pA에서 실제 속도와 관성으로 비역전 상한을 계산하며, 상한이 걸리면 검 반동도 감소한다. 명시한 플레이어 객체와 index 0이 모두 맞을 때만 켜진다. 일반값은 `legacy`다.

과거 실패한 표면 공통점 후보·budgeted 후보를 되살린 것이 아니다. 요청 예산 유지 자체는 옛 impulse-only 후보에도 있었으며, **새 차이는 공통점을 검 pA로 제한하는 것**이다. 피해자 축토크가 새로 생겨 단순한 20% 보완으로 설명하면 안 된다.

관찰 on/off 4회·3,844 step와 후보 대조 4회·4,228 step, 총 8회·8,072 step이다. 장면은 seed 7의 두 무기 순서뿐이며 8개 독립 표본으로 세지 않는다. 접촉 전 native·제어·입력, 첫 충격 뒤 검 속도/각속도, 첫 피해가 exact다. 원래 관찰 off 검증도 재사용했다. 후보 실제 18쌍에서 상한 발동·ΔK 증가가 없었고, 구성요소 6그룹은 상한/분리속도/범위/운동량을 별도로 확인했다.

접촉 후 1초에서 새 낙상·그립 상실은 없었고 최종 건강·사지값은 같았다. 피해자 사지 축속도 peak는 31.148→31.316, 27.456→27.447 rad/s였다. 최대 관절 gap 변화는 0.002mm 미만이다. 그러나 반응 AI 입력은 접촉 0.075/0.0917초 뒤 달라졌으므로 이후 차이를 같은 입력의 효과로 주장하지 않는다. `stand`도 자연스러움 수락이 아니다.

아직 머리·몸통·한손·실제 stuck/상한 발동·장시간 접촉은 검증하지 않았다. 예산 차감은 실제 운동에너지 손실과 여전히 다르다. 원자료의 각운동량 원점 정정과 미사용 산술 필드 정리는 JSON에 남겼으며 원본/동결 소스를 보존했다. 제한된 선택형의 화면·입력·재시작·공개 코드 검사는 위 전달 영수증에서 확인한다. 다음 물리 관문은 실제 머리/몸통·오래 걸림과 상한 발동이며, 현재 두 장면을 반복해 독립 표본 수를 늘리지 않는다.
