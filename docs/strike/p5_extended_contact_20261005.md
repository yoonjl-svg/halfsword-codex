사용자의 “B안 괜찮은 것 같다”는 평가 뒤, **생존 상대의 머리·가슴 접촉과 기존 자연 박힘 상태에서의 상한 작동을 확인했다. 일반판 승격 근거는 아직 부족하다.** 생성부터 켠 B의 박힘은 미관측이며, 박힘 검사는 특정 실제 상태에서 늦게 켠 별도 진단이다. 공개 선택형 B와 게임 코드는 유지한다. [수치·소스·해시·명령](p5_extended_contact_20261005.json)이 재현 입구다.

기준 `2cb4915c96a69da722dfd65ef2c2bae2ceaa341f`를 독립 파일 사본으로 동결했다. 기존 seed 7 롱소드↔츠바이핸더 두 장면을 A/B 각각 30초로 연장했다. 4회·14,400 step 중 이전 4,228 step의 native/제어/입력이 모두 exact이며 새 관측은 10,172 step이다. 같은 전투의 연장을 새 독립 표본으로 세지 않는다. 물리 실행은 87.33초였다. 실행 전 문법오류 1회는 물리 0회로 보존·정정했고, 기존 helper 단위검사는 반복하지 않았다.

양쪽 생존 중 B의 살아 있고 무장한 몸체에서 최대 유효 관절 gap은 롱소드 장면 2.515/2.570mm, 츠바이핸더 장면 3.179/2.406mm였다. 이 범위에서 유효 그립 상실은 없었다. 롱소드 B는 실제로 두 팔을 잃었으며 주팔 손상 다음 step에 보정이 `suspended/inactive`, 가용성 0으로 바뀌었다. 이는 제어 상태 관찰이며 손상 직후 오래된 손목 debug 값을 실제 토크로 읽지 않는다.
