# 2단계 남은 묶음 중 2·3회차 판정

무게·힘 전달(P1/P3), 지지·부상 제어(P2/P6)를 병렬 준비하고 실제 물리 실행은 서로 겹치지 않게 진행했다. **이번에는 기존 v2를 바꿀 근거와 새 후보의 효과가 확인되지 않아 게임 변경 없이 관측·검증을 보존한다.** 중력9.81, 검술 보정v2, 기존 타격/회복B를 유지한다. 불필요한 새 플레이 요청은 없다.

실제13실행·18,770step을 진행했다. 전체 실행·원자료·소스·실패와 비용은 [통합 기록](phase2_round23_20261005.json), 상세 CLI는 각 보고 JSON에 있다. 초기 계측 assertion 실패1step을 포함하고, 같은 회복 재생4106step을 새 효능 표본으로 중복 집계하지 않는다. 기존 내려베기·공통6회귀·변경 없는 공개 게임의 모바일 입력 검사는 재실행하지 않는다. 배포 때 JS 바이트 동등성과 갱신된 폰 계획을 확인한다.

**현재 위치:** 초기5회 목표에서2·3회차의 검사·판정을 마치고4회차 통합 준비로 이동한다. 예정상4·5의2회가 남지만 완료 보장은 아니다. 실제 옆넘어짐, 생성부터 v2의 심한 부분손상, P4 명령 경계/실제 접촉, P5 생성부터 박힘·후속 축회전·피해 연결은 남는다. native 전신 힘의 완전한 장부도 미완료다. P1–P6를 일괄 종료하지 않는다.

다음60–90분은 정상 조이스틱 접근+동일 터치의 접촉 관문과 기존 통과 B들의 통합 입력/부상/재시작을 한 번에 묶는다. 이미 확인한 올림·버팀/하중 관찰과 실패 후보 gain 탐색은 반복하지 않는다. 새 일반판 메이저 반영은 구체적인 통합 결과 뒤 사용자 확인을 받는다.
