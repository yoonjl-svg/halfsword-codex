# 2단계 남은 묶음 중 4회차 판정

**통합 연구 검사·판정은 끝났고, 새 통합판 공개는 보류한다.** 사용자 요청의 중력3수준 임시판은 별도로 먼저 전달한다. 중력판은 기존 회복B 그대로이며 이번 결합 후보를 몰래 섞지 않는다. [중력판·실제 전달 영수증](gravity_v2_release.json).

| 조사 | 결과와 적용 |
|---|---|
| [회복B+반작용B](round4_integrated_20261006.md) | 생성부터4행의 설정·입력·기존 기록 동등성 확인. 두 효과의 동시 개입은 미노출. 실제 회복 뒤 반작용을 켠 추가1행에서는 생존 상대44접촉쌍·상한12회·순간 에너지 증가0, 부상·그립 유지. 좁은 연속 개입 관문만 수락 |
| [P4 정상 접근 뒤 베기](p4_round4_20261006.md) | 시작 잠금 누락2행을 보존하고 정상 접근 한 쌍으로 실제 접촉 관문 확인. 첫 베기 진행/날 정렬은 개선됐으나 반전 회전 증가·후보만 목 피격이 남음. 연구 보존·공개 보류 |

실제 연구9실행·15,245step이다. 임시 중력판4행·3,840step과 공통 회귀/모바일 검사는 별도 집계한다. [통합 수치·원보고 연결](phase2_round4_20261006.json)에 소스·명령·해시·실패로 가는 입구를 남겼다. 독립 준비/분석을 병렬 수행하고 무거운 실행은 짧게 조율했다. 이전 올림·버팀/기존P5 전체 실험은 반복하지 않았다.

**현재 위치:** 최초5회 묶음의4회차 연구 판정까지 진행했다. 5회차 최종 통합·모바일 전달 관문이 남으며, 4회차의 새 통합판도 아직 전달 완료가 아니다. 생성부터 두 후보가 실제로 개입한 회복/생존 상대 접촉, 사람 입력 재베기를 닫아야 한다. P4 후속 재베기·P5 피해 연결·심한 부상/전신 지지 등 미완료 목표는5회차라는 이름만으로 완료 처리하지 않는다.

다음은 통과 원자료를 재사용하고, 실제 회복 후 같은 손 입력으로 살아 있는 상대를 베는 한 장면에 시간을 집중한다. 추가 gain/seed 탐색·실패 후보 재권유는 하지 않는다. 공개/보류 범위를 구체화한 뒤 새 메이저 일반판 반영만 사용자 확인을 받는다. 중력 임시판의 체감 피드백은 이 통합 검증과 독립적으로 받을 수 있다.
