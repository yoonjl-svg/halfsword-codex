# 5회차 판정 — 통합 공개 보류

**검사·판정은 수행했지만 새 통합판 전달은 완료하지 않았다.** 생성부터 기존 회복 B·검술 보정v2·중력9.81을 고정하고 타격 반작용만 비교했다. [물리 원보고](round5_recovery_20261006.md)의 새4실행·9,102step, 준비판 진입93계약·로컬 모바일5흐름을 확인했다.

- 제자리 대기 한 쌍은 첫 피격에 주팔을 잃어 회복 검사가 불가능했다. 후보 개입 전 두 판은 완전히 같았다.
- 정상 투구 상대/AI 전투 보완 한 쌍은30초 생존·무장·그립을 유지했다. B의 살아 있는 상대169충격·상한72회에서 순간 에너지 증가는0이었다.
- 보완에서는 넘어짐/회복이 없어 손 재베기로 넘기지 못했다. 에너지 예산·피해 연결이나 자연스러움 수락도 아니다.

**실제 회복 뒤 손 입력으로 살아 있는 상대를 베는 관문은 남는다.** 추가 seed/장비 탐색은 중단했다. 준비한 코드·모바일 결과는 연구 패치/외부 원본으로 보존하고 공개 연결을 제거했다. 기존5물리 결과는 의존393파일·엔진·환경·원자료 해시를 대조해 재사용했으며 새 공통6검사 통과라고 세지 않았다. [전달 영수증](phase2_round5_release.json)에 소스·패치·감사·공개 상태를 연결한다.

폰의 [기존 회복 비교](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#stance-v2-comparison), [타격 반작용 비교](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#contact-v2-comparison), [중력3판](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#gravity-v2-comparison)은 유지한다. 이번에는 추가 사용자 테스트를 요구하지 않는다.

**현재 위치:** 최초5회 묶음의 검사·판정까지 진행했고, 통합 전달과 전체2단계는 미완료다. 회복 통합의 미확보 장면은 별도로 남기고, 다음은 독립적인 P4 재베기 방향 급변의 작은 수정·접촉 검사다. 전신 지지·native 힘 전달·심한 부상·절삭 피해 연결도 [현재 계획](../codex_team/ACTIVE_PLAN.md)에서 계속 추적한다.
