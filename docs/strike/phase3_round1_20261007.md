# 3단계1회차 · 현재 일반판의 갑옷 마무리

사용자가3단계 진행을 지시했다. 기준 `552accf3c2f63817d73980293339fe9b1f713e18`에서 **현재 일반판 기반의 선택형 A/B**를 준비했다. 일반판의 승인된 갑옷 독립 마무리는 유지한다. 새 B는 갑옷이 실제 방어력을 보태는 부위에서 상처 문턱 이하의 마무리를 특례 즉사로 처리하지 않는다. 충분한 찌르기 상처, 일반 둔격·기절·죽음은 유지한다. 일반 적용은 결과를 확인한 사용자 결정 뒤에 한다.

## 필요한 이유와 변경

옛 `armorCausal`는 맨몸이면 상처가 나지만 갑옷 때문에 막힌 구간만 특례를 취소했다. 고정된 갑옷에 아주 약한 찌르기는 즉사, 더 강한 중간 찌르기는 생존하는 역전이 남는다. 당시 승인 규칙을 좁게 보존한 설계이며 우발적 버그가 아니다. 새 `armorGuard`를 별도 모델로 만들고 과거 후보도 유지한다.

| 찌르기 조건 | 일반판 legacy | 옛 armorCausal | 새 B armorGuard |
|---|---|---|---|
| 갑옷 기여 있음, 맨몸 상처 문턱 이하 | 특례 유지 | 특례 유지 | 특례 취소 |
| 맨몸 문턱 초과~갑옷 문턱 이하 | 특례 유지 | 특례 취소 | 특례 취소 |
| 갑옷 문턱 초과이나 관통은 실패 | 특례 유지 | 특례 유지 | 특례 유지 |
| 맨몸·갑옷 무시·방어력 기여 없는 소진 갑옷 | 특례 유지 | 특례 유지 | 특례 유지 |

`pass=false`만으로 갑옷 차단이라 부르지 않는다. `armorBlocked`는 맨몸 상처를 막은 인과 구간이고 `armorGuarded`는 약한 찌르기까지 포함하는 새 규칙이다. 방어력이 소진되어 갑옷 문턱=맨몸 문턱이면 원래 특례로 돌아간다. 보이는 갑옷이 모든 공격/즉사를 막는 설계가 아니다.

## 검사와 한계

- **구성요소:** 새63검사와 기존61회귀 통과. 고정 갑옷의 약함/같음/중간/관통 전 상처/충분한 관통, 판금·투구·맨몸·무시 무기·마모·틈, 예측 무부작용, 실제 둔격 에너지 복구, 마모·기절/일반 죽음, 플레이어 범위와 옛 일반 출력의 일치를 확인했다. 새 모델을 추가해 실행 분기가 바뀌었으므로 기존61을 다시 확인했다. 준비된 캐시/상처 구성요소 검사이며 물리 진행0이다. [명령·소스·원자료 해시](phase3_round1_20261007.json).
- **실제 물리:** [별도 실제 접촉 기록](phase3_finish_contact_20261007.md). 자연 입력 표본에서는 마무리가 미노출이었다. 통제된 down 준비 후 실제 입력·Rapier 접촉에서 롱소드/레이피어 판금 마무리의 특례 취소와 맨몸 대조를 확인했다. 새 약한 구간 자체의 실제 전투 노출은 주장하지 않는다.
- **후속:** 롱소드의 갑옷 막힘은 일반 둔격12.440J로 생존/마모, 레이피어는5.454J로 기존6J 최소 피해 판정 아래지만 반동은 남았다. 피해 적용 뒤 갑옷 마모가 달라지므로 모든 후속 물리의 일치를 주장하지 않는다. 통제1초 생존은 장시간 전투 수락이 아니다.
- **진입:** 새6·일반 기본값6·옛 통합29검사 통과. 새 URL의 중복/잘못된/혼합 값은 비교를 켜지 않는다. 저장된 설정을 쓰지 않는다. 실제 컴파일본·신뢰된 터치·적 AI·재시작·공개 파일 검사는 [전달 영수증](phase3_round1_release.json)이 기준이다.
- **독립 감사:** 규칙·일반 진입 격리에는 차단 결함 없음. 연구 도구의 휴면 autoGuard 플래그 불일치는 수정 후 원자료와 비교했고, 기본 harness AI와 실제 하인리히 AI 차이를 기록한다. 연구 표본을 공개 상대의 동일한 전투라고 쓰지 않는다.

## 폰 비교와 다음

[비교 화면](https://yoonjl-svg.github.io/halfsword-codex/feature-lab.html#finish-v2-comparison)에서 롱소드/레이피어 A→B를 선택한다. 두 판은 같은 현재 v2·회복 fresh·재베기 bounded·타격 centerline·절단 ON·중력9.81이다. 하인리히(롱소드)의 원래 제어를 유지하고 플레이어의 마무리 규칙만 다르다. 재시작에도 유지되며 일반 게임으로 나가면 기존 규칙이다.

상대가 넘어진 뒤 갑옷 부위를 톡 눌러 마무리할 때 비교한다. 그 장면에 도달하지 않았다면 차이 없음을 실패나 체감 수락으로 해석하지 않는다. 사용자가 같은 희귀 장면을 반복해서 만들도록 개발을 멈추지 않는다. 이번에는 형상·찌르기 운반·힘/피해 배율·중력·보조팔 부상 규칙을 바꾸지 않았다.

**다음2회차:** 기존 실제 절삭 근거를 재사용하고 받아내기/피해 연결의 첫 불일치를 좁게 확인·교정한다. **3회차:** 바뀐 부분의 무기/부상 통합과 휴대폰 반복 플레이·실제 전달. 세 번은 실행 묶음이며 전체 장기 물리 연구 완료의 보장이 아니다.
