# 3단계 2회차 · 절삭·받아내기·피해 연결

**대표 장면의 연결 검사를 마쳤다. 새 게임 결함은 확인되지 않아 현재 일반판을 유지한다.** 갑옷 마무리 B의 일반 승격은 별도 사용자 결정 대상이다.

- **절삭:** 롱소드·청강검의 수동 연속 입력에서 실제 절상9개가 상처 목록·출혈·해당 팔다리 기능에 연결됐다. 반작용124회는 두 물체의 운동에너지를 줄였다. 과거 저항 예산의 작은 차이가 이번 장면에는 개입하지 않았으므로 힘·피해 배율이나 저항을 조정하지 않는다. [절삭 기록](phase3_cut_link_20261007.md).
- **받아내기:** 칼끼리4.522Ns 접촉 뒤 반작용이 생겼고 같은/다음step의 신체 피해는0이었다. 후속 몸 접촉의 둔격3회는 의식·멍함·통증으로 연결됐다. 기존 손아귀 회전 처리는 근사임을 남기며 기각한 신체 회전 후보를 되살리지 않는다. [받아내기 기록](phase3_parry_20261007.md).
- **공개 화면:** 현재 일반판의 실제 절상1개가 저장된 상처→붙은 상처/번짐→렌더 제출과 혈흔으로 이어졌다. 갑옷 막힘은 새 절상 없이 긁힌 흔적을 냈다. 화면에서 개별 상처 선의 모양을 명확히 식별한 것은 아니며, 렌더 제출과 미관을 같은 수락으로 쓰지 않는다. [공개 브라우저 기록](phase3_damage_visual_20261007.md).

기존 사지 절단의 통제 접촉·후속 제어·표현 [101검사/공개 근거](limb_default_release.json)는 해시와 관련 소스 동일성을 확인해 재사용했다. 이번 자연 전투에서는 절단이 없었으므로 발생률·자연스러움 검증으로 확대하지 않는다. 실제 상처와 화면 표시를 인위적으로 생성한 새 장면도 없다.

절삭·받아내기는 독립 감사와 관찰OFF 대조를 거쳤다. 절삭의 초기 계측 오류2실행도 보존했다. 이 검사는 조직 파괴의 완전한 에너지 모델이나 전체 무기·인간 동작을 인증하지 않는다. 사용자가 유보한 보조팔 파지/힘/피해 공백과 v2 미승격2종은 그대로 남는다.

**다음은3회차 통합·최종 전달이다.** 이번에는 게임 코드 변경0이므로 이미 통과한 같은 코드의 전 무기·진입·재시작을 반복하지 않는다. v2·회복·재베기·충돌·부상 근거를 묶고, 실제 남은 대표 통합 경계만 검사해 채택/보류/유보를 최종 분리한다. 공개 게임과 휴대폰 실행 계획의 전달은 [이번 영수증](phase3_round2_release.json)을 따른다. 사용자가 지금 추가로 비교할 새 조작판은 없다.
