# 3단계 3회차 · 통합과 최종 판정

**정한 3회차 범위의 핵심 통합 검사를 마쳤다. 게임 코드는 유지한다.** 일반판은 v2·회복fresh·재베기bounded·절삭centerline·사지 절단ON·중력9.81이며 갑옷 마무리 B는 선택형이다. 기준 `ede1807c9b4bb45f8309f00a3b748e9b2aecdcb0`.

기존 청강검의 실제 팔 절상→재베기, 갑옷/절삭/받아내기, 절단 제어·표현 검사는 해시·소스 호환성을 확인해 재사용했다. 새 검사는 예전 회복 장면에 없었던 **현재 재베기+절단 기본값의 츠바이핸더 회복→수동 타격**, 공개 웹의 **실제 부상 뒤 중단·재개·재시작**으로 한정했다.

헤드리스 장면은 손 이동을 끝낸7step 뒤의 관성 타격이다. tick2037 후속 목 절상·참수로 상대가 사망하여 손 입력245/324step에서 종료됐으므로 전체 놓기 완료를 주장하지 않는다. 관찰OFF는 같은 장면의 대조이지 별도 효능 표본이 아니다. 브라우저는 실제 게임7.4417초·893step의 한 실행으로, 완전 기립·부상 뒤 타격 효능이나 실물 폰 성능 검사가 아니다. [수치·명령·원자료·재사용 감사](phase3_round3_20261007.json), [공개 입력/재시작](phase3_closure_mobile_20261007.md).

**판정:** 2단계 공통 조작 기반에 이어 3단계의 대표 충돌·피해·표현·부상/회복/다음 입력 통합을 닫고, 다음은4단계 폰 반복 플레이 품질·성능·판독성이다. 갑옷 보호 B 일반 승격은 사용자 결정 대기, 보조팔 상실의 힘/파지 공백·v2 미승격2종은 명시적 유보다. 자연 사지 절단 빈도·작은 상처 선의 육안 식별·모든 무기의 인간 동작을 완료 처리하지 않는다. 새 힘/속도 배율이나 실패 후보를 넣지 않았다.
