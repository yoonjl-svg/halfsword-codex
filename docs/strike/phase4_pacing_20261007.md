# 4단계 · 상대 첫 공방의 두 결함 수정

**브란의 승인된 시작 성향과 상대 공격 경로의 종료를 복구한다.** 사용자 지시 “다음 작업 시작해”에 따라 `0eaadf8c74702a7a9ca1bd960877afcf6eb7835a`에서 대표 상대의 접근→첫 공격→공방을 확인했다. 실제 공개 완료 여부는 [전달 영수증](phase4_pacing_release.json), 소스·원자료 해시와 검사 명령은 [기계 기록](phase4_pacing_20261007.json)을 따른다.

## 확인한 문제와 결정

1. **브란 시작 인내심이 덮임.** [기존 사용자 지시](../characters.md#시작-감정공포-면역-사장-지시-2026-09-28)는 시작 분노0.7·인내심0.2다. 하지만 미초기화된 인내심에 제한을 적용한 뒤 무작위0.55–0.85로 덮었다. 기존 난수 호출을 그대로 소비한 뒤 지배 감정이 분노일 때만0.2 제한을 적용한다. 새 난도 조정이 아니다.
2. **공격 목표가 손의 이동 범위 밖에 놓임.** 옆 방향 보정 뒤 목표 `[-.6,-.42]`는 반경0.7324m지만 손은0.62m 안으로 제한된다. 남은 거리가 한 스텝 손 이동보다 크면 마지막 경로점을 끝내지 못한다. 공격 중 목표만 같은 원 안으로 투영한다. 속도를 올리거나 시간 초과로 강제 취소하는 우회책은 넣지 않는다.

두 수정은 `src/ai.js`에 국한된다. 플레이어 v2, 무기 힘·피해·이동 속도·중력9.81, 시작2초 대치, 상대 난도 수치는 유지한다. 브란의 약함이 의도라는 과거 결정도 유지하며 승률을 끌어올리는 목표를 붙이지 않는다.

## 검증과 한계

[실제 게임 비교](phase4_opening_20261007.md)는 브란·이졸데·마르그레테 × 대기/작은 전진·손동작, 동일seed7·10초씩이다. 수정 전후 각각7,200 native step. 새 관찰기의 비간섭은 별도1,200step에서 끝 물리 snapshot·입력·제어 상태 일치로 확인했다.

| 브란 전진 입력: 첫 실제 strike | 3.383 →3.442초 | 모든 공격을 일률적으로 빠르게 만든 것은 아님 |

브란의 접촉 결과는 달라진다. 대기 조건의 몸 타격2→0, 전진 조건1→2이며 후자의 새 목 둔타는 의식을 낮췄다. 이를 명중률·난도 개선이나 피해 불변으로 선언하지 않는다. 전투6조건의 지속 공격 정체는 수정 전에도 미노출이었다. 이졸데의 긴 간보기에는 현재 건강·거리·인내심에 따른 이유가 있어 임의로 줄이지 않는다.

실제 생성자 검사5개와 실제 `AI.moveHand`의60조건/306검사가 통과했다. 손 검사에는 세계·신체·피해 계산이 없고 공포 떨림/속임수 대기·자연 발생 빈도를 판정하지 않는다. 헤드리스 입력도 저작 대용이며 폰 사람 입력이나 인간 동작의 자연스러움을 입증하지 않는다. 독립 소스 검토에서 두 수정의 범위·난수 순서·정상 궤적 보존을 수락했다.

브라우저는 **상대만 브란으로 지정한 일반 카드 진입** `?foe=bran`을 사용한다. 무쿼리라고 부르지 않으며, 연구 제어를 켜지 않고 현재 일반 정책을 읽어 확인한다. 공개8파일 byte-exact, 실제 공개808step에서 시작 인내심0.2·첫 공격→strike→follow·중단/재개 후 새 touch·재시작을 확인했다. 첫 무기 츠바이핸더와 재시작 레이피어 모두 현재v2가 적용됐다. 오류0, 폰 계획390×844/844×390 overflow0. [영수증](phase4_pacing_release.json)에 소스/Actions/원자료 해시를 남긴다. 실물 폰 성능 검사는 아니다.

로컬 첫 자동 검사는 reveal0.5초에 너무 이른 넘기기 입력을 보내고10초 대기 제한에 걸렸다. 실제 허용0.95초 이후 같은 카드0 경로를 누르고 전환 대기를45초·전체150초로 한정해 교정했다. 최초 실패는 보존했으며 교정 로컬790step와 공개808step만 실행했다. 게임 수정·난수 주입·원하는 카드 재추첨은 없다.

## 재현과 다음 작업

기준 소스 동결본·후보·raw는 `/workspace/halfsword-handoff/phase4-pacing-20261007/`에 보존하며 파일별 크기/SHA와 명령을 JSON에 남긴다. 기준 생성자 검사는 **4통과·1실패(결함 재현)**였으며, 손 기준의 프로토콜 통과와 게임 계약 실패도 구별해 보존했다. 새 경로를 써서 이전 증거를 덮어쓰지 않는다.
