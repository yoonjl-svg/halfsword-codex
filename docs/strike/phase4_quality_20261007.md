[같은 3판 수정 전후 검사](phase4_repeat_20261007.md)에서 수정판의 시작 참조 수는 **185→185→185**로 돌아왔다. [소유권 회귀](phase4_quality_20261007.json)는 실제 효과 생성기·투구 정리의21개 검사를 통과했다. 이는 자원 수명 결함의 교정이며 실물 폰 FPS 향상률이나 GPU 메모리 절감량을 측정한 것은 아니다. 공격·이동·중력·관성·피해 수치는 그대로다.

[화면 가독성 검토](phase4_readability_20261007.md)는 기존 영상을 재사용했다. 약한 피복 타격을 “갑옷이 막았다”고 단정할 수 없어 새 알림을 넣지 않는다. 작은 상처 선의 가림도 확인했지만, 근거 없이 데칼·HUD를 키우지 않는다.

[일반 카드 진입 검사](phase4_entry_20261007.md)에서는 시작 대치 중 걷기 안내·조이스틱이 보이지만 이동이 의도적으로 잠겨 있음을 두 번 확인했다. 입력은 도착했고 대치 해제 후 정상 이동했다. 안내를 **“대치 후 왼쪽 조이스틱으로 걷기”**로 고쳤다. 기울기/키보드 안내도 맞추되 대치 시간·검 조작·카메라는 그대로다. 기존 수정판의 자원 검사는 재사용하고, 최종 공개 빌드에서 새 안내와 두 카드 진입을 확인했다.

공개8파일의 정확한 바이트 일치, 공개3연전과 카드 진입/재시작, 폰 계획의 세로·가로 배치를 확인했다. [영수증](phase4_quality_release.json)에 배포 SHA·Actions·원자료 해시를 남긴다.
