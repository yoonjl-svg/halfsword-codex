## 목표와 현재 결정

2026-10-02 후속 [사용자 다섯 피드백](realism_feedback_round2.md)을 추가했다. 절삭 후보는 자세 붕괴로 사용자 수락 실패다. 당시 P-03/P-04의 자동 조향 축소/제거 허용은 이후 사용자의 보정 유지·갱신 지시로 대체됐다. 현재는 검술 보정 v2를 고정한 상태에서 물리 오류와 의도된 관성/지연을 구분한다. P-03/P-06은 팔꿈치 상대각·위상/도달 포화를 계측하며, P-06의 수직 터치 증폭은 물리 힘 배율과 별도 입력 보정으로 구현한다. P-01은 COM 중력 일, P-05는 실제 접촉점 속도/전달량을 기준으로 한다. 칼끝에 중력을 작용시키거나 끝점 가속도/무게를 피해 보너스로 중복 적용하지 않는다. 기존 팔 도움 .3kg/피해 에너지 배율2의 근사도 실제 전신 전달로 오인하지 않는다.

사용자가 요구한 중심은 **중력·가속도·관성·체중을 손으로 느끼며, 지면부터 몸과 검까지 힘이 전달되는 강타**다. 다리 증상이나 `stand` 전환의 개선만으로 이 목표를 달성했다고 보고하지 않는다. 무거운 검은 같은 중력장에서 더 빨리 떨어져야 하는 것이 아니라, 질량 분포에 따른 가속·제동·지지 부담과 충돌 후 반응이 일관되어야 한다.

B(assist0.1/catch on/scale1)는 사용자가 A보다 조금 낫다고 느낀 비교 기준이다. 큰 차이는 없었다는 평가를 함께 보존한다. B를 실제 인간의 최적 제어값이나 해결 완료값으로 확정하지 않는다. assist와 catch를 동시에 바꾼 A/B 결과로 한 변수의 인과 효과를 추정하지 않는다.

초기 contact recovery R은 건강 장면도 기립에 실패했다. 게임 소스의 실험 연결을 제거하고 [재현 패치](../../tools/sim/experiments/README.md)와 [실행 요약](recovery_contact_round1_metrics.json)으로 보존했다. 접촉 기반 구조의 목적은 유효하지만 현재 R의 구현·공학 문턱은 채택 근거가 없다.

## 첫 우선순위: 계의 경계와 장부를 고정한다

신체 모델의 표현 한계를 함께 확인한다. [모델·협응 조사](body_model_assessment.md)와 [실제 생성물](body_model_inventory.json)에 팔 연결 길이/IK, 손·전완·어깨 자유도, 몸통/자기 충돌, 발 추가 질량을 기록했다. 기립은 같은 신체 체계의 체중 지지 검증에 계속 포함한다. 필요한 움직임이 뼈대에서 불가능한지, 가능한 움직임을 제어가 상쇄하는지 구분한 뒤 모델과 제어를 변경한다.

실험마다 포함하는 동적 몸·검·방어구와 고정 바닥/kinematic 기준체를 명시한다. 실제 강체 질량·COM·월드 관성 텐서를 읽으며, totalMass 상수·추가 발 질량·추가 관성 보정의 의미를 따로 적는다. 칼끝 높이는 mgh의 h가 아니다.

- 외력: 중력, 지면/벽/상대 접촉 충격량, 직접 지지/추진력, kinematic upright의 반력, 시험 외란. 관절의 k,d 설정을 실제 힘/토크로 대신하지 않는다.
- 내부 제어: 관절 PD의 spring/damping/목표속도, gravity feedforward, twist, 그립 spring/damping을 분리하고 부모·자식 반작용을 함께 기록한다. 읽을 수 없는 엔진 모터 충격량은 ‘미계측’으로 남긴다.
- 운동량·에너지: 전체 선/각 운동량 변화와 외부 충격량의 잔차, 병진+회전 K, 중력 V, 제어 일과 감쇠/접촉 손실을 기록한다. 그립 스프링 저장 에너지를 일과 중복 합산하지 않는다. 추가 관성·엔진 감쇠도 장부에 포함한다.
- 접촉: contactImpulse/dt는 우선 raw로 보존하고 별도 정적 교정이 끝난 정의만 N/BW로 해석한다. 단순 정적 75kg 상자에서 6/7 보정이 이번 Rapier 0.19.3·6회 솔버 설정에 맞음을 독립 교정했다. raw 858.3751N → 보정 735.7501N, Mg 735.75N이다. [교정 결과](contact_force_calibration_metrics.json). 인체 관절·충돌 과도응답에 대한 보정은 아직 검증하지 않았으므로 자동 일반화하지 않는다. solver 접촉점과 impulse 접촉 배열을 같은 인덱스로 대응시키지 않는다.

허용 오차는 측정 정의·솔버 교정·dt 비교로 정한다. 장부 잔차를 숨기기 위한 새 관절 상한이나 성공 문턱을 게임 규칙에 넣지 않는다. 단독 검의 ΔK와 mgh가 같지 않다고 곧바로 엔진 오류/손실로 판정하지 않는다.

## ground → 다리 → 골반/몸통 → 팔/그립 → 검 → 접촉의 검증 순서

| 순서 | 다음에 분리할 질문 | 최소 기록·다음 계층으로 넘기는 조건 |
|---|---|---|
| 1. 지면 | 실제 접촉·하중·마찰과 가상 지지 상태가 구별되는가? | 정적 접촉 교정, 전체 지면 충격량, 실제 접촉점 상대 점속도, 직접 상향/수평력. 바닥 제거에서 남는 직접 보조의 상태별 경로를 모두 식별한다. 공중 stand 방지만을 완료 조건으로 쓰지 않는다. |
| 2. 다리 | 관절이 발을 통해 지면을 밀어 체중과 회전을 받는가? | foot/shin 접촉, 다리 관절 총토크·반작용·일, 월드 발목 목표와 실제 위치, 부하 이동·미끄러짐·신전/중단. 다리 COM 속도를 미끄럼으로 치환하지 않는다. 실패도 전체 시도 분모에 넣는다. |
| 3. 골반·몸통 | 다리의 힘과 검의 반작용이 몸통으로 전달되는가? | 골반/몸통 각속도·각운동량, 몸통 관절 일, 지면 부하 이동, upright/직접힘 기여. 보조가 남아 있으면 그 몫을 공개한다. 골반 높이 또는 전체 운동에너지 하나로 체중 사용을 판정하지 않는다. |
| 4. 팔·그립 | 몸통 회전이 팔/검을 가속하며 제동 반작용을 다시 받는가? | 어깨·팔꿈치·손목의 PD/FF/twist 전후 토크, 부모 반작용, 한손/양손 그립 힘·점속도·저장 에너지. 여러 cap과 경로를 합친 실제 제어 일을 확인한다. 단순히 손목 힘을 높여 강타를 만들지 않는다. |
| 5. 검 | 지지·가속·관성 진행·제동이 질량 분포에 맞게 달라지는가? | 실제 검 m/COM/I, 방향·목표 각속도와 실제 속도, mgh의 일, K, 입력 종료 뒤 진행/제동 거리, 그립 반작용. 세계 g와 보상을 별도 표기하고 동일 초기 상태에서 한 항씩 바꾼다. 같은 목표 경로와 같은 토크 예산은 서로 다른 비교임을 명시한다. |
| 6. 접촉 | 몸·검에서 준비한 운동량이 충돌에 어떻게 전달되는가? | 충돌 직전 실제 접촉점의 상대 법선속도, 접촉점/법선/시간/충격량, 양쪽 운동량 변화와 제어 상태를 전투 PM에 전달한다. 검-몸 유효질량·날 방향·전달 에너지·손상 연결은 전투 PM과 루트가 별도 설계한다. |

위 순서는 몸의 활성화가 늘 직렬로 한 번씩 일어나야 한다는 생체학적 가정이 아니다. 역학 경계부터 검증하는 순서이며 실제 회전·부하·근육 협응은 겹치거나 상황에 따라 바뀔 수 있다. ‘전신 강타’는 공격자 전체 K를 피해 에너지로 넣는 규칙으로 구현하지 않는다.

## 작은 실험과 판정의 구분

먼저 같은 코드·초기 상태·검·입력에서 고정 지지/지지 제거, 한손/양손, 자유 진행/명시 제동 같은 한 축의 통제 비교로 장부를 닫는다. 체중 이동과 몸통 회전을 포함하는 경우도 손 입력·준비 자세·관찰 구간을 보존한다. 강타 검증은 이 계층 계약이 정리된 뒤 전투 PM의 접촉 시험에 연결한다.

| 근거 종류 | 사용할 수 있는 판단 | 사용할 수 없는 판단 |
|---|---|---|
| 엔진 교정·공학 통제 실험 | 법칙·힘 경로·계측 단위·잔차·회귀 및 특정 결함 인과 | 자연스러움, 실제 부상자의 근력/반사 상수, 게임의 최적값 |
| 문헌의 사람 실측 | 사건 정의, 접촉 순서, 지면 하중·관절 부담·외란 회복의 관찰 지표 | 과제가 다른 검객/판금/심한 부상에 대한 고정 시간·최대토크·낙상 확률 |
| 문헌의 가정 모델·저작 클립 | 가설과 관찰할 방향·동작 의도·자기 관통/관절 목표 조사 | 실제 사람의 모캡/힘판 결과, 전달 에너지 또는 인간 한도의 확정 |
| 사용자 직접 플레이 | 중력·체중·관성·조작·피격 반응의 체감 수락 | 체감 차이 하나로 개별 제어 항의 기여 크기 확정 |
| AI 결투 | 충돌·실패·반복 입력 장면 확보, 게임 내 회귀 | 승률로 인간 유사성 또는 전신 강타의 역학적 타당성 입증 |

이미 공개 원문을 실제 열람한 연구는 Stutzenberger 등(2025, [PMC12452367](https://pmc.ncbi.nlm.nih.gov/articles/PMC12452367/), 활동적50–80세34명 바닥 기립·힘 비교24명), Hagedoorn 등(2025, [PMC12238075](https://pmc.ncbi.nlm.nih.gov/articles/PMC12238075/), 건강한 젊은15명 플랫폼 외란/자발 걸음), Hanawa 등(2025, [PMC12101179](https://pmc.ncbi.nlm.nih.gov/articles/PMC12101179/), 건강10명 의자 기립·CoP/EMG·2D 모델)이다. 여기서 접촉·FO/FD·몸통 자세·COM 속도·관절 요구의 측정 정의를 인계받는다. 표본·과제 차이 때문에 이 논문들에서 assist/catch 값이나 검 강타 한도가 직접 나오지는 않는다.

Meyer와 동작 PM 자료는 읽은 깊이·번역본 접근·실측/문헌/저작 클립을 구별한 기존 연구 인계를 유지한다. 교본의 전술·동작 설명을 힘/토크의 실측 수치로 바꾸지 않는다. 검객의 전신 강타 실측, 부상·무기·판금 조건의 지지/회복 자료는 여전히 공백이다.

## PM 입력/출력 계약과 완료 보고

물리·조작은 입력 목표와 실제 강체 반응을 분리해 지면부터 그립까지 외력·토크·반작용·일을 제공한다. 물리·조작 PM은 기존 동작 연구도 맡아 문헌/실측/저작 클립별로 몸통·골반·팔의 동작 의도와 측정 정의를 제공한다. 전투 PM은 실제 접촉 전후 양쪽 상태와 접촉 기하를 받아 검-몸 전달/손상 계약을 맡는다. 루트는 장부·통제 비교·사용자 체감을 함께 통합한다.

후속 보고는 ‘측정/구조가 통과한 범위’와 ‘미계측 경로’, ‘사용자 체감 수락 여부’를 따로 적는다. 건강 기립도 실패한 초기 R, 바닥 없는 상향력, B에 대한 사용자의 작은 선호를 유지한 채 다음 설계를 정한다. 지면부터 접촉까지의 전달과 실제 플레이가 확인되기 전에는 자연스러운 전신 강타를 구현했다고 보고하지 않는다.


## 전신 타격에서 먼저 검증할 두 경로

1. **입력 목표의 좌표계.** `Fighter.driveSword`는 손 목표와 검 방향을 실제 가슴 회전이 아닌 `this.yaw`로 월드화한다. `armIK`는 실제 가슴 회전을 역변환해 그 목표를 유지한다. 몸통 회전의 기여를 제어기가 얼마나 상쇄하는지는 아직 미측정이다. 같은 준비 상태·무기·손 입력에서 몸통 회전 고정/허용 × 이동 고정/허용의 네 조건을 비교한다. 고정 장치의 반력·일도 외력으로 계상한다. 확인 후 입력 의도를 유지하면서 몸통의 실제 움직임을 받아들이는 목표·근력 제어를 한 경로씩 바꾼다.
2. **물리량과 피해량.** `Combat`의 접촉 상대속도는 실제 `v+ω×r`이지만, `ephys`는 검의 유효질량에 고정 팔 도움 .3kg을 더하고 이후 `energyScale=2` 등 배율을 적용한 값이다. 이것은 공격자 전신의 전달 에너지 측정이 아니다. 베고 지나감의 수동 충격은 검 −J/상대 +.8J이며 30m/s 초과 접촉은 판정에서 제외된다. 실제 양쪽 운동량·충격량·접촉 속도를 먼저 분리 기록하고, 피해 배율을 올리는 방법으로 전신 타격을 대체하지 않는다. 절삭·찌름의 손상 모델은 운동량 보존과 별개로 검증한다.

그 뒤는 다음 세 회차로 진행한다. 소요 시간은 각 회차 착수 때 앞선 결과를 반영해 다시 보고한다.

- **체중 지지:** 실제 지면 접촉과 마찰 한계 안에서 다리의 반작용으로 서고 추진하게 한다. 골반 직접 보조의 책임을 관절로 점진적으로 넘긴다. 무접촉 외부 받침, 한 발/양발 지지, 부상 시 하중 이동/중단을 함께 본다. ‘일어남 상태’가 아니라 하중 이전과 운동량으로 판단한다.
- **전신 가속·관성·제동:** 몸통/이동 네 조건과 동일 토크 예산·다른 질량/관성의 검 비교로 시작한다. 목표추종·중력 보상·제동의 합이 실제 근육 예산을 넘지 않게 정리하고, 가속·따라가는 움직임·멈추는 부담이 일관되게 나오도록 한다. 단순 감쇠 증가나 손목 강화는 처방으로 고정하지 않는다.
- **접촉과 플레이:** 몸통/검 운동이 충돌 상대에게 전달되는지 확인한 뒤 실제 베기·받아내기·빗맞음·과도한 강타 후 빈틈을 휴대폰 웹에서 비교한다. 인간 피드백은 사실감·조작감의 필수 수락 조건이다.
