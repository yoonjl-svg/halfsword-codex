# P4 재베기: 완성된 날 목표의 회전속도 제한

판정: **좁은 선택형 비교로 전달 가능**. 기존 목표 급변을 제한하면서 관측한 자유 베기 속도·검 운동에너지와 실제 첫 타격을 보존했고, 후속 입력과 관절 연결도 유지했다. 전체 불필요 회전 해결, P4 전체 완료, 일반판 승격 또는 모든 전력 타격의 위력 보장은 아니다. 이 문서는 물리 근거와 전달 허용 판정이며 실제 공개·모바일 확인은 별도 전달 기록을 따른다.

## 변경과 근거

`src/roll_target.js`는 기존 rest/moving 법선 선택·혼합을 마친 **최종 지향 목표**만 처리한다. 이전 목표를 새 검축으로 운반하고, 그 축 주위 목표 변화량을 `wristVmax × sqrt(strength) × dt` 이내로 제한한다. 기준 강도·120 Hz에서는 약 **14.32°/step**이다. 기존 `wristVmax`를 제한된 후보의 명령 예산으로 사용했으며, 인체 최적 회전속도를 입증한 값은 아니다. 물리 자세·실제 각속도를 강제로 고정하거나 손 입력·힘을 줄이지 않는다. 다만 목표를 바꾸면 실제 힘과 접촉 결과도 달라질 수 있다.

과거 rest/temporal/planePotential/tensor/velocity 교체·command-plane 실패안을 재활성화하지 않았다. 실험 helper와 생산 helper의 활성 경로 수학은 같고, 실제 접촉 두 쌍은 생산 helper를 직접 사용했다. 생산 코드의 비활성·우회 시 이력 초기화는 별도 보호다. `prevAim` 비활성 구간 초기화 수정과도 근거를 구분한다.

자유 공간의 동일 444-step 입력을 청강검(Q)·롱소드(LS)에 적용했다. 먼저 재베기 직전 tick318에 선택한 4행, 이어 생성부터 선택한 4행이다. 후자의 재베기 30-step 결과는 다음과 같다(기준 → 후보).

| 항목 | LS | Q |
|---|---:|---:|
| 최대 목표 변화/step | 42.06° → 14.32° | 40.41° → 14.32° |
| 검 끝 최고속도 (m/s) | 7.8587 → 7.8620 | 10.0719 → 10.1285 |
| 검 끝 평균속도 (m/s) | 4.9968 → 5.0089 | 6.3942 → 6.4008 |
| 검 평균 운동에너지 (J) | 7.2333 → 7.2324 | 7.8532 → 7.9112 |
| 실제 날 면 오차 변화 | +0.73° | +4.39° |
| 축방향 누적 회전 (rad) | 1.1961 → 1.0996 | 2.8176 → 2.8273 |

속도·에너지는 이 표본에서 근접하게 유지되었으며 수학적 불변은 아니다. 날 오차는 실제 .7 blade 점 횡속도로 가중한 무방향 면각이다. 축 누적은 움직이는 검축에 대한 `∫|ω·axis|dt`이므로 무조건 작을수록 좋은 점수로 쓰지 않는다. 전체 자유 입력에서 지향 목표와 실제 날 사이 90° 초과는 없었다.

## 실제 접촉과 남은 한계

LS 대 츠바이핸더, seed7, 정상 간격 5.6 m, 중력 9.81, v2 r2/manual·기존 절삭·상대 AI를 고정했다. 240-step 시작 잠금 뒤 정상 조이스틱으로 접근했다. 기준의 실제 간격 2.8 m 진입 시점(tick420)을 양쪽 동일 터치 시작으로 사용했다. 후보는 생성부터 플레이어에게만 켰다. 좌표·체력·장비 주입은 없다.

- 첫 생존 상대 절삭은 양쪽 tick576–578이며 **첫 베기 전체와 타격이 exact**다. 첫 목표·native 차이는584, controller 차이는585였다. 따라서 이 첫 타격만으로 제한기 개입 뒤 능동 절삭 위력을 입증하지 않는다.
- 864-step 전체와 한 번 연장한 1,002-step 전체에서 플레이어 요청·적용 입력이 같고 모두 수락됐다. tap·반전·재베기·놓기까지 생존·무기·그립을 유지했으며, 지향 목표 오차 90° 초과는0이었다. 이전 round4 기준의 697-step native/controller도 exact다.
- 개입 뒤 양의 절삭 반작용은 **tap 구간에서만** 기준34/후보33쌍이다. 48-step 올림·24-step 버팀·30-step 베기·36-step 버팀과 정상 전진을 한 번 추가했지만, 추가 능동 베기의 양의 절삭 반작용은 양쪽0이었다. 생존 상대의 둔타 접촉은 있었으므로 “접촉 전무”로 해석하지 않는다. **개입 후 능동 절삭 접촉 관문은 미노출이며 통과로 바꾸지 않는다.**
- 상대 입력은646부터 갈라졌다. 이후 tap 축 최고속도는33.14→43.94 rad/s, 놓기 축 누적은2.594→3.403 rad로 후퇴했다. 반대로 일부 구간은 개선됐다. 이는 반응하는 전투에서 관측한 한계이며, 단독 위력·승패 효과나 후보의 인과적 실패로 단정하지 않는다. 목표 변화 제한은 실제 회전속도 제한이 아니다.

Q의 실제 접촉, 폭넓은 무기·상태, 외형 자연스러움은 이 검사로 확정하지 않았다. 다음에 공격 위력 보장을 확대할 때는 **제한기 실제 개입 뒤의 생존 상대 능동 절삭 한 쌍**을 먼저 확인해야 한다. 이번 회차는 추가 거리·seed 탐색 없이 종료했다.
