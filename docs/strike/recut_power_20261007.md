# 재베기 보정 뒤 실제 절삭 위력 · 2026-10-07

**판정:** 미뤘던 롱소드·청강검의 실제 수동 재베기 접촉 검사를 마쳤다. 보정이 실제 개입한 뒤 살아 있는 상대를 베어 상처를 전달했다. 검사한 재베기의 칼끝 속도·검 운동에너지 차이는 근소했고, 피해·근력 배율을 바꿀 근거는 찾지 못했다. 모든 공격의 피해가 같거나 커진다는 보장은 아니다. 게임 코드는 변경하지 않고 현재 일반판을 유지한다.

청강검의 한 몸통 타격만 보면 에너지가 작아졌으나, 후보에서는 먼저 위팔을 베고 뒤이어 몸통에 닿았다. 아래 접촉 순서와 감속을 함께 봐야 한다. 이를 보정이 무조건 위력을 낮춘 증거로 쓰거나 임의 배율로 상쇄하지 않는다.

## 무엇을 실행했나

기준 `f395a13b6c62c5f15faa017270eebad5c3f0618f`, 중력9.81, 실제 Fighter·Combat·Rapier를 사용했다. 플레이어는 생성부터 v2·수동 팔·회복 fresh·타격 centerline·팔다리 절단 ON이다. 재베기 목표만 legacy/bounded로 비교했다. 상대는 seed7·츠바이핸더·보통 AI이며 플레이어 감정 갱신은 기존 헤드리스 도구의 중립 조건이다.

- 정상 시작 간격5.6m에서 조이스틱으로 접근했다. 캐릭터·검의 좌표/속도/체력·방어구·상처를 주입하지 않았다.
- 처음 두 프로토콜의4행씩은 개입 후 유효 재베기를 확보하지 못했다. 계속 전진한 입력은 지나치게 밀착했고, 거리만 관리해도 기존 상대량 손 입력의 후속 베기가 맞지 않았다. 실패 결과를 보존했다.
- 세 번째는 기존 자세표의 오른 어깨 `[.42,.42]` → 왼 아래 `[-.4,-.42]`, 왼 어깨 `[-.4,.42]` → 오른 아래 `[.38,-.44]`를 일반 손 입력으로 이었다. 순간 자세 강제 설정이 아니다. 기준의 정상 아날로그 조이스틱으로 골반 간격1.15m를 관리하고, 후보는 기록된 손·이동 입력을 그대로 재생했다. 새 seed·거리 전수 탐색은 하지 않았다.
- 마지막은 청강검 상대 AI의 입력만 idle로 고정한1쌍이다. 다른 물리 상태는 주입하지 않았다. 이어 원본 Fighter를 사용한 계측 제거1행으로 재생 동등성을 확인했다.

총 **15실행·14,234step·물리 실행 벽시간28.25초**다. 준비·원인 분석·문서 시간은 제외하며 계측 대조1행을 독립 효과 성공으로 세지 않는다.

## 실제 베기와 위력

반응하는 상대4행 모두 생성·요청 입력·실제 적용 입력이 같았고, 첫 목표 제한 전 native 상태도 같았다. 목표 제한은 LS tick516, Q585부터 실제로 개입했다. 이후 상대 AI 입력은 LS544, Q588부터 갈라졌으므로 뒤의 피해는 동일 충돌 상태 비교가 아니다.

| 수동 재베기 결과 | 기존 목표 | bounded 목표 |
|---|---:|---:|
| LS 골반 접촉 에너지 | 68.38J | 71.50J |
| LS 골반 상처 심각도 | 0.290 | 0.323 |
| Q 골반 접촉 에너지 | 52.65J | 34.41J |
| Q 골반 상처 심각도 | 0.369 | 0.085 |
| Q 그보다 먼저 기록된 위팔 베기 | 없음 | 44.19J·심각도0.419 |

LS 후보는 위 골반과 앞다리, Q 후보는 주팔 위팔과 골반에서 실제 `Combat.strike`·상처 훅을 확인했다. 드래그 끝은 tick719, 접촉은728–732로 **손 이동 종료75–108ms 뒤 관성 진행 중 타격**이다. 탭 찌르기나 합성 상처가 아니지만, 접촉 순간 `inputActive=true`인 절삭을 확인한 것은 아니다. 같은 재베기 동안 목표 제한이 추가 개입한 step은 LS6/Q0이며 Q는 앞선 개입 뒤 도달한 실제 상태에서 재베기했다. 양쪽 검객은 전체 입력 종료까지 생존했고 플레이어 무장·그립을 유지했다.

Q 골반의 `passing=true`는 실제 통과 접촉 처리 경로이고, 그 접촉을 다시 분석한 `pass=false`는 당시 에너지가 추가 관통 문턱을 넘지 못했음을 뜻한다. 이 둘을 모두 관통 성공으로 쓰지 않는다. 위팔 베기는 `passing=true/pass=true`다.

## 청강검 몸통 에너지 차이 분해

| 같은 골반 부위·tick732 | 기존 목표 | bounded 목표 |
|---|---:|---:|
| 접촉 상대 속도 | 11.138m/s | 9.066m/s |
| 유효 질량 | 0.42445kg | 0.41866kg |
| 날 길이상 접촉 위치(0–1) | 0.9028 | 1.0000 |
| 실효 에너지 / 접촉 에너지 | 1.3907 | 1.3854 |
| 상처 시작 문턱 | 40J | 40J |

`E = mEff × speed²`인 현재 판정에서 질량비×속도비²가 실제 에너지비0.6535와 일치한다. 날 품질·무기/감정 배율의 합성 비율 변화는 작고 문턱도 같다. 접촉 상대 속도 차이가 주된 수치 요인이다. 이 표의 속도는 해당 접촉점과 맞은 몸의 상대 속도이며 전체 공격 속도가 아니다.

수동 재베기 입력 구간의 칼끝 최고속도는 **10.420→10.390m/s(−0.29%)**, 평균 검 운동에너지는 **3.268→3.257J(−0.34%)**였다. 첫 기록 절상 직전인 tick727의 **post-step 표본**도 칼끝14.562→14.552m/s, 검19.622→19.666J로 근접했다. tick728에 후보는 위팔을 베었고 검 에너지는11.525J, 기존은18.672J였다. 후보가 먼저 다른 부위에 에너지를 전달한 순서와 이후 몸통 타격의 낮은 속도가 함께 관측된다.

이는 모든 감소를 팔 절삭 저항 하나로 분리해 입증한 실험은 아니다. 개별 저항 충격량/일 장부는 수집하지 않았다. `strikes[]`는 null 결과·모든 native 접촉을 기록하지 않으므로 기존728에 기록된 상처가 없다고 물리 접촉까지 없었다고 말하지 않는다.

## 상대 반응 제거·계측 검증

- **Q idle1쌍:** 생성·손/이동·상대 입력이 모두 같았다. 재베기 칼끝 최고15.179→15.228m/s(+0.32%), 평균 검7.756→7.731J(−0.32%)다. 후보 전완 접촉이1step 먼저였고 뒤의 몸통 부위·에너지는 달라졌다. 양쪽 유효 절상은0이라 이 행을 절삭 위력 보존 통과로 쓰지 않는다. 적 AI 반응을 제거해도 물리 접촉 순서는 달라질 수 있음을 확인했다.
- **계측 제거:** LS bounded954step을 raw/목표 callback이 없는 원본 Fighter로 재생했다. 전 native 스냅샷·양쪽 입력·개입 표시를 제외한 전체 타격 기록이 exact였다. 계측이 새 타격을 만들지 않았음을 해당1행에서 확인했다.
- 전 실행에서 소스 동결 해시·유한 상태·설정·입력 수락을 검사했다. 사람 자연스러움·모든 무기·모든 공격 피해 무감소의 검증은 아니다. 현재 한정된 위력 조사 때문에 새로운 힘·피해 가중치를 넣지 않는다.
