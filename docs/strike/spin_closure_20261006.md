# 두 무기 시작 급회전 교정 · 2026-10-06

모노호시자오·라이트세이버의 확정된 첫 자세 결함만 교정한다. [기존 시작 검사](startup_grip_20261004.md)는 보조손의 공통 작용점이 칼 축 밖에 놓여 작은 길이축 관성을 비트는 원인을 확인했다. 두 무기 생성 시 기존 `axial` 점을 기본으로 쓰고, 명시적 `gripPoint=midpoint` 비교는 보존한다. 질량·관성·근력·스프링 상수는 바꾸지 않았다. **최종 공개 영수증은 아직 미완료다.**

이번 실제 게임 12실행·9,978스텝은 보정 `.7`의 기존 제어를 사용했다. 두 무기의 v2 제외는 유지한다. 축점은 플레이어에 적용하고 상대는 롱소드인 범위를 검사했으며, 관찰 반복을 독립 효능 표본으로 세지 않는다. 현재 생성자 기본값의 공통 회귀·웹 전달은 별도 통합 검사 대상이다.

| 무기 | 이전 중점 시작 최대각속도 → 이번 축점 수동 입력 시작 | 베기→놓기→재베기 |
|---|---:|---|
| 모노호시자오 | 1378 → 9.37 rad/s | 두 베기 인식·복귀 활성, 무장/기립 유지 |
| 라이트세이버 | 1808 → 13.85 rad/s | 두 베기 인식·복귀 활성, 무장/기립 유지 |

두 수동 입력 행은 각각 생성부터 5.15초·618스텝이며 부상·상대 접촉이 없는 검사다. 전체 입력 중 축속도 43.41/40.53 rad/s는 남았지만 30 rad/s 초과의 최장 연속 구간은 25/41.7ms였다. 축속도 적분에는 반전이 섞이므로 연속 회전 수나 해부학적 손목 각도로 해석하지 않는다.

별도 `F·dt` 충격량 후보는 이산 에너지 주입으로 기각했다. 암시적 감쇠 후보는 수학·native 힘/일 검사를 통과했으나 손과 자루 간격·첫 베기 추종 후퇴와 후속 무접촉 급회전이 남아 공개하지 않는다. 낮은 축속도만으로 관성 개선을 선언하지 않으며 전투 급회전 전체 해결·v2 승격·사람 동작 수락은 미완료다.

기준 커밋·실행별 소스 해시·원자료 크기/SHA·복사 가능한 명령은 [재현 지도](spin_closure_20261006.json)를 따른다. [이전 전투 분리](axial_combat_20261004.md)의 접촉/비접촉 구분도 유지한다.
