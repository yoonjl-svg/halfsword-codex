# 기립 폭주와 실제 모터 힘 한도 — 독립 연구 3차

공개 지지 연구판은 계속 철회 상태다. 이번 작업은 게임 소스와 일반 설정을 바꾸지 않고, 폭주를 일으키는 native 제약과 근육 제어의 힘 한도를 분리한다. 현재 결과로 재공개할 회복 후보는 없다.

## 폭주 직전까지 동일한 상태에서의 분리

2차의 실패 후보 `catchLoad`를 그대로 재생했다. 첫 발 선택 변화는5.983초, 재넘어짐은6.108초였다. 뒤이어 접촉이 바뀌고6.492초에 운동에너지가 급증했다. 그 사이 질량과 자세 목표도 변했으므로, 초기부터 서로 다른 제어를 적용한 두 궤적의 최고점만 비교해서 원인을 단정하지 않았다.

새 `late_upright_probe.mjs`는6.433333초(772프레임)까지 같은 제어를 실행한다. 원판 전체 궤적, catchLoad 전체 궤적, 그 순간의 native world snapshot, 몸·관절·제어 상태 및772프레임 누적 해시가 대조와 일치해야만 다음 요청부터 개입한다. hook 설치 자체로 native/제어 상태가 바뀌지 않는 것도 검사했다. 모든 관문이 통과했다.

그 뒤 k=d=0인 upright 요청을 기존대로 보내는 경우와 실제 native 관절을 제거하는 경우를 비교했다. 양수 요청은 기존 모터로 처리하고, 필요하면 관절을 재생성한다.

| 관찰 시점 | 0계수 모터 유지 | 실제 비활성화 |
|---|---:|---:|
| 개입 직전6.433333초 운동에너지 | 38.382J | 38.382J |
| 다음6.441667초 운동에너지 | 70.627J | 24.205J |
| 6.491667초 운동에너지 | 3,456.561J | 14.980J |
| 같은 시점 관절점 최대 간격 | 27.900mm | 0.196mm |
| 전체 최고 골반 높이 | 2.832m | 0.882m |
| 전체 최고 운동에너지 | 4,166.878J | 365.805J |
| 전체 재넘어짐 | 4 | 6 |

에너지 급증 시점의 총질량은 두 경우 모두76.699998kg이었다. **이 실패 장면에서 0계수 native 제약을 유지하는 것이 폭주 경로에 기여한다는 직접 분리 근거**다. 단순한 질량 변화만으로 그 순간의 차이를 설명할 수 없다. 다만 관절 제거는 solver 상태도 바꾸며, native 접촉/모터의 일을 직접 측정한 것은 아니다. 모든 발사 증상의 유일 원인이나 기립 해결로 일반화하지 않는다. 이후 재넘어짐은 오히려 늘었다.

## 위치오차 한도는 전체 근력 한도가 아니었다

`Fighter.driveJoints`는 `maxErr = j.max * mus / k`로 목표 위치오차만 제한한다. 목표속도와 감쇠가 만드는 회전력은 이 한도 밖이다.

`native_motor_limit_probe.mjs`는 중력·접촉·몸 감쇠·수면이 없는1kg·m² 등방성 관성의 고정점 회전 관절에서 이를 재현한다. 같은 native snapshot의 분기끼리 비교하며, 측정치는 한 스텝의 `I * Δω / dt` 평균 native 회전력이다. 입력500N·m는 인체 근력 자료가 아닌 진단값이다.

| 입력 | 평균 native 회전력 |
|---|---:|
| 위치오차만500N·m 상당으로 제한 | 316.967N·m |
| 같은 위치오차 + 목표속도15rad/s | 1,288.998N·m |
| 초기 회전속도−15rad/s의 제동 | 1,350.552N·m |

자유 회전 대조의 회전력/에너지 변화는0이었다. 이 결과는 근력 한도 해석의 결함을 입증하지만 전신 폭주의 에너지 원인을 전부 설명하지는 않는다. 현재 Rapier JS API에는 이 native 모터의 최대 힘/충격량을 설정하는 함수가 노출되지 않는다.

## 발 추가 질량 분리

같은 자연 누움 checkpoint의 실제 발 질량1.100000024kg을 보존하고, 이후 Gait의 추가 질량 변경 요청만 억제했다. 실제 dispatch를 교체하고, 요청 실행 및 매 스텝의 질량 불변을 검사했다. 새 질량·관성·속도를 덮어쓰는 방식은 아니다.

| 후보 | 건강 재넘어짐 | 손상 재넘어짐 | 손상 마지막 연속 기립 기하 구간 |
|---|---:|---:|---:|
| 투영 축력 대조 | 0 | 3 | 6.792초 |
| 발 질량 고정 | 0 | 1 | 12.792초 |
| 질량 고정 + 실제 upright 비활성화 | 0 | 6 | 0초 |
| 질량 고정 + catchLoad | 0 | 1 | 9.292초 |
| 위 조합 + 실제 upright 비활성화 | 0 | 2 | 9.733초 |

고정 질량 catchLoad의 손상 최고 운동에너지는314.579J로 낮아졌지만, 개입 후 움직임 전체가 달라졌으므로 특정 시점 에너지 차이를 질량 삽입의 일로 계산하지 않는다. 질량 고정만으로 회복 문제가 해결되지 않으며 전체 후보 채택을 보류한다.

## 전체 회전력에 상한을 거는 연구용 제어기

`bounded_joint_motor.mjs`는 다리6관절의 native 모터를 제거하고, 부모/자식에 같은 크기의 반대 회전력을 건다. 위치·목표속도·감쇠를 합한 **최종 벡터 크기**를 기존 근력 값으로 제한한다. 관절의 각도 한도와 연결점은 유지한다. 연결을 다시 만든 것만의 효과를 분리하는 `recreatedLegMotors` 대조도 둔다.

회전력 요청은 두 자유 강체의 역관성으로 근사한 implicit PD다. 접촉과 연결된 나머지 몸의 관성은 이 근사에 포함되지 않는다. 이 상한은 해당 근육 actuator의 적용량이며, 수동 관절/접촉 반력과 게임의 다른 보조력까지 제한한다는 뜻이 아니다. 목표 회전의 벡터 속도 제한도 기존 축별 제한과 달라, 이 후보 전체를 단순한 native cap 교체로 부르지 않는다.

독립 검토에서 Gait의 `resetRates`가 native 목표속도 이력을 초기화하는데 새 후보의 quaternion 이력은 남는 문제가 발견됐다. 새 `prevRV` 객체를 감지한 첫 요청에서는 목표속도를0으로 만들도록 수정했다. 수정 전10행은 별도 원자료로 보존하고 최종 후보 평가에서 제외한다. 단일 관절의 float32 각속도 차분으로 발생한 약1.49e−5N·m의 횡축 잔차 때문에 초기 시험이 한 번 실패했으며,500N·m 축 토크의 검증 허용오차는 유지하고 횡축 허용오차만1e−5→1e−4N·m로 고쳤다. 물리 코드 수정으로 시험을 통과시킨 것은 아니다.

교정6그룹은 모두 통과했다. 고정점500N·m 시험의 실제 평균 토크 최대500.000127N·m는 명시한 float32 허용오차 안이었다. 힘쌍 각운동량 보존, 기울어진 경첩 축, 감쇠만의 에너지 감소, 잘못된 입력9개의 무변경 거부, 실제 Fighter의 native 모터 호출 차단과 목표속도 이력 초기화를 검사했다.

수정 뒤 전신10행에서도 원판/같은 native·제어 상태/입력/실행/소스 불변 관문을 모두 통과했다. 재생성만 한 대조는 건강·손상 모두 projected 전체 궤적과 exact였으므로 이번 장면의 차이를 재생성 자체에 귀속하지 않는다.

| 후보 | 건강 재넘어짐 | 손상 재넘어짐 | 손상 기립 기하 구간 | 판정 |
|---|---:|---:|---:|---|
| 재생성만, 기존 native 모터 | 0 | 3 | 있음 | projected와 exact |
| bounded 다리 | 2 | 6 | 없음 | 기각 |
| bounded 다리 + 실제 upright 비활성화 | 8 | 6 | 없음 | 기각 |

native 비활성화까지 조합한 건강 후보는 최고 운동에너지4,022.145J·관절점 최대 간격52.500mm로 다시 크게 불안정했다. 따라서 upright의0계수 문제를 없애는 것만으로 모든 폭주가 사라진다는 주장도 하지 않는다.

다리 actuator의 벡터 상한은 모든 호출에서 반올림 범위 내로 지켰지만, 손상 후보마다15,984회 중 상한 포화는3회뿐이었다. 따라서 이번 회복 실패를 “인간적 근력 제한이 너무 낮아서”라고 단정할 수 없다. 두 자유 강체 implicit 응답과 전신 native 제어의 차이를 먼저 식별해야 한다. 기립 기하는 관찰값이며 인간의 자연스러움 판정 또는 제어 문턱이 아니다.

## 연결된 몸에서 실제 관절 응답 확인

후속 `joint_response_probe.mjs`는 회복 시험과 별개로 일반 legacy 지지/받침.3, 수동 양쪽 캐릭터, seed7, 거리8m, 벽 없음으로3초간 보통 서기를 준비한다. 여섯 다리 모터만 미구성 관절로 다시 만든 뒤 모든 동적 몸의 명시적 force/torque 누산기를 동일하게 비우고 하나의 snapshot을 만든다. 몸 위치·속도·질량·관성과 관절 개수는 보존되며, 지면·상체/upright native 모터·중력은 남긴다. 각 분기에서는 controller update 없이 physics 한 스텝만 실행한다.

같은 snapshot에서 앞쪽 고관절/무릎/발목의 부모 Z축으로0 및 ±.001/.01/.1N·m·s의 회전 충격량 힘쌍을 가했다.0입력은 관절마다 두 번 재생했다. 총24분기의 초기 몸 상태와 restored native 상태가 서로 exact이며,0입력 결과도 exact다. impulse 직후의 상대 각속도 변화는 자유 두 강체 예측과 float32 허용오차 내로 일치한다.

| .001N·m·s 시험 | 자유 두 강체 예상 응답 | 한 스텝 뒤 ±중앙차분 응답 | 예측 대비 비율 |
|---|---:|---:|---:|
| 앞 고관절 | 26.2708 | 2.0527 | 7.81% |
| 앞 무릎 | 31.3778 | 8.3865 | 26.73% |
| 앞 발목 | 83.6075 | 2.3548 | 2.82% |

응답 단위는 `(rad/s)/(N·m·s)`다. 첫 impulse 자체의 적용 오류보다, 다음 solver 단계의 연결 관절·접촉·나머지 모터가 응답을 크게 바꾼다는 근거다. 발목.1N·m·s의 +/− 응답 계수는3.7200/7.0953으로 방향 의존성도 크다. 이를 고유 유효 관성으로 단순 역산하거나 사람의 관성이라고 부르지 않는다. 자세 하나·스텝 하나의 결합 응답이며 회복 자세까지 같은 비율이라는 뜻도 아니다.

첫 실행은 원본 snapshot과 restore 후 재직렬화 bytes의 exact 관문에서 멈췄다. 몸 상태는 원본과 exact였고, 최종 검사에서는 동일한 입력 snapshot 및 restored 분기끼리 native exact를 요구하면서 원본 재직렬화 차이를 별도 기록했다. 두 번째는 작은 impulse의 float32 차분 허용오차에서 멈춰, 즉시 자유 두 강체 응답의 상대 허용오차를1e−7→2e−6으로 명시했다. 두 미완료 자료는 판정에서 제외하고 최종9관문이 모두 통과한 r3만 사용한다.

## 재현과 다음 판단

회복 비교는 건강/앞다리 controller health .45, longsword, seed7, B(.1/on/1), paired, 각25초다. 실제 상처와 공격 입력·누움 방향으로 확대하기 전의 선별 검사다. 같은 대조 궤적 반복은 독립 표본으로 세지 않는다.

```sh
node tools/sim/experiments/native_motor_limit_probe.mjs --out=/tmp/native-motor-limit.json
node tools/sim/experiments/late_upright_probe.mjs --out=/tmp/late-upright-new.json
node tools/sim/experiments/bounded_joint_motor.test.mjs /tmp/bounded-tests.json
node tools/sim/experiments/joint_response_probe.mjs --out=/tmp/joint-response-new.json
node tools/sim/experiments/recovery_control_probe.mjs --variants=projected,constantFootMass,nativeConstantFootMass,constantMassCatchLoad,nativeConstantMassCatchLoad --out=/tmp/recovery-mass.json
node tools/sim/experiments/recovery_control_probe.mjs --variants=recreatedLegMotors,boundedLegMotors,nativeBoundedLegMotors --out=/tmp/recovery-bounded.json
```

후속 순서는 실제 비활성화 의미를 유지하면서, 이번 결합 응답 측정을 낮은 기립 자세와 접촉 상태별로 넓혀 그 응답에 맞는 bounded 근력 제어를 설계하는 것이다. 하나의 서기 자세에서 얻은 응답 비율을 전역 gain으로 쓰지 않는다. 낮은 자세에서 손/무릎 지지를 거쳐 발을 몸 아래로 모으는 동작도 필요하다. 독립 관절의 힘 상한 충족을 전신 협응이나 자연스러움의 성공으로 바꾸어 해석하지 않는다. 단순 gain 증량, 상태 고정, 순간 자세 이동 또는 관찰 문턱 조정으로 통과시키지 않는다.

측정 비용은 질량12행80.737초, late 분리22.438초, bounded 수정 전10행70.171초·수정 후10행68.210초다. 반복된 대조를 독립 표본 수에 더하지 않는다.

소스·명령·소요·관문·원자료 해시는 [지표](support_motor_limits_round3_metrics.json)를 따른다. 대용량 원자료는 저장소 밖 로컬에 보존하며, 외부 백업이 확인된 것은 아니다. 게임 소스 변경과 Pages 배포는 없다.
