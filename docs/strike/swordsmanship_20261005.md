# 단일 검술 보정 통합 후보

목적은 현재 무기·물리에서 준비 자세와 몸 사용·놓은 뒤 복귀를 되살리고, 이후 플레이 비교의 공통 기반을 만드는 것이다. 일반판 승격이 아닌 선택형이다. [설계](swordsmanship_design_20261005.md), [무기/문헌 근거](swordsmanship_profiles_sources_20261005.md), [소스·명령·원자료·수치](swordsmanship_20261005.json)를 구분한다.

한 목표 정책이 손·칼·몸과 찌르기 인계를 작성한다. 첫 입력이 초기 offset에 흡수되는 결함과 실제 드래그 뒤 dead-band 때문에 홈 옆에 멈추던 결함을 수정했다. 강도 메뉴를 없애고 무기만 고른다. 기존 근육·관절 한도는 유지하지만 목표와 실제 힘·접촉은 달라진다.

| 실제 선별 | 기준 → 후보 / 판정 |
|---|---|
| 청강검 옆 준비 | 안내 offset 평균 2 → 12.14cm. 도움은 커졌으나 손 추종 오차 평균 24.1 → 43.1mm로 증가 |
| 롱소드 높은 준비 | 손 추종 오차 평균 107 → 16.4mm. 이 값만으로 자연스러움을 판정하지 않음 |
| 입력·복귀 | 같은 공급 입력, 생성 복귀 중 새 swing/lunge 및 held 이동 0. 실제 손 목표 평면 투영 최소 .65 |
| 찌르기 종료 | 다음 실제 손 목표 변화 청강검 11.30 → 14.35mm, 롱소드 9.67 → 12.55mm. 내부 준비 목표의 큰 변경은 완전 찌르기 아래 가려지며 최종 목표 점프와 구분 |

모노호시자오·라이트세이버는 기준/후보 양쪽에 심한 축 회전이 있어 **새 통합 선택에서 보류**했다. 나머지 무기 smoke도 자연스러움 인증이 아니다. 청강검 일부 준비/복귀 회전과 롱소드 사선 베기 속도 변화는 화면·체감 판정에 남긴다. 실제 전투에서 청강검 후보는 피격 뒤 getup→stand를, 롱소드는 getup 진입을 관찰했으나 심한 주팔 손상과 마무리·조기 중단은 미관측이다. 다른 접촉/상처 이후 생존 차이를 효능으로 쓰지 않는다.

원자료는 저장소 밖 새 이름으로 보존한다. 개발 중 실패 단위 결과도 남겼으며 최종 고정 소스 검사와 구별한다. [전달 영수증](swordsmanship_release.json): 코드 b973063·Pages 성공·공개8파일 byte exact·공개 모바일12흐름/오류0을 확인했다. 로컬 최초 기능12흐름은 통과했으나 전환 중 이미지 요청 오류로 전체 FAIL을 보존했고, 도구 대기 수정 뒤 해당5메뉴만 재검사했다. 공통6회귀도 통과했으며 일반판 승격·인간 자연스러움 수락은 아니다. 다음은 통과 범위의 단일 시험판에서 사용자 자세 도움/자유도 균형을 확인하고, 같은 정책을 후속 A/B의 양쪽에 적용하는 것이다.
