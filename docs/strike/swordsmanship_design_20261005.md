# 현재 게임의 공통 검술 보정

2026-10-05 KST. 사용자는 초기 검술 보정을 현재의 다종 무기·물리 체계에 맞게 갱신하고, 강도 단계를 없애거나 줄이며, 최종 보정과 같은 기반에서 플레이 평가하도록 지시했다. 청강검의 작은 v2 안내는 그 전체 요구를 충족한 후속 체계가 아니었다. 이번 산출물은 **일반 게임 승격 전, 단일 기본 보정을 쓰는 다종 무기 통합 시험판**이다.

## 목적과 역할

플레이어가 베기 방향·높이·속도·중단·명시적 찌르기를 결정하면, 검술 층은 무기에 맞는 준비와 몸 사용·다음 동작 연결을 돕는다. 실제 가속·감속·접촉·부상 결과는 현재 근육과 물리가 만든다. 목표만 바꾸어도 실제 토크·접촉·생사가 달라질 수 있으므로, 힘 상수 불변을 동작 불변으로 쓰지 않는다. 모든 동작의 최대 힘·가장 빠른 정지·작은 추종 오차를 공통 최적화 목표로 삼지 않는다.

| 기존 역할 | 이번 정책 |
|---|---|
| 손·칼 자세표 | 무기별 준비 참조. 실제 입력 중 유한 위치·회전 보정을 더하고, 빠른 통과에는 도움을 완화한다. 잡고 멈추면 보정 offset을 유지하며 뒤늦게 강도를 올리지 않는다 |
| 몸통 협응 | 같은 스텝의 공통 목표에서 작성한다. 선호 B의 작은 raw→filtered 선행 원리는 유지하고, 무기별 회전·숙임·높낮이 준비를 연결한다. 다른 무기에 B의 동일 효과를 선행 선언하지 않는다 |
| 이어 베기 | 기존 level 비례 목표 연장과 물리 관성을 구분한다. 이번 공통 후보는 옛 추가 follow를 끄고 실제 입력 흐름과 물리적 이어짐을 사용한다. 체감·강타 보존은 별도 판정한다 |
| 자동 내딛기 | 보정 level에 묶인 일반 베기 전진을 추가하지 않는다. 명시적 탭과 기존 짧은 무기의 받아내며 들어가기 계약은 유지한다. 발 제어를 새 자세표로 덮지 않는다 |
| 놓은 뒤 복귀 | 실제 입력과 분리한 목표 이동으로 무기별 준비에 돌아간다. 잡기/재입력/특수 명령/불가용 상태에서 자동 이동을 중단한다 |
| 찌르기·마무리 | 직전 목표를 연속 인계하며 명령이 최종 손·칼·몸 목표를 맡는다. 근접 거리 접기·누르기는 그 뒤의 기존 기하 제약으로 유지한다 |
| 부상·기립·낙검 | 실제 근육 제한을 유지하고 자동 준비의 가용성을 줄인다. 양보할 때 기존 큰 준비 offset을 즉시 삭제하지 않는다. 재시작은 새 상태를 생성한다 |

## 구현과 첫 설계값

`src/swordsmanship.js`의 실제 입력 갱신→한 스텝 공통 목표→몸/검 읽기로 연결한다. 기존 v1·motionAssist·swordAssist v2가 같은 플레이어 목표를 중복 작성하지 않는다. [무기 프로파일 근거](swordsmanship_profiles_sources_20261005.md)의 질량·관성·파지·용도를 사용한다. 기존 실패 heavy/cover/flow 라이브러리를 켜지 않는다.

처음 시험할 느린 이동의 참조 혼합은 깊이 .65/높이·옆 .40/방향 .65, 빠른 이동은 .40/.18/.25다. 보정 변화율 제한과 입력 평면 변위의 최소 .65 투영 보존을 별도로 둔다. 위치32cm·회전60도는 원하는 일반 보정의 설계 예산이며, 초기 준비 offset·입력 보존 처리·홈 참조까지 포함한 누적 상태의 절대 한도는 아니다. 최종 목표와 누적 보정은 따로 계측한다. 이 값은 일반 메뉴의 강도가 아니며 인간에게서 산출한 최적값도 아니다. 목표 속도·회전 제한을 실제 손/검의 속도 제한으로 표현하지 않는다. 잡고 멈춘 동안에는 추가 보정을 키우지 않고, 원래 입력 필터와 물리적 관성은 계속 작동한다.

청강검의 겸용 베기 참조는 옛 찌르기 표와 방향이 크게 다르므로 단순 분류 정정으로 취급하지 않는다. 첫 준비와 탭의 인계를 보존하면서 높은/옆 준비→다음 베기를 검사한다. 양손 기본은 기존 자세표를 출발점으로 하며 실패한 앞무게 자세 교체를 재도입하지 않는다.

## 검증·전달 관문

1. 청강검은 직전 공개 v2, 롱소드는 일반 v1(.7)을 각각 기준으로 같은 입력의 후보를 검사한다. 두 무기의 기준 정책이 다름을 기록한다. 청강검의 기존 접촉 형상·찌르기 운반·갑옷 마무리는 양쪽 동일하다.
2. 첫 실제 4행에서 목적 효과와 방향/변위 보존, 정지·복귀·재입력, 탭 인계, 원래 질량/근육 설정, 실제 움직임과 관성을 확인한다. 낮은 오차·무사망만으로 개선을 판정하지 않는다.
3. 통과 뒤 일반15종+내부 시험1종의 짧은 기본 동작, 필요한 대표 접촉·실제 부상·기립·마무리를 검사한다. 합성 상태 계약과 실제 노출을 구분하며, 사건이 없으면 미관측으로 남긴다. 같은 사건을 찾는 seed 전수 탐색을 하지 않는다.
4. 회귀·완성 빌드·신뢰된 브라우저 터치/재시작·공개 바이트 확인 뒤 `?swordsmanshipTrial=unified&weapon=...`의 단일 시험판을 제공한다. 권총은 기존 사격 경로를 쓴다. 일반 저장 설정은 보존하고 시험판에서는 강도 메뉴를 숨긴다.

이후 다른 기능의 사용자 A/B는 같은 보정 정책을 양쪽에 적용한다. 기존 물리 오류/입력 계약 증거를 보존하고, 목표 경로가 바뀐 체감·상호작용만 다시 검사한다. 구현·시험·실제 공개 상태는 후속 실험 기록/전달 영수증에 따로 남긴다. 이 설계 문서의 작성은 검증 또는 일반판 적용 완료가 아니다.
