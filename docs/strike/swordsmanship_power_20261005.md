# 베기 속도·힘 보존과 검술 보정 일반 적용 판단

준비 자세를 돕는 보정이 베는 방향의 손 목표 이동을 최대35% 상쇄하고 있었다. **빠른 베기로 인식된 동안 입력 방향의 평면 목표 이동을100% 이상 보존**하도록 작은 계수를 바꿨다. 느린 준비의65% 정책과 기존 힘 한도·물리 엔진은 유지한다. 실제 칼 속도나 피해를100% 보장하는 설정은 아니다.

[소스·실행·원자료 지도](swordsmanship_power_20261005.json)에108실행/30,432step을 기록했다. 일반 근접14종+내부1종×3방향의45쌍과 청강검 일반 물리 문맥3쌍을 비교했다. 각 쌍은 생성·물리 준비 이력·선택 제어 경계·입력이 같다. 첫6쌍의 전체 제어 해시는 렌더 UUID가 섞여 사용할 수 없으며, 원래 실패 결과와 원인 진단을 보존했다. 이후42쌍은 수정된 전체 제어 준비 이력도 일치한다.

| 주요 판독 | 결과와 판단 |
|---|---|
| 청강검·롱소드6조건 | 최고 검 강체 에너지 모두 증가. 칼끝 최고속도는−0.52~+5.69%로 작은 감소도 남음 |
| 레이피어 가로 | 공격 중 속도·에너지 증가, 이후 잔여 운동 감소. 사용자는 이 감속을 타당하다고 판단 |
| 고무닭 수직 | 순간 최고속도−17.34%, 최고 에너지−20.90%. 기존 peak는3.20→9.91→4.49m/s의 단일step 변화. 사용자는 이를 보존할 강타가 아닌 버그성 peak로 판단 |
| 모노호시자오·라이트세이버 | 기존 심한 축 회전이 지속되어 일반 승격 보류 |

고무닭 최대50ms평균은 속도·에너지가 비슷하거나 증가했으나, 이는 사후 시간 분포 해석이다. 사전에 정한5% 속도/10% 에너지 감소 검토 기록을 지우지 않았다. 보정을 공격 중 통째로 동결한 진단도 방향별 득실이 섞여 채택하지 않았다.

사용자 판정과 검증을 바탕으로 **공개 근접12종의 검술 보정+수동 팔 정책을 일반 적용하기로 결정**했다. 청강검 형상·찌르기 운반·갑옷 마무리 규칙은 별도 선택형으로 유지한다. 권총은 기존 사격, 모르겐슈테른은 내부 시험 범위다. 추가 일반 청강검3쌍은 감소 검토 조건 없이 통과했으며, 새 일반 진입 배선과 공개 웹 반영은 별도 배포 검증 대상이다.

실제 전투2행에서 접촉·부상·getup을 관찰했지만, 공격 전부터 AI 경로가 갈라졌다. **같은 타점의 피해·전달 에너지 동등성은 미검증**이다. 검 강체 에너지를 타격 피해로 바꾸어 해석하지 않는다. 다음은 결정된 범위의 배포·공개 코드·모바일 진입/플레이/재시작 확인이며, 이 연구 문서만으로 실제 전달 완료를 선언하지 않는다.
