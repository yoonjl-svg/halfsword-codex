# 통합 검술 보정의 무기 참조 · 2026-10-05

`src/swordsmanship_profiles.js`, version `20261005-r1`. 한 번의 공통 보정 안에서 무기별 준비·자세 참조를 고른다. 이 문서는 설계 근거이며 실제 게임 검증·배포의 완료 기록은 아니다. 자세 좌표와 보정 배율은 게임 설계값으로, 인체 실측이나 역사적 최적값이 아니다.

## 계승 범위와 구분

| 무기군 | 현재 로스터 | 자세 참조 | 몸통 배율 / 복귀 배율 |
|---|---|---|---|

| 사격 | 리볼버 | 검술 참조 비활성 | 0 / 0 |

후속 실제 선별에서 모노호시자오·라이트세이버의 심한 축 회전이 기준/후보 양쪽에 남아 새 공개 선택에서 보류했다. 아래 프로파일 정의의 존재는 공개 수락이 아니다. [실제 결과](swordsmanship_20261005.md)를 따른다.

일반 15종과 시험 1종을 포함한다. `classifyWeapon()`의 현재 분류와 `buildParts()` 질량 분포를 읽는다. 길이·질량·손 기준 COM·관성 I는 프로파일에 기록하며 몸이나 무기 물리를 바꾸지 않는다. 예를 들어 I는 청강검 .11356, 레이피어 .07915, 세이버 .17900, 롱소드 .27242, 츠바이핸더 .76674, 모르겐슈테른 .43605 kg·m²다. 이들은 게임 모델의 계산값이다.

한손 앞무게 구분에는 기존 기준 I≥.3 kg·m²와 COM≥.33m를 함께 사용한다. 모르겐슈테른의 큰 부하에 복귀 목표를 천천히 보내는 설계이며, 부족한 실제 근력을 강화하는 장치가 아니다. 몸통 배율도 공통 보정 목표의 상대 배율이다. `.7`을 사람 힘의 70%라고 읽지 않는다.

한손 기본 준비는 교정된 현재 시작 손 위치·수평 칼 방향을 유지한다. 양손은 기존 `SKILL.homeGuard` 위치에서 기존 양손 표를 읽어 복귀 참조로 삼는다. 시작 몸체를 직접 움직이거나 모든 상황에서 그 자세를 강제하는 의미는 아니다.

청강검은 현재 베기·찌르기 겸용임에도 레이피어와 같은 전방 위주 표를 쓰던 경로에서 분리한다. 베기 표의 옆·어깨 방향은 기존과 크게 다르므로 **단순 분류 수정이 아니라 자세 목표 변경**이다. 이를 청강검 역사 유파의 복원으로 부르지 않는다. 처음의 수평 준비와 명시적 찌르기 목표는 별개로 유지해야 한다.

## 근거와 적용 한계

이번 담당은 아래 **기존에 보존한 원문·번역의 해당 문단을 직접 재열람**했다. 새로운 웹 조회, 영인본·전체 책 검토, 전임자의 읽기를 이번 읽기로 대체하는 주장은 없다. 출처 영수증과 원자료 해시는 [앞선 검술 연구](sword_assist_v2_20261005.json)에 연결되어 있다.

- Burton, *A New System of Sword Exercise for Infantry* (1876), [Stand on Guard / Engaging Guards / Guards](https://www.gutenberg.org/cache/epub/59336/pg59336.txt): 기본 교전의 편하게 굽힌 팔꿈치와 별도 높고 낮은 방어 자세를 구별한다. 모든 한손 무기의 같은 자세를 규정하는 근거가 아니다.
- Meyer (1570), Rebecca L. R. Garber 번역·병렬 독일어, [Ⅰ.5r.7 및 Ⅰ.9v.1–3](https://sprechfenster.org/meyer/1570/longsword-chapter-3-the-guards/#9v-1): 준비에 전신과 검이 함께 참여하고, 베기는 여러 자세를 지나 다음 자세로 이어진다. 따라서 멈춰 준비하는 참조와 움직이며 통과하는 제어를 구분한다.
- Meyer Dusack, [Ⅱ.4v.1–2](https://sprechfenster.org/meyer/1570/dusack-chapter-3-the-four-cuts/#4v-1): 반베기·중간 정지에서 방어로 전환하는 설명. 놓거나 멈춘 입력을 자동 추가 공격으로 바꾸는 근거가 아니다.
- [과거 무기 모션 §5-2](../weapon_motions.md): 정지 방어 가드를 베기 경유점에 넣어 경로를 바꾼 실패, 앞무게 자세의 정지 추종 개선과 전투 후퇴, 둔기 날 세우기 제거 실패를 보존한다. 옛 승률은 인간 자연스러움의 증명이 아니다. `motion_library`의 heavy·cover·flow·런지 묶음은 불러오지 않는다.

프로파일 표는 준비·저속 참조다. 통과 중 강도 조절, 목표의 연속성, 입력 우선, 피격·찌르기·마무리 양보는 공통 컨트롤러의 책임이다. 특히 `guardAt`의 거의 반대 방향 평균→nearest 대체 경계를 큰 보정으로 그대로 증폭하면 안 된다. 청강검 옆/높은 자세 유지→다시 베기, 찌르기 종료, 양손 앞무게의 기존 불안정 경계는 실제 게임 검사로 판정한다. 수치·분류 검사만으로 이 판정을 대신하지 않는다.
