# 두 유보 무기 검술보정 v2 판정 · 10/08

사용자가 수정된 기반에서 v2 비교를 진행하도록 지시했다. **모노호시자오는 일반판 적용, 라이트세이버는 현재 보정을 유지하고 v2 비교판만 공개**한다. 라이트세이버의 재베기 속도·에너지 감소가 확인돼 두 무기를 일괄 통과로 처리하지 않는다. 실제 공개 여부는 [전달 기록](thin_v2_release.json)을 따른다.

## 비교 조건과 결과

기준 `531cfa131271bc386c85582fffd8d5393c79ede6`. 현재 축상 그립·양쪽 보조팔 linked·회복 fresh·재베기 bounded·중심선 절삭·마무리2.5배·팔다리 절단·중력9.81을 고정했다. 기존 보정0.7과 생성부터 설치한 v2를 비교한다. v2는 기존 목표 생성과 중복되지 않도록 옛 level/autoGuard를 끄고 자체 자세·복귀를 사용한다. 새 근력·속도·피해 가중치와 새 검술 표를 만들지 않았다.

- **비접촉8실행·6,912step:** 두 무기 × 기존/v2 × 건강/보조팔 기능0.2 준비. 같은 생성·요청 입력으로 올림→첫 베기→반전→재베기→놓기2초를 실행했다. 부상은 tick300의 통제 준비이며 자연 피격 빈도 실험이 아니다. 모두 유한·생존·무장 상태를 유지했다. v2는 네 조건 모두 `ready`로 돌아왔고 시작 급회전이 재발하지 않았다.
- **채택 접촉4실행·4,098step:** 서 있는 idle 상대에게 같은 접근·베기·반전·재베기 입력을 재생했다. 생성/입력이 일치하고 실제 접촉·절상이 발생했다. 움직임이 이미 달라졌으므로 서로 다른 첫 접촉을 동일 타점의 피해 비교라고 하지 않는다.
- 앞선 접촉4실행·4,098step은 상대에게도 fresh/bounded를 설치한 준비 오류 때문에 제외했다. 원자료를 보존하고 일반판과 같은 플레이어 전용 설정으로 정정했다. **실행 총16회·15,108step, 판정에 쓴 실행12회·11,010step**을 구별한다.

건강 조건의 능동 입력 구간에서, 50ms 이동평균의 최고치를 비교했다. 아래 에너지는 검 강체의 운동에너지이며 접촉 피해가 아니다.

|---|---:|---:|

모노호시자오 재베기의 칼끝 속도는1.6% 낮았지만 날 속도는1.1%, 운동에너지는10.4% 높았다. 접촉 실행의 능동 베기 세 구간 칼끝 최고 속도도9.07/10.44/7.23→11.82/11.94/9.74m/s였다. 이들은 **각 구간 전체 최대치이며 실제 접촉점 속도가 아니다.** v2에서 첫 베기 직후 골반50.12J·허벅지48.68J, 재베기 직후 머리55.33J의 실제 절삭을 확인했다. 입력 직후 관성으로 이어진 명중도 유효한 공격으로 센다. 모든 방향·타점·팔 부상의 위력이 늘었다는 보장은 하지 않는다.

라이트세이버는 재베기 칼끝 속도41.8%, 운동에너지42.5% 감소를 확인했다. 기존 최고점은 실제 횡방향 휘두름을 포함하므로 단순 축 회전 제거로 설명할 수 없다. v2의 목표 추종과 회수는 좋아졌지만, 접촉 실행에서도 일부 베기 구간 속도가 낮아졌다. 기존 재베기 뒤 가슴 타격105.84J와 v2 능동 재베기42.98J는 서로 다른 시점·상태의 타격이어서 피해 감소율로 직접 나누지 않는다. v2에서도 실제 절상이 났다는 사실만으로 위력 유지 판정을 내리지 않는다.

놓은 뒤 건강 v2의 마지막250ms 평균 각속도는 모노0.0251, 라이트0.000879rad/s였다. 접촉 뒤 축 회전 최고는 모노117.46→57.09, 라이트59.20→33.48rad/s였다. 낮은 회전 최고치 자체가 인간 동작의 자연스러움이나 위력 개선 증명은 아니다. 보조팔 부상 뒤도 건강할 때와 같은 속도여야 한다는 요구는 하지 않는다.

## 적용·플레이 안내

- [모노호시자오 일반판 v2](https://yoonjl-svg.github.io/halfsword-codex/?weapon=monohoshizao): 일반 지원 근접 무기13종. 기존 `heavy:cut` 프로필·복귀 배율0.75를 사용한다. 새 노다치 전용 고증 동작을 만든 결과가 아니다.
- 라이트세이버 [A · 현재 보정](https://yoonjl-svg.github.io/halfsword-codex/?weapon=lightsaber) / [B · v2](https://yoonjl-svg.github.io/halfsword-codex/?weapon=lightsaber&swordsmanshipPreview=v2): 같은 일반 물리·피해·보조팔 정책 위에서 플레이어 보정만 비교한다. B는 기존 `two:versatile` 프로필이다. 빠르게 두 번 베었을 때 후속타의 힘과 자세/복귀 개선을 함께 확인한다. B의 일반 승격은 이 절충의 사용자 체감 확인이 남는다.
- `swordsmanship=legacy`는 회복·마무리 등 여러 일반 정책까지 빠지는 옛 호환 주소라 이 비교의 A로 사용하지 않는다. 옛 `swordsmanshipTrial`의 무기 목록은 그대로 보존하며 시험실에 현재 링크를 구별해 표시한다. 새 선택은 저장하지 않는다.

독립 검토도 모노 일반 적용·라이트 비교 공개를 권고했다. 라이트는 이미 목표를 잘 따라가므로 단순 힘 가중치만 더할 근거가 부족하다. 이번 문제를 피하려고 전체 v2 공식을 바꾸거나 다른 무기 힘까지 키우지 않는다.
