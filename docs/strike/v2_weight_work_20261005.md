**현재 보정에서도 내려베기에 중력이 기여한다.** 그러나 나머지를 몸통 기여로 빼서 계산할 수는 없다. 직접 토크 일은 호출 순간 속도의 근사 적분이며 손의 힘·구속·native 모터·감쇠 등을 포함하지 않는다. 서로 다른 무기의 자세·제어도 달라 질량만의 효과나 체감 우위를 뜻하지 않는다. 충돌 없는 기록이므로 전달 피해 증거도 아니다.

**새 물리0회·게임 변경0.** 원자료에는 올려베기와 버티기의 상세 제어 일, 몸통 반작용의 완전한 기록이 없어 그 부분만 다음에 측정한다. 무기2종×올림/버팀4행 이내에서 v2의 실제 입력 이벤트와 명시적 어깨·팔꿈치·손목의 일/반작용을 읽는다. 기존 중력 보상 제거·가슴 추종 실패를 반복하지 않는다. P1 체감·P3 전신 전달 완료는 아니다. [수치·SHA·명령·소스 연결](v2_weight_work_20261005.json).
