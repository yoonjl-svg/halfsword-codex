## 설정에서 바꿔 보실 것 (두 스위치, 주소로도)
- **칼 든 손 (시험)** 몸통만 (기본, trunkOnly) / 큰 감기 — `?hand=trunk|wind`. 몸통만 = 몸통·다리·걸음은 클립대로, 칼 든 손은 R1 팔 베기 그대로 (손은 클립을 쫓지 않음). 큰 감기 = 감는 동안 손도 클립의 큰 감기 자세를 쫓고 베기부터는 손가락. 싸움을 새로 열 때 적용됩니다.
- **베기 입력 (시험)** (A) 감기 / (B) 긋기 — `?input=wind|stroke`. (A) 손가락을 준비 자리로 끌어 감고 되돌려 벱니다. (B) 긋기 길이·빠르기만 보고 몸이 짧게 스스로 감습니다.
- 주소로 고른 값은 처음에는 저장되지 않지만, 설정 줄을 하나라도 누르면 저장되어 주소 없이 열어도 남습니다. 설정 화면의 두 줄로 지금 값을 확인해 주세요.
- 금빛 자취 + 짧은 진동: "몸이 클립에 실렸다" (베기의 첫 c(S) = 1 스텝) 는 뜻입니다. "멈출 수 없다" 가 아닙니다.
