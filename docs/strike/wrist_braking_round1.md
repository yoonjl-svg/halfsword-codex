# 검 거두기 예측 1차 · 공개 보류

2026-10-03 UTC / 10-04 KST. 기준 `b23f732` → 구현 `cd0eabc` → 물리·도구 소스 `63be055`. 목적은 힘을 실은 베기를 유지하면서, 급히 검을 거둘 때 몸과 검이 부담을 나누는 느낌을 개선하는 것이다. 짧게 멈추거나 오차가 작아지는 것을 사실감 점수로 삼지 않았다.

**판정:** 후보는 연구로 보존하며 공개하지 않는다. 강한 내려베기는 보존했지만, 거두기의 차이가 작고 방향 오차가 증가했다. 실제 화면에서 설득력 있는 회복 빈틈 개선을 확정하지 못했다. 일반 물리 승격·사용자 추가 테스트 요청 없음. 직접 `wristBraking=available` 주소도 현재 방식과 보류 안내로 실행한다.

## 작은 변경과 한계

기존 정지거리 계산의 `기본 cap × eccentric` 대신 **같은 호출의 기존 전체 감쇠 요청이 낼 순 반대 토크**를 선택형으로 예측했다. 위치 요구·목표 각속도·중력 보상을 합친 뒤 원래 Hill 곡선/30ms 필터/근력 cap을 적용한다. 외부 중력은 같은 손 피벗에서 cap 밖에 한 번 더한다. 예측은 실제 Hill 상태·목표·latch·native 토크를 변경하지 않는다. 실제 제어 경로는 기존 요청/clip/반작용을 그대로 한 번 실행한다. 반대 성분이 없으면 원래 판단으로 복귀하며 0 제동력이나 무한 정지거리로 강제 latch하지 않는다. sharedCap 조합은 적용하지 않는다.

고정 손·스칼라 관성·순간 일정 토크의 근사다. 팔의 가속·native 모터·두손·접촉을 포함한 전신 근력 또는 인간 최대 제동력으로 부르지 않는다. 특히 큰 정지각은 보정된 현실 거리의 증거가 아니다.

## 게임 목적에 대한 결과

내려베기 최대 tip 속도는 sabre12.95993 / zwei11.05595m/s로 exact였다. 내려베기 뒤 고정과 **반전 명령 중** native도 exact다. 변화는 반전 명령이 끝난 뒤 hold에서 시작했고 전체 afterstroke 축 이동은 .52%/1.13% 감소했다. 이후 hold 평균 방향 오차는 .129→.171 / .774→.797rad로 증가했다.
