# 무기 층 — 온몸 타격이 무기마다 읽을 값 (초안, 무기 PM)

디렉터 9/29 지시 3. 온몸 타격 재설계(`docs/whole_body_redesign.md`)의 클립 추적 위에 얹는 **무기별 값**이다. 동작 라이브러리(`src/motion_library.js`)를 온몸 타격의 '무기 층'으로 합치는 자리(역할 분담안 4번 기본값).
- 코드: `src/weapon_class.js` 의 `WEAPON_LAYER`(표) · `weaponLayer(spec)`(무기 하나의 값). **칸과 첫 값만** 있고 게임은 읽지 않는다. 배선은 디렉터 R2.
- 표시: **[재설계]** 재설계 문서의 첫 값 · **[측정]** 무기 PM 도구로 잰 값 · **[제안]** 근거는 있으나 시험 전 · **[원전 2차]** 연구 ASS 조사.
- 확인: `node -e "Promise.all([import('./src/weapons.js'),import('./src/weapon_class.js')]).then(([m,c])=>m.WEAPON_LIST.forEach(w=>console.log(w.id, JSON.stringify(c.weaponLayer(w)))))"`

## 2. T0 — 관성으로 나머지를 정한다
재설계의 첫 값 셋(롱소드 0.30 · 츠바이핸더 0.38 · 세이버 0.24 s) [재설계 §2-4]을 **한 식으로** 맞추고 나머지 무기에 쓴다.

T0 = T0기준 × √((I + K) / (I기준 + K))
- I: 손 기준 칼 관성(`weaponPhysics().I`, kg·m²) [측정]. K = 0.547: 칼과 함께 도는 팔·몸 관성 몫 — 츠바이핸더 0.38 이 맞게 푼 값(같은 힘이면 시간 ∝ √관성).
- 기준: 두손(A·B·E) = 롱소드 0.30 (I 0.272), 한손(C) = 세이버 0.24 (I 0.179). 한손 클립은 몸통 몫이 작아 따로 둔다 [재설계 §2-2].
- 칼만의 √I(K = 0)로는 츠바이핸더가 0.50 이 나와 맞지 않는다 — 몸이 함께 돌아 무거운 칼의 차이가 줄어든다.

| 무기 | 몸 틀 | I | T0 | | 무기 | 몸 틀 | I | T0 |
|---|---|---|---|---|---|---|---|---|
| 롱소드 | A | 0.272 | **0.30** | | 세이버 | C | 0.179 | **0.24** |
| 츠바이핸더 | B | 0.767 | **0.38** | | 레이피어 | C | 0.079 | 0.22 |
| 에스톡 | A | 0.363 | 0.32 | | 팔쉬온 | C | 0.137 | 0.23 |
| 모노호시자오 | B | 0.328 | 0.31 | | 청강검 | C | 0.114 | 0.23 |
| 엑스칼리버·복제품 | A | 0.209 | 0.29 | | 나뭇가지 | C | 0.101 | 0.23 |
| 라이트세이버 | A | 0.058 | 0.26 | | 고무 닭 | C | 0.011 | 0.21 |
| 냉동 참치 | B | 0.363 | 0.32 | | 봉·창 시제품 | E | 0.86~1.03 | 0.39~0.42 |

- 사장님 답(9/29, Q26): **무기별 온몸 배율 목표는 두지 않는다** — 무기 관성과 몸 몫이 결과를 정한다. 그래서 이 층에는 "배율 목표" 칸이 없다. R2 시험판에서는 T0 가 사람다운지만 본다(손이 클립을 따라가나, 추적 오차).
- 동작 연구 PM `docs/motion/weapon_body.md` §1 과 맞다: 세이버 T0 비 0.80 ≈ √I 비 0.81(같은 힘), 츠바이핸더 1.27 < √I 1.68 — 칼만으로는 1.7배 돌림힘이 필요한데, 이 식은 그 몫을 몸이 함께 도는 관성(K)으로 푼 것이다. (그 표의 라이트세이버 '한손'은 main 기준이다 — 무기 PM 브랜치는 두 손, 병합 목록 4절)
- 가벼운 무기(라이트세이버·고무 닭)가 T0 가 너무 짧아 손목이 못 따라가면 T0 아래 한도가 필요할 수 있다 — **제한이므로 사장님께 제안만**.

## 3. 감기·지나가기 배율과 몸통 몫 [제안]
| 몸 틀 | windMul | followMul | trunkShare | 근거 |
|---|---|---|---|---|
| A 양손 보통 | 1.0 | 1.0 | 0.4 | 재설계 롱소드 기준(감기 0.25 · 지나가기 0.30 s, trunkCarry 0.4) |
| B 양손 앞무게 | 1.25 | 1.25 | 0.5 | 재설계 "츠바이핸더는 같은 클립, 감기·지나가기가 더 길고 몸통 몫이 더 크다". 1.25 ≈ T0 비 0.38/0.30. 몬탄테 물레(멈추지 않고 이어 벰) [원전 2차] — [측정] 흐름 켜면 츠바이핸더 28 → 36% |
| C 한손 | 0.85 | 0.85 | 0.25 | 재설계 "세이버는 몸통 몫이 작다", 0.85 ≈ 0.24/0.30 보다 조금 느슨하게(손목·팔꿈치 원운동이 시간을 먹는다) |
| E 자루 | 1.0 | 0.8 | 0.4 | 찌르기가 주, 되돌리기가 빠르다(연구 ASS `pole_thrust_kinematics.md`: 지렛대 되돌리기 0.10~0.15 s) — R2 대상 아님 |
- **연구 ASS R6 조사 반영** (`claude/pm-weapons` `docs/r6_body_contribution.md` 4548145, 모두 "참고, 한도 아님"):
  - 한손 베기 칼끝 속도 중 몸통 회전 약 20~30%, 걸음 13~20% [해석] → C `trunkShare` 0.25 는 그 안이라 그대로 둔다(근거 [제안] → [해석]). moulinet 은 팔꿈치 축이라 몸통·걸음 몫 10% 안팎 [추정] → moulinet 무리는 `trunkShare` 0.1 을 따로 주는 안.
  - 대검 "걸음마다 베기 하나" 0.6~0.9 s [해석, 몬탄테 규칙 10 해설] ↔ 롱소드 Zornhau 클립 합(감기 0.25 + 풀기~닿기 0.22 + 지나가기 0.30 = 0.77 s)의 0.8~1.2배 → B `windMul`·`followMul` 1.25 는 위쪽 끝이다. R2 시험판에서 1.0~1.25 사이를 잰다.
  - 레이피어 런지: 칼끝 전진 중 몸 전진 몫 55~70% [해석], 손이 발보다 0.07 s 먼저(엘리트) [1차 요약] → 찌르기 방식은 걸음 몫이 큰 쪽(런지 덧씌우기가 레이피어에서만 이긴 측정과 같다, `weapon_motions.md` 규칙 6).
- 조사 전 원래 적은 것: 연구 ASS 에 R6 조사로 넣은 것(디렉터 지시 5-(3)): 세이버 moulinet·레이피어 큰 공격의 몸통·걸음 기여 문헌값, 츠바이핸더/몬탄테 큰 베기의 감기·지나가기 시간 → 오면 이 표를 [원전 2차] 값으로 바꾼다.

## 4. 동작 라이브러리에서 무기 층으로 옮기는 것 / 버리는 것
| 라이브러리 것 | 무기 층에서 | 비고 |
|---|---|---|
| 몸 틀별 자세표(`FRAME_GUARDS`·`POLE_GUARDS`) | `stanceTable` (S = 0 자세) | 규칙 1: 자세 자리는 베기 길의 경유점 — 온몸 클립의 감기 끝 자세(φw)와 겹치는 자리(지붕·황소·어깨)는 클립이 이긴다 |
| 방식별 기술 목록(`styleTech`) | `families`·`thrustFirst` + AI 가중 | 몰리넬로는 AI 금지 그대로(한 판 70~99번 골라 짐) |
