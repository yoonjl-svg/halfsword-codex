현재: 이 기기 저장만 사용 가능
실제 계정 서버를 아직 연결하지 않았습니다. 이메일 인증·다른 기기 복원은 연결 후 열립니다. 이 화면은 가입 완료를 의미하지 않습니다.
게임에서 이름·설정 저장 확인

게임 설정 화면의 내 정보를 열어 이름을 적어보세요. 저장한 뒤 페이지를 새로 열어도 이름과 설정을 기억합니다. 일반판의 기존 설정과 분리된 준비판입니다.

서버 연결 후의 사용 방식

  1. 게임에 들어오면 자동으로 게스트 계정을 만듭니다. 회원가입 화면·비밀번호는 없습니다.
  2. 이름은 선택 사항입니다. 그대로 싸움을 시작해도 됩니다.
  3. 기록을 지키고 싶을 때만 이메일로 계정 보관에서 인증번호를 한 번 입력합니다.
  4. 새 기기에서는 같은 이메일로 계정을 불러옵니다.

이메일을 연결하지 않은 게스트는 앱·브라우저 데이터가 지워지면 복구할 수 없습니다. 홈 화면 앱과 브라우저가 서로 다른 저장 공간을 쓰는 경우에도 이메일로 복원합니다.
