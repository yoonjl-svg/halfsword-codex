현재 최우선 · 10/05: 공통 검술 보정 설계. 사용자는 초기 보정의 다종 무기/현재 물리 적합성, 단계 단순화, 최종 보정과 동일한 플레이 평가 기반을 요구했다. 청강검의 작은 v2 후보를 전체 갱신으로 취급하지 않는다. 단일 기본 보정의 목표 작성자를 통합하고 청강검·롱소드 4행→무기별 기본 동작→필요한 접촉/명령 인계→공개 시험판 순으로 진행한다. 일반판 승격은 결과 확인 후 별도다. 아래 이전 v2 전달은 보존된 역사이며 현재 개발 완료를 뜻하지 않는다.

현재 실행: 무기별 단일 기본 보정 구현과 독립 검토를 마쳤으며, 첫 입력·실제 드래그 뒤 홈 복귀 결함을 수정했다. 실제 게임 26행·25,272스텝을 검사했다. 모노호시자오·라이트세이버의 심한 회전은 기준/후보 양쪽에 남아 새 선택에서 보류했다. 전달 영수증의 공개8파일·모바일12흐름/오류0 확인까지 완료했다. 시작 시 전체 구현·검증·전달 예상은 4–6 작업시간이었다. 실제 물리 실행26행85.47초·공통 회귀183.77초·공개 브라우저약6분은 각 도구 실행 시간이며 전체 설계/검토 시간을 대체하지 않는다.

폰에서 단일 통합 시험판을 연다. 청강검·롱소드에서 천천히 자세 잡기 → 손을 대고 유지 → 놓아 복귀 → 다시 베기를 확인한다. 선택13종 중 근접12종에 공통 보정, 리볼버는 기존 사격이다. 모노호시자오·라이트세이버는 미해결 회전 때문에 보류한다.

다음 실행: 같은 보정 정책을 후속 비교의 양쪽에 고정한다. 심한 실제 주팔 부상/마무리 인계는 미관측으로 남아 있으며, 사용자 자세 도움/자유도 체감과 함께 일반 승격 전 확인한다. 미관측 사건을 찾는 seed 전수 탐색이나 실패 후보 재활성화는 하지 않는다.

직전 청강검 v2는 전달한 역사이며 이번 다종 무기 갱신의 완료가 아니다. 새 공통 보정을 고정하기 전에는 다른 기능의 사용자 체감 A/B를 늘리지 않는다. 기존 물리 결함·입력 계약 증거를 보존하고, 보정에 영향을 받는 체감과 접촉만 다시 확인한다.

비용과 실험 규칙

  1. 30–45분에 첫 판정, 90분에 계속/기각 결정. 한 회차는 질문1개·변경1개. 실패한 스칼라 제동 예측/gain·관절 교체·projected 지지·budgeted 절삭을 다시 권하지 않는다.
  2. 첫 선별은 무기2종×기준/후보 4실행부터 시작한다. 개입/소스/입력 동등성은 기존 계측으로 확인한다. 긍정 효과 뒤에만 중단·재입력·알려진 부상/접촉 반례로 넓힌다. 실제 안전/동등성 의문이 있으면 필요한 검사를 추가한다.
  3. 기존 원자료·교정·실패 trace·검증된 기준선을 재사용한다. 바뀐 소스/엔진/입력 계약만 다시 검사한다. 관찰 off는 새 계측의 비간섭 검증에 사용하고 변하지 않은 계측에 습관적으로 반복하지 않는다. 동일 궤적 반복을 새 독립 표본으로 세지 않는다.
