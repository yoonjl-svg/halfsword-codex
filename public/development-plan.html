비용과 실험 규칙

  1. 30–45분에 첫 판정, 90분에 계속/기각 결정. 한 회차는 질문1개·변경1개. 실패한 스칼라 제동 예측/gain·관절 교체·projected 지지·budgeted 절삭을 다시 권하지 않는다.
  2. 첫 선별은 무기2종×기준/후보 4실행부터 시작한다. 개입/소스/입력 동등성은 기존 계측으로 확인한다. 긍정 효과 뒤에만 중단·재입력·알려진 부상/접촉 반례로 넓힌다. 실제 안전/동등성 의문이 있으면 필요한 검사를 추가한다.
  3. 기존 원자료·교정·실패 trace·검증된 기준선을 재사용한다. 바뀐 소스/엔진/입력 계약만 다시 검사한다. 관찰 off는 새 계측의 비간섭 검증에 사용하고 변하지 않은 계측에 습관적으로 반복하지 않는다. 동일 궤적 반복을 새 독립 표본으로 세지 않는다.
  4. 무거운 헤드리스와 화면 녹화를 동시에 돌려 제한 시간을 넘기지 않는다. 공통 소스는 배치 중 고정하고 통합은 순차 처리한다. 브라우저는 목적 효과가 남은 후보의 입력/화면을 보완한다. 문서 변경에 물리 회귀를 반복하지 않는다.
  5. 실험일지 계약에 따라 짧은 요약1개 + 수치/해시 JSON + 저장소 밖 원자료를 남긴다. 실험 색인에서 찾는다. 계획·일일 노트에는 결론과 링크만 넣는다.
  6. 실제 개발 시간과 첫 플레이판까지의 시간을 기록한다. 실행 수를 성과 점수로 쓰지 않는다. 2배 이상 압축은 목표이며 실제 배수는 같은 범위의 측정 뒤에만 보고한다.

다음 승인 작업 · 재개 위치

현재 R0: 선택형 일지와 폰 A/B의 세이버·청강검·레이피어를 실제 공개 전달했다. 손 조작을 자세표가 완전히 덮어쓰던 경로와 raw 최대도달 포화를 분리했고 swivel2종은 후퇴로 제외했다. 후속 두 AI 실제 접촉6회에서 청강검 후보의 기립 복귀를 관찰했다. 팔/다리 절상은 그 뒤 발생했으므로 부상 후 복귀 근거로 묶지 않는다. down/마무리는 미관측이다. 레이피어 추종, 실제 마무리, 인간 부상 후 조작·화면 수락은 일반 승격 전 관문이다. 다음은 사용자 A/B의 팔/칼 방향·조작감 판정과 해당 반례를 좁게 처리한다. 미관측 마무리를 찾는 seed 전수 탐색과 실패 swivel 재시험은 하지 않는다.
