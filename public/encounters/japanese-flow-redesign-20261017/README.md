# 일본 흘림 인간 시험 후보 · 2026-10-17

일반 게임에 채택하기 전, 양 역할로 체감과 손익을 비교하는 별도 시험판입니다. 확정 출시안이나 모든 베기 방향의 개선을 뜻하지 않습니다.

## 비교안

- `base`: 연구 시작판의 기존 흘림 판정·기력 비용·탈진. 현재 배포판 전체가 동일하다는 뜻은 아닙니다.
- `core`: 방향/접촉 판정 확대, 유효 흘림의 공격자 추가 기력40(공격당1회), 자연 탈진(−70 진입→−35 해제, 플레이어21/AI15초당 회복). 팔 제어력 저하 없음.
- `intercept`(기본 선택): core와 같은 비용·탈진에 **실제 가로 위협을 예측한 선제 자세 선택**을 추가한 추천 인간 시험 후보입니다.
- `horizontal`: 앞 단계 가로받기 몸꼴 비교안. 최종 추천안은 아닙니다.

방어자는 일본 검으로 받고 반격, 공격자는 청강검으로 일본 막기를 상대합니다. 보통 대련과 반복 연습을 고를 수 있습니다. 반복 연습의 공격자 역할에서는 상대가 중앙 막기를 유지합니다. 휴대폰은 가로로 이용합니다.

```text
./?role=defender&variant=intercept&practice=1&direction=zwerch
./?role=attacker&variant=intercept&practice=1
./?role=defender&variant=core&practice=0
./?role=defender&variant=base&practice=0
```

## 관측과 비교 한계

앞선 core와 추천안의 가로4조건(씨앗755/756의 좌우 가로, 조건당10.1초)에서 흘림1→4, 사지 손실합0.5661→0.3487, 혈액 손실합0.02335→0.01594였습니다. 의식 충격합은0→0.1114, 막기 비용합은19.90→32.34로 늘었습니다. 작은 새 목/머리 둔타와 가슴 충격도 있어 약30초 인간 전투의 종합 손익을 직접 확인해야 합니다.

**1→4는 일반 게임 base가 아니라 앞선 core 대비입니다.** 같은 노출·씨앗의 base4조건 원자료가 없습니다. 기존755 자료는10초이며756 자료는core이므로 이를 섞어 base 개선율을 만들지 않았습니다. 이 좁은 선택 표본의 합계는 전체 유저 평균·승률·확정 우월성을 뜻하지 않습니다.

대표 오른쪽 가로에서 실제 첫 칼 접점이 약41.7ms 빨라졌습니다. 왼쪽 독립 조건은 변화가 없고, 다리 베기와 실제 공격 종료 판독의 한계는 남습니다. 단순히 흘림 횟수만 높이는 것이 목표가 아닙니다.
