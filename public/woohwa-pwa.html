우화가 가져갈 PWA

우화의 halfsword에 홈 화면 설치와 오프라인 실행을 붙이는 소스 묶음입니다. 게임 전투·캐릭터·무대는 수정하지 않았습니다.

전달 ZIP 다운로드

이 페이지 주소 또는 ZIP을 우화에게 전달하면 됩니다. 플레이 링크가 아니라 개발용 전달 자료입니다.

우화가 할 일

  1. ZIP을 풀고 README를 읽습니다.
  2. 새 작업 브랜치에서 적용 도구의 --check를 실행합니다.
  3. 적용 후 npm run build로 빌드하고 기존 Pages 방식으로 배포합니다.

자동 적용 도구와 Git 패치를 모두 포함했습니다. 기존 파일 충돌 시 덮어쓰지 않고 중단합니다.

사용자가 받는 기능

  • iPhone: Safari 공유 → 홈 화면에 추가.
  • Android: 지원 브라우저의 앱 설치 메뉴.
  • 첫 온라인 저장 완료 뒤 오프라인 플레이.
  • 패치는 온라인에서 준비하고 모든 게임 창을 닫았다 다시 열 때 적용. 전투 도중 강제 재시작하지 않습니다.

확인한 범위

Chromium에서 설치 조건, 모바일 터치, 오프라인 진입·플레이·재시작, 여러 창의 업데이트 대기, 손상된 업데이트 거절과 다른 게임 캐시 보존을 검사했습니다. 기준 빌드 저장량은 약4.8MB입니다.

현재는 전달 묶음 완성 단계입니다. 우화 원본에 아직 적용하거나 배포하지 않았습니다. 실제 iPhone·Android의 홈 화면 설치는 원본 배포 후 기기 확인이 남아 있습니다.
